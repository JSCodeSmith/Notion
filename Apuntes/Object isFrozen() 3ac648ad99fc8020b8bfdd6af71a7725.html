Object.isFrozen()

📄 Título

Object.isFrozen(objeto) en JavaScript

📝 Definición

  • Object.isFrozen() es un método estático del objeto global Object que permite comprobar si un objeto está congelado (frozen).
  • Devuelve un valor booleano:
    • true → si el objeto está congelado.
    • false → si no está congelado.

🧠 ¿Qué es?

  • Es un método estático de Object.
  • Forma parte del lenguaje JavaScript (ECMAScript), no de una Web API.
  • Se utiliza principalmente para verificar objetos que fueron protegidos mediante:
Object.freeze()

Un objeto congelado significa:

✅ Puede ser leído.

❌ No puede agregar propiedades nuevas.

❌ No puede eliminar propiedades existentes.

❌ No puede modificar valores existentes.

🎯 ¿Para qué sirve?

Se utiliza para:

  • Verificar si un objeto está protegido contra cambios.
  • Validar estados inmutables.
  • Crear controles de seguridad en aplicaciones.
  • Detectar si una configuración fue congelada.
  • Realizar pruebas (testing) sobre objetos.

⚙️ ¿Cómo funciona?

  1. Recibe un objeto.
  1. Revisa las características internas del objeto:
    • Si no permite extensiones.
    • Si todas sus propiedades son no modificables (writable: false).
    • Si sus propiedades no pueden eliminarse (configurable: false).
  1. Devuelve:
true

si cumple las condiciones de un objeto congelado.

Ejemplo:

const usuario= {
    nombre:"Ana"
};
Object.freeze(usuario);
Object.isFrozen(usuario);

Proceso:

Objeto normal
      ↓
Object.freeze()
      ↓
Objeto congelado
      ↓
Object.isFrozen()
      ↓
true

Object.isFrozen(objeto);

💡 Ejemplos

Objeto normal

const persona= {
    nombre:"Luis"
};
console.log(Object.isFrozen(persona));

Resultado:

false

Objeto congelado

const usuario= {
    nombre:"Ana",
    edad:20
};
Object.freeze(usuario);
console.log(Object.isFrozen(usuario));

Resultado:

true

Comparación con Object.seal()

const producto= {
    nombre:"Laptop"
};
Object.seal(producto);console.log(Object.isFrozen(producto));

Resultado:

false

¿Por qué?

Porque seal() permite modificar valores:

producto.nombre="PC";

Mientras que freeze() no permite ningún cambio.

Un objeto congelado también está sellado

const config= {
    modo:"oscuro"
};Object.freeze(config);console.log(Object.isSealed(config));

Resultado:

true

Relación:

freeze()
   ↓
seal()
   ↓
preventExtensions()

Arrays congelados

Los arrays también son objetos:

const numeros= [1,2,3];
Object.freeze(numeros);console.log(Object.isFrozen(numeros));

Resultado:

true

⚠️ Errores comunes

❌ Pensar que congela objetos internos

const usuario= {
    perfil: {
        edad:17
    }
};
Object.freeze(usuario);usuario.perfil.edad=18;console.log(usuario.perfil.edad);

Resultado:

18

¿Por qué?

Porque freeze() solo protege el primer nivel.

Es una congelación:

Shallow Freeze ✅

No:

Deep Freeze ❌

❌ Confundir isFrozen() con freeze()

Incorrecto:

Object.isFrozen(usuario);

No congela nada.

Solo pregunta:

"¿Este objeto ya está congelado?"

Para congelar:

Object.freeze(usuario);

❌ Pensar que devuelve una copia

const resultado=Object.isFrozen(usuario);

Resultado:

true

No devuelve el objeto, devuelve un booleano.

❌ Confundirlo con Object.isSealed()

MétodoPregunta
Object.isSealed()¿Está sellado?
Object.isFrozen()¿Está congelado?

Un objeto congelado:

Object.isFrozen(obj)

también es:

Object.isSealed(obj)

💼 Casos de uso

  • Verificar configuraciones protegidas:
if (Object.isFrozen(CONFIG)) {
	console.log("Configuración bloqueada");
}
  • Validar estados inmutables.
  • Pruebas unitarias.
  • Librerías que requieren objetos sin modificaciones.
  • Depuración de aplicaciones grandes.

"¿Esta caja está completamente congelada?"
