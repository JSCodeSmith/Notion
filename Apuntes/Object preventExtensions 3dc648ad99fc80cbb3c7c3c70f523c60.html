Object.preventExtensions()

📄 Título

Object.preventExtensions()

📝 Definición

Object.preventExtensions()

Es un método estático de Object que impide que se agreguen nuevas propiedades a un objeto.

🧠 ¿Qué es?

Es una herramienta para convertir un objeto en no extensible.

El objeto sigue existiendo y sus propiedades actuales pueden continuar siendo modificadas o eliminadas, dependiendo de sus descriptores.

🎯 ¿Para qué sirve?

Sirve para:

  • 🔒 Evitar que se agreguen propiedades accidentalmente.
  • 🛡️ Controlar la estructura de un objeto.
  • 🧩 Crear objetos cuya cantidad de propiedades no pueda aumentar.
  • 🧪 Aplicar restricciones durante validaciones o configuraciones.

⚙️ ¿Cómo funciona?

const usuario= {
    nombre:"Josué",
    edad:17
};
Object.preventExtensions(usuario);

Después:

usuario.email="correo@example.com";

La propiedad email no podrá agregarse.

Pero las propiedades existentes todavía pueden modificarse:

usuario.edad=18;

Y también pueden eliminarse:

deleteusuario.edad;

Por eso:

preventExtensions() bloquea la adición de propiedades, no todas las modificaciones.

📝 Sintaxis / Estructura

Object.preventExtensions(obj)

Parámetro

obj

El objeto que quieres convertir en no extensible.

Retorno

Devuelve el mismo objeto que recibió.

const usuario= {};
const resultado=Object.preventExtensions(usuario);
console.log(resultado===usuario);

Resultado:

true

💡 Ejemplos

1. Impedir nuevas propiedades

const persona= {
    nombre:"Josué"
};
Object.preventExtensions(persona);
persona.edad=17;
console.log(persona);

La propiedad edad no se agrega.

2. Las propiedades existentes sí pueden modificarse

const persona= {
    nombre:"Josué"
};
Object.preventExtensions(persona);
persona.nombre="Juan";
console.log(persona.nombre);

Resultado:

Juan

3. Las propiedades existentes pueden eliminarse

const persona= {
    nombre:"Josué",
    edad:17
};
Object.preventExtensions(persona);
delete persona.edad;
console.log(persona);

Resultado:

{
	nombre:"Josué"
}

4. Comprobar si el objeto es extensible

Puedes utilizar:

Object.isExtensible(persona);

Ejemplo:

const persona= {};
console.log(Object.isExtensible(persona));// true
Object.preventExtensions(persona);
console.log(Object.isExtensible(persona));// false

⚠️ Errores comunes

Confundirlo con Object.seal()

No son lo mismo.

MétodoAgregarModificarEliminar
preventExtensions()❌✅✅
seal()❌✅❌
freeze()❌❌❌

La progresión mental es:

preventExtensions()
        ↓
"No agregues propiedades"

seal()
        ↓
"No agregues ni elimines propiedades"

freeze()
        ↓
"No agregues, elimines ni modifiques propiedades"

Pensar que vuelve al objeto completamente inmutable

Esto:

Object.preventExtensions(obj);

NO significa:

objeto inmutable ❌

Significa:

objeto no extensible ✅

💼 Casos de uso

  • Proteger la estructura de objetos.
  • Evitar propiedades agregadas accidentalmente.
  • Validaciones de objetos.
  • APIs o configuraciones donde la estructura debe permanecer limitada.
  • Programación defensiva.

🧠 Analogía

Imagina un local 🏪.

Object.preventExtensions() coloca un cartel:

🚫 “No se pueden agregar nuevas habitaciones.”

Pero las habitaciones que ya existen todavía pueden:

  • cambiarse 🔧
  • remodelarse 🎨
  • incluso eliminarse 🗑️

Es decir:

estructura nueva → ❌
modificación → ✅
eliminación → ✅
