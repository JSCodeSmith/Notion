Uint8Array.from

Uint8Array.from()

📄 Título

Uint8Array.from() — Crear un Uint8Array a partir de un iterable o array-like

📝 Definición

Uint8Array.from()

Es un método estático que crea una nueva instancia de Uint8Array a partir de un objeto iterable o array-like, copiando sus valores y convirtiéndolos en enteros sin signo de 8 bits.

🧠 ¿Qué es?

Es la versión de from() específica de Uint8Array.

Permite tomar datos como un Array, una cadena iterable o cualquier otro iterable y convertirlos en un Typed Array de bytes.

const numeros= [65,66,67];
const bytes=Uint8Array.from(numeros);
console.log(bytes);// Uint8Array(3) [65, 66, 67]

Cada elemento ocupa 1 byte y puede representar valores de 0 a 255.

🎯 ¿Para qué sirve?

Principalmente para convertir colecciones de valores en una secuencia de bytes.

Es especialmente útil cuando trabajas con:

  • Datos binarios.
  • ArrayBuffer.
  • APIs que trabajan con bytes.
  • Archivos.
  • TextEncoder.
  • Codificación y decodificación Base64.
  • Procesamiento de datos de bajo nivel.

⚙️ ¿Cómo funciona?

Uint8Array.from([65,66,67])

Conceptualmente:

[65, 66, 67]
      ↓
Uint8Array.from()
      ↓
┌────┬────┬────┐
│ 65 │ 66 │ 67 │
└────┴────┴────┘
  1B   1B   1B

Cada valor se convierte a un entero sin signo de 8 bits.

Por ejemplo:

const bytes=Uint8Array.from([0,100,255]);
console.log(bytes);// Uint8Array(3) [0, 100, 255]

Los valores que no pueden representarse directamente en 0–255 se convierten mediante la conversión a entero sin signo de 8 bits.

📝 Sintaxis / Estructura (JavaScript)

Uint8Array.from(arrayLike)

También admite una función de transformación:

Uint8Array.from(arrayLike,mapFn)

Parámetros:

  • arrayLike → objeto iterable o array-like cuyos elementos se convertirán en bytes.
  • mapFn → opcional. Función que transforma cada elemento antes de almacenarlo.

La función recibe:

mapFn(element,index)

Retorno:

  • Una nueva instancia de Uint8Array.

💡 Ejemplos

1. Desde un Array

const numeros= [10,20,30];
const bytes=Uint8Array.from(numeros);
console.log(bytes);// Uint8Array(3) [10, 20, 30]

2. Desde un Set

const datos=new Set([10,20,30]);
const bytes=Uint8Array.from(datos);
console.log(bytes);// Uint8Array(3) [10, 20, 30]

3. Utilizando mapFn

const numeros= [1,2,3];
const bytes=Uint8Array.from(numeros,numero =>numero*10);
console.log(bytes);// Uint8Array(3) [10, 20, 30]

Aquí ocurre:

1 → 10
2 → 20
3 → 30

4. Con valores mayores que 255

const bytes=Uint8Array.from([255,256,257]);
console.log(bytes);// Uint8Array(3) [255, 0, 1]

Esto ocurre porque Uint8Array solamente puede almacenar valores de 0 a 255.

⚠️ Errores comunes

1. Pensar que conserva cualquier número

Uint8Array.from([300]);

No almacenará 300, porque un Uint8Array solo representa un byte.

// Uint8Array(1) [44]

2. Confundirlo con Array.from()

Array.from(...)

crea un Array normal.

Uint8Array.from(...)

crea un Typed Array de bytes.

Array.from()
    ↓
Array

Uint8Array.from()
    ↓
Uint8Array

3. Confundir Uint8Array.from() con new Uint8Array()

Ambos pueden crear un Uint8Array, pero tienen usos diferentes:

Uint8Array.from([10,20,30]);

está pensado para crear el Typed Array a partir de valores.

Mientras:

newUint8Array(3);

crea un Typed Array con 3 posiciones inicializadas en 0.

💼 Casos de uso

Un caso muy relacionado con btoa() es convertir datos en bytes antes de realizar operaciones con Base64.

Por ejemplo:

const bytes=Uint8Array.from([72,111,108,97]);
console.log(bytes);// Uint8Array(4) [72, 111, 108, 97]

Estos valores corresponden a bytes que pueden representar texto.

También es común utilizar Uint8Array para manipular:

  • Crea un nuevo Uint8Array.
  • Convierte los elementos a enteros sin signo de 8 bits.
  • Rango representable: 0–255.
  • Cada elemento ocupa 1 byte.
  • Es muy útil para trabajar con datos binarios.
