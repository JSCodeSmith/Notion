Object.isSealed

📄 Título

Object.isSealed(objeto) en JavaScript

📝 Definición

  • Object.isSealed() es un método estático del objeto global Object que permite comprobar si un objeto está sellado (sealed).
  • Devuelve un valor booleano:
    • true → si el objeto está sellado.
    • false → si no está sellado.

🧠 ¿Qué es?

  • Es un método estático de Object.
  • Forma parte del lenguaje JavaScript (ECMAScript), no de una Web API.
  • Se utiliza principalmente para verificar el estado de un objeto después de usar:
Object.seal();

Un objeto sellado significa:

✅ Puede modificar valores existentes.

❌ No puede agregar nuevas propiedades.

❌ No puede eliminar propiedades existentes.

🎯 ¿Para qué sirve?

Se utiliza para:

  • Verificar si un objeto fue sellado con Object.seal().
  • Validar el estado de objetos antes de modificarlos.
  • Crear controles de seguridad en aplicaciones.
  • Evitar cambios estructurales inesperados.

⚙️ ¿Cómo funciona?

  1. Recibe un objeto.
  1. Revisa las características internas del objeto:
    • Si está extensible o no.
    • Si sus propiedades tienen configurable: false.
  1. Devuelve:
true

si cumple las condiciones de un objeto sellado.

Ejemplo:

const usuario= {
    nombre:"Ana"
};
Object.seal(usuario);
Object.isSealed(usuario);

Proceso:

Objeto normal
      ↓
Object.seal()
      ↓
Objeto sellado
      ↓
Object.isSealed()
      ↓
true

📝 Sintaxis / Estructura

Object.isSealed(objeto);

Parámetro

ParámetroDescripción
objetoValor que se desea comprobar.

Valor de retorno

TipoDescripción
booleantrue si el objeto está sellado, false si no lo está.

💡 Ejemplos

Objeto no sellado

const persona= {
    nombre:"Luis"
};
console.log(Object.isSealed(persona));

Resultado:

false

Objeto sellado

const usuario= {
    nombre:"Ana",
    edad:20
}; 
Object.seal(usuario); 
console.log(Object.isSealed(usuario));

Resultado:

true

Modificar una propiedad después de sellar

const producto= {
    nombre:"Laptop",
    precio:2500
}; Object.seal(producto);
producto.precio=3000;
console.log(Object.isSealed(producto));
console.log(producto);

Resultado:

true
{nombre:"Laptop",precio:3000
}

El objeto sigue sellado aunque sus valores cambien.

Comparación con Object.freeze()

const config= {
    modo:"oscuro"
};
Object.freeze(config);console.log(Object.isSealed(config));

Resultado:

true

¿Por qué?

Porque un objeto congelado (freeze) también está sellado.

⚠️ Errores comunes

❌ Pensar que verifica si fue creado con Object.seal()

Incorrecto:

Object.isSealed(objeto);

No pregunta:

"¿Usaste exactamente Object.seal()?"

Pregunta:

"¿El objeto tiene las características de un objeto sellado?"

❌ Confundirlo con Object.isFrozen()

Object.isSealed()

Comprueba:

¿No puede agregar?
¿No puede eliminar?

Pero puede modificar valores.

Object.isFrozen()

Comprueba:

¿No puede agregar?
¿No puede eliminar?
¿No puede modificar?

❌ Usarlo con valores primitivos

Ejemplo:

Object.isSealed(10);

Resultado:

true

Los valores primitivos se consideran sellados porque no pueden modificarse como objetos.

❌ Pensar que revisa objetos internos

const usuario= {
    datos: {
        edad:20
    }
};
Object.seal(usuario);
console.log(Object.isSealed(usuario.datos));

Resultado:

false

Porque solo se selló el objeto externo.

💼 Casos de uso

  • Validar objetos protegidos:
if (Object.isSealed(config)) {
		console.log("Configuración protegida");
}
  • Sistemas donde varios módulos comparten objetos.
  • Pruebas (testing) para comprobar restricciones.
  • Depuración de código.
  • Librerías que necesitan verificar estados internos.

🧠 Analogía

Imagina una caja 📦:

Caja normal:

Puedes:

  • Meter cosas nuevas.
  • Sacar cosas.
  • Cambiar cosas.

Caja sellada (Object.seal()):

La caja está cerrada:

✅ Puedes cambiar etiquetas de lo que ya existe.

❌ No puedes meter objetos nuevos.

❌ No puedes sacar objetos.

Object.isSealed() es como preguntar:

"¿Esta caja ya está sellada?"

Respuesta:

  • Sí → true
  • No → false
