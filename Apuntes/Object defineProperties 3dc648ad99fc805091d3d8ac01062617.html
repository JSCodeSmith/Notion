Object.defineProperties

📄 Título

Object.defineProperties()

📝 Definición

Object.defineProperties()

Es un método estático de Object que permite crear o modificar varias propiedades de un objeto al mismo tiempo, definiendo sus características mediante property descriptors.

🧠 ¿Qué es?

Es una herramienta para controlar con precisión cómo se comportan las propiedades de un objeto.

Por ejemplo, puedes decidir si una propiedad:

  • puede cambiar su valor (writable)
  • puede aparecer en Object.keys() (enumerable)
  • puede ser eliminada o modificada (configurable)
  • utiliza get y set
const persona= {};
Object.defineProperties(persona, {
    nombre: {
        value:"Josué",
        writable:true,
        enumerable:true,
        configurable:true
    },

    edad: {
        value:17,
        writable:false,
        enumerable:true,
        configurable:false
    }
});

🎯 ¿Para qué sirve?

Principalmente para:

  • ⚙️ Definir varias propiedades con características específicas.
  • 🔒 Controlar si una propiedad puede modificarse.
  • 👀 Controlar si una propiedad es enumerable.
  • 🗑️ Controlar si puede configurarse o eliminarse.
  • 🧮 Crear propiedades mediante get y set.
  • 🧩 Construir objetos con un comportamiento más controlado.

⚙️ ¿Cómo funciona?

Recibe dos argumentos principales:

Object.defineProperties(obj,descriptors)

El primero es el objeto que queremos modificar.

El segundo es un objeto que describe cada propiedad que queremos definir.

Object.defineProperties()
        │
        ├── objeto
        │
        └── descriptores
              │
              ├── propiedad 1
              │     ├── value
              │     ├── writable
              │     ├── enumerable
              │     └── configurable
              │
              └── propiedad 2
                    ├── value
                    └── ...

📝 Sintaxis / Estructura

Object.defineProperties(obj, {
    propiedad1: {
        value:valor,
        writable:true,
        enumerable:true,
        configurable:true
    },

    propiedad2: {
        value:valor
    }
});

Parámetros

obj

Es el objeto sobre el cual se crearán o modificarán las propiedades.

descriptors

Es un objeto que contiene los descriptores de las propiedades.

Cada propiedad del descriptor puede utilizar:

DescriptorFunción
valueDefine el valor
writablePermite cambiar el valor
enumerableDetermina si aparece en enumeraciones
configurablePermite modificar/eliminar la propiedad
getDefine un getter
setDefine un setter

Retorno

Devuelve el mismo objeto que fue pasado como primer argumento.

const persona= {};
const resultado=Object.defineProperties(persona, {
    nombre: {
        value:"Josué"
    }
});console.log(resultado===persona);// true

💡 Ejemplos

1. Crear varias propiedades

const usuario= {};
Object.defineProperties(usuario, {
    nombre: {
        value:"Josué",
        writable:true,
        enumerable:true,
        configurable:true
    },

    edad: {
        value:17,
        writable:true,
        enumerable:true,
        configurable:true
    }
});
console.log(usuario.nombre);
console.log(usuario.edad);

2. Crear una propiedad que no pueda modificarse

const usuario= {};
Object.defineProperties(usuario, {
    id: {
        value:100,
        writable:false
    }
});
usuario.id=200;
console.log(usuario.id);// 100

La propiedad existe, pero su valor no puede modificarse mediante una asignación normal.

3. Controlar enumerable

const usuario= {};
Object.defineProperties(usuario, {
    nombre: {
        value:"Josué",
        enumerable:true
    },

    password: {
        value:"123456",
        enumerable:false
    }
});
console.log(Object.keys(usuario));

Resultado:

["nombre"]

password existe, pero al tener enumerable: false, no aparece en Object.keys().

4. Utilizar get y set

const persona= {
    nombre:"Josué",
    apellido:"Rodriguez"
};
Object.defineProperties(persona, {
    nombreCompleto: {
        get() {
		        return`${this.nombre}${this.apellido}`;
        }
    }
});
console.log(persona.nombreCompleto);// "Josué Rodriguez"

Aquí nombreCompleto no almacena directamente un valor. Su valor se calcula mediante get.

5. Varias propiedades a la vez

Esta es justamente la principal diferencia frente a Object.defineProperty():

Object.defineProperty(objeto,"nombre",descriptor);

define una propiedad.

Mientras:

Object.defineProperties(objeto, {
    nombre:descriptor,
    edad:descriptor,
    email:descriptor
});

define varias propiedades.

⚠️ Errores comunes

1. Confundirlo con Object.defineProperty()

Object.defineProperty()

→ una propiedad.

Object.defineProperties()

→ varias propiedades.

2. Olvidar que los valores predeterminados de los descriptores son restrictivos

Por ejemplo:

const obj= {};
Object.defineProperties(obj, {
    nombre: {
        value:"Josué"
    }
});

Si no especificas writable, enumerable o configurable, sus valores son false.

Conceptualmente:

{
	value:"Josué",
	writable:false,
	enumerable:false,
	configurable:false
}

Por eso, cuando quieres una propiedad que se comporte como una propiedad normal, suele ser necesario especificar explícitamente:

{
	value:"Josué",
	writable:true,
	enumerable:true,
	configurable:true
}

3. Mezclar value con get/set

Un descriptor es de tipo data descriptor o accessor descriptor.

No debes definir simultáneamente:

{
	value:10,
	get() {
		return 10;
	}
}

Es decir, value/writable pertenecen a un tipo, mientras get/set pertenecen al otro.

🧠 Analogía

Imagina que estás construyendo una casa 🏠.

Una propiedad normal sería simplemente:

"Esta habitación existe."

Pero un descriptor permite poner reglas:

"Esta habitación existe, el dueño puede cambiarla, los visitantes pueden verla y además no se puede eliminar."

Object.defineProperties() sería como configurar varias habitaciones de la casa de una sola vez, estableciendo las reglas de cada una.

📝 Notas Personales

Object.defineProperties() es un método estático de Object utilizado para definir o modificar múltiples propiedades mediante descriptores de propiedades.

Idea clave:

Object.defineProperty()
        ↓
    UNA propiedad

Object.defineProperties()
        ↓
    VARIAS propiedades

Y el concepto fundamental detrás de ambos es:

Property Descriptor → controlar cómo se comporta una propiedad.
