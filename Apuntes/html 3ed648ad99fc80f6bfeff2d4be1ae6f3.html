<html>

📄 <html>

📝 Definición

<html> es el elemento raíz de todo documento HTML.

Contiene a todos los demás elementos (excepto el <!DOCTYPE>) y envuelve tanto el <head> como el <body>.

🧠 ¿Qué es?

Es una etiqueta contenedora obligatoria en HTML.

Representa la raíz del árbol DOM.

Todo lo que se renderiza o se define en la página vive dentro de ella (salvo el DOCTYPE).

🎯 ¿Para qué sirve?

  • Delimitar el documento HTML: marca dónde empieza y termina.
  • Declarar el idioma de la página con el atributo lang (accesibilidad y SEO).
  • Servir de raíz al DOM para que el navegador construya el árbol.
  • Aplicar estilos globales mediante selectores html { ... }.

⚙️ ¿Cómo funciona?

El navegador:

  1. Lee <!DOCTYPE html>.
  1. Encuentra <html> → crea el nodo raíz del DOM.
  1. Dentro coloca <head> (metadatos) y <body> (contenido visible).
  1. Cierra con </html> al final del documento.

Solo puede haber un <html> por documento.

📝 Sintaxis / Estructura

<!DOCTYPE html>
<html lang="es">
  <head>
    <!-- metadatos -->
  </head>
  <body>
    <!-- contenido visible -->
  </body>
</html>

💡 Ejemplos

Documento básico:

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi sitio</title>
  </head>
  <body>
    <h1>Hola</h1>
  </body>
</html>

Con idioma y dirección:

<html lang="ar" dir="rtl">

Aplicando estilos globales:

html {
  scroll-behavior: smooth;
  font-size: 16px;
}

⚠️ Errores comunes

  • ❌ Omitir lang → mala accesibilidad y SEO.
  • ❌ Poner contenido directamente dentro de <html> sin <body>.
  • ❌ Colocar más de un <html> en el documento.
  • ❌ Escribir el <head> fuera del <html>.
  • ❌ Usar lang="es-ES" cuando el contenido es genérico (o viceversa).
  • ❌ Anidar <html> dentro de otro elemento.

💼 Casos de uso

  • Todo documento HTML lo necesita.
  • Definir idioma global para lectores de pantalla y traductores.
  • Aplicar estilos base (fuente, scroll, tamaño rem).
  • Establecer dirección de texto en sitios multilingües (árabe, hebreo).
  • Anclar variables CSS globales con :root (que es equivalente a html).

🧩 Relación con otros conceptos

  • <!DOCTYPE html>: va justo antes.
  • <head>: primer hijo, contiene metadatos.
  • <body>: segundo hijo, contiene el contenido visible.
  • :root (CSS): pseudoclase que apunta al elemento <html>.
  • DOM: <html> es el document.documentElement.
  • document.documentElement en JS: referencia directa.

🧠 Analogía

Es como el edificio entero de una casa: el <!DOCTYPE> es el permiso de construcción, el <head> son los planos y servicios (agua, luz), y el <body> son las habitaciones donde vive la gente. Todo está contenido dentro del edificio <html>.

📝 Notas personales

  • En HTML5 las etiquetas <html>, <head> y <body> pueden omitirse en algunos casos, pero no se recomienda (mala legibilidad, errores en validación).
  • lang es obligatorio en accesibilidad: los lectores de pantalla cambian la pronunciación según su valor.
  • :root en CSS = html, pero con mayor especificidad. Mucha gente usa :root para variables CSS.
  • Puedes acceder desde JS con document.documentElement.
  • Si trabajas con XHTML, no olvides el atributo xmlns.
  • Buena práctica: siempre lang en el <html>, nunca en <body>.
