Object.setPrototypeOf()

📄 Título

Object.setPrototypeOf()

📝 Definición

Object.setPrototypeOf()

Es un método estático de Object que permite establecer o cambiar el prototipo ([[Prototype]]) de un objeto existente.

🧠 ¿Qué es?

Es una forma de modificar la cadena de prototipos de un objeto.

Object.setPrototypeOf(objeto,prototipo);

Por ejemplo:

const animal= {
    comer() {
	    console.log("Comiendo...");
    }
};
const perro= {
    ladrar() {c
		    onsole.log("¡Guau!");
    }
};Object.setPrototypeOf(perro,animal);
perro.comer();

Aunque comer() no está directamente dentro de perro, JavaScript lo encuentra en su prototipo:

perro
  │
  └── [[Prototype]]
          ↓
        animal
          │
          └── comer()

🎯 ¿Para qué sirve?

Principalmente para:

  • 🧬 Cambiar la relación de herencia de un objeto.
  • 🔗 Modificar la cadena de prototipos.
  • 🧩 Crear relaciones de prototipado dinámicamente.
  • 🔍 Experimentar o trabajar con metaprogramación.
  • 🛠️ Modificar objetos existentes cuando realmente se necesita.

⚙️ ¿Cómo funciona?

Recibe:

Object.setPrototypeOf(obj,prototype);

El primer argumento es el objeto que será modificado.

El segundo es el nuevo prototipo.

        Object.setPrototypeOf()
                 │
       ┌─────────┴─────────┐
       ↓                   ↓
    objeto             prototipo
       │                   │
       └───────┬───────────┘
               ↓
       cambia [[Prototype]]

Después de cambiarlo, las búsquedas de propiedades y métodos pueden continuar hacia el nuevo prototipo.

Ejemplo

const padre= {
    saludar() {
	    console.log("Hola");
    }
};
const hijo= {};
Object.setPrototypeOf(hijo,padre);
hijo.saludar();

Resultado:

Hola

Porque:

hijo
 │
 └── [[Prototype]]
        ↓
      padre
        └── saludar()

📝 Sintaxis / Estructura

Object.setPrototypeOf(obj,prototype)

Parámetros

obj

El objeto cuyo prototipo quieres cambiar.

prototype

El nuevo prototipo.

Normalmente es otro objeto o null.

Object.setPrototypeOf(obj,otroObjeto);

También:

Object.setPrototypeOf(obj,null);

Retorno

Devuelve el mismo objeto al que se le cambió el prototipo.

const objeto= {};
const resultado=Object.setPrototypeOf(objeto,null);
console.log(resultado===objeto);// true

💡 Ejemplos

1. Cambiar el prototipo

const animal= {
    comer() {
		    console.log("Comiendo");
    }
};
const perro= {};
Object.setPrototypeOf(perro,animal);
perro.comer();// Comiendo

2. Cambiar el prototipo después de crear el objeto

const objeto= {
    nombre:"Josué"
};
const metodos= {
    saludar() {
		    console.log(`Hola, soy${this.nombre}`);
    }
};
Object.setPrototypeOf(objeto,metodos);
objeto.saludar();// Hola, soy Josué

3. Utilizar null como prototipo

También puedes eliminar la cadena de prototipos:

const objeto= {};
Object.setPrototypeOf(objeto,null);

Ahora:

console.log(Object.getPrototypeOf(objeto));// null

Esto crea un objeto que no hereda de Object.prototype.

Por ejemplo:

console.log(objeto.toString);// undefined

porque toString() normalmente se hereda desde Object.prototype.

4. Verificar el nuevo prototipo

Puedes utilizar Object.getPrototypeOf():

const padre= {};
const hijo= {};
Object.setPrototypeOf(hijo,padre);
console.log(Object.getPrototypeOf(hijo)===padre);// true

⚠️ Errores comunes

1. Confundirlo con Object.create()

Ambos están relacionados con prototipos, pero hacen cosas diferentes.

Object.create(prototipo);

→ crea un nuevo objeto con ese prototipo.

Object.setPrototypeOf(objeto,prototipo);

→ modifica un objeto existente.

Object.create()
      ↓
CREAR + establecer prototipo

Object.setPrototypeOf()
      ↓
CAMBIAR prototipo de objeto existente

2. Confundir el prototipo con una clase

El prototipo no es simplemente "la clase".

JavaScript utiliza una cadena de prototipos para realizar búsquedas de propiedades y métodos.

objeto
   ↓
prototipo
   ↓
otro prototipo
   ↓
Object.prototype
   ↓
null

3. Cambiar prototipos constantemente

Aunque es posible, modificar el prototipo de objetos existentes puede afectar el rendimiento del motor de JavaScript.

Por eso, cuando sea posible, normalmente es mejor establecer el prototipo al crear el objeto mediante:

Object.create();

o utilizar:

class

💼 Casos de uso

  • 🧩 Metaprogramación.
  • 🧪 Experimentos con prototipos.
  • 🔗 Modificación dinámica de cadenas de prototipos.
  • 🛠️ Implementación de ciertas estructuras avanzadas.

En código cotidiano, no suele ser la primera opción.

🧠 Analogía

Imagina que cada objeto tiene una persona a la que puede pedir ayuda.

perro
  │
  └── "Si no sé hacer esto..."
              ↓
            animal
              │
              └── comer()

Si haces:

Object.setPrototypeOf(perro,animal);

estás diciendo:

"A partir de ahora, cuando perro no encuentre algo por sí mismo, puede buscarlo en animal."

Cambiar el prototipo es como cambiar a quién puede acudir el objeto cuando no encuentra una propiedad o método. 🧬
