🧟‍♂️ Método array.push()

Cada vez que eliminas a un zombie, su objeto se añade al final del array zombiesKilled usando push():

const zombiesKilled = [];

function eliminarZombie(zombie) {
  // El zombie muere y se añade a la lista
  zombiesKilled.push({
    id: zombie.id,
    lane: zombie.lane,
    status: 'dead'
  });

  console.log(`Total bajas: ${zombiesKilled.length}`);
}
