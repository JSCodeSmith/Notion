<!DOCTYPE html>

📄 <!DOCTYPE html>

📝 Definición

<!DOCTYPE html> es una declaración (no una etiqueta HTML) que se coloca al inicio de un documento HTML para indicarle al navegador qué versión del lenguaje se está utilizando.

En HTML5, su forma es simplemente <!DOCTYPE html>.

🧠 ¿Qué es?

Es una instrucción especial para el motor de renderizado del navegador.

No es un elemento HTML, no tiene cierre y no forma parte del árbol DOM.

Proviene del estándar SGML (y luego XML), donde se usaba para declarar la Definición del Tipo de Documento (DTD).

🎯 ¿Para qué sirve?

  • Evitar el "quirks mode": sin DOCTYPE, el navegador entra en modo compatibilidad y renderiza como navegadores antiguos (IE5, etc.).
  • Activar el "standards mode": el navegador aplica las reglas modernas del W3C.
  • Especificar la versión de HTML que se usará.
  • Validar el documento contra una DTD (en versiones antiguas).

⚙️ ¿Cómo funciona?

Al cargar una página, el navegador lee la primera línea:

  1. Si encuentra <!DOCTYPE html> → standards mode.
  1. Si no lo encuentra o está mal escrito → quirks mode.
  1. Si es un DOCTYPE antiguo con URL de DTD → puede activar almost standards mode.

El modo afecta cómo se calculan tamaños, márgenes, box model, etc.

📝 Sintaxis / Estructura

HTML5 (actual):

<!DOCTYPE html>

HTML 4.01 Strict (antiguo):

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
   "http://www.w3.org/TR/html4/strict.dtd">

XHTML 1.0 Strict:

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
   "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

💡 Ejemplos

Documento HTML5 mínimo:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi página</title>
</head>
<body>
  <h1>Hola mundo</h1>
</body>
</html>

⚠️ Errores comunes

  • ❌ Escribirlo después de <html> o de un comentario.
  • ❌ Dejar espacios o caracteres antes (<!DOCTYPE html>).
  • ❌ Usar sintaxis HTML4 en un proyecto HTML5 (funciona, pero no es necesario).
  • ❌ Confundir <!DOCTYPE> con una etiqueta con cierre </!DOCTYPE>.
  • ❌ Omitirlo → provoca quirks mode y estilos rotos.

💼 Casos de uso

  • Todo documento HTML moderno debe comenzar con él.
  • Plantillas base, boilerplates y frameworks lo incluyen siempre.
  • Útil al migrar sitios antiguos para forzar standards mode.

🧩 Relación con otros conceptos

  • Quirks mode / Standards mode: determina cuál se activa.
  • <html>: elemento raíz que sigue al DOCTYPE.
  • DTD: especificación formal en versiones antiguas.
  • Validación W3C: usa el DOCTYPE para validar.
  • <meta charset>: complementa al DOCTYPE en HTML5.

🧠 Analogía

Es como el encabezado de una carta formal: antes de escribir el contenido, indicas qué tipo de documento es y bajo qué normas se rige. Si lo omites, el receptor (navegador) puede malinterpretar el resto del mensaje.

📝 Notas personales

  • En HTML5 ya no se necesita URL de DTD; es retrocompatible y funciona en todos los navegadores modernos.
  • Es case-insensitive: <!doctype html> también funciona, aunque por convención se escribe en mayúsculas.
  • Es lo primero que se escribe siempre. Antes de <html>, antes de cualquier comentario.
  • Un buen boilerplate siempre lo incluye como línea 1.
