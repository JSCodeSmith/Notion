<section>

📄 <section>

📝 Definición

<section> es un elemento semántico de HTML5 que representa una sección temática de un documento.

Agrupa contenido relacionado bajo un mismo tema, normalmente con un encabezado (<h1>–<h6>) que lo identifica.

🧠 ¿Qué es?

Es un elemento de bloque y semántico.

No es un contenedor genérico: solo se usa cuando el contenido forma una unidad temática coherente que podría aparecer en un índice o esquema del documento.

Suele contener un encabezado propio.

🎯 ¿Para qué sirve?

  • Agrupar contenido por tema (capítulos, apartados).
  • Estructurar documentos largos en bloques lógicos.
  • Mejorar accesibilidad: los lectores de pantalla pueden navegar por regiones.
  • Facilitar SEO: ayuda a los buscadores a entender la estructura.
  • Organizar visualmente con CSS (grid, flexbox).
  • Servir de contenedor a artículos, listas, formularios, etc.

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como bloque (sin estilos visuales por defecto).
  1. Debe tener un encabezado (<h1>–<h6>) como primer hijo recomendado, salvo en casos excepcionales.
  1. Puede anidarse dentro de <article>, <main>, <aside> o en otro <section>.
  1. No debe usarse como contenedor genérico (para eso <div>).
  1. Los lectores de pantalla lo anuncian como "region" si tiene aria-label o aria-labelledby.

📝 Sintaxis / Estructura

<section>
  <h2>Título de la sección</h2>
  <p>Contenido de la sección...</p>
</section>

💡 Ejemplos

Sección con encabezado:

<section>
  <h2>Historia del HTML</h2>
  <p>HTML fue creado por Tim Berners-Lee en 1991...</p>
</section>

Varias secciones dentro de un artículo:

<article>
  <h1>Guía de HTML5</h1>
  <section>
    <h2>Introducción</h2>
    <p>...</p>
  </section>
  <section>
    <h2>Etiquetas básicas</h2>
    <p>...</p>
  </section>
  <section>
    <h2>Formularios</h2>
    <p>...</p>
  </section>
</article>

Sección con aria-labelledby:

<section aria-labelledby="titulo-contacto">
  <h2 id="titulo-contacto">Contacto</h2>
  <form>...</form>
</section>

Sección anidada:

<section>
  <h2>Frontend</h2>
  <section>
    <h3>HTML</h3>
    <p>...</p>
  </section>
  <section>
    <h3>CSS</h3>
    <p>...</p>
  </section>
</section>

Con estilos CSS:

<section class="destacada">
  <h2>Productos destacados</h2>
  <ul>...</ul>
</section>
section.destacada {
  background: #f9f9f9;
  padding: 2rem;
  border-radius: 8px;
  margin-bottom: 2rem;
}

⚠️ Errores comunes

  • ❌ Usarlo como contenedor genérico (para eso <div>).
  • ❌ Usarlo sin encabezado cuando agrupa contenido temático.
  • ❌ Usar <section> para envolver todo el contenido de la página.
  • ❌ Confundirlo con <article> (contenido autónomo) o <div> (sin semántica).
  • ❌ Anidar <section> dentro de <p> (inválido).
  • ❌ Usar <section> solo por estilos (para eso <div> con class).
  • ❌ No aportar aria-label cuando no hay encabezado visible.
  • ❌ Usarlo para contenido que no es temáticamente agrupable.
  • ❌ Abusar: si todo es <section>, pierde sentido.

💼 Casos de uso

  • Capítulos de un documento largo.
  • Apartados dentro de un artículo.
  • Secciones temáticas de una landing page (características, precios, testimonios).
  • Agrupación de contenido en documentación.
  • Formularios en secciones (datos personales, envío).
  • Tablas de contenido con anclas.
  • Páginas de producto: descripción, especificaciones, reseñas.
  • Secciones anidadas en un <article>.

🧩 Relación con otros conceptos

  • <article>: contenido autónomo y reutilizable (una <section> puede ir dentro).
  • <div>: contenedor genérico sin semántica.
  • <main>: contenido principal del documento (suele contener <section>).
  • <aside>: contenido lateral relacionado.
  • <header> / <footer>: pueden ir dentro de una <section>.
  • <h1>–<h6>: encabezado de la sección (recomendado).
  • <nav>: sección especializada de navegación.
  • aria-labelledby: etiqueta accesible para lectores de pantalla.
  • CSS: display: grid, flex, padding, margin, background.
  • Accesibilidad: lectores de pantalla anuncian "region" si tiene etiqueta.

🧠 Analogía

Una <section> es como un capítulo de un libro: agrupa contenido sobre un mismo tema y tiene un título. Puedes tener capítulos dentro de partes (secciones anidadas), y cada capítulo tiene sentido por sí mismo pero forma parte de una obra mayor.

📝 Notas personales

  • No es un <div>: solo se usa para contenido temáticamente agrupable.
  • Debe tener un encabezado (<h1>–<h6>), salvo casos excepcionales.
  • Si no puedes ponerle un título, probablemente sea un <div>.
  • Se puede anidar dentro de <article>, <main>, <aside> u otra <section>.
  • No debe ir dentro de <p> ni de elementos inline.
  • Para accesibilidad, añade aria-labelledby apuntando al id del encabezado.
  • En CSS, <section> no tiene estilos por defecto (solo display: block).
  • Diferencia clave: <article> es autónomo; <section> es temático.
  • Si el contenido se puede sindicar o reutilizar solo → <article>.
  • Si el contenido es parte de un tema mayor → <section>.
  • Si no tiene significado semántico → <div>.
