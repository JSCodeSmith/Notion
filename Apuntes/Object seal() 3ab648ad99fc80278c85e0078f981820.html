Object.seal()

📄 Título

Object.seal() en JavaScript

📝 Definición

  • Object.seal() es un método estático del objeto global Object que permite sellar un objeto, evitando que se puedan agregar o eliminar propiedades, pero permitiendo modificar los valores de las propiedades existentes.

🧠 ¿Qué es?

  • Es un método estático de Object.
  • Forma parte del lenguaje JavaScript (ECMAScript), no de una Web API.
  • Cambia el estado interno del objeto usando el concepto de propiedades configurables (configurable).

Cuando un objeto es sellado:

✅ Puedes:

  • Leer propiedades.
  • Modificar valores existentes.

❌ No puedes:

  • Agregar nuevas propiedades.
  • Eliminar propiedades existentes.
  • Cambiar la configuración de las propiedades.

🎯 ¿Para qué sirve?

Se utiliza para:

  • Proteger estructuras de datos contra cambios de forma accidental.
  • Evitar que otras partes del programa agreguen o eliminen propiedades.
  • Crear objetos con una estructura fija.
  • Mejorar la seguridad y control del código.

⚙️ ¿Cómo funciona?

Cuando ejecutas:

Object.seal(objeto);

JavaScript modifica las propiedades internas del objeto:

Antes:

{nombre:"Ana"
}

Puedes:

objeto.edad=20;
delete objeto.nombre;

Después de seal():

{nombre:"Ana"
}

La estructura queda bloqueada.

Pero:

objeto.nombre="Luis";

Sí funciona.

📝 Sintaxis / Estructura

Object.seal(objeto);

Parámetro

ParámetroDescripción
objetoObjeto que será sellado.

Valor de retorno

TipoDescripción
ObjectDevuelve el mismo objeto que fue sellado.

💡 Ejemplos

Sellar un objeto

const usuario= {
    nombre:"Josué",
    edad:17
};
Object.seal(usuario);
usuario.edad=18;
console.log(usuario);

Resultado:

{nombre:"Josué",edad:18}

Modificar funciona ✅

Intentar agregar una propiedad

const persona= {
    nombre:"Ana"
};
Object.seal(persona);
persona.edad=25;
console.log(persona);

Resultado:

{nombre:"Ana"
}

edad no se agregó ❌

Intentar eliminar una propiedad

const producto= {
    nombre:"Laptop",
    precio:2500
}
;Object.seal(producto);
delete producto.precio;
console.log(producto);

Resultado:

{nombre:"Laptop",precio:2500
}

No se puede eliminar ❌

Verificar si un objeto está sellado

const usuario= {
    nombre:"Luis"
}
;
Object.seal(usuario);
console.log(Object.isSealed(usuario));

Resultado:

true

⚠️ Errores comunes

❌ Pensar que congela completamente el objeto

const usuario= {
    nombre:"Ana"
};
Object.seal(usuario);
usuario.nombre="María";console.log(usuario);

Resultado:

{nombre:"María"
}

seal() permite modificar valores.

Para bloquear todo:

Object.freeze();

❌ Confundir seal() con freeze()

MétodoAgregarEliminarModificar
Object.seal()❌❌✅
Object.freeze()❌❌❌

❌ Pensar que crea una copia

const copia=Object.seal(usuario);

No crea un nuevo objeto.

Devuelve el mismo:

copia===usuario

Resultado:

true

❌ No considerar objetos anidados

const usuario= {
    direccion: {
        ciudad:"Lima"
    }
};
Object.seal(usuario);
usuario.direccion.ciudad="Cusco";

Esto funciona.

¿Por qué?

Porque seal() solo protege el primer nivel.

Es una protección superficial (shallow).

💼 Casos de uso

  • Configuraciones que no deben cambiar de estructura:
const config= {
    idioma:"es",
    modo:"oscuro"
};
Object.seal(config);
  • Objetos compartidos entre módulos.
  • Modelos de datos con propiedades definidas.
  • Evitar errores accidentales durante desarrollo.
  • Controlar modificaciones en aplicaciones grandes.

🧠 Analogía

Imagina una casa 🏠:

Objeto normal:

Puedes:

  • Construir habitaciones nuevas.
  • Derribar paredes.
  • Pintar habitaciones.

Object.seal():

La casa queda sellada:

✅ Puedes pintar las habitaciones.

❌ No puedes construir nuevas habitaciones.

❌ No puedes eliminar habitaciones existentes.

Object.freeze():

La casa queda completamente congelada:

❌ No puedes cambiar nada.
