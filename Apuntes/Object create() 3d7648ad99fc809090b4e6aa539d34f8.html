Object.create()

😊 Object.create()

📝 Definición

Object.create() es un método estático de JavaScript que crea un nuevo objeto utilizando un objeto existente como prototipo del nuevo objeto creado.

Object.create(proto, propiedades)

🧠 ¿Qué es?

Es una función nativa de JavaScript (ES5, 2009) que permite crear objetos especificando explícitamente su prototipo.

A diferencia de new o de los literales {}, aquí tú decides directamente de quién hereda el nuevo objeto.

🎯 ¿Para qué sirve?

  • Crear objetos con herencia prototípica personalizada.
  • Implementar patrones de herencia sin usar clases.
  • Crear objetos sin prototipo (Object.create(null)).
  • Definir propiedades con descriptores (writable, enumerable, configurable).
  • Evitar el uso de __proto__ (mala práctica).

⚙️ ¿Cómo funciona?

  1. Recibe un primer argumento: el objeto que será el prototipo ([[Prototype]]).
  1. Opcionalmente recibe un segundo argumento: un objeto con descriptores de propiedades.
  1. Devuelve un nuevo objeto cuyo prototipo es el indicado.
  1. Si el primer argumento es null, el objeto no hereda nada (ni siquiera de Object.prototype).

📝 Sintaxis / Estructura

Object.create(proto)
Object.create(proto, propiedadesDescriptoras)
ParámetroTipoDescripción
protoObject | nullPrototipo del nuevo objeto
propiedadesDescriptorasObject (opcional)Propiedades con descriptores

Descriptor válido:

{
  value: ...,
  writable: true|false,
  enumerable: true|false,
  configurable: true|false,
  get() {...},
  set(v) {...}
}

💡 Ejemplos

🔹 Ejemplo 1: Herencia básica

const animal = {
  hablar() {
    console.log(`${this.nombre} hace un sonido`);
  }
};

const perro = Object.create(animal);
perro.nombre = "Rex";
perro.hablar(); // "Rex hace un sonido"

🔹 Ejemplo 2: Objeto sin prototipo

const limpio = Object.create(null);
console.log(limpio.toString); // undefined

🔹 Ejemplo 3: Con descriptores

const persona = Object.create(Object.prototype, {
  nombre: {
    value: "Ana",
    writable: false,
    enumerable: true
  }
});
console.log(persona.nombre); // "Ana"
persona.nombre = "Luis";      // ❌ no cambia (writable: false)

🔹 Ejemplo 4: Herencia en cadena

const A = { a: 1 };
const B = Object.create(A);
const C = Object.create(B);
console.log(C.a); // 1 (heredado)

⚠️ Errores comunes

ErrorExplicación
Object.create(undefined)❌ TypeError: solo acepta objeto o null
Confundir proto con propiedadesEl primer argumento no son propiedades, es el prototipo
Olvidar enumerable: trueLas propiedades no aparecen en for...in ni Object.keys
Usar Object.create con clasesNo copia métodos de instancia, solo enlaza prototipos
Modificar el prototipo despuésAfecta a todos los objetos que lo usan

💼 Casos de uso

  • ✅ Herencia prototípica pura (sin clases).
  • ✅ Crear objetos diccionario sin métodos heredados → Object.create(null).
  • ✅ Implementar mixins y composición.
  • ✅ Crear objetos con propiedades de solo lectura o no enumerables.
  • ✅ Polimorfismo basado en prototipos.
  • ✅ Evitar contaminar Object.prototype.

🧠 Analogía

Imagina que vas a fabricar un mueble nuevo.

Object.create(muebleBase) es como decir:

"Hazme un mueble igual al modelo base, pero con mis propios detalles."

  • El modelo base = el prototipo (hereda forma, color, estructura).
  • El mueble nuevo = tu objeto (puede añadir o modificar cosas).

Y Object.create(null) sería un mueble sin plano, sin modelo: existe, pero no hereda nada.
