Object.freeze()

📄 Título

Object.freeze(objeto) en JavaScript

📝 Definición

  • Object.freeze() es un método estático del objeto global Object que permite congelar un objeto, evitando que sus propiedades puedan ser agregadas, eliminadas o modificadas.
  • Devuelve el mismo objeto que fue congelado.

🧠 ¿Qué es?

  • Es un método estático de Object.
  • Forma parte del lenguaje JavaScript (ECMAScript), no de una Web API.
  • Convierte un objeto en un estado de solo lectura superficial (shallow read-only).

Cuando un objeto está congelado:

✅ Puedes:

  • Leer propiedades.
  • Acceder a sus valores.

❌ No puedes:

  • Agregar nuevas propiedades.
  • Eliminar propiedades existentes.
  • Cambiar valores.
  • Cambiar configuraciones de propiedades.

🎯 ¿Para qué sirve?

Se utiliza para:

  • Proteger objetos importantes contra modificaciones accidentales.
  • Crear constantes de configuración.
  • Evitar cambios en datos compartidos.
  • Mantener estados inmutables en aplicaciones.
  • Ayudar en patrones como programación funcional y gestión de estados.

⚙️ ¿Cómo funciona?

Cuando ejecutas:

Object.freeze(objeto);

JavaScript realiza dos acciones principales:

  1. Evita que se agreguen nuevas propiedades.
  1. Hace que las propiedades existentes sean:
    • writable: false → no se pueden modificar.
    • configurable: false → no se pueden eliminar.

Ejemplo:

Antes:

const usuario= {
    nombre:"Ana",
    edad:20
};

Después:

Object.freeze(usuario);

Intentos:

usuario.edad=30;// ❌usuario.email="ana@gmail.com";// ❌deleteusuario.nombre;// ❌

📝 Sintaxis / Estructura

Object.freeze(objeto);

Parámetro

ParámetroDescripción
objetoObjeto que será congelado.

Valor de retorno

TipoDescripción
ObjectDevuelve el mismo objeto congelado.

Ejemplo:

const resultado=Object.freeze(usuario);
console.log(resultado===usuario);

Resultado:

true

💡 Ejemplos

Congelar un objeto

const persona= {
    nombre:"Luis",
    edad:25
}; 
Object.freeze(persona);
persona.edad=30;
console.log(persona);

Resultado:

{nombre:"Luis",edad:25
}

La modificación no se realizó.

Intentar agregar una propiedad

const producto= {
    nombre:"Laptop"
};
Object.freeze(producto);producto.precio=2500;console.log(producto);

Resultado:

{nombre:"Laptop"
}

La propiedad no se agregó.

Intentar eliminar una propiedad

const usuario= {
    nombre:"Ana",
    edad:20
};
Object.freeze(usuario);deleteusuario.edad;console.log(usuario);

Resultado:

{nombre:"Ana",edad:20
}

No se elimina.

Verificar si está congelado

const config= {
    modo:"oscuro"
};Object.freeze(config);console.log(Object.isFrozen(config));

Resultado:

true

Congelar un array

Los arrays también son objetos:

const numeros= [1,2,3];
Object.freeze(numeros);
numeros.push(4);

Resultado:

Error

No puede cambiarse.

⚠️ Errores comunes

❌ Pensar que congela objetos internos

const usuario= {
    nombre:"Ana",
    direccion: {
        ciudad:"Lima"
    }
};
Object.freeze(usuario);
usuario.direccion.ciudad="Cusco";
console.log(usuario);

Resultado:

{nombre:"Ana",direccion: {ciudad:"Cusco"
 }
}

¿Por qué?

Porque freeze() solo congela el primer nivel.

Es una:

Shallow Freeze ✅

No una:

Deep Freeze ❌

❌ Confundirlo con Object.seal()

MétodoAgregarEliminarModificar
Object.seal()❌❌✅
Object.freeze()❌❌❌

❌ Pensar que crea una copia

const nuevo=Object.freeze(objeto);

No crea otro objeto.

Es el mismo:

nuevo===objeto

Resultado:

true

❌ No usar modo estricto para detectar errores

Sin "use strict":

objeto.nombre="Pedro";

Puede fallar silenciosamente.

Con:

"use strict";

JavaScript lanzará un error.

💼 Casos de uso

Configuraciones constantes

const CONFIG=Object.freeze({
    API_URL:"/api",
    VERSION:"1.0"
});

Estados inmutables

Ejemplo en aplicaciones:

const estadoInicial=Object.freeze({
    usuario:null,
    conectado:false
});

Evitar modificaciones accidentales

  • Librerías.
  • Constantes globales.
  • Datos compartidos.
  • Objetos de configuración.

🧩 Relación con otros conceptos

MétodoFunción
Object.preventExtensions()No permite agregar propiedades
Object.seal()No permite agregar ni eliminar
Object.freeze()No permite agregar, eliminar ni modificar
Object.isFrozen()Comprueba si está congelado

Jerarquía de protección:

Objeto normal
      ↓
preventExtensions()
      ↓
seal()
      ↓
freeze()

Relación con inmutabilidad

Object.freeze() ayuda a crear objetos inmutables:

const usuario=Object.freeze({
    nombre:"Ana"
});

Pero recuerda:

  • Congelación superficial → solo primer nivel.
  • Para estructuras profundas se necesita una técnica de deep freeze.

🧠 Analogía

Objeto normal

Estatua congelada

Solo puedes observarla:

➖ Eliminar → ❌
