<iframe>

📄 <iframe>

📝 Definición

<iframe> (del inglés inline frame, "marco en línea") es el elemento que permite incrustar otro documento HTML dentro de la página actual.

Se usa para insertar contenido externo: videos de YouTube, mapas, publicaciones de redes sociales, anuncios, etc.

🧠 ¿Qué es?

Es un elemento reemplazado que crea un contexto de navegación anidado.

Dentro de él se carga una página completa e independiente, con su propio DOM, CSS y JavaScript.

Es como una "ventana" a otra página dentro de la tuya.

🎯 ¿Para qué sirve?

  • Incrustar videos externos (YouTube, Vimeo).
  • Insertar mapas (Google Maps, OpenStreetMap).
  • Mostrar contenido de redes sociales (tweets, posts).
  • Incrustar anuncios publicitarios.
  • Insertar documentos PDF u otros.
  • Cargar widgets de terceros.
  • Aislar contenido con sandbox por seguridad.

⚙️ ¿Cómo funciona?

  1. El navegador crea un contexto de navegación anidado.
  1. Carga el documento indicado en src como una página independiente.
  1. Tiene su propio DOM, CSS y JS: no comparte con la página padre.
  1. La comunicación entre padre e iframe se hace con postMessage (con restricciones).
  1. Puede tener sandbox para limitar lo que el contenido puede hacer.
  1. Los motores de búsqueda no indexan el contenido del iframe como parte de la página.

📝 Sintaxis / Estructura

<iframe src="https://example.com" title="Descripción"></iframe>

💡 Ejemplos

YouTube:

<iframe
  width="560" height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="Video de YouTube"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowfullscreen
  loading="lazy">
</iframe>

Google Maps:

<iframe
  src="https://www.google.com/maps/embed?pb=..."
  width="600" height="450"
  style="border:0;"
  allowfullscreen=""
  loading="lazy"
  title="Mapa de ubicación"
  referrerpolicy="no-referrer-when-downgrade">
</iframe>

Con srcdoc (HTML inline):

<iframe srcdoc="<p>Hola desde el iframe</p>" title="Ejemplo srcdoc"></iframe>

Con sandbox (contenido no confiable):

<iframe
  src="https://ejemplo-externo.com"
  sandbox="allow-scripts allow-same-origin"
  title="Contenido externo seguro">
</iframe>

PDF incrustado:

<iframe
  src="documento.pdf"
  width="100%" height="600"
  title="Documento PDF">
</iframe>

Con estilos CSS (responsive):

<div class="video-wrapper">
  <iframe
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="Video"
    allowfullscreen
    loading="lazy">
  </iframe>
</div>
.video-wrapper {
  position: relative;
  padding-bottom: 56.25%; /* 16:9 */
  height: 0;
  overflow: hidden;
}
.video-wrapper iframe {
  position: absolute;
  top: 0; left: 0;
  width: 100%; height: 100%;
  border: 0;
}

⚠️ Errores comunes

  • ❌ Olvidar title → problema de accesibilidad.
  • ❌ Incrustar contenido no confiable sin sandbox.
  • ❌ No usar loading="lazy" → carga innecesaria.
  • ❌ Usar frameborder (obsoleto): usar CSS border: 0.
  • ❌ No definir width/height → layout shift (CLS).
  • ❌ Abusar de iframes → mala práctica y rendimiento.
  • ❌ Usar iframes para estructurar layout (era el patrón antiguo, hoy es mala práctica).
  • ❌ No considerar CSP (frame-src, frame-ancestors).
  • ❌ Incrustar contenido sin permiso del dueño (problemas legales).
  • ❌ Confiar en postMessage sin validar el origin → riesgo de seguridad.

💼 Casos de uso

  • Videos de YouTube/Vimeo.
  • Mapas de Google Maps o similares.
  • Publicaciones de redes sociales (tweets, posts de Facebook).
  • Anuncios publicitarios.
  • PDFs u otros documentos.
  • Widgets de terceros (calendarios, formularios).
  • Pagos (Stripe, PayPal) en modo embebido.
  • Contenido aislado con sandbox.
  • Demos o playgrounds de código (CodePen, JSFiddle).

🧩 Relación con otros conceptos

  • <frame> / <frameset>: obsoletos, reemplazados por <iframe>.
  • <embed> / <object>: alternativas para incrustar contenido.
  • <video>: para video propio (sin iframe).
  • sandbox: atributo de seguridad clave.
  • postMessage: comunicación entre padre e iframe.
  • CSP: frame-src y frame-ancestors controlan iframes.
  • X-Frame-Options: cabecera HTTP que impide ser incrustado.
  • loading="lazy": carga diferida.
  • title: accesibilidad (obligatorio en la práctica).
  • Responsive: técnica del wrapper con padding-bottom.

🧠 Analogía

Un <iframe> es como una ventana a otra casa: puedes ver lo que pasa dentro, pero es un espacio independiente con sus propias reglas. No puedes cambiar los muebles de la otra casa (no compartes DOM), y si la otra casa es peligrosa, mejor ponerle rejas (sandbox).

📝 Notas personales

  • title es obligatorio en accesibilidad: describe el contenido.
  • loading="lazy" para iframes fuera del viewport (mejora rendimiento).
  • sandbox siempre para contenido no confiable.
  • allow para permisos específicos (fullscreen, camera, etc.).
  • Nunca uses iframes para layout (patrón obsoleto).
  • Responsive: usa wrapper con padding-bottom: 56.25% (16:9).
  • X-Frame-Options o CSP frame-ancestors impiden que tu sitio sea incrustado.
  • postMessage: valida siempre el origin por seguridad.
  • SEO: el contenido del iframe no se indexa como parte de la página.
  • Rendimiento: cada iframe es un documento completo → pesa.
  • Buena práctica: úsalo solo cuando sea necesario; si puedes embeber el contenido nativamente, mejor.
