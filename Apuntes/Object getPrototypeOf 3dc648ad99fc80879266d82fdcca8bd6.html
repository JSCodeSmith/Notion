Object.getPrototypeOf()

📄 Título

Object.getPrototypeOf()

📝 Definición

Object.getPrototypeOf()

Es un método estático de Object que devuelve el prototipo ([[Prototype]]) de un objeto.

🧠 ¿Qué es?

Es una herramienta para consultar qué objeto está conectado como prototipo de otro objeto.

En otras palabras, permite preguntar:

“¿Cuál es el prototipo de este objeto?”

🎯 ¿Para qué sirve?

Sirve para:

  • 🔍 Inspeccionar la cadena de prototipos.
  • 🧬 Saber de qué objeto hereda otro objeto.
  • 🛠️ Trabajar con herencia basada en prototipos.
  • 🔗 Complementar Object.setPrototypeOf().
  • 🧪 Analizar objetos creados mediante Object.create().
  • 📚 Comprender cómo funciona la prototype chain.

⚙️ ¿Cómo funciona?

JavaScript utiliza una propiedad interna llamada [[Prototype]].

Cuando haces:

const persona= {};

persona normalmente tiene como prototipo a Object.prototype.

Puedes consultarlo:

const persona= {};
console.log(Object.getPrototypeOf(persona));

Resultado aproximado:

Object.prototype

La función no busca propiedades directamente; simplemente devuelve el objeto que está conectado como prototipo.

📝 Sintaxis / Estructura

Object.getPrototypeOf(obj)

Parámetro

obj

El objeto cuyo prototipo quieres obtener.

Retorno

Devuelve el prototipo del objeto.

También puede devolver:

null

si el objeto no tiene prototipo.

💡 Ejemplos

1. Obtener el prototipo de un objeto

const persona= {};
const prototipo=Object.getPrototypeOf(persona);
console.log(prototipo===Object.prototype);

Resultado:

true

2. Objeto creado con Object.create()

const animal= {
    comer() {
	    console.log("Comiendo...");
    }
};
const perro=Object.create(animal);
console.log(Object.getPrototypeOf(perro)===animal);

Resultado:

true

Aquí:

perro
  ↓
animal
  ↓
Object.prototype
  ↓
null

3. Obtener el prototipo de un array

const numeros= [1,2,3];
console.log(Object.getPrototypeOf(numeros)===Array.prototype);

Resultado:

true

4. Obtener el prototipo de una instancia de clase

class Persona {}
const josue= new Persona();
console.log(Object.getPrototypeOf(josue)===Persona.prototype);

Resultado:

true

La relación es:

josue
  ↓
Persona.prototype
  ↓
Object.prototype
  ↓
null

5. Un objeto sin prototipo

const objeto=Object.create(null);
console.log(Object.getPrototypeOf(objeto));

Resultado:

null

Este objeto no hereda de Object.prototype.

⚠️ Errores comunes

Confundirlo con Object.prototype

Esto:

Object.getPrototypeOf(objeto)

obtiene el prototipo de objeto.

Mientras que:

Object.prototype

es directamente el objeto prototipo base de los objetos normales.

Confundirlo con Object.setPrototypeOf()

get → obtiene

Object.getPrototypeOf(obj);

set → cambia

Object.setPrototypeOf(obj,nuevoPrototipo);

Una forma fácil de recordarlo:

get → leer 🔍
set → cambiar 🔧

Confundirlo con obj.__proto__

También puedes encontrarte con:

obj.__proto__

pero __proto__ es una propiedad heredada histórica/accesor especial.

Para consultar el prototipo, la forma recomendada es:

Object.getPrototypeOf(obj);

💼 Casos de uso

  • Inspeccionar herencia prototípica.
  • Depurar objetos.
  • Comprobar relaciones entre instancias y prototipos.
  • Trabajar con Object.create().
  • Analizar clases y sus instancias.
  • Estudiar la cadena de prototipos.
  • Complementar operaciones con Object.setPrototypeOf().
