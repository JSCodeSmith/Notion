Function.prototype.bind()

😊 Function.prototype.bind()

📝 Definición

Function.prototype.bind() es un método de las funciones en JavaScript que crea una nueva función con el this fijado permanentemente a un valor dado y, opcionalmente, con argumentos preestablecidos (partial application).

funcionOriginal.bind(thisArg, arg1, arg2, ...)

🧠 ¿Qué es?

Es uno de los tres métodos que permiten controlar el this en JavaScript (junto con call y apply).

A diferencia de ellos, bind() no ejecuta la función:

devuelve una copia enlazada que puedes invocar más tarde, en cualquier contexto, y siempre conservará el this y los argumentos iniciales que le indicaste.

🎯 ¿Para qué sirve?

  • 🔒 Fijar el this de una función de forma permanente.
  • 🧩 Crear funciones parcialmente aplicadas (partial application).
  • 🎛️ Pasar métodos como callbacks sin perder su contexto.
  • 🏗️ Implementar currying sencillo.
  • 🔄 Reutilizar funciones con valores predefinidos.
  • 🧱 Emular métodos de instancia en otros objetos.

⚙️ ¿Cómo funciona?

  1. Recibe un primer argumento: el valor que será this dentro de la función.
  1. Recibe argumentos opcionales que se "congelan" al inicio.
  1. Devuelve una nueva función (bound function).
  1. Esa nueva función, al llamarse:
    • Usa el this fijado (ignora el this de la llamada).
    • Antepone los argumentos preestablecidos a los nuevos.
  1. bind() no modifica la función original.

⚠️ El this fijado con bind no se puede cambiar ni con call ni con apply.

📝 Sintaxis / Estructura

const nuevaFuncion = funcionOriginal.bind(thisArg, arg1, arg2, ...);
ParámetroDescripción
thisArgValor que será this dentro de la función (obligatorio)
arg1, arg2, ...Argumentos que se preestablecen (opcional)
RetornoUna nueva función enlazada

💡 Ejemplos

🔹 Ejemplo 1: Fijar this

const persona = {
  nombre: "Ana",
  saludar() {
    console.log(`Hola, soy${this.nombre}`);
  }
};

const saludarSuelto = persona.saludar;
saludarSuelto(); // ❌ "Hola, soy undefined"

const saludarFijado = persona.saludar.bind(persona);
saludarFijado(); // ✅ "Hola, soy Ana"

🔹 Ejemplo 2: Partial application (argumentos preestablecidos)

function multiplicar(a, b) {
  return a * b;
}

const duplicar = multiplicar.bind(null, 2);
console.log(duplicar(5)); // 10
console.log(duplicar(10)); // 20

const triplicar = multiplicar.bind(null, 3);
console.log(triplicar(4)); // 12

🔹 Ejemplo 3: this + argumentos combinados

function presentar(saludo, puntuacion) {
  console.log(`${saludo}, soy${this.nombre}${puntuacion}`);
}

const persona = { nombre: "Luis" };

const saludarLuis = presentar.bind(persona, "Hey");
saludarLuis("!"); // "Hey, soy Luis!"
saludarLuis("!!!"); // "Hey, soy Luis!!!"

🔹 Ejemplo 4: Como callback en setTimeout

const contador = {
  valor: 0,
  incrementar() {
    this.valor++;
    console.log(this.valor);
  }
};

// ❌ Pierde el this
setTimeout(contador.incrementar, 1000); // NaN

// ✅ Con bind
setTimeout(contador.incrementar.bind(contador), 1000); // 1

🔹 Ejemplo 5: Como callback en eventos

class Boton {
  constructor() {
    this.clicks = 0;
    const btn = document.querySelector("#btn");
    btn.addEventListener("click", this.manejarClick.bind(this));
  }
  manejarClick() {
    this.clicks++;
    console.log(`Clicks:${this.clicks}`);
  }
}

🔹 Ejemplo 6: El this no se puede sobreescribir

function quienSoy() {
  console.log(this.nombre);
}

const fija = quienSoy.bind({ nombre: "Fijo" });
fija.call({ nombre: "Otro" }); // "Fijo" ✅ (bind gana)

🔹 Ejemplo 7: Reutilizar métodos de un objeto en otro

const coche = {
  marca: "Toyota",
  mostrar() {
    console.log(this.marca);
  }
};

const moto = { marca: "Yamaha" };
const mostrarMoto = coche.mostrar.bind(moto);
mostrarMoto(); // "Yamaha"

⚠️ Errores comunes

ErrorExplicación
Creer que bind() ejecuta la función❌ No la ejecuta; devuelve una nueva
Esperar que call/apply cambien el this❌ bind tiene prioridad absoluta
Usar bind en arrow functions❌ Las arrows ignoran this; no tiene efecto
Llamar bind dentro de un bucle sin guardarCrea funciones nuevas cada vez → ineficiente
Olvidar new con constructores boundnew (F.bind(obj)) crea instancia de F, no de obj
Pensar que modifica la función original❌ Es inmutable, devuelve copia
No guardar la función boundfunc.bind(x)() funciona, pero pierdes la referencia
Confundir con call/applyAquellos ejecutan; bind prepara

❌ Ejemplo de error clásico

const obj = {
  nombre: "Ana",
  saludar: () => console.log(this.nombre) // ❌ arrow ignora bind
};

const f = obj.saludar.bind({ nombre: "Luis" });
f(); // undefined (las arrows no tienen this propio)

❌ bind y new

function Persona(nombre) {
  this.nombre = nombre;
}
const Bound = Persona.bind({ nombre: "ignorado" });
const p = new Bound("Pedro");
console.log(p.nombre); // "Pedro" ✅ (el this del bind se ignora con new)

💼 Casos de uso

  • 🎯 Pasar métodos como callbacks (setTimeout, addEventListener).
  • 🧩 Partial application: crear funciones derivadas.
  • 🏗️ En clases: enlazar métodos en el constructor.
  • 🎛️ Event handlers que necesitan acceso a this.
  • 🔄 Currying básico.
  • 🧪 Testing: fijar contexto en spies/mocks.
  • 🧱 Reutilizar métodos entre objetos no relacionados.
  • ⚙️ React class components: this.handleClick = this.handleClick.bind(this).

🧠 Analogía

Imagina que tienes una plantilla de carta 📄 que dice:

"Hola, soy [nombre]. [mensaje]"

  • call / apply = rellenas los campos y envías la carta ya.
  • bind = imprimes una copia con [nombre] ya escrito como "Ana" y la guardas.

    Cada vez que quieras, solo agregas el [mensaje] y la envías.

    El [nombre] ya quedó fijo para siempre, no se puede cambiar.

Y si intentas usar la carta con otro nombre → no funciona, sigue diciendo "Ana".

🧩 Patrones útiles con bind

🔸 Partial application

const suma = (a, b, c) => a + b + c;
const suma5 = suma.bind(null, 5);
console.log(suma5(3, 2)); // 10

🔸 Polyfill de bind (para entender su magia)

Function.prototype.miBind = function (thisArg, ...args) {
  const fn = this;
  return function (...nuevosArgs) {
    return fn.apply(thisArg, [...args, ...nuevosArgs]);
  };
};

🔸 Enlazar y guardar (patrón clásico en clases)

class Contador {
  constructor() {
    this.valor = 0;
    this.incrementar = this.incrementar.bind(this); // 🔗 enlace permanente
  }
  incrementar() { this.valor++; }
}
