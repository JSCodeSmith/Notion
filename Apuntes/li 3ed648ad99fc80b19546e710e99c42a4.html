<li>

📄 <li>

📝 Definición

<li> (del inglés list item, "ítem de lista") es el elemento que representa un elemento individual dentro de una lista.

Actúa como el contenedor de cada elemento, agrupando su contenido específico

Es el hijo obligatorio de <ul>, <ol> y <menu>, y puede contener texto, enlaces, imágenes u otros elementos de bloque.

🧠 ¿Qué es?

Es un elemento de bloque (aunque se comporta como ítem dentro de su lista padre).

Cada <li> representa una entrada de la lista.

Los lectores de pantalla lo anuncian como "elemento X de N" dentro de listas ordenadas.

🎯 ¿Para qué sirve?

  • Definir cada ítem de una lista (<ul>, <ol>, <menu>).
  • Contener contenido variado: texto, enlaces, imágenes, párrafos, sublistas.
  • Aportar semántica: indica al navegador que es un elemento de lista.
  • Facilitar accesibilidad: los lectores de pantalla cuentan los ítems.
  • Servir de base para menús, pasos, ingredientes, etc.

⚙️ ¿Cómo funciona?

  1. Solo es válido dentro de <ul>, <ol> o <menu>.
  1. El navegador le asigna un marcador (viñeta o número) según el padre.
  1. Puede contener elementos de flujo: texto, <p>, <div>, <img>, otra lista, etc.
  1. Si el <li> contiene una sublista, esta debe ir dentro del <li>.
  1. El cierre </li> es opcional si el siguiente elemento es otro <li>, pero se recomienda escribirlo.

📝 Sintaxis / Estructura

<ul>
  <li>Elemento de lista</li>
</ul>

💡 Ejemplos

Ítem en lista desordenada:

<ul>
  <li>Manzana</li>
  <li>Plátano</li>
  <li>Naranja</li>
</ul>

Ítem en lista ordenada con value:

<ol>
  <li>Primero</li>
  <li value="10">Décimo</li>
  <li>Undécimo</li>
</ol>

Ítem con contenido enriquecido:

<ul>
  <li>
    <h3>Título del ítem</h3>
    <p>Descripción del ítem.</p>
    <a href="/detalle">Ver más</a>
  </li>
</ul>

Ítem con sublista anidada:

<ul>
  <li>Frutas
    <ul>
      <li>Manzana</li>
      <li>Plátano</li>
    </ul>
  </li>
  <li>Verduras</li>
</ul>

Menú de navegación:

<nav>
  <ul>
    <li><a href="/">Inicio</a></li>
    <li><a href="/blog">Blog</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>

Ítem con estilos personalizados:

li::marker {
  color: #007bff;
  font-weight: bold;
}
li.destacado {
  background: #fffbe6;
  padding: 0.5rem;
  border-radius: 4px;
}

⚠️ Errores comunes

  • ❌ Usar <li> fuera de <ul>, <ol> o <menu> (inválido).
  • ❌ Poner contenido directamente en <ul>/<ol> sin <li>.
  • ❌ Anidar una sublista fuera del <li> (debe ir dentro).
  • ❌ Usar type en <li> (obsoleto, usar CSS).
  • ❌ Usar value en un <li> dentro de <ul> (solo funciona en <ol>).
  • ❌ Olvidar el cierre </li> cuando hay contenido complejo (puede causar anidamientos raros).
  • ❌ Poner un <li> vacío.
  • ❌ Anidar un <li> directamente dentro de otro <li> sin una sublista intermedia.
  • ❌ Usar <li> como contenedor genérico fuera de listas.

💼 Casos de uso

  • Menús de navegación (<ul> + <li> + <a>).
  • Listas de características de productos.
  • Pasos de una receta o tutorial (<ol> + <li>).
  • Rankings y clasificaciones.
  • Breadcrumbs (migas de pan).
  • Redes sociales en el footer.
  • Etiquetas / tags.
  • Listas de archivos o recursos.
  • Ítems de un carrito de compras.

🧩 Relación con otros conceptos

  • <ul>: lista desordenada (padre).
  • <ol>: lista ordenada (padre).
  • <menu>: lista de comandos (padre, poco usado).
  • value: solo válido en <li> dentro de <ol>.
  • ::marker (CSS): pseudoelemento para estilizar viñetas/números.
  • list-style (CSS): controla el marcador.
  • <dl> / <dt> / <dd>: alternativa para listas de definiciones.
  • Accesibilidad: lectores de pantalla anuncian posición en <ol>.
  • role="listitem": rol ARIA implícito.

🧠 Analogía

Un <li> es como una línea de una lista de compras: cada ítem es una entrada independiente. Puedes tener una lista de frutas (con viñetas) o una receta (numerada), pero en ambos casos cada línea es un <li>.

📝 Notas personales

  • Solo válido dentro de <ul>, <ol> o <menu>.
  • El cierre </li> es opcional si el siguiente elemento es otro <li>, pero se recomienda escribirlo.
  • value solo funciona en <ol>: cambia el número del ítem y de los siguientes.
  • Para estilizar viñetas, usa ::marker o ::before.
  • Las sublistas van dentro del <li>, nunca directamente dentro del <ul>/<ol>.
  • Para menús, el patrón típico es <ul> → <li> → <a>.
  • En Safari, list-style: none elimina la semántica de lista; añade role="list" al padre.
  • Puedes poner varios párrafos o bloques dentro de un <li> si es necesario.
  • Los lectores de pantalla anuncian "elemento X de N" en listas ordenadas: muy útil para procesos.
  • No abuses: si no es una lista real, no uses <li>.
