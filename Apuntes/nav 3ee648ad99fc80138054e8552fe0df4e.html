<nav>

📄 <nav>

📝 Definición

<nav> (del inglés navigation, "navegación") es un elemento semántico de HTML5 que representa una sección de navegación compuesta por enlaces.

Agrupa los enlaces principales o secundarios de un sitio o documento.

🧠 ¿Qué es?

Es un elemento de bloque y semántico.

Se usa para envolver bloques de enlaces de navegación: menús principales, menús laterales, migas de pan, paginación, índices, etc. 

No todos los enlaces van en <nav>: solo los que forman bloques de navegación.

🎯 ¿Para qué sirve?

  • Agrupar enlaces de navegación principal del sitio.
  • Menús laterales o secundarios.
  • Migas de pan (breadcrumbs).
  • Paginación de listados.
  • Índices o tablas de contenido.
  • Aportar semántica: indica al navegador y a lectores de pantalla que es navegación.
  • Mejorar accesibilidad: los lectores de pantalla pueden saltar directo al <nav>.
  • Mejorar SEO: los buscadores identifican los enlaces de navegación.

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como bloque (sin estilos visuales por defecto).
  1. Puede haber varios <nav> en una página (principal, secundario, footer, breadcrumbs).
  1. Suele contener una lista <ul> con <li> y <a>.
  1. No es obligatorio envolver todos los enlaces: solo los bloques de navegación.
  1. Los lectores de pantalla lo anuncian como "navigation" si tiene etiqueta.
  1. Se recomienda añadir aria-label para diferenciar varios <nav>.

📝 Sintaxis / Estructura

<nav>
  <ul>
    <li><a href="/">Inicio</a></li>
    <li><a href="/blog">Blog</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>

💡 Ejemplos

Navegación principal:

<nav aria-label="Navegación principal">
  <ul>
    <li><a href="/">Inicio</a></li>
    <li><a href="/blog">Blog</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>

Dentro del header:

<header>
  <h1>Mi sitio</h1>
  <nav aria-label="Principal">
    <ul>
      <li><a href="/">Inicio</a></li>
      <li><a href="/blog">Blog</a></li>
    </ul>
  </nav>
</header>

Migas de pan (breadcrumbs):

<nav aria-label="Ruta de navegación">
  <ol>
    <li><a href="/">Inicio</a></li>
    <li><a href="/productos">Productos</a></li>
    <li aria-current="page">Zapatillas rojas</li>
  </ol>
</nav>

Paginación:

<nav aria-label="Paginación">
  <ul>
    <li><a href="?page=1">1</a></li>
    <li><a href="?page=2">2</a></li>
    <li><a href="?page=3" aria-current="page">3</a></li>
  </ul>
</nav>

Navegación secundaria en footer:

<footer>
  <nav aria-label="Enlaces legales">
    <ul>
      <li><a href="/aviso-legal">Aviso legal</a></li>
      <li><a href="/privacidad">Privacidad</a></li>
    </ul>
  </nav>
</footer>

Índice de contenido:

<nav aria-label="Índice">
  <h2>Contenido</h2>
  <ol>
    <li><a href="#intro">Introducción</a></li>
    <li><a href="#etiquetas">Etiquetas básicas</a></li>
    <li><a href="#formularios">Formularios</a></li>
  </ol>
</nav>

Con estilos CSS:

<nav class="principal" aria-label="Principal">
  <ul>
    <li><a href="/">Inicio</a></li>
    <li><a href="/blog">Blog</a></li>
  </ul>
</nav>
nav.principal ul {
  list-style: none;
  display: flex;
  gap: 1.5rem;
  padding: 0;
  margin: 0;
}
nav.principal a {
  text-decoration: none;
  color: #333;
}
nav.principal a:hover {
  color: #007bff;
}

⚠️ Errores comunes

  • ❌ Usar <nav> para cualquier grupo de enlaces (no todos son navegación).
  • ❌ Usar <nav> para un enlace suelto.
  • ❌ No usar aria-label cuando hay varios <nav> (se confunden).
  • ❌ Usar <nav> para navegación de contenido (mejor <ul> normal).
  • ❌ Anidar <nav> dentro de otro <nav> sin sentido.
  • ❌ Ponerlo dentro de <p> (inválido).
  • ❌ Usarlo como contenedor genérico (para eso <div>).
  • ❌ No usar listas (<ul>/<ol>) dentro: los lectores de pantalla cuentan los ítems.
  • ❌ Usar <nav> solo por estilos (para eso <div> con class).
  • ❌ Olvidar aria-current="page" en el enlace actual.

💼 Casos de uso

  • Navegación principal de un sitio.
  • Menús secundarios o laterales.
  • Migas de pan (breadcrumbs).
  • Paginación de listados.
  • Índices o tablas de contenido.
  • Navegación de secciones en documentación.
  • Enlaces legales en el footer.
  • Navegación entre pasos de un formulario wizard.
  • Menús de usuario (perfil, ajustes, cerrar sesión).

🧩 Relación con otros conceptos

  • <header>: suele contener el <nav> principal.
  • <footer>: suele contener <nav> secundario (legales, redes).
  • <ul> / <ol>: estructura típica del <nav>.
  • <a>: enlaces dentro del <nav>.
  • <aside>: puede contener un <nav> secundario.
  • <main>: el <nav> principal no va dentro del main.
  • role="navigation": rol ARIA implícito.
  • aria-label / aria-labelledby: etiqueta accesible (muy recomendado).
  • aria-current="page": marca el enlace actual.
  • CSS: display: flex, grid, list-style: none.
  • Accesibilidad: los lectores de pantalla anuncian "navigation".

🧠 Analogía

Un <nav> es como el índice o el menú de un libro: agrupa los enlaces a las secciones principales. No todos los enlaces del libro están en el índice (solo los importantes), y puede haber varios (índice general, índice de figuras, etc.).

📝 Notas personales

  • No todos los enlaces van en <nav>: solo los bloques de navegación.
  • Puede haber varios <nav> en una página (principal, breadcrumbs, footer).
  • Usa aria-label cuando hay varios para diferenciarlos.
  • Usa <ul> o <ol> dentro para que los lectores de pantalla cuenten los ítems.
  • Marca el enlace actual con aria-current="page".
  • En CSS, quita las viñetas con list-style: none.
  • Los lectores de pantalla lo anuncian como "navigation".
  • Pregunta clave: "¿Este bloque es para navegar entre páginas o secciones?" → Sí = <nav>.
  • Si es un grupo de enlaces relacionados (no navegación) → <ul> normal.
  • En frameworks (React, Vue), <nav> es un componente más.
