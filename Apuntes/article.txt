# **📄 `<article>`**

## **📝 Definición**

`<article>` 

Es un elemento **semántico** de HTML5 que representa un **contenido autónomo e independiente**, que puede distribuirse o reutilizarse por sí solo sin perder sentido (un post de blog, una noticia, un comentario, una tarjeta de producto, etc.).

## **🧠 ¿Qué es?**

Es un elemento de **bloque** y **semántico**. 

Su contenido debe tener sentido **por sí mismo**, incluso si se saca de la página y se muestra en otro contexto (RSS, redes sociales, sindicación). 

Puede contener sus propios encabezados, secciones y pies.

## **🎯 ¿Para qué sirve?**

- **Agrupar contenido autónomo** (posts, noticias, comentarios).
- **Facilitar la sindicación**: RSS, AMP, redes sociales.
- **Mejorar accesibilidad**: los lectores de pantalla pueden navegar por artículos.
- **Aportar semántica**: diferencia contenido reutilizable de contenido de estructura.
- **Mejorar SEO**: los buscadores identifican contenido principal.
- **Organizar visualmente** con CSS (grid, flexbox).

## **⚙️ ¿Cómo funciona?**

1. El navegador lo renderiza como **bloque** (sin estilos visuales por defecto).
2. **Debe tener un encabezado** (`<h1>`–`<h6>`) como primer hijo recomendado.
3. Puede contener `<header>`, `<footer>`, `<section>`, `<p>`, `<ul>`, etc.
4. Puede **anidarse**: un `<article>` (post) puede contener otros `<article>` (comentarios).
5. Los lectores de pantalla lo anuncian como **"article"** si tiene etiqueta.

## **📝 Sintaxis / Estructura**

```html
<article>
  <header>
    <h2>Título del artículo</h2>
    <p>Por Autor · Fecha</p>
  </header>
  <p>Contenido del artículo...</p>
  <footer>
    <p>Etiquetas: HTML, CSS</p>
  </footer>
</article>
```

## **💡 Ejemplos**

**Post de blog:**

```html
<article>
  <header>
    <h2>Cómo aprender HTML en 30 días</h2>
    <p>Por <strong>Ana Pérez</strong> · <time datetime="2026-10-02">2 de octubre de 2026</time></p>
  </header>
  <p>HTML es el lenguaje base de la web...</p>
  <footer>
    <p>Etiquetas: <a href="/tag/html">HTML</a>, <a href="/tag/web">Web</a></p>
  </footer>
</article>
```

**Artículo con secciones:**

```html
<article>
  <h1>Guía completa de HTML5</h1>
  <section>
    <h2>Introducción</h2>
    <p>...</p>
  </section>
  <section>
    <h2>Etiquetas básicas</h2>
    <p>...</p>
  </section>
</article>
```

**Comentarios anidados:**

```html
<article>
  <h2>Post principal</h2>
  <p>Contenido...</p>

  <section>
    <h3>Comentarios</h3>
    <article>
      <h4>Ana dijo:</h4>
      <p>¡Muy buen artículo!</p>
    </article>
    <article>
      <h4>Luis dijo:</h4>
      <p>Gracias por compartir.</p>
    </article>
  </section>
</article>
```

**Tarjeta de producto:**

```html
<article class="producto">
  <img src="producto.jpg" alt="Zapatillas rojas">
  <h3>Zapatillas rojas</h3>
  <p class="precio">59,99 €</p>
  <button>Añadir al carrito</button>
</article>
```

**Con estilos CSS:**

```html
<article class="post">
  <h2>Título</h2>
  <p>Contenido...</p>
</article>
```

```css
article.post {
  background: #fff;
  padding: 1.5rem;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
  margin-bottom: 2rem;
}
```

## **⚠️ Errores comunes**

- ❌ Usarlo como **contenedor genérico** (para eso `<div>`).
- ❌ Usarlo **sin encabezado** cuando el contenido es autónomo.
- ❌ Usar `<article>` para **contenido que no es reutilizable** (para eso `<section>`).
- ❌ Confundirlo con `<section>` (temático) o `<div>` (sin semántica).
- ❌ Anidar `<article>` dentro de `<p>` (inválido).
- ❌ Usar `<article>` solo por **estilos** (para eso `<div>` con class).
- ❌ No aportar `aria-label` cuando no hay encabezado visible.
- ❌ Abusar: si todo es `<article>`, pierde sentido.
- ❌ Usarlo para contenido que **depende del contexto** para entenderse.

## **💼 Casos de uso**

- **Posts de blog** o noticias.
- **Comentarios** en un foro o red social.
- **Tarjetas de producto** en e-commerce.
- **Resultados de búsqueda**.
- **Widgets** independientes (clima, cotizaciones).
- **Publicaciones de redes sociales**.
- **Artículos de documentación**.
- **Testimonios** o reseñas.
- **Entradas de un glosario** o wiki.

## **🧩 Relación con otros conceptos**

- **`<section>`**: agrupación temática (puede ir dentro de `<article>`).
- **`<div>`**: contenedor genérico sin semántica.
- **`<main>`**: contenido principal del documento (suele contener `<article>`).
- **`<aside>`**: contenido lateral relacionado.
- **`<header>` / `<footer>`**: pueden ir dentro de un `<article>`.
- **`<h1>`–`<h6>`**: encabezado del artículo (recomendado).
- **`<time>`**: fecha de publicación.
- **`aria-labelledby`**: etiqueta accesible para lectores de pantalla.
- **CSS**: `display: grid`, `flex`, `padding`, `margin`, `box-shadow`.
- **Accesibilidad**: lectores de pantalla anuncian "article" si tiene etiqueta.

## **🧠 Analogía**

Un `<article>` es como un **artículo de periódico**: tiene título, autor, fecha, cuerpo y quizá un pie. Si lo recortas y lo pegas en otro periódico, **sigue teniendo sentido por sí solo**. En cambio, una `<section>` sería como un capítulo de un libro: solo tiene sentido dentro de la obra completa.

## **📝 Notas personales**

- **Contenido autónomo**: si se puede sindicar o reutilizar solo → `<article>`.
- **Debe tener un encabezado** (`<h1>`–`<h6>`), salvo casos excepcionales.
- Se puede **anidar**: comentarios dentro de un post, por ejemplo.
- **Diferencia clave**: `<article>` es autónomo; `<section>` es temático.
- Si el contenido **depende del contexto** para entenderse → `<section>`.
- Si no tiene **significado semántico** → `<div>`.
- Para **accesibilidad**, añade `aria-labelledby` apuntando al `id` del encabezado.
- En CSS, `<article>` no tiene estilos por defecto (solo `display: block`).
- **Pregunta clave**: "¿Este contenido tendría sentido si lo saco de la página?" → Sí = `<article>`.
- En frameworks (React, Vue), `<article>` es un componente más.
