<ol>

📄 <ol>

📝 Definición

<ol> (del inglés ordered list, "lista ordenada") es el elemento que crea una lista con orden jerárquico o secuencial en HTML.

Sus ítems se muestran numerados por defecto (1, 2, 3…), y el orden de los elementos es relevante.

🧠 ¿Qué es?

Es un elemento de bloque que contiene ítems de lista (<li>) como hijos directos.

Se usa cuando el orden importa: pasos de una receta, instrucciones, rankings, procedimientos, etc.

🎯 ¿Para qué sirve?

  • Mostrar secuencias numeradas o alfabéticas.
  • Listar pasos de un proceso o tutorial.
  • Rankings (top 10, posiciones).
  • Instrucciones ordenadas.
  • Aportar semántica: indica que el orden es relevante, no solo texto numerado.
  • Facilitar accesibilidad: los lectores de pantalla anuncian "lista de N elementos, elemento 1 de N".

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como bloque con padding-left y números.
  1. Cada <li> dentro se muestra numerado (1, 2, 3…) por defecto.
  1. Los lectores de pantalla anuncian "lista ordenada" y la posición de cada ítem.
  1. Solo admite <li> como hijos directos en HTML válido (más <script> y <template>).
  1. Los estilos y el tipo de numeración se controlan con CSS (list-style-type).

📝 Sintaxis / Estructura

<ol>
  <li>Primer paso</li>
  <li>Segundo paso</li>
  <li>Tercer paso</li>
</ol>

💡 Ejemplos

Lista ordenada simple:

<ol>
  <li>Precalentar el horno a 180°C</li>
  <li>Mezclar los ingredientes</li>
  <li>Hornear durante 30 minutos</li>
</ol>

Con start y type:

<ol start="5" type="A">
  <li>Elemento E</li>
  <li>Elemento F</li>
  <li>Elemento G</li>
</ol>

Cuenta atrás con reversed:

<ol reversed>
  <li>3</li>
  <li>2</li>
  <li>1</li>
</ol>

Lista anidada:

<ol>
  <li>Preparar la masa
    <ol>
      <li>Mezclar harina y agua</li>
      <li>Amasar 10 minutos</li>
    </ol>
  </li>
  <li>Hornear</li>
</ol>

Con valor personalizado en un <li>:

<ol>
  <li>Primero</li>
  <li value="10">Décimo</li>
  <li>Undécimo</li>
</ol>

Con estilos CSS:

ol.pasos {
  list-style-type: decimal-leading-zero;
  counter-reset: paso;
}
ol.pasos li::marker {
  color: #007bff;
  font-weight: bold;
}

⚠️ Errores comunes

  • ❌ Poner contenido que no sea <li> directamente dentro.
  • ❌ Usar <ol> para listas donde el orden no importa (ahí va <ul>).
  • ❌ Usar type="1" cuando el valor por defecto ya es numérico.
  • ❌ Anidar <ol> fuera de un <li> (debe ir dentro).
  • ❌ Omitir <li> y separar ítems con <br>.
  • ❌ Usar list-style: none sin considerar accesibilidad (Safari elimina la semántica de lista).
  • ❌ Poner un <ol> vacío.
  • ❌ Confundir start (número inicial) con value (solo en <li>).
  • ❌ Usar <ol> para layouts de página.

💼 Casos de uso

  • Recetas de cocina (pasos ordenados).
  • Tutoriales y guías paso a paso.
  • Instrucciones de montaje o instalación.
  • Rankings (top 10, listas de posiciones).
  • Procedimientos legales o médicos.
  • Tablas de contenido numeradas.
  • Resultados deportivos o clasificaciones.
  • Pasos de un formulario (wizard).
  • Algoritmos o secuencias lógicas.

🧩 Relación con otros conceptos

  • <ul>: lista desordenada (con viñetas).
  • <li>: ítem de lista (hijo obligatorio).
  • <dl> / <dt> / <dd>: lista de definiciones.
  • start / reversed / type: atributos propios de <ol>.
  • value: atributo de <li> para cambiar su número.
  • CSS: list-style-type, counter-reset, counter-increment.
  • ::marker: pseudoelemento para estilizar números.
  • Accesibilidad: lectores de pantalla anuncian "elemento X de N".
  • <nav>: no suele usar <ol>, pero es válido para pasos.

🧠 Analogía

Un <ol> es como una receta de cocina: los pasos están numerados porque el orden importa. Si cambias el orden, el resultado cambia. En cambio, un <ul> sería como una lista de compras: el orden no afecta al resultado.

📝 Notas personales

  • Solo <li> como hijo directo (en HTML válido).
  • Usa <ol> solo si el orden importa: si no, <ul>.
  • type acepta: 1 (defecto), a, A, i, I.
  • start define el número inicial; reversed invierte la cuenta.
  • value en un <li> cambia su número y afecta a los siguientes.
  • En Safari, list-style: none elimina la semántica; añade role="list" para restaurarla.
  • Las listas anidadas van dentro de un <li>, no directamente dentro del <ol>.
  • Para numeración personalizada, usa CSS counters o ::marker.
  • No abuses: no conviertas todo en <ol> solo por los números.
  • Los lectores de pantalla anuncian "elemento 3 de 5": muy útil para procesos.
