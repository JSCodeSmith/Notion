<code>

📄 <code>

📝 Definición

<code> es el elemento que representa un fragmento de código informático en HTML.

Se usa para marcar texto que debe interpretarse como código fuente: nombres de variables, funciones, etiquetas, fragmentos de programas, etc.

🧠 ¿Qué es?

Es un elemento inline (en línea) y semántico.

Por defecto se renderiza con una fuente monoespaciada (como Courier o Consolas), pero su valor real es semántico: indica que el texto es código, no prosa normal.

🎯 ¿Para qué sirve?

  • Marcar código dentro de un texto.
  • Distinguir nombres de variables, funciones o etiquetas.
  • Aportar semántica: indica al navegador y a lectores de pantalla que es código.
  • Aplicar estilos con fuente monoespaciada.
  • Mejorar accesibilidad: los lectores de pantalla pueden cambiar la entonación.
  • Facilitar la copia de fragmentos por el usuario.

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza con fuente monoespaciada por defecto (font-family: monospace).
  1. No conserva espacios ni saltos de línea (a diferencia de <pre>).
  1. Es un elemento inline: no genera saltos de línea.
  1. Se puede combinar con <pre> para bloques de código con formato.
  1. Los lectores de pantalla lo anuncian como "código".

📝 Sintaxis / Estructura

<code>fragmento de código</code>

💡 Ejemplos

Código inline en un párrafo:

<p>Para declarar una variable en JavaScript, usa <code>let</code> o <code>const</code>.</p>

Nombre de etiqueta HTML:

<p>La etiqueta <code>&lt;p&gt;</code> define un párrafo.</p>

Nombre de función o variable:

<p>La función <code>saludar()</code> devuelve un saludo.</p>

Bloque de código con <pre>:

<pre><code>
function saludar(nombre) {
  return `Hola, ${nombre}`;
}
</code></pre>

Con resaltado de sintaxis (usando clases):

<pre><code class="language-javascript">
const x = 10;
console.log(x);
</code></pre>
code.language-javascript {
  color: #333;
  background: #f5f5f5;
}

Con estilos CSS personalizados:

<p>Usa <code class="inline">npm install</code> para instalar.</p>
code.inline {
  background: #f4f4f4;
  padding: 0.2em 0.4em;
  border-radius: 4px;
  font-family: 'Fira Code', monospace;
  font-size: 0.9em;
  color: #c7254e;
}

Escapando caracteres especiales:

<p>Para escribir un párrafo usa <code>&lt;p&gt;texto&lt;/p&gt;</code>.</p>

⚠️ Errores comunes

  • ❌ Usarlo para texto normal que no es código.
  • ❌ Esperar que conserve espacios y saltos: para eso usa <pre>.
  • ❌ Usarlo para bloques de código sin <pre> → se colapsan los espacios.
  • ❌ No escapar caracteres especiales (<, >, &) → rompe el HTML.
  • ❌ Usarlo para estilos visuales sin semántica de código (mejor CSS).
  • ❌ Anidar <code> dentro de otro <code> (redundante).
  • ❌ Usarlo en títulos (<h1>–<h6>) sin necesidad.
  • ❌ Olvidar que la fuente monoespaciada no es legible para textos largos.
  • ❌ Usar <code> para nombres de archivos sin contexto de código.

💼 Casos de uso

  • Documentación técnica con fragmentos de código.
  • Tutoriales de programación.
  • Nombres de etiquetas HTML (<code>&lt;div&gt;</code>).
  • Nombres de variables o funciones.
  • Comandos de terminal (<code>npm install</code>).
  • Nombres de archivos o rutas.
  • Atajos de teclado (aunque <kbd> es más apropiado).
  • Respuestas en foros de programación (Stack Overflow).
  • Blogs técnicos con ejemplos de código.

🧩 Relación con otros conceptos

  • <pre>: preserva espacios y saltos (se combina con <code>).
  • <kbd>: entrada de teclado (teclas).
  • <samp>: salida de un programa.
  • <var>: variables matemáticas o de programación.
  • <tt>: obsoleto, equivalente visual a <code>.
  • <pre><code>: patrón clásico para bloques de código.
  • Resaltado de sintaxis: Prism.js, Highlight.js, Shiki.
  • CSS: font-family: monospace, background, padding, border-radius.
  • Accesibilidad: lectores de pantalla lo anuncian como "código".

🧠 Analogía

<code> es como resaltar con un marcador gris un fragmento de código en un libro de texto: no cambia el significado de la frase, pero indica "esto es código, no prosa". Para bloques enteros, combinas el marcador con una caja (<pre>).

📝 Notas personales

  • Inline: no genera saltos de línea.
  • No conserva espacios: para eso <pre>.
  • Patrón clásico: <pre><code>...</code></pre> para bloques.
  • Escapa <, >, & como &lt;, &gt;, &amp;.
  • Fuente monoespaciada por defecto, se puede cambiar con CSS.
  • Resaltado de sintaxis: usa Prism.js, Highlight.js o Shiki con class="language-xxx".
  • Para teclas usa <kbd>; para salida de programa, <samp>; para variables, <var>.
  • No abuses: úsalo solo cuando el texto sea realmente código.
  • Buena práctica: añade class con el lenguaje para resaltado automático.
  • En frameworks (React, Vue), <code> es un componente más.
