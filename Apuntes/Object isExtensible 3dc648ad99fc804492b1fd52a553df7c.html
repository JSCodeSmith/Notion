Object.isExtensible

Object.isExtensible()

📄 Título

Object.isExtensible()

📝 Definición

Object.isExtensible()

Es un método estático de Object que determina si un objeto puede recibir nuevas propiedades.

🧠 ¿Qué es?

Es una herramienta que permite comprobar si un objeto es extensible.

En otras palabras, pregunta:

“¿A este objeto todavía se le pueden agregar nuevas propiedades?”

Devuelve únicamente:

true  → sí puede extenderse
false → no puede extenderse

🎯 ¿Para qué sirve?

Sirve para:

  • 🔍 Comprobar si un objeto permite nuevas propiedades.
  • 🛡️ Verificar restricciones aplicadas a un objeto.
  • 🧩 Comprobar el efecto de Object.preventExtensions().
  • 🔒 Detectar si un objeto fue sellado o congelado.
  • 🧪 Validar el estado de un objeto antes de modificarlo.

⚙️ ¿Cómo funciona?

Un objeto normal es extensible:

const usuario= {
    nombre:"Josué"
};
console.log(Object.isExtensible(usuario));

Resultado:

true

Después podemos impedir que se agreguen nuevas propiedades:

Object.preventExtensions(usuario);
console.log(Object.isExtensible(usuario));

Resultado:

false

Por lo tanto:

Objeto normal
    ↓
extensible
    ↓
true

Object.preventExtensions()
    ↓
no extensible
    ↓
false

📝 Sintaxis / Estructura

Object.isExtensible(obj)

Parámetro

obj

El objeto que quieres comprobar.

Retorno

Devuelve un valor booleano:

true

si el objeto es extensible.

false

si el objeto no es extensible.

💡 Ejemplos

1. Objeto extensible

const persona= {
    nombre:"Josué"
};
console.log(Object.isExtensible(persona));

Resultado:

true

2. Después de Object.preventExtensions()

const persona= {
    nombre:"Josué"
};
Object.preventExtensions(persona);
console.log(Object.isExtensible(persona));

Resultado:

false

3. Con Object.seal()

Un objeto sellado tampoco es extensible:

const persona= {
    nombre:"Josué"
};
Object.seal(persona);
console.log(Object.isExtensible(persona));

Resultado:

false

4. Con Object.freeze()

Un objeto congelado tampoco es extensible:

const persona= {
    nombre:"Josué"
};
Object.freeze(persona);
console.log(Object.isExtensible(persona));

Resultado:

false

Por eso:

preventExtensions() → false
seal()              → false
freeze()            → false

⚠️ Errores comunes

Confundir extensible con modificable

Que un objeto sea:

Object.isExtensible(obj)===false

no significa necesariamente que sus propiedades existentes no puedan modificarse.

Por ejemplo:

const persona= {
    nombre:"Josué"
};
Object.preventExtensions(persona);
persona.nombre="Juan";
console.log(persona.nombre);

Resultado:

Juan

El objeto no acepta propiedades nuevas, pero todavía puede modificar propiedades existentes.

Confundirlo con Object.isFrozen()

Object.isExtensible() pregunta:

¿Puede recibir nuevas propiedades?

Mientras:

Object.isFrozen(obj)

pregunta si el objeto está congelado.

Son preguntas diferentes.

💼 Casos de uso

  • Comprobar el estado de un objeto antes de modificarlo.
  • Validar objetos recibidos por una función.
  • Detectar si un objeto fue restringido.
  • Trabajar junto con preventExtensions(), seal() y freeze().
  • Depuración de estructuras de objetos.

Object.preventExtensions(obj);

Uno restringe y el otro comprueba.

Y responde:

true  → sí
