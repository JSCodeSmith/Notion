.format(valor)

😊 formateador.format(valor)

📝 Definición

.format() 

Es el método principal de los objetos de la API de Internacionalización (Intl) que convierte un valor (número, fecha, etc.) en un string formateado según una configuración regional (locale) y opciones específicas.

formateador.format(valor)

🧠 ¿Qué es?

Es el método que produce el resultado final de cualquier formateador Intl.

Cada formateador (NumberFormat, DateTimeFormat, RelativeTimeFormat, ListFormat, etc.) tiene su propio .format(), pero todos comparten la misma idea: 

Reciben un valor y devuelven un string listo para mostrar al usuario, respetando su idioma, moneda, formato de fecha, etc.

🎯 ¿Para qué sirve?

  • 🌍 Formatear números según el locale (1.234,56 vs 1,234.56).
  • 💰 Mostrar monedas con símbolo y decimales correctos.
  • 📅 Formatear fechas en el formato local (dd/mm/aaaa vs mm/dd/yyyy).
  • ⏰ Formatear horas (12h vs 24h).
  • 📊 Porcentajes, unidades, notación científica.
  • 🗣️ Tiempo relativo ("hace 2 días").
  • 📋 Listas ("A, B y C" vs "A, B, and C").
  • 🎯 Comparar y ordenar strings localizados.

⚙️ ¿Cómo funciona?

  1. Creas un formateador con new Intl.XxxFormat(locales, opciones).
  1. Llamas a .format(valor) con el valor a formatear.
  1. El método aplica las reglas del locale y las opciones.
  1. Devuelve un string listo para mostrar.
  1. Puedes reutilizar el formateador muchas veces (es eficiente).
  1. También existe .formatToParts() que devuelve un array con las partes (útil para estilos personalizados).

⚠️ Los formateadores no modifican el valor original; solo generan strings.

📝 Sintaxis / Estructura

const formateador = new Intl.TipoFormat(locales, opciones);
const resultado = formateador.format(valor);
ParteDescripción
Intl.TipoFormatNumberFormat, DateTimeFormat, RelativeTimeFormat, ListFormat, etc.
localesString o array (ej: "es-PE", ["es", "en"])
opcionesObjeto de configuración
.format(valor)Devuelve string formateado
.formatToParts(valor)Devuelve array de partes

🔸 Formateadores con .format()

FormateadorFormatea

💡 Ejemplos

🔹 Ejemplo 1: Intl.NumberFormat — números

const nf = new Intl.NumberFormat("es-PE");
console.log(nf.format(1234567.89)); // "1,234,567.89"

const nfDe = new Intl.NumberFormat("de-DE");
console.log(nfDe.format(1234567.89)); // "1.234.567,89"

🔹 Ejemplo 2: Monedas

const precio = new Intl.NumberFormat("es-PE", {
  style: "currency",
  currency: "PEN"
});
console.log(precio.format(1234.5)); // "S/ 1,234.50"

const usd = new Intl.NumberFormat("en-US", {
  style: "currency",
  currency: "USD"
});
console.log(usd.format(1234.5)); // "$1,234.50"

🔹 Ejemplo 3: Porcentajes

const pct = new Intl.NumberFormat("es-ES", {
  style: "percent",
  minimumFractionDigits: 1
});
console.log(pct.format(0.256)); // "25,6 %"

🔹 Ejemplo 4: Intl.DateTimeFormat — fechas

const fecha = new Date("2026-09-10T15:30:00");

const df = new Intl.DateTimeFormat("es-PE", {
  dateStyle: "full",
  timeStyle: "short"
});
console.log(df.format(fecha)); // "jueves, 10 de septiembre de 2026, 15:30"

const dfEn = new Intl.DateTimeFormat("en-US");
console.log(dfEn.format(fecha)); // "9/10/2026"

🔹 Ejemplo 5: Intl.RelativeTimeFormat

const rtf = new Intl.RelativeTimeFormat("es", { numeric: "auto" });
console.log(rtf.format(-2, "day"));   // "anteayer"
console.log(rtf.format(1, "week"));   // "la próxima semana"
console.log(rtf.format(-5, "minute")); // "hace 5 minutos"

🔹 Ejemplo 6: Intl.ListFormat

const lf = new Intl.ListFormat("es", { style: "long", type: "conjunction" });
console.log(lf.format(["Ana", "Luis", "Pedro"])); // "Ana, Luis y Pedro"

const lfEn = new Intl.ListFormat("en", { type: "disjunction" });
console.log(lfEn.format(["rojo", "azul", "verde"])); // "rojo, azul, or verde"

🔹 Ejemplo 7: formatToParts()

const nf = new Intl.NumberFormat("es-PE", {
  style: "currency",
  currency: "PEN"
});
console.log(nf.formatToParts(1234.5));
// [
//   { type: "currency", value: "S/" },
//   { type: "literal", value: " " },
//   { type: "integer", value: "1" },
//   { type: "group", value: "," },
//   { type: "integer", value: "234" },
//   { type: "decimal", value: "." },
//   { type: "fraction", value: "50" }
// ]

🔹 Ejemplo 8: Reutilizar formateador (eficiente)

const nf = new Intl.NumberFormat("es-PE");

// ✅ Reutiliza el mismo formateador
[100, 2000, 30000].forEach(n => console.log(nf.format(n)));
// "100" / "2,000" / "30,000"

🔹 Ejemplo 9: Auto-detección del locale

const nf = new Intl.NumberFormat(); // usa el locale del navegador
console.log(nf.format(1234.56)); // según el sistema del usuario

🔹 Ejemplo 10: Múltiples locales (fallback)

const nf = new Intl.NumberFormat(["es-PE", "es", "en"]);
console.log(nf.format(1234.56));

⚠️ Errores comunes

ErrorExplicación
Crear formateador en cada llamada⚠️ Ineficiente; reutilízalo
Confundir format() con formatToParts()El primero da string; el segundo, array
Pasar valor incorrectoDateTimeFormat espera Date, no string
Olvidar style: "currency" para monedasSin eso, no muestra símbolo
Usar currency sin style❌ Ignorado
Esperar locale exacto⚠️ El navegador usa el mejor disponible
Confundir numeric: "auto" en RelativeTimeFormatSin eso, siempre da "hace 2 días" en vez de "anteayer"
Asumir soporte total⚠️ Algunos locales son limitados
Formatear null/undefined❌ NaN o error

❌ Ejemplos de errores

// ❌ Ineficiente: crea un formateador por cada número
[1, 2, 3].forEach(n => new Intl.NumberFormat("es").format(n));

// ✅ Correcto: reutiliza
const nf = new Intl.NumberFormat("es");
[1, 2, 3].forEach(n => nf.format(n));

// ❌ currency sin style
new Intl.NumberFormat("es", { currency: "EUR" }).format(10);
// "10" (sin símbolo)

// ✅ Correcto
new Intl.NumberFormat("es", { style: "currency", currency: "EUR" }).format(10);
// "10,00 €"

// ❌ DateTimeFormat con string
new Intl.DateTimeFormat("es").format("2026-09-10"); // ⚠️ error

// ✅ Correcto
new Intl.DateTimeFormat("es").format(new Date("2026-09-10"));

🔸 Verificar soporte de locale

Intl.NumberFormat.supportedLocalesOf(["es-PE", "xx-YY"]);
// ["es-PE"] → "xx-YY" no soportado

💼 Casos de uso

  • 💰 E-commerce: precios con moneda local.
  • 📊 Dashboards: números grandes con separadores.
  • 📅 Calendarios y agendas con formato local.
  • 🗣️ Redes sociales: "hace 5 minutos".
  • 🌍 Apps multi-idioma: formateo automático por locale.
  • 📈 Reportes financieros: porcentajes, monedas, decimales.
  • 📋 Listas de usuarios: "Ana, Luis y Pedro".
  • ⏰ Recordatorios: fechas relativas.
  • 🧾 Facturación: importes y fechas.
  • 🎯 Comparación de precios: ordenar con Intl.Collator.

🆚 Intl vs toLocaleString()

AspectoIntl.XxxFormattoLocaleString()
Rendimiento✅ Mejor (reutilizable)⚠️ Crea formateador cada vez
Control✅ Total⚠️ Limitado
Legibilidad✅ Clara⚠️ Parámetros confusos
formatToParts✅ Disponible❌ No
Recomendado✅ Sí⚠️ Solo casos simples

// ❌ Cada llamada crea un formateador interno
(1234.5).toLocaleString("es-PE", { style: "currency", currency: "PEN" });

// ✅ Reutilizable y más eficiente
const nf = new Intl.NumberFormat("es-PE", {
  style: "currency",
  currency: "PEN"
});
nf.format(1234.5);

🧠 Analogía

Imagina que .format() es un traductor profesional 🌐 que conoce las reglas de cada país.
  • Le das un número o una fecha en bruto.
  • Le dices para quién es (el locale: "es-PE", "en-US", "de-DE").
  • Le indicas cómo quieres el resultado (moneda, porcentaje, fecha larga, etc.).
  • Y él te devuelve el texto perfecto para ese público.

🎯 Lo mejor: puedes reutilizar al mismo traductor para muchos valores.

No lo contratas de nuevo cada vez (eso sería ineficiente).

Y si quieres ver cómo construyó la traducción → formatToParts() te da las piezas.
