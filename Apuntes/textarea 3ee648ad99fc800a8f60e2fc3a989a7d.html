<textarea>

📄 <textarea>

📝 Definición

<textarea> es el elemento que crea un campo de texto multilínea en HTML.

Permite al usuario escribir textos largos: comentarios, mensajes, descripciones, biografías, etc.

🧠 ¿Qué es?

Es un elemento inline-block y semántico que representa un control de formulario editable.

A diferencia de <input type="text">,

admite saltos de línea y tiene contenido propio (el texto inicial se escribe entre las etiquetas).

🎯 ¿Para qué sirve?

  • Escribir textos largos (comentarios, mensajes).
  • Recoger descripciones o biografías.
  • Formularios de contacto con mensaje.
  • Reseñas o valoraciones.
  • Código o texto preformateado (aunque <pre> es mejor para mostrar).
  • Aportar semántica: indica un campo multilínea.
  • Mejorar accesibilidad: los lectores de pantalla lo anuncian como "cuadro de texto multilínea".

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como una caja de texto con rows y cols.
  1. El texto inicial va entre las etiquetas (no en un atributo value).
  1. Se puede redimensionar con CSS (resize) o nativamente (esquina inferior derecha).
  1. Los saltos de línea se respetan al enviar (a diferencia de <input>).
  1. Los espacios y saltos se conservan en el valor enviado.
  1. Se controla con JavaScript (value, selectionStart, selectionEnd, etc.).

📝 Sintaxis / Estructura

<textarea name="mensaje" rows="4" cols="50">Texto inicial</textarea>

💡 Ejemplos

Textarea básico:

<label for="mensaje">Mensaje:</label>
<textarea id="mensaje" name="mensaje" rows="4" cols="50"></textarea>

Con placeholder:

<textarea
  name="comentario"
  rows="5"
  cols="40"
  placeholder="Escribe tu comentario aquí..."></textarea>

Con texto inicial:

<textarea name="biografia" rows="6" cols="50">
Ana Pérez es desarrolladora web con 10 años de experiencia.
</textarea>

Con validación:

<form action="/enviar" method="post">
  <label for="mensaje">Mensaje (10-500 caracteres):</label>
  <textarea
    id="mensaje"
    name="mensaje"
    rows="5"
    minlength="10"
    maxlength="500"
    required></textarea>
  <button type="submit">Enviar</button>
</form>

Con readonly (solo lectura):

<textarea name="codigo" rows="8" cols="60" readonly>
function saludar(nombre) {
  return `Hola, ${nombre}`;
}
</textarea>

Con wrap="hard" (envía saltos reales):

<textarea name="mensaje" rows="4" cols="40" wrap="hard"></textarea>

Con estilos CSS:

<textarea class="elegante" name="mensaje" rows="5"></textarea>
textarea.elegante {
  width: 100%;
  padding: 1rem;
  border: 1px solid #ccc;
  border-radius: 8px;
  font-family: inherit;
  font-size: 1rem;
  resize: vertical;
  min-height: 120px;
  max-height: 400px;
}
textarea.elegante:focus {
  outline: none;
  border-color: #007bff;
  box-shadow: 0 0 0 3px rgba(0,123,255,0.2);
}

Con contador de caracteres (JS):

<textarea id="mensaje" name="mensaje" maxlength="200" rows="4"></textarea>
<p><span id="contador">0</span> / 200</p>
<script>
  const ta = document.getElementById('mensaje');
  const contador = document.getElementById('contador');
  ta.addEventListener('input', () => {
    contador.textContent = ta.value.length;
  });
</script>

⚠️ Errores comunes

  • ❌ Olvidar name → no se envía el valor.
  • ❌ Olvidar label asociado con for → problema de accesibilidad.
  • ❌ Usar value="..." en el HTML → no funciona en <textarea> (el valor va entre las etiquetas).
  • ❌ Poner espacios o saltos de línea al inicio del contenido (se incluyen en el valor).
  • ❌ Usar rows/cols en lugar de CSS para dimensionar.
  • ❌ No limitar maxlength cuando el servidor tiene límite.
  • ❌ Usar <textarea> para una sola línea (mejor <input type="text">).
  • ❌ Olvidar resize en CSS → el usuario puede redimensionar y romper el layout.
  • ❌ No validar en el servidor (la validación nativa es solo del cliente).
  • ❌ Usar <textarea> para mostrar código (mejor <pre><code>).

💼 Casos de uso

  • Formularios de contacto con mensaje.
  • Comentarios en blogs o redes sociales.
  • Reseñas o valoraciones.
  • Biografías o "sobre mí".
  • Descripciones de productos.
  • Notas o recordatorios.
  • Mensajes en apps de mensajería.
  • Código editable (aunque con cuidado).

🧩 Relación con otros conceptos

  • <input type="text">: campo de una sola línea.
  • <input type="email">, <input type="password">, etc.: campos especializados.
  • <label>: etiqueta asociada al <textarea>.
  • <form>: contenedor del <textarea>.
  • <pre> / <code>: para mostrar texto preformateado (no editable).
  • contenteditable: alternativa para edición enriquecida.
  • rows / cols: dimensiones iniciales.
  • wrap: controla si se envían saltos de línea reales.
  • maxlength / minlength: validación de longitud.
  • CSS: resize, width, height, padding, border.
  • Accesibilidad: lectores de pantalla lo anuncian como "cuadro de texto multilínea".

🧠 Analogía

Un <textarea> es como una hoja en blanco en un formulario: puedes escribir varias líneas, párrafos completos. En cambio, un <input type="text"> sería como una línea única en un formulario: solo cabe una frase corta.

📝 Notas personales

  • value no funciona en <textarea>: el texto inicial va entre las etiquetas.
  • Cuidado con espacios/saltos al inicio: se incluyen en el valor.
  • rows y cols son solo dimensiones iniciales; usa CSS para controlar.
  • resize: vertical en CSS para permitir redimensionar solo en vertical.
  • maxlength para limitar caracteres (también valida en el servidor).
  • placeholder no sustituye a un label visible.
  • wrap="hard" para enviar saltos de línea reales al servidor.
  • No uses <textarea> para mostrar código: usa <pre><code>.
  • readonly permite copiar pero no editar; disabled no se envía.
  • Contador de caracteres con JS: input event + value.length.
  • En frameworks (React, Vue), usa componentes controlados con value y onChange.
