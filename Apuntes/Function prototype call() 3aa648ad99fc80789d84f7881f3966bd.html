Function.prototype.call()

📄 Título

Function.prototype.call() en JavaScript

📝 Definición

  • call() es un método de Function.prototype que permite invocar una función inmediatamente, especificando explícitamente el valor de this y pasando los argumentos uno por uno.

🧠 ¿Qué es?

  • Es un método heredado de Function.prototype.
  • Sí forma parte del lenguaje JavaScript (ECMAScript), no de una Web API.
  • Permite controlar el contexto (this) con el que se ejecuta una función.

🎯 ¿Para qué sirve?

Se utiliza para:

  • Cambiar el valor de this al ejecutar una función.
  • Reutilizar métodos entre distintos objetos.
  • Invocar funciones con un contexto específico.
  • Implementar herencia o composición en algunos patrones de JavaScript.

⚙️ ¿Cómo funciona?

  1. Se tiene una función.
  1. Se llama al método call().
  1. El primer argumento indica cuál será el valor de this.
  1. Los demás argumentos se pasan a la función de forma individual.
  1. La función se ejecuta inmediatamente.

📝 Sintaxis / Estructura

funcion.call(thisArg,arg1,arg2, ...,argN);

Parámetros

ParámetroDescripción
thisArgObjeto que será el valor de this durante la ejecución.
arg1...argNArgumentos que recibe la función, separados por comas.

Valor de retorno

Devuelve el mismo valor que retorna la función ejecutada.

💡 Ejemplos

Cambiar el valor de this

function saludar() {
		console.log(`Hola, soy${this.nombre}`);
}
const persona= {
    nombre:"Josué"
};
saludar.call(persona);

Resultado:

Hola, soy Josué

Si thisArg es null

function mostrar() {
	console.log(this);
}
mostrar.call(null);
  • En modo no estricto (non-strict), this será el objeto global (window en navegadores).
  • En modo estricto ("use strict"), this será null.

⚠️ Errores comunes

❌ Confundir call() con apply()

funcion.call(objeto,1,2,3);

call() recibe los argumentos uno por uno.

Mientras que:

funcion.apply(objeto, [1,2,3]);

apply() los recibe dentro de un array.

❌ Pensar que cambia permanentemente this

saludar.call(persona);

call() solo cambia this durante esa ejecución.

❌ Usarlo sobre algo que no es una función

const numero=10;
numero.call();

Esto produce un error porque call() solo existe en funciones.

💼 Casos de uso

  • Reutilizar métodos entre objetos.
  • Controlar explícitamente el valor de this.
  • Invocar funciones con un contexto diferente.
  • Compatibilidad con código antiguo.
  • Algunos patrones avanzados de programación orientada a objetos.

🧩 Relación con otros conceptos

  • this → call() permite establecer su valor.
  • apply() → Similar a call(), pero recibe un array de argumentos.
  • bind() → Crea una nueva función con this fijo, pero no la ejecuta inmediatamente.
  • Function.prototype → call() está definido en este prototipo.
  • Métodos y funciones → Puede utilizarse para compartir métodos entre objetos.

🧠 Analogía

Imagina que un profesor normalmente da clase en un salón.

Con call() es como decirle:

"Hoy vas a dar la misma clase, pero en este otro salón."
  • La clase (función) es la misma.
  • El salón (this) cambia temporalmente.
  • Al terminar, todo vuelve a la normalidad.
