<option>

📄 <option>

📝 Definición

<option> es el elemento que define una opción individual dentro de un <select>, <optgroup> o <datalist>.

Representa cada una de las elecciones posibles que el usuario puede seleccionar.

🧠 ¿Qué es?

Es un elemento contenedor de texto que vive obligatoriamente dentro de un <select>, <optgroup> o <datalist>.

Su texto visible es lo que ve el usuario; su atributo value es lo que se envía al formulario.

🎯 ¿Para qué sirve?

  • Definir una opción seleccionable en una lista.
  • Aportar el valor que se enviará al formulario.
  • Preseleccionar una opción con selected.
  • Deshabilitar opciones no disponibles.
  • Agrupar opciones bajo un <optgroup>.
  • Servir de sugerencia en un <datalist>.

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como una opción dentro del menú desplegable.
  1. Al seleccionarla, el <select> toma su value (o su texto si no hay value).
  1. Si tiene selected, aparece preseleccionada.
  1. Si tiene disabled, no se puede elegir.
  1. En <datalist>, aparece como sugerencia mientras el usuario escribe.
  1. No se puede usar fuera de <select>, <optgroup> o <datalist>.

📝 Sintaxis / Estructura

<option value="valor">Texto visible</option>

💡 Ejemplos

Opción básica:

<select name="pais">
  <option value="es">España</option>
  <option value="mx">México</option>
  <option value="ar">Argentina</option>
</select>

Con opción preseleccionada:

<select name="pais">
  <option value="es">España</option>
  <option value="mx" selected>México</option>
  <option value="ar">Argentina</option>
</select>

Con opción por defecto (placeholder):

<select name="pais" required>
  <option value="" disabled selected>-- Elige un país --</option>
  <option value="es">España</option>
  <option value="mx">México</option>
</select>

Con opciones deshabilitadas:

<select name="plan">
  <option value="basico">Básico</option>
  <option value="pro" disabled>Pro (agotado)</option>
  <option value="premium">Premium</option>
</select>

Dentro de <optgroup>:

<select name="ciudad">
  <optgroup label="Europa">
    <option value="mad">Madrid</option>
    <option value="par">París</option>
  </optgroup>
  <optgroup label="América">
    <option value="mex">Ciudad de México</option>
    <option value="bue">Buenos Aires</option>
  </optgroup>
</select>

Sin value (se envía el texto):

<select name="color">
  <option>Rojo</option>
  <option>Verde</option>
  <option>Azul</option>
</select>
<!-- Se envía color=Rojo, color=Verde, etc. -->

Dentro de <datalist>:

<label for="lenguaje">Lenguaje favorito:</label>
<input list="lenguajes" id="lenguaje" name="lenguaje">
<datalist id="lenguajes">
  <option value="HTML">
  <option value="CSS">
  <option value="JavaScript">
  <option value="Python">
</datalist>

Con estilos CSS (limitado):

option {
  background: #fff;
  color: #333;
  padding: 0.5rem;
}
option:disabled {
  color: #999;
}
Nota: los estilos de <option> están muy limitados por el navegador/SO.

⚠️ Errores comunes

  • ❌ Usar <option> fuera de <select>, <optgroup> o <datalist> (inválido).
  • ❌ Olvidar value cuando el texto visible no es el valor deseado.
  • ❌ Usar selected en varias opciones de un <select> sin multiple (solo la última cuenta).
  • ❌ Poner value="" en una opción válida (confunde con placeholder).
  • ❌ Usar <option> como botón o enlace.
  • ❌ Anidar <option> dentro de otro <option>.
  • ❌ Esperar estilos CSS completos: los navegadores limitan mucho.
  • ❌ Olvidar disabled en el placeholder con required.
  • ❌ Usar <option> con contenido HTML complejo (solo texto plano).
  • ❌ Confundir <option> con <optgroup> (agrupador).

💼 Casos de uso

  • Selección de país, ciudad, idioma.
  • Tallas, colores, cantidades.
  • Categorías en filtros.
  • Fechas (día, mes, año).
  • Planes o suscripciones.
  • Sugerencias en <datalist>.
  • Ordenación de listados.
  • Configuración de perfil.

🧩 Relación con otros conceptos

  • <select>: contenedor principal de <option>.
  • <optgroup>: agrupa <option> relacionadas.
  • <datalist>: contiene <option> como sugerencias.
  • <input list>: se asocia con <datalist>.
  • selected: preselecciona una opción.
  • disabled: deshabilita una opción.
  • value: valor enviado al formulario.
  • <label>: etiqueta del <select> (no de la <option>).
  • CSS: estilos muy limitados en <option>.
  • Accesibilidad: lectores de pantalla leen el texto de la opción.

🧠 Analogía

Una <option> es como una línea del menú de un restaurante: cada plato es una opción. Puedes elegir una (o varias con multiple), y el camarero (formulario) anota lo que pediste (value). Si un plato está agotado, lo marcas como disabled.

📝 Notas personales

  • Solo válido dentro de <select>, <optgroup> o <datalist>.
  • value es lo que se envía; si falta, se envía el texto visible.
  • selected preselecciona; solo una opción por <select> (sin multiple).
  • disabled deshabilita la opción (no se puede elegir).
  • Placeholder: <option value="" disabled selected>-- Elige --</option>.
  • Estilos CSS muy limitados: los navegadores controlan la apariencia.
  • No HTML complejo: solo texto plano dentro de <option>.
  • En <datalist>, las <option> son sugerencias mientras el usuario escribe.
  • Buena práctica: siempre incluye value explícito cuando el valor difiera del texto.
  • En frameworks (React, Vue), las <option> se generan normalmente con .map().
