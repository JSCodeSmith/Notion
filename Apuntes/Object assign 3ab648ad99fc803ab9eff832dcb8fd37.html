Object.assign

📄 Título

Object.assign() en JavaScript

📝 Definición

  • Object.assign() es un método estático del objeto global Object que permite copiar propiedades de uno o varios objetos origen hacia un objeto destino.
  • Devuelve el objeto destino después de haber recibido las propiedades copiadas.

🧠 ¿Qué es?

  • Es un método estático de Object.
  • Forma parte del lenguaje JavaScript (ECMAScript), no de una Web API.
  • Se utiliza principalmente para:
    • Copiar objetos.
    • Combinar objetos (merge).
    • Actualizar propiedades existentes.

Ejemplo:

const destino= {
    nombre:"Ana"
};
const origen= {
    edad:20
};
Object.assign(destino,origen);
console.log(destino);

Resultado:

{nombre:"Ana",edad:20}

🎯 ¿Para qué sirve?

Se utiliza para:

  • Copiar propiedades de objetos.
  • Fusionar configuraciones.
  • Crear copias superficiales (shallow copy).
  • Actualizar objetos existentes.
  • Combinar datos provenientes de diferentes fuentes.

⚙️ ¿Cómo funciona?

  1. Recibe un objeto destino.
  1. Recibe uno o varios objetos origen.
  1. Copia las propiedades enumerables propias del origen.
  1. Si una propiedad ya existe, la reemplaza.
  1. Devuelve el objeto destino.

Ejemplo:

Object.assign(destino,origen);

Proceso:

Antes:

destino:
{nombre:"Luis"}
origen:
{nombre:"Carlos",edad:25}

Después:

destino:
{nombre:"Carlos",edad:25}

La propiedad nombre fue sobrescrita.

📝 Sintaxis / Estructura

Object.assign(objetivo, ...fuentes);

Parámetros

ParámetroDescripción
objetivoObjeto que recibirá las propiedades.
fuentesUno o varios objetos desde donde se copiarán propiedades.

Valor de retorno

TipoDescripción
ObjectEl objeto objetivo modificado.

💡 Ejemplos

Copiar propiedades de un objeto

const usuario= {
    nombre:"Josué",
    edad:17
};
const copia= Object.assign({},usuario);
console.log(copia);

Resultado:

{nombre:"Josué",edad:17
}

Combinar objetos

const datosPersonales= {
    nombre:"Ana"
};
const datosTrabajo= {
    profesion:"Programadora"
};
const persona=Object.assign(
    {},datosPersonales,datosTrabajo
);
console.log(persona);

Resultado:

{nombre:"Ana",profesion:"Programadora"}

Sobrescribir propiedades

const usuario= {
    nombre:"Luis",
    edad:20
};
Object.assign(usuario, {
    edad:25
});
console.log(usuario);

Resultado:

{nombre:"Luis",edad:25}

Copiar varios objetos

const objeto=Object.assign(
    {},
    {a:1},
    {b:2},
    {c:3}
);
console.log(objeto);

Resultado:

{a:1,b:2,c:3}

Usar múltiples fuentes

const configuracionBase= {
    idioma:"es",
    modo:"claro"
};
const configuracionUsuario= {
    modo:"oscuro"
};
const config=Object.assign(
    {},configuracionBase,configuracionUsuario
);
console.log(config);

Resultado:

{idioma:"es",modo:"oscuro"}

⚠️ Errores comunes

❌ Pensar que hace una copia profunda (deep copy)

const usuario= {
    nombre:"Ana",
    direccion: {
        ciudad:"Lima"
    }
};
const copia=Object.assign({},usuario);
copia.direccion.ciudad="Cusco";
console.log(usuario.direccion.ciudad);

Resultado:

Cusco

¿Por qué?

Porque Object.assign() solo copia la primera capa.

Es una:

Shallow Copy ✅

No:

Deep Copy ❌

❌ Olvidar que modifica el primer objeto

const a= {
    nombre:"Luis"
};
Object.assign(a, {
    edad:20
});
console.log(a);

Resultado:

{nombre:"Luis",edad:20
}

El objeto a fue cambiado.

❌ Confundirlo con spread operator

También puedes hacer:

const copia= {
    ...usuario
};

Ambos hacen copia superficial:

Object.assign({},usuario);

{
    ...usuario
}

❌ No considerar propiedades repetidas

Object.assign(
    {},
    {nombre:"Ana"},
    {nombre:"Luis"}
);

Resultado:

{nombre:"Luis"
}

La última propiedad gana.

💼 Casos de uso

  • Crear configuraciones personalizadas.
  • Combinar estados en aplicaciones.
  • Actualizar objetos.
  • Copiar datos antes de modificarlos.
  • Trabajar con patrones de programación funcional.

Ejemplo:

const usuarioActualizado=Object.assign(
    {},usuarioAnterior,nuevosDatos
);

🧠 Analogía

Imagina que tienes una carpeta 📁:

Carpeta A:

Nombre: Ana
Edad: 20

Carpeta B:

Ciudad: Lima
Trabajo: Programadora

Object.assign() toma la información de ambas carpetas y la coloca en una nueva:

Nombre: Ana
Edad: 20
Ciudad: Lima
Trabajo: Programadora

Pero si dos carpetas tienen la misma etiqueta:

Edad: 20
Edad: 25

La última información reemplaza a la anterior.
