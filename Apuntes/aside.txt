# **📄 `<aside>`**

## **📝 Definición**

`<aside>` 

Es un elemento **semántico** de HTML5 que representa contenido **secundario o tangencial** al contenido principal: 

barras laterales, notas al margen, publicidad, enlaces relacionados, biografías de autor, glosarios, etc.

## **🧠 ¿Qué es?**

Es un elemento de **bloque** y **semántico**. 

Su contenido está **relacionado** con el contenido principal, pero **no es esencial** para entenderlo. 

Si se elimina, el contenido principal sigue teniendo sentido completo.

## **🎯 ¿Para qué sirve?**

- **Barras laterales** con contenido relacionado.
- **Notas al margen** o aclaraciones.
- **Publicidad** o promociones.
- **Enlaces relacionados** o "leer también".
- **Biografías de autor** en un artículo.
- **Glosarios** o definiciones al margen.
- **Aportar semántica**: diferencia contenido principal de secundario.
- **Mejorar accesibilidad**: los lectores de pantalla pueden saltar al contenido principal.

## **⚙️ ¿Cómo funciona?**

1. El navegador lo renderiza como **bloque** (sin estilos visuales por defecto).
2. Puede ir **dentro** de `<main>`, `<article>` o `<section>` (relacionado con ese contenido).
3. Puede ir **fuera** de `<main>` (como barra lateral global).
4. Puede contener `<h1>`–`<h6>`, `<p>`, `<ul>`, `<nav>`, `<figure>`, etc.
5. Los lectores de pantalla lo anuncian como **"complementary"** si tiene etiqueta.

## **📝 Sintaxis / Estructura**

```html
<aside>
  <h2>Contenido relacionado</h2>
  <p>...</p>
</aside>
```

## **💡 Ejemplos**

**Barra lateral de blog:**

```html
<aside>
  <h2>Sobre el autor</h2>
  <p>Ana Pérez es desarrolladora web con 10 años de experiencia.</p>
</aside>
```

**Enlaces relacionados dentro de un artículo:**

```html
<article>
  <h1>Cómo aprender HTML</h1>
  <p>Contenido del artículo...</p>
  <aside>
    <h2>Leer también</h2>
    <ul>
      <li><a href="/css">Guía de CSS</a></li>
      <li><a href="/js">Introducción a JavaScript</a></li>
    </ul>
  </aside>
</article>
```

**Nota al margen:**

```html
<p>HTML fue creado en 1991...</p>
<aside>
  <p><strong>Nota:</strong> la primera versión fue publicada por Tim Berners-Lee.</p>
</aside>
```

**Publicidad o promoción:**

```html
<aside class="publicidad">
  <p>Patrocinado por <a href="https://example.com">Example</a></p>
  <img src="banner.jpg" alt="Oferta especial">
</aside>
```

**Barra lateral global (fuera del main):**

```html
<body>
  <header>...</header>
  <main>
    <article>...</article>
  </main>
  <aside>
    <h2>Más leídos</h2>
    <ul>...</ul>
  </aside>
  <footer>...</footer>
</body>
```

**Con estilos CSS:**

```html
<aside class="lateral">
  <h2>Relacionados</h2>
  <ul>...</ul>
</aside>
```

```css
aside.lateral {
  background: #f5f5f5;
  padding: 1.5rem;
  border-radius: 8px;
  border-left: 4px solid #007bff;
}
```

## **⚠️ Errores comunes**

- ❌ Usarlo como **contenedor genérico** (para eso `<div>`).
- ❌ Usar `<aside>` para **contenido principal** (va en `<main>`).
- ❌ Usarlo para **navegación principal** (para eso `<nav>`).
- ❌ Ponerlo **dentro de `<p>`** (inválido).
- ❌ Usarlo sin relación con el contenido que lo rodea.
- ❌ Usarlo solo por **estilos** (para eso `<div>` con class).
- ❌ No aportar `aria-label` cuando no hay encabezado visible.
- ❌ Abusar: si todo es `<aside>`, pierde sentido.
- ❌ Confundirlo con `<section>` o `<article>`.

## **💼 Casos de uso**

- **Barras laterales** de blogs o noticias.
- **Enlaces relacionados** ("leer también").
- **Publicidad** o patrocinios.
- **Biografías de autor**.
- **Glosarios** o notas al margen.
- **Citas destacadas** (pull quotes).
- **Widgets** de redes sociales o clima.
- **Índices de contenido** en documentación.
- **Notas legales** o descargos.

## **🧩 Relación con otros conceptos**

- **`<main>`**: contenido principal (el `<aside>` es secundario).
- **`<article>`**: contenido autónomo (puede contener un `<aside>`).
- **`<section>`**: agrupación temática.
- **`<nav>`**: navegación (el `<aside>` puede contener un `<nav>`).
- **`<div>`**: contenedor genérico sin semántica.
- **`<header>` / `<footer>`**: pueden ir dentro de un `<aside>`.
- **`role="complementary"`**: rol ARIA implícito.
- **CSS**: `float`, `grid`, `flex`, `position: sticky`.
- **Accesibilidad**: lectores de pantalla anuncian "complementary" si tiene etiqueta.

## **🧠 Analogía**

Un `<aside>` es como una **nota al margen en un libro**: aporta contexto, datos curiosos o referencias, pero si la quitas, **el capítulo sigue entendiéndose perfectamente**. Es contenido **relacionado pero no esencial**.

## **📝 Notas personales**

- **Contenido secundario**: si lo quitas, el contenido principal sigue teniendo sentido.
- Puede ir **dentro** de `<main>`/`<article>` (relacionado con ese contenido) o **fuera** (barra lateral global).
- **No** es un contenedor genérico: si no aporta semántica → `<div>`.
- **No** es para navegación principal (para eso `<nav>`).
- Para **accesibilidad**, añade `aria-labelledby` apuntando al `id` del encabezado.
- Los lectores de pantalla lo anuncian como **"complementary"**.
- En CSS, `<aside>` no tiene estilos por defecto (solo `display: block`).
- **Pregunta clave**: "¿Este contenido es esencial para entender el principal?" → No = `<aside>`.
- Si es **navegación principal** → `<nav>`.
- Si es **contenido autónomo** → `<article>`.
- Si es **agrupación temática** → `<section>`.
- Si no tiene **significado semántico** → `<div>`.
- En frameworks (React, Vue), `<aside>` es un componente más.
