<img>

📄 <img>

📝 Definición

<img> es el elemento que incrusta una imagen en un documento HTML.

Es un elemento vacío (no tiene etiqueta de cierre) y reemplazado (el navegador sustituye la etiqueta por el recurso visual).

🧠 ¿Qué es?

Es un elemento inline que carga un archivo de imagen externo mediante el atributo src.

No contiene texto ni otros elementos: se representa a sí mismo como una imagen en el flujo del documento.

🎯 ¿Para qué sirve?

  • Mostrar imágenes: fotos, ilustraciones, iconos, logotipos.
  • Aportar contenido visual a la página.
  • Mejorar la experiencia del usuario.
  • Apoyar el SEO con imágenes optimizadas y con alt.
  • Servir de enlace si se envuelve en un <a>.
  • Mostrar imágenes responsive con srcset y sizes.

⚙️ ¿Cómo funciona?

  1. El navegador lee el src y descarga la imagen.
  1. Mientras carga, reserva espacio según width/height (si se especifican).
  1. Al terminar, sustituye el elemento por la imagen renderizada.
  1. Si falla, muestra el texto alternativo (alt) o un icono roto.
  1. Si es lazy (loading="lazy"), la carga se difiere hasta que está cerca del viewport.

📝 Sintaxis / Estructura

<img src="imagen.jpg" alt="Descripción de la imagen">

💡 Ejemplos

Imagen básica:

<img src="/img/perro.jpg" alt="Perro labrador sentado en el parque">

Con dimensiones (evita saltos de layout):

<img src="foto.jpg" alt="Paisaje montañoso" width="800" height="600">

Responsive con srcset:

<img
  src="foto-800.jpg"
  srcset="foto-400.jpg 400w, foto-800.jpg 800w, foto-1600.jpg 1600w"
  sizes="(max-width: 600px) 400px, 800px"
  alt="Playa al atardecer"
  loading="lazy">

Imagen como enlace:

<a href="https://example.com">
  <img src="logo.png" alt="Ir al sitio de Example">
</a>

Imagen decorativa (alt vacío):

<img src="decoracion.svg" alt="">

Con figure y figcaption:

<figure>
  <img src="grafico.png" alt="Gráfico de ventas 2026">
  <figcaption>Ventas anuales 2026</figcaption>
</figure>

⚠️ Errores comunes

  • ❌ Olvidar alt → problema de accesibilidad y SEO.
  • ❌ alt genérico: alt="imagen", alt="foto".
  • ❌ alt redundante: alt="imagen de un perro" (mejor alt="Perro labrador").
  • ❌ No especificar width/height → layout shift (CLS).
  • ❌ Usar imágenes enormes sin optimizar → página lenta.
  • ❌ Poner width/height en CSS y en HTML con valores distintos.
  • ❌ Usar <img> para iconos cuando SVG inline o fuentes de iconos son mejores.
  • ❌ No usar loading="lazy" en imágenes fuera del viewport.
  • ❌ Olvidar el / final si escribes XHTML.
  • ❌ Usar <img> con src vacío → petición innecesaria al servidor.

💼 Casos de uso

  • Fotos de productos en e-commerce.
  • Avatares de usuarios.
  • Ilustraciones en blogs y artículos.
  • Logotipos en cabeceras.
  • Iconos decorativos o informativos.
  • Gráficos y diagramas.
  • Imágenes de fondo (aunque CSS background-image es más apropiado).
  • Banners publicitarios.
  • Capturas de pantalla en documentación.

🧩 Relación con otros conceptos

  • <picture>: contenedor para imágenes responsive con <source>.
  • <figure> / <figcaption>: imagen con pie de foto.
  • <a>: envuelve la imagen para hacerla enlace.
  • <svg>: imágenes vectoriales inline.
  • <video> / <audio>: medios con comportamiento propio.
  • <map> / <area>: mapas de imagen.
  • background-image (CSS): para imágenes decorativas.
  • srcset / sizes: imágenes responsive.
  • loading="lazy": carga diferida.
  • alt: accesibilidad y SEO.

🧠 Analogía

Un <img> es como un marco de fotos en una pared: el src es la foto que colocas, el alt es la etiqueta descriptiva para quien no puede verla, y width/height son las dimensiones del marco. El navegador "coloca" la foto en el hueco reservado.

📝 Notas personales

  • alt es obligatorio en la práctica: si la imagen es decorativa, usa alt="" (vacío, no ausente).
  • Siempre especifica width y height para evitar layout shift (CLS).
  • Usa formatos modernos: WebP, AVIF; con fallback a JPG/PNG.
  • loading="lazy" para imágenes fuera del viewport; eager para las críticas (hero, logo).
  • Para imágenes responsive, usa srcset + sizes o <picture>.
  • En XHTML, <img> se cierra como <img ... />; en HTML5 no necesita cierre.
  • El atributo alt no debe empezar con "imagen de" ni "foto de"; describe el contenido.
  • Para imágenes decorativas, alt="" (vacío) evita que los lectores de pantalla las anuncien.
  • Considera fetchpriority="high" para la imagen principal (LCP).
  • Comprime las imágenes antes de subirlas: TinyPNG, Squoosh, ImageOptim.
  • Nunca uses <img> para texto: usa HTML + CSS.
