:hover

📄 :hover

📝 Definición

:hover es una pseudo-clase de CSS que selecciona un elemento cuando el usuario coloca el puntero del ratón (o dispositivo apuntador) sobre él, sin necesidad de hacer clic.

🧠 ¿Qué es?

Es una de las pseudo-clases dinámicas de CSS.

Forma parte de las pseudo-clases de estado del usuario (junto con :active, :focus, :visited, etc.).

Permite aplicar estilos condicionales según la interacción del usuario con el elemento.

🎯 ¿Para qué sirve?

  • Dar feedback visual al usuario (indicar que algo es interactivo).
  • Crear efectos de transición y animación.
  • Mejorar la accesibilidad y usabilidad de interfaces.
  • Resaltar elementos en tablas, listas, tarjetas, botones, enlaces, etc.

⚙️ ¿Cómo funciona?

El navegador detecta cuándo el cursor entra en el área del elemento y aplica los estilos definidos. Cuando el cursor sale, los estilos se revierten (salvo que haya transition).

Internamente se activa el estado :hover en el hit-testing del navegador.

No requiere JavaScript.

📝 Sintaxis / Estructura

selector:hover {
  propiedad: valor;
}

También se puede combinar con otros selectores:

a:hover { }
.btn:hover { }
.menu li:hover > ul { }
input:hover:focus { }

💡 Ejemplos

/* 1. Enlace simple */
a:hover {
  color: crimson;
  text-decoration: underline;
}

/* 2. Botón con transición */
.btn {
  background: #3498db;
  transition: background 0.3s ease;
}
.btn:hover {
  background: #2980b9;
  transform: scale(1.05);
}

/* 3. Mostrar submenú */
.menu li ul { display: none; }
.menu li:hover ul { display: block; }

/* 4. Resaltar fila de tabla */
tr:hover {
  background-color: #f5f5f5;
}

/* 5. Solo en dispositivos con puntero fino */
@media (hover: hover) {
  .card:hover { box-shadow: 0 8px 20px rgba(0,0,0,0.2); }
}

⚠️ Errores comunes

  1. Usarlo en móviles sin precaución → en pantallas táctiles :hover se "pega" tras el toque. Solución: usar @media (hover: hover).
  1. Sobrescribir estados → :hover debe ir después de :link y :visited, pero antes de :active (regla LVHA).
  1. Olvidar :focus → usuarios de teclado no verán el efecto. Combina :hover, :focus.
  1. Animar propiedades costosas → evitar animar width, top, margin. Preferir transform y opacity.
  1. Confundirlo con :active → :hover es al pasar el cursor; :active es al presionar.

🧩 Relación con otros conceptos

  • :active → mientras se presiona el botón.
  • :focus → cuando el elemento tiene foco (teclado).
  • :focus-visible → foco visible solo por teclado.
  • :visited / :link → estados de enlaces.
  • transition → suaviza el cambio de estado.
  • @media (hover: hover) → detecta capacidad de hover.
  • pointer-events → controla si el elemento recibe el cursor.
  • :has() → permite efectos hover en el padre.

Orden recomendado (LVHA):

a:link    { }
a:visited { }
a:hover   { }
a:active  { }

🧠 Analogía

Imagina una tienda con luces sensoras: cuando te acercas a un producto, la luz se enciende para mostrarlo mejor. Al alejarte, se apaga. Eso es :hover: el navegador "ilumina" el elemento cuando tu cursor se acerca.

📝 Notas personales

  • Recordar la regla LVHA para no romper estados de enlaces.
  • En proyectos responsive, siempre envolver efectos hover en @media (hover: hover) para evitar comportamientos raros en táctil.
  • Combinar con transition mejora muchísimo la percepción de calidad.
  • Para accesibilidad, incluir siempre :focus-visible junto con :hover.
  • :hover no funciona en elementos sin caja (ej. display: inline con contenido vacío); asegurar display: block/inline-block.
  • Es 100% CSS, sin JS → mejor rendimiento y menos dependencias.
