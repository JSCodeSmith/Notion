:focus

📄 :focus

📝 Definición

:focus es una pseudo-clase de estado de usuario en CSS que selecciona el elemento que tiene el foco en ese momento, es decir, el elemento que está "activo" para recibir entrada del teclado u otros dispositivos.

🧠 ¿Qué es?

Forma parte de las pseudo-clases dinámicas (junto con :hover, :active, :visited, :focus-within, :focus-visible).

A diferencia de :hover (que depende del puntero), :focus depende del foco del documento, que normalmente se asigna:

  • Al hacer clic en un elemento enfocable.
  • Al navegar con Tab entre elementos.
  • Al llamar element.focus() desde JavaScript.
  • Al cargar la página si hay autofocus.

Solo los elementos enfocables pueden recibirlo: enlaces, botones, inputs, select, textarea, [tabindex], [contenteditable], etc.

🎯 ¿Para qué sirve?

  • Dar feedback visual al usuario sobre qué elemento está activo.
  • Mejorar la accesibilidad para usuarios de teclado o lectores de pantalla.
  • Estilizar formularios (bordes, sombras, colores de fondo al enfocar).
  • Crear menús o modales que reaccionan al foco.
  • Sustituir/mejorar el outline por defecto del navegador.

⚙️ ¿Cómo funciona?

  1. El navegador mantiene un estado de foco en el documento: solo un elemento puede tenerlo a la vez.
  1. Cuando un elemento recibe el foco (clic, Tab, JS), el navegador aplica los estilos de :focus.
  1. Cuando pierde el foco (blur), los estilos se revierten.

Existen dos conceptos relacionados importantes:

  • :focus → el elemento tiene foco (por cualquier medio).
  • :focus-visible → el elemento tiene foco y el navegador determina que es apropiado mostrarlo (típicamente por teclado).

📝 Sintaxis / Estructura

selector:focus {
  propiedad: valor;
}

Variantes relacionadas

:focus          /* el elemento tiene foco */
:focus-visible  /* foco visible (recomendado para teclado) */
:focus-within   /* el elemento o algún descendiente tiene foco */

💡 Ejemplos

/* 1. Input con borde resaltado */
input:focus {
  border-color: #3498db;
  box-shadow: 0 0 0 3px rgba(52, 152, 219, 0.3);
  outline: none;
}

/* 2. Botón enfocado */
button:focus {
  background: #2980b9;
}

/* 3. Solo mostrar outline al navegar con teclado */
button:focus-visible {
  outline: 3px solid #f39c12;
  outline-offset: 2px;
}

/* 4. Contenedor reacciona cuando un hijo tiene foco */
.form-group:focus-within {
  background: #f0f8ff;
}

/* 5. Enlaces con subrayado al enfocar */
a:focus {
  text-decoration: underline;
  background: yellow;
}

/* 6. Combinar con hover para consistencia */
.btn:hover,
.btn:focus-visible {
  background: #2980b9;
}

⚠️ Errores comunes

  1. Eliminar el outline sin reemplazo → outline: none sin alternativa rompe la accesibilidad. Siempre sustituir por un estilo visible (borde, sombra, fondo).
  1. Confundir :focus con :focus-visible → :focus se activa incluso al hacer clic con ratón; :focus-visible solo cuando el navegador cree que es por teclado. Para estilos "bonitos" usa :focus-visible.
  1. Usarlo en elementos no enfocables → un <div> normal no recibe foco. Añadir tabindex="0" si necesitas.
  1. Olvidar el orden LVHA → :focus debe ir después de :hover si quieres que gane en especificidad al enfocar.
  1. No considerar :focus-within → útil para estilizar contenedores cuyos hijos tienen foco.
  1. Usar solo :focus para accesibilidad → mejor combinar con :focus-visible para evitar outlines feos al hacer clic.
  1. Problemas con tabindex negativo → tabindex="-1" permite foco programático pero no con Tab; puede ser intencional o un error.

🧩 Relación con otros conceptos

  • :hover → cursor encima.
  • :active → presionando.
  • :focus-visible → foco visible por teclado (mejor práctica moderna).
  • :focus-within → el elemento o un hijo tiene foco.
  • :visited / :link → estados de enlaces.
  • tabindex → controla si un elemento es enfocable.
  • autofocus → enfoca un elemento al cargar.
  • outline → propiedad clave para indicar foco visual.
  • element.focus() / element.blur() → control desde JS.

Orden recomendado (LVHA + focus):

a:link    { }
a:visited { }
a:hover   { }
a:focus   { }
a:active  { }

🧠 Analogía

Imagina un escenario con un micrófono. Solo una persona puede tener el micrófono en la mano en cada momento: esa persona es la que "tiene el foco". :focus es el reflector que ilumina al que tiene el micrófono. :focus-visible sería el reflector que solo se enciende cuando alguien sube al escenario caminando (teclado) y no cuando ya estaba allí (clic de ratón).

📝 Notas personales

  • Nunca hagas outline: none sin reemplazo → es un problema de accesibilidad serio (WCAG 2.4.7).
  • Regla de oro moderna: usa :focus-visible para estilos de teclado y :focus para estilos generales de formularios.
  • Combina :hover y :focus-visible con los mismos estilos para dar consistencia entre ratón y teclado.
  • :focus-within es oro puro para contenedores de formularios (labels, wrappers, cards con inputs).
  • Un tabindex="-1" permite foco por JS pero no por Tab → ideal para gestionar foco en modales.
  • El orden LVHA (link, visited, hover, active) es el clásico, pero hoy se suele completar con :focus-visible intercalado.
  • Recuerda: un solo elemento puede tener :focus a la vez en todo el documento.
  • Los :focus en contenteditable también funcionan, útil para editores inline.
