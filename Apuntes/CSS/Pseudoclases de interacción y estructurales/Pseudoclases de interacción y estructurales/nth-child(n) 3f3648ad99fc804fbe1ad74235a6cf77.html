:nth-child(n)

📄 :nth-child(n)

📝 Definición

:nth-child() es una pseudo-clase estructural de CSS que selecciona elementos según su posición entre sus hermanos, usando una fórmula o palabra clave (odd, even, an+b).

🧠 ¿Qué es?

Forma parte de las pseudo-clases estructurales (junto con :first-child, :last-child, :nth-of-type(), :only-child, etc.).

No depende de la interacción del usuario, sino del árbol DOM.

Es una generalización de :first-child (equivale a :nth-child(1)) y de :last-child (equivale a :nth-last-child(1)).

🎯 ¿Para qué sirve?

  • Aplicar estilos a posiciones específicas o patrones repetidos (cada 2, cada 3, pares, impares…).
  • Crear tablas cebreadas (filas alternas).
  • Estilizar grids con ítems destacados en ciertas posiciones.
  • Separar visualmente grupos de elementos sin clases extra.
  • Construir layouts complejos sin JavaScript.

⚙️ ¿Cómo funciona?

El navegador evalúa la posición del elemento dentro de su padre usando la fórmula an+b:

  1. Toma el elemento al que apunta el selector.
  1. Calcula su posición entre todos los hermanos (contando solo elementos, no texto ni comentarios).
  1. Sustituye n por valores enteros 0, 1, 2, 3… en la fórmula an+b.
  1. Si la posición coincide con algún resultado válido (≥ 1), aplica los estilos.

⚠️ No cuenta nodos de texto ni comentarios, solo elementos. Y cuenta todos los hijos, no solo los del mismo tipo.

📝 Sintaxis / Estructura

selector:nth-child(fórmula) {
  propiedad: valor;
}

Variantes relacionadas

:nth-last-child(n)   /* cuenta desde el final */
:nth-of-type(n)      /* solo entre hermanos del mismo tipo */
:nth-last-of-type(n) /* desde el final, mismo tipo */

💡 Ejemplos

/* 1. Tabla cebreada */
tr:nth-child(even) {
  background: #f7f7f7;
}

/* 2. Cada tercer ítem destacado */
li:nth-child(3n) {
  color: crimson;
  font-weight: bold;
}

/* 3. Primeros 3 elementos */
li:nth-child(-n+3) {
  border-bottom: 2px solid #333;
}

/* 4. A partir del 4º */
li:nth-child(n+4) {
  opacity: 0.7;
}

/* 5. Solo el 5º */
li:nth-child(5) {
  background: gold;
}

/* 6. Grid: quitar margen a cada 3º */
.grid > *:nth-child(3n) {
  margin-right: 0;
}

/* 7. Alternar animación de entrada */
.card:nth-child(odd)  { animation-delay: 0.1s; }
.card:nth-child(even) { animation-delay: 0.2s; }

Ejemplo comparativo clave

<div>
  <h1>Título</h1>
  <p>Párrafo 1</p>
  <p>Párrafo 2</p>
</div>
div p:nth-child(2)   { color: red; }   /* ✅ Aplica a <p>Párrafo 1</p> (posición 2) */
div p:nth-of-type(1) { color: blue; }  /* ✅ Aplica a <p>Párrafo 1</p> (1er <p>) */

⚠️ Errores comunes

  1. Confundir :nth-child() con :nth-of-type() → el más habitual. :nth-child cuenta todos los hermanos; :nth-of-type solo los del mismo tipo.
  1. Creer que empieza en 0 → empieza en 1, no en 0. :nth-child(0) no selecciona nada.
  1. Olvidar que cuenta todos los hijos → un <span> o <script> intercalado desplaza las posiciones.
  1. Escribir mal la fórmula → 2n + 1 es válido con espacios, pero 2 n+1 no lo es. El formato debe ser an+b con posibles espacios alrededor del +/.
  1. Usar paréntesis incorrectos → debe ser :nth-child(3n+1), no :nth-child[3n+1] ni :nth-child 3n+1.
  1. Esperar que cuente texto → los nodos de texto no cuentan como hijos.
  1. Problemas con display: none → los elementos ocultos sí cuentan en la posición, salvo que se eliminen del DOM.
  1. Confundir signos en rangos → n+3 = primeros 3; n+3 = del 3º en adelante.

🧩 Relación con otros conceptos

  • :first-child = :nth-child(1).
  • :last-child = :nth-last-child(1).
  • :nth-of-type() → cuenta solo entre hermanos del mismo tipo.
  • :nth-last-child() → cuenta desde el final.
  • :only-child → el único hijo.
  • :not(:nth-child(...)) → excluir posiciones.
  • :has() → condicionar según descendientes.
  • Custom properties + calc() → para animaciones escalonadas modernas.

Equivalencias útiles:

:first-child        ≡ :nth-child(1)
:last-child         ≡ :nth-last-child(1)
:nth-child(even)    ≡ :nth-child(2n)
:nth-child(odd)     ≡ :nth-child(2n+1)

🧠 Analogía

Imagina una fila de butacas numeradas en un cine. :nth-child(3) señala la butaca 3. :nth-child(2n) señala todas las pares. :nth-child(3n+1) señala las butacas 1, 4, 7, 10… Es un selector de butacas por patrón, contando desde el inicio de la fila.

📝 Notas personales

  • Fórmula mental: an+b = "cada a elementos, empezando en b".
    • 2n+1 → cada 2, desde 1 → impares.
    • 3n+2 → cada 3, desde 2 → 2, 5, 8, 11…
  • Las posiciones empiezan en 1, nunca en 0.
  • n+3 es un truco elegante para "primeros 3".
  • n+4 es lo mismo que "desde el 4º en adelante".
  • Combinar dos :nth-child permite rangos: :nth-child(n+3):nth-child(-n+6) = del 3º al 6º.
  • Recordar que cuenta todos los hijos, no solo del mismo tipo → si dudas, usa :nth-of-type().
  • Para animaciones escalonadas modernas: :nth-child(n) { animation-delay: calc(var(--i, 1) * 0.1s) } o usar @property / counter para exponer n como variable.
  • Muy útil combinado con :not(:nth-child(...)) para excluir posiciones concretas.
