:last-child

📄 :last-child

📝 Definición

:last-child es una pseudo-clase estructural de CSS que selecciona un elemento solo si es el último hijo de su elemento padre.

🧠 ¿Qué es?

Forma parte de las pseudo-clases estructurales (junto con :first-child, :nth-child(), :only-child, etc.).

No depende de la interacción del usuario, sino de la posición del elemento dentro del árbol DOM.

Es la contraparte simétrica de :first-child.

Al igual que ella, se basa en la posición entre hermanos, no en el tipo de elemento.

🎯 ¿Para qué sirve?

  • Aplicar estilos solo al último elemento de una lista, contenedor o grupo.
  • Eliminar márgenes/bordes inferiores del último ítem sin usar clases extra.
  • Crear listas con separadores donde el último no lleva línea.
  • Evitar añadir clases como .last en HTML.

⚙️ ¿Cómo funciona?

El navegador evalúa la posición del elemento dentro de su padre:

  1. Toma el elemento al que apunta el selector.
  1. Verifica si es el último hijo de su padre (contando cualquier tipo de nodo elemento).
  1. Si lo es, aplica los estilos.

⚠️ No cuenta nodos de texto ni comentarios, solo elementos.

Pero sí cuenta elementos de cualquier tipo, no solo del mismo tag.

📝 Sintaxis / Estructura

selector:last-child {
  propiedad: valor;
}

Variantes relacionadas

:last-child        /* último hijo de cualquier tipo */
:last-of-type      /* último hijo de su mismo tipo */
:nth-last-child(1) /* equivalente a :last-child */

💡 Ejemplos

/* 1. Último párrafo de un artículo */
article p:last-child {
  margin-bottom: 0;
}

/* 2. Quitar borde inferior al último ítem */
ul li:last-child {
  border-bottom: none;
}

/* 3. Último hijo directo de una tarjeta */
.card > *:last-child {
  margin-bottom: 0;
}

/* 4. Diferencia con :last-of-type */
div p:last-child {
  color: red;   /* solo si el <p> es el ÚLTIMO hijo del div */
}
div p:last-of-type {
  color: blue;  /* el último <p> aunque no sea el último hijo */
}

Ejemplo comparativo clave

<div>
  <p>Párrafo 1</p>
  <p>Párrafo 2</p>
  <span>Nota final</span>
</div>
div p:last-child    { color: red; }   /* ❌ NO aplica: el <span> es el último */
div p:last-of-type  { color: blue; }  /* ✅ Aplica a <p>Párrafo 2</p> */

⚠️ Errores comunes

  1. Confundir :last-child con :last-of-type → el más habitual. :last-child exige ser el último hijo absoluto; :last-of-type solo exige ser el último de su tipo.
  1. Ignorar nodos posteriores → un <span>, un <small> o incluso un <script> después rompe el :last-child del elemento deseado.
  1. Olvidar el contexto del padre → p:last-child requiere que ese <p> sea hijo directo del mismo padre.
  1. Usarlo dentro de :not() mal escrito → :not(:last-child) es válido y muy útil; olvidar los dos puntos rompe todo.
  1. Esperar que cuente texto → los nodos de texto no cuentan como hijos para esta pseudo-clase.
  1. Problemas con display: none → los elementos ocultos sí cuentan en la posición, salvo que se eliminen del DOM.

🧩 Relación con otros conceptos

  • :first-child → el primer hijo.
  • :only-child → el único hijo.
  • :nth-last-child(n) → posición contando desde el final.
  • :last-of-type → último de su tipo (no confundir).
  • :not(:last-child) → todos menos el último (muy usado).
  • :has() → permite condicionar según descendientes.
  • Combinadores > y + → + (hermano adyacente) suele combinarse para separadores.

Combinación típica:

li:not(:last-child) { border-bottom: 1px solid #ddd; }

Alternativa al patrón li + li para separadores.

🧠 Analogía

Imagina una fila de personas esperando el autobús. :last-child señala únicamente a la última persona de la fila, sin importar quién sea (niño, adulto, anciano). En cambio, :last-of-type señalaría "el último niño de la fila", aunque no esté al final.

📝 Notas personales

  • Regla de oro: :last-child = posición absoluta; :last-of-type = posición relativa al tipo.
  • Si algo no funciona, inspecciona el DOM: probablemente hay un nodo posterior (incluso un <script> o un <span> decorativo).
  • :not(:last-child) es más limpio que añadir clases .not-last en HTML.
  • Muy útil en combinación con :first-child para limpiar márgenes/bordes del primer y último ítem.
  • No confundir con :last-line, que no existe; existen ::first-line y ::first-letter como pseudo-elementos.
  • Los elementos con display: none siguen contando en la posición → cuidado con menús colapsados.
