line-height

📄 line-height

📝 Definición

line-height es una propiedad CSS heredable que establece la altura de cada línea de texto dentro de un elemento.

Es la distancia vertical entre las líneas base de dos líneas consecutivas.

🧠 ¿Qué es?

Forma parte de las propiedades de tipografía (junto con font-size, font-family, font-weight, etc.).

Es heredable, pero con un matiz importante: cuando se define sin unidad, los hijos heredan el factor (no el valor calculado); cuando se define con unidad, los hijos heredan el valor computado.

Es una de las propiedades más importantes para la legibilidad del texto, más incluso que el tamaño o la fuente.

🎯 ¿Para qué sirve?

  • Mejorar la legibilidad del texto (ni muy apretado ni muy suelto).
  • Crear ritmo vertical en el diseño.
  • Centrar verticalmente texto en una caja de altura fija.
  • Controlar el espaciado entre líneas de títulos, párrafos, listas.
  • Ajustar texto en botones, badges, inputs.
  • Evitar el "salto" del texto al cargar fuentes web (evitar CLS).

⚙️ ¿Cómo funciona?

El navegador calcula la altura de línea y distribuye el espacio extra mitad arriba, mitad abajo del texto (leading).

Reglas clave:

  1. Sin unidad (1.5) → se multiplica por el font-size del propio elemento. Recomendado.
  1. Con longitud (24px) → valor fijo, no escala.
  1. Con porcentaje (150%) → se calcula al heredar, no al usar.
  1. Número (1.5) → se calcula al usar, no al heredar → mejor herencia.
  1. Afecta al espaciado vertical entre líneas dentro del mismo bloque.
  1. No afecta al margen entre párrafos → eso es margin.
  1. En elementos vacíos o inline → puede no notarse; requiere contenido.
  1. Afecta a la altura de la caja → si el bloque tiene texto, la altura mínima es line-height * número de líneas.

📝 Sintaxis / Estructura

selector {
  line-height: valor;
}

💡 Ejemplos

/* 1. Recomendado: sin unidad */
body {
  font-size: 16px;
  line-height: 1.5; /* 24px efectivos */
}

/* 2. Títulos más apretados */
h1, h2, h3 {
  line-height: 1.2;
}

/* 3. Párrafos largos, más aire */
p {
  line-height: 1.6;
}

/* 4. Texto pequeño, más apretado */
small {
  line-height: 1.4;
}

/* 5. Centrar verticalmente texto */
.boton {
  height: 48px;
  line-height: 48px;
  text-align: center;
}

/* 6. Botón moderno con flex (mejor práctica) */
.boton {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  height: 48px;
}

/* 7. Valor fijo (usar con cuidado) */
.input {
  line-height: 24px;
}

/* 8. Reset universal recomendado */
:root {
  line-height: 1.5;
}
h1, h2, h3, h4, h5, h6 {
  line-height: 1.2;
}

Diferencia entre 1.5, 150% y 24px

/* Caso 1: sin unidad (recomendado) */
.padre {
  font-size: 16px;
  line-height: 1.5; /* 24px */
}
.hijo {
  font-size: 32px;
  /* line-height heredado = 1.5 → 48px ✅ escala */
}

/* Caso 2: porcentaje (problemático al heredar) */
.padre {
  font-size: 16px;
  line-height: 150%; /* 24px computado */
}
.hijo {
  font-size: 32px;
  /* line-height heredado = 24px (fijo) ⚠️ NO escala */
}

/* Caso 3: valor fijo (no escala nunca) */
.padre {
  font-size: 16px;
  line-height: 24px;
}
.hijo {
  font-size: 32px;
  /* line-height heredado = 24px ⚠️ texto puede solaparse */
}

⚠️ Errores comunes

  1. Usar px o % en line-height → al heredar, los hijos reciben el valor computado (fijo), no el factor. Usar sin unidad siempre que sea posible.
  1. Aplicar line-height demasiado pequeño → las líneas se solapan y el texto es ilegible. Mínimo ~1.2.
  1. Aplicar line-height demasiado grande → las líneas se separan demasiado y el texto pierde cohesión. Máximo ~1.8 para párrafos.
  1. Usar line-height para centrar en botones modernos → truco antiguo; mejor flex con align-items: center.
  1. Confundir line-height con margin → line-height espacia líneas dentro de un bloque; margin espacia bloques entre sí.
  1. Aplicar line-height a un elemento sin texto → no tiene efecto visible.
  1. No ajustar line-height al cambiar font-size → si aumentas el tamaño de fuente, probablemente debas ajustar line-height.
  1. Olvidar los títulos → los títulos necesitan line-height menor (~1.1–1.2) para verse compactos y potentes.
  1. Usar line-height: 0 → colapsa el texto; solo útil en trucos muy concretos (iconos, sprites).
  1. No considerar el idioma → textos en chino/japonés/coreano suelen necesitar más line-height (1.7–2) por la densidad de glifos.

🧩 Relación con otros conceptos

  • font-size → el line-height sin unidad se multiplica por este valor.
  • font → shorthand que puede incluir line-height (ej. font: 16px/1.5 sans-serif).
  • margin → espacia bloques, no líneas.
  • padding → espacia contenido del borde, no líneas.
  • vertical-align → alineación dentro de la línea.
  • height → si se fija, puede entrar en conflicto con line-height.
  • display: flex → align-items: center sustituye al truco line-height para centrar.
  • text-box-trim → propiedad experimental que recorta el espacio extra arriba/abajo.
  • CLS (Cumulative Layout Shift) → line-height bien definido reduce saltos al cargar fuentes.

🧠 Analogía

Imagina un cuaderno con renglones. El font-size es el tamaño de tu letra; el line-height es la separación entre renglones. Si los renglones están muy juntos, tu letra se solapa con la de arriba y abajo (ilegible). Si están muy separados, cuesta seguir la línea con la vista. El punto ideal es cuando la letra respira sin perderse.

📝 Notas personales

  • Regla de oro: usar line-height sin unidad (1.5, 1.2) → hereda el factor, no el valor computado.
  • Nunca px ni % para line-height general → problemático al heredar en hijos con distinto font-size.
  • Valores recomendados:
    • Texto base: 1.5
    • Párrafos largos: 1.6
    • Títulos grandes: 1.1
    • Títulos pequeños: 1.3
  • Definir line-height en :root (o body) y ajustar solo en títulos.
  • El truco line-height + height para centrar vertical es antiguo → hoy usar flex con align-items: center.
  • Idiomas CJK → necesitan line-height mayor (~1.7–2) por la densidad de glifos.
  • text-box-trim → propiedad experimental que elimina el espacio extra arriba/abajo, ideal para alinear títulos con otros elementos.
  • Reduce CLS → definir line-height estable evita saltos cuando carga una fuente web.
  • font: 16px/1.5 sans-serif → shorthand útil, pero resetea otras propiedades de font → usar con cuidado.
  • No confundir con margin → line-height = espacio entre líneas; margin = espacio entre bloques.
