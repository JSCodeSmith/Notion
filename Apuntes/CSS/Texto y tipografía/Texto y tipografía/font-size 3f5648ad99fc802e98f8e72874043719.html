font-size

📄 font-size

📝 Definición

font-size es una propiedad CSS heredable que establece el tamaño de la fuente (el tamaño del texto) de un elemento.

Acepta valores absolutos, relativos y palabras clave.

🧠 ¿Qué es?

Forma parte de las propiedades de tipografía (junto con font-family, font-weight, line-height, font-style, letter-spacing, etc.).

Es heredable: los hijos heredan el tamaño del padre salvo que lo sobrescriban.

Es la propiedad clave para construir escalas tipográficas y sistemas de diseño responsive que respetan las preferencias del usuario.

🎯 ¿Para qué sirve?

  • Definir el tamaño del texto en toda la interfaz.
  • Crear jerarquía visual (h1 > h2 > p > small).
  • Construir escalas tipográficas consistentes con rem/em.
  • Adaptar el texto a distintos dispositivos con media queries o clamp().
  • Respetar la accesibilidad: si el usuario aumenta el tamaño base del navegador, todo escala.
  • Controlar el tamaño de iconos cuando usan font-size (emojis, icon fonts).

⚙️ ¿Cómo funciona?

El navegador calcula el tamaño de cada glifo a partir del valor de font-size.

Reglas clave:

  1. Heredable → los hijos heredan el valor del padre (el valor computado, no el declarado).
  1. Unidades relativas dependen del contexto:
    • em → relativo al font-size del padre.
    • rem → relativo al font-size del elemento raíz (<html>).
    • % → relativo al font-size del padre.
    • ex, ch → relativos a la fuente actual.
    • vw, vh → relativos al viewport.
  1. Tamaño base por defecto → los navegadores usan 16px en <html> salvo que el usuario lo cambie.
  1. Palabras clave absolutas → small, medium, large, etc., tienen tamaños fijos definidos por el navegador.
  1. Palabras clave relativas → smaller, larger → relativas al padre.
  1. Afecta a em de los hijos → cuidado con la herencia acumulativa.

📝 Sintaxis / Estructura

selector {
  font-size: valor;
}

💡 Ejemplos

/* 1. Base del documento con rem */
html {
  font-size: 16px; /* 1rem = 16px */
}
body {
  font-size: 1rem;
}

/* 2. Jerarquía tipográfica con rem */
h1 { font-size: 2.5rem; }   /* 40px */
h2 { font-size: 2rem; }     /* 32px */
h3 { font-size: 1.5rem; }   /* 24px */
p  { font-size: 1rem; }     /* 16px */
small { font-size: 0.875rem; } /* 14px */

/* 3. Escala fluida con clamp() */
h1 {
  font-size: clamp(1.75rem, 4vw + 1rem, 3rem);
}

/* 4. Relativo con em (cuidado con herencia) */
.card {
  font-size: 1rem;
}
.card__title {
  font-size: 1.5em; /* 1.5 * 16px = 24px */
}

/* 5. Palabras clave */
.small  { font-size: small; }
.medium { font-size: medium; }
.large  { font-size: large; }

/* 6. Tamaño relativo al viewport */
.hero-title {
  font-size: 5vw;
}

/* 7. Ajustar el root para diseño fluido */
html {
  font-size: clamp(14px, 1vw + 10px, 18px);
}

/* 8. Accesibilidad: respetar preferencias del usuario */
html {
  font-size: 100%; /* no fijar en px, permitir escalado */
}

Diferencia entre em, rem y %

html { font-size: 16px; }

.padre {
  font-size: 20px;
}
.hijo-em  { font-size: 1.5em; }  /* 1.5 * 20 = 30px */
.hijo-rem { font-size: 1.5rem; } /* 1.5 * 16 = 24px */
.hijo-pct { font-size: 150%; }   /* 150% * 20 = 30px */

Escala tipográfica moderna con clamp()

:root {
  --step-0: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);
  --step-1: clamp(1.25rem, 1.15rem + 0.5vw, 1.5rem);
  --step-2: clamp(1.5rem, 1.35rem + 0.75vw, 2rem);
  --step-3: clamp(2rem, 1.75rem + 1.25vw, 2.75rem);
}
h1 { font-size: var(--step-3); }
h2 { font-size: var(--step-2); }
h3 { font-size: var(--step-1); }
p  { font-size: var(--step-0); }

⚠️ Errores comunes

  1. Usar px para todo → no respeta las preferencias del usuario y complica el responsive. Preferir rem para tamaños base.
  1. Anidar em sin control → em se multiplica en cascada: 1.5em dentro de 1.5em da 2.25. Usar rem para evitar sorpresas.
  1. Fijar html { font-size: 62.5% } sin pensar → truco clásico para que 1rem = 10px, pero rompe accesibilidad si el usuario cambió su tamaño base.
  1. No respetar el tamaño mínimo → texto menor a 12px es difícil de leer. WCAG no exige un mínimo, pero la usabilidad sí.
  1. Usar vw sin límites → en pantallas grandes el texto se vuelve gigante; en pequeñas, ilegible. Combinar con clamp().
  1. Olvidar line-height → cambiar font-size sin ajustar line-height puede romper la legibilidad.
  1. Confundir font-size con font → font es shorthand y resetea font-family, font-weight, line-height, etc.
  1. No probar con zoom del navegador → el diseño debe funcionar al 200% de zoom (WCAG 1.4.4).
  1. Usar font-size para iconos sin line-height → los iconos pueden desalinearse.
  1. Mezclar unidades sin sistema → elegir rem para escala y px para bordes, por ejemplo, y ser consistente.

🧩 Relación con otros conceptos

  • font → shorthand que incluye font-size (y resetea otras).
  • line-height → debe ajustarse en proporción al font-size.
  • font-weight → independiente, pero afecta a la percepción del tamaño.
  • letter-spacing → a veces se ajusta en relación al tamaño.
  • em / rem → unidades clave para tamaños escalables.
  • clamp() → función moderna para tipografía fluida.
  • vw / vh → unidades de viewport, útiles para heroes.
  • prefers-reduced-motion → no afecta a font-size pero sí a transiciones.
  • WCAG 1.4.4 → exige que el texto escale hasta 200% sin pérdida de contenido.
  • text-size-adjust → propiedad relacionada que evita ajustes automáticos en móvil.

Unidades relativas visualizadas:

html { font-size: 16px }  ← base
  └── body { font-size: 1rem } = 16px
        └── .card { font-size: 1.5em } = 24px  ← relativo al padre
              └── .card__title { font-size: 1.5em } = 36px  ← ⚠️ se multiplica
        └── .card { font-size: 1.5rem } = 24px  ← relativo al root
              └── .card__title { font-size: 1.5rem } = 24px  ← ✅ consistente

🧠 Analogía

Imagina que cada elemento es una habitación y el font-size es el tamaño de los muebles. Con px fijas el tamaño en centímetros exactos: si el dueño de la casa quiere muebles más grandes, no puede. Con rem usas una unidad de medida estándar que se adapta a la casa entera: cambias una vez y todo escala. Con em el tamaño depende del mueble del padre: si el padre tiene muebles grandes, los hijos serán aún más grandes (efecto multiplicador).

📝 Notas personales

  • Regla de oro: usar rem para tamaños de texto, px para bordes, em para espaciados internos relativos al texto.
  • No fijar html { font-size: 62.5% } → truco antiguo que rompe accesibilidad. Usar 100% y calcular con rem.
  • clamp() es la herramienta moderna para tipografía fluida → evita media queries para tamaños.
  • em se multiplica → es su mayor peligro. Reservarlo para componentes que deben escalar con su propio texto (botones, badges).
  • line-height sin unidad (ej. 1.5) es lo mejor → se calcula sobre el font-size del propio elemento, no del padre.
  • WCAG 1.4.4 → probar siempre con zoom al 200% para asegurar que nada se rompe.
  • Escala tipográfica → definir un sistema (1.125, 1.25, 1.333…) antes de empezar. Utopia y Typescale son buenas herramientas.
  • Modo oscuro → no afecta al font-size pero sí a la percepción; a veces conviene aumentar ligeramente el tamaño o el peso.
  • text-size-adjust: 100% → evita que Safari iOS agrande el texto automáticamente en modo landscape.
  • No usar font-size para layout → para espaciado usa margin, padding o gap.
