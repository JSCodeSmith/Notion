text-align

📄 text-align

📝 Definición

text-align es una propiedad CSS heredable que establece la alineación horizontal del contenido en línea (texto, imágenes inline, etc.) dentro de un elemento de bloque.

🧠 ¿Qué es?

Forma parte de las propiedades de texto (junto con text-decoration, text-transform, text-indent, text-shadow, letter-spacing, etc.).

Es heredable: los hijos heredan la alineación del padre salvo que la sobrescriban.

Afecta al contenido inline (texto, <span>, <img>, etc.), no a los elementos de bloque hijos.

Para alinear cajas, se usan margin: auto, flexbox o grid.

🎯 ¿Para qué sirve?

  • Alinear texto a izquierda, derecha, centro o justificado.
  • Centrar títulos y encabezados.
  • Alinear números en tablas a la derecha.
  • Justificar párrafos largos (con criterio).
  • Alinear contenido según la dirección del texto (RTL/LTR).
  • Crear diseños editoriales (revistas, blogs).

⚙️ ¿Cómo funciona?

El navegador distribuye el contenido inline dentro de la caja de línea del elemento de bloque. Reglas clave:

  1. Heredable → los hijos heredan la alineación.
  1. Afecta solo al contenido inline → no a elementos de bloque hijos.
  1. Aplica al bloque contenedor → el texto se alinea dentro del ancho del bloque.
  1. Valores lógicos → start y end respetan la dirección del texto (dir="rtl").
  1. justify → distribuye el espacio entre palabras (y a veces letras).
  1. text-align-last → controla la alineación de la última línea (útil con justify).
  1. No funciona en elementos inline → necesita display: block, inline-block, flex (con matices), grid, table-cell.

📝 Sintaxis / Estructura

selector {
  text-align: valor;
}

Parámetros / Valores

ValorDescripción
leftAlinea a la izquierda (físico).
rightAlinea a la derecha (físico).
centerCentra el contenido.
justifyJustifica: estira las líneas para ocupar todo el ancho.
startAlinea al inicio según direction (lógico).
endAlinea al final según direction (lógico).
match-parentHereda el text-align del padre, calculado con su direction.
justify-allComo justify, pero también la última línea (experimental).
inheritHereda del padre.
initialValor por defecto (start en la mayoría de navegadores).
unsetHereda (porque es heredable).

💡 Ejemplos

/* 1. Texto centrado */
.titulo {
  text-align: center;
}

/* 2. Párrafo justificado */
.articulo p {
  text-align: justify;
  hyphens: auto; /* evita ríos de espacio */
}

/* 3. Números alineados a la derecha en tabla */
td.numero {
  text-align: right;
  font-variant-numeric: tabular-nums;
}

/* 4. Alineación lógica (respeta RTL) */
.texto {
  text-align: start; /* izquierda en LTR, derecha en RTL */
}

/* 5. Última línea del párrafo justificado */
p {
  text-align: justify;
  text-align-last: center;
}

/* 6. Centrar en un contenedor flex */
.card {
  display: flex;
  flex-direction: column;
  align-items: center;
  text-align: center;
}

/* 7. Alinear según dirección del documento */
:root {
  direction: ltr;
}
.rtl {
  direction: rtl;
  text-align: start; /* se alinea a la derecha automáticamente */
}

/* 8. Reset útil */
body {
  text-align: start; /* más robusto que left */
}

Diferencia entre valores físicos y lógicos

/* Físicos: siempre igual, sin importar direction */
.izquierda { text-align: left; }   /* siempre izquierda */
.derecha   { text-align: right; }  /* siempre derecha */

/* Lógicos: se adaptan a direction */
.inicio { text-align: start; }     /* izquierda en LTR, derecha en RTL */
.fin    { text-align: end; }       /* derecha en LTR, izquierda en RTL */

Justificado con control de la última línea

p {
  text-align: justify;
  text-align-last: left;   /* última línea a la izquierda */
  hyphens: auto;           /* divide palabras para evitar huecos */
}

⚠️ Errores comunes

  1. Usar text-align: center para centrar un bloque → solo centra el contenido inline, no el bloque en sí. Para centrar una caja: margin: 0 auto o flex/grid.
  1. Justificar texto corto o en pantallas estrechas → genera "ríos" de espacio y problemas de legibilidad. Usar hyphens: auto y considerar evitar justify en móvil.
  1. Confundir text-align con align-items / justify-content → en flex/grid, text-align no controla la posición de los ítems, solo el texto interno.
  1. Usar left/right en sitios multiidioma → rompe RTL. Preferir start/end.
  1. No aplicar text-align a un elemento inline → no tiene efecto visible porque los elementos inline no tienen "caja de línea" propia.
  1. Justificar sin hyphens → huecos enormes entre palabras en columnas estrechas.
  1. Olvidar text-align-last → con justify, la última línea queda rara (justificada o estirada).
  1. Asumir que text-align: center centra imágenes → sí centra imágenes inline, pero si son display: block necesitan margin: auto.
  1. Usar text-align: justify en títulos → efecto raro y poco legible. Reservarlo para párrafos.

🧩 Relación con otros conceptos

  • direction → define si start/end es izquierda/derecha.
  • text-align-last → última línea en justify.
  • vertical-align → alineación vertical (inline/table-cell).
  • align-items → alineación vertical en flex/grid.
  • justify-content → alineación horizontal en flex/grid.
  • justify-items / justify-self → alineación horizontal en grid.
  • margin: 0 auto → centrar un bloque, no texto.
  • hyphens → divide palabras al justificar.
  • word-spacing / letter-spacing → ajustes finos al justificar.
  • text-justify → controla el método de justificación (experimental).

🧠 Analogía

Imagina una hoja de papel con líneas para escribir. El text-align es cómo decides escribir sobre esas líneas: pegado al margen izquierdo, al derecho, centrado en la página o estirando las palabras para que todas las líneas terminen igual (justificado). El papel (el bloque) no se mueve; solo cambias cómo escribes dentro de él.

📝 Notas personales

  • text-align alinea texto, no cajas → para centrar un bloque: margin: 0 auto o flex/grid.
  • Preferir start/end sobre left/right → soporta RTL automáticamente.
  • justify con moderación → solo en párrafos largos y con hyphens: auto + text-align-last.
  • En flex/grid, text-align no mueve los ítems → usar align-items, justify-content, justify-items.
  • Heredable → definirla en body afecta a todo; sobrescribir donde haga falta.
  • En tablas, alinear números a la derecha mejora la comparación visual → combinar con font-variant-numeric: tabular-nums.
  • text-align: center en botones → cuidado: el texto se centra pero el padding puede desequilibrar; a veces conviene flex.
  • No usar justify en la web sin necesidad → es más común en print; en pantalla, muchos usuarios prefieren texto alineado a la izquierda por legibilidad.
  • Con direction: rtl, text-align: start se convierte automáticamente en derecha → ideal para i18n.
