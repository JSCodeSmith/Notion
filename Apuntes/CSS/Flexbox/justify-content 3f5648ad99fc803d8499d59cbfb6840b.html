justify-content

📄 justify-content

📝 Definición

justify-content es una propiedad CSS que alinea y distribuye los ítems de un contenedor flex (o grid) a lo largo del eje principal, controlando cómo se reparte el espacio libre entre ellos.

🧠 ¿Qué es?

Forma parte de las propiedades de alineación de flexbox (junto con align-items, align-self, align-content, place-content).

Es una de las propiedades más usadas para centrar y distribuir ítems.

Actúa sobre el eje principal, que depende de flex-direction:

  • Con flex-direction: row → eje principal horizontal.
  • Con flex-direction: column → eje principal vertical.

⚠️ No confundir con align-items → justify-content alinea en el eje principal; align-items, en el eje transversal.

🎯 ¿Para qué sirve?

  • Centrar ítems horizontal o verticalmente.
  • Distribuir ítems con espacio entre ellos.
  • Agrupar ítems al inicio, final o centro.
  • Repartir el espacio libre de forma uniforme.
  • Construir menús de navegación, barras de acciones, grids.
  • Crear layouts con espaciado consistente sin márgenes.

⚙️ ¿Cómo funciona?

El navegador distribuye los ítems flex a lo largo del eje principal según el valor:

  1. flex-start (por defecto) → los ítems se agrupan al inicio del eje.
  1. flex-end → al final del eje.
  1. center → al centro.
  1. space-between → el primer ítem al inicio, el último al final, y el espacio se reparte entre ellos.
  1. space-around → cada ítem tiene el mismo espacio alrededor; los extremos tienen la mitad.
  1. space-evenly → el espacio entre todos los ítems (incluidos los extremos) es igual.
  1. start, end → valores lógicos (respetan writing-mode y direction).
  1. left, right → valores físicos (ignoran direction).
  1. stretch → estira los ítems (solo en grid, no en flex).

Reglas clave:

  • Solo aplica si hay espacio libre → si los ítems llenan el contenedor, no se nota.
  • Depende de flex-direction → con column, flex-start es arriba.
  • Afecta a los ítems en conjunto → no a uno individual (eso es align-self o márgenes).
  • Funciona con flex y grid → en grid alinea las columnas (eje inline).
  • No confundir con align-content → align-content distribuye líneas de ítems (con flex-wrap).

📝 Sintaxis / Estructura

selector {
  display: flex;
  justify-content: valor;
}
ValorDescripción
flex-startPor defecto. Ítems al inicio del eje principal.
flex-endÍtems al final del eje principal.
centerÍtems centrados en el eje principal.
space-betweenPrimer ítem al inicio, último al final, espacio entre ellos.
space-aroundEspacio uniforme alrededor de cada ítem (extremos con la mitad).
space-evenlyEspacio uniforme entre todos los ítems (incluidos los extremos).
startLógico. Inicio según writing-mode/direction.
endLógico. Final según writing-mode/direction.
leftFísico. Izquierda (ignora direction).
rightFísico. Derecha (ignora direction).
stretchEstira los ítems (solo grid).

💡 Ejemplos

/* 1. Centrar horizontalmente */
.center {
  display: flex;
  justify-content: center;
}

/* 2. Ítems al final */
.end {
  display: flex;
  justify-content: flex-end;
}

/* 3. Espacio entre ítems (menú clásico) */
.menu {
  display: flex;
  justify-content: space-between;
}

/* 4. Espacio uniforme alrededor */
.around {
  display: flex;
  justify-content: space-around;
}

/* 5. Espacio uniforme entre todos */
.evenly {
  display: flex;
  justify-content: space-evenly;
}

/* 6. Centrar horizontal y verticalmente */
.centrar {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* 7. Con flex-direction: column */
.column-center {
  display: flex;
  flex-direction: column;
  justify-content: center;
  min-height: 100vh;
  /* Centra verticalmente porque el eje principal es vertical */
}

/* 8. Header con logo a la izquierda y nav a la derecha */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px;
}

/* 9. Grid con columnas centradas */
.grid-center {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  justify-content: center;
  /* Centra las columnas horizontalmente */
}

/* 10. Valores lógicos (i18n) */
.logico {
  display: flex;
  justify-content: start; /* respeta direction */
}

Menú de navegación (logo + links)

.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 24px;
  background: white;
}
.logo { font-weight: bold; }
.nav { display: flex; gap: 16px; }

Centrar contenido en pantalla completa

.hero {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
  text-align: center;
}

Botones de acción alineados a la derecha

.actions {
  display: flex;
  justify-content: flex-end;
  gap: 8px;
}

Columna centrada verticalmente

.column-center {
  display: flex;
  flex-direction: column;
  justify-content: center;
  min-height: 100vh;
  gap: 16px;
}

Grid con columnas centradas

.grid-center {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  justify-content: center;
  gap: 16px;
  max-width: 800px;
  margin: 0 auto;
}

Espaciado uniforme sin márgenes

.nav {
  display: flex;
  justify-content: space-evenly;
  /* Alternativa moderna: gap */
}
/* Equivalente moderno */
.nav-gap {
  display: flex;
  gap: 24px;
  justify-content: center;
}

⚠️ Errores comunes

  1. Confundir justify-content con align-items → justify-content = eje principal; align-items = eje transversal. Error nº1.
  1. Esperar que funcione sin display: flex → no tiene efecto si el padre no es flex/grid.
  1. Confundir space-around con space-evenly → around da la mitad de espacio en los extremos; evenly da el mismo espacio en todos.
  1. Usarlo para alinear un solo ítem → justify-content alinea el conjunto. Para un ítem individual, usar margin: auto o align-self.
  1. Olvidar que depende de flex-direction → con column, justify-content alinea verticalmente.
  1. Confundir justify-content con align-content → align-content distribuye líneas cuando hay flex-wrap.
  1. Usar justify-content en grid sin entender el eje → en grid, justify-content alinea las columnas (eje inline) dentro del contenedor.
  1. No considerar gap → hoy gap es más limpio que space-between para espaciado uniforme entre ítems.
  1. space-between con un solo ítem → no hace nada visible (no hay espacio que repartir).
  1. left/right en lugar de start/end → rompe RTL. Preferir valores lógicos.
  1. Esperar que justify-content: center centre el texto → centra los ítems; para el texto, usar text-align: center.
  1. justify-content en un ítem flex → no tiene efecto; solo aplica al contenedor.

🧩 Relación con otros conceptos

  • display: flex → activa el contenedor flex.
  • flex-direction → define el eje principal sobre el que actúa justify-content.
  • align-items → alinea en el eje transversal.
  • align-content → distribuye líneas en el eje transversal (con flex-wrap).
  • align-self → alineación individual de un ítem.
  • place-content → shorthand de align-content + justify-content.
  • gap → alternativa moderna para espaciado uniforme.
  • margin: auto → centra un ítem individual en flex.
  • text-align → centra texto, no ítems flex.
  • Grid → justify-content alinea columnas (eje inline).
  • writing-mode / direction → afectan a start/end.

🧠 Analogía

Imagina que los ítems flex son libros en una estantería. justify-content decide cómo los colocas a lo largo del estante:

  • flex-start → todos pegados a la izquierda.
  • flex-end → todos pegados a la derecha.
  • center → todos en el centro.
  • space-between → uno en cada extremo y el resto repartidos en medio.
  • space-around → cada libro con el mismo espacio alrededor (los extremos con la mitad).
  • space-evenly → todos los huecos iguales, incluidos los extremos.

📝 Notas personales

  • flex-start es el valor por defecto → los ítems se agrupan al inicio del eje principal.
  • Actúa sobre el eje principal → depende de flex-direction. Con column, alinea verticalmente.
  • No confundir con align-items → justify-content = eje principal; align-items = eje transversal.
  • space-around vs space-evenly → around da la mitad de espacio en los extremos; evenly da el mismo espacio en todos.
  • Hoy gap es más limpio → para espaciado uniforme entre ítems, gap es preferible a space-between con márgenes.
  • Para un solo ítem → usar margin: auto en el ítem, no justify-content.
  • justify-content en grid → alinea las columnas dentro del contenedor (eje inline).
  • Valores lógicos → preferir start/end sobre flex-start/flex-end en proyectos multiidioma.
  • No centra texto → para eso, text-align: center. justify-content: center centra los ítems.
