flex-wrap

📄 flex-wrap

📝 Definición

flex-wrap es una propiedad CSS que define si los ítems de un contenedor flex se colocan en una sola línea o se envuelven en varias líneas cuando no caben en el eje principal.

🧠 ¿Qué es?

Forma parte de las propiedades de flexbox (junto con flex-direction, justify-content, align-items, align-content, flex, gap).

Solo aplica a contenedores flex (display: flex o display: inline-flex).

Por defecto, los ítems flex no se envuelven (nowrap): intentan caber todos en una línea, encogiéndose si es necesario.

flex-wrap permite que salten a la siguiente línea cuando no hay espacio.

🎯 ¿Para qué sirve?

  • Permitir que los ítems salten a la siguiente línea cuando no caben.
  • Crear galerías y grids con flexbox.
  • Evitar que los ítems se encojan demasiado.
  • Construir layouts responsive sin media queries.
  • Crear menús que se adaptan a distintos tamaños.
  • Activar align-content (que requiere múltiples líneas).

⚙️ ¿Cómo funciona?

El navegador decide si los ítems se colocan en una sola línea o se envuelven:

  1. nowrap (por defecto) → todos los ítems en una sola línea. Si no caben, se encogen (flex-shrink).
  1. wrap → los ítems se envuelven en varias líneas cuando no caben.
  1. wrap-reverse → como wrap, pero las líneas se invierten en el eje transversal.

Reglas clave:

  • Afecta al eje transversal → las líneas se apilan perpendicularmente al eje principal.
  • Activa align-content → sin wrap, align-content se ignora.
  • nowrap es el valor por defecto → por eso los ítems se encogen en lugar de saltar de línea.
  • Con wrap → los ítems mantienen su tamaño y saltan de línea.
  • wrap-reverse → la primera línea queda abajo (con row) o a la derecha (con column).
  • No cambia el orden del DOM → solo el orden visual de las líneas.

📝 Sintaxis / Estructura

selector {
  display: flex;
  flex-wrap: valor;
}
ValorDescripción
nowrapPor defecto. Todos los ítems en una sola línea (se encogen si no caben).
wrapLos ítems se envuelven en varias líneas.
wrap-reverseComo wrap, pero las líneas se invierten en el eje transversal.

💡 Ejemplos

/* 1. Nowrap (por defecto) */
.nowrap {
  display: flex;
  flex-wrap: nowrap;
  /* Todos en una línea, se encogen si no caben */
}

/* 2. Wrap (múltiples líneas) */
.wrap {
  display: flex;
  flex-wrap: wrap;
  /* Los ítems saltan a la siguiente línea cuando no caben */
}

/* 3. Wrap-reverse (líneas invertidas) */
.wrap-reverse {
  display: flex;
  flex-wrap: wrap-reverse;
  /* La primera línea queda abajo */
}

/* 4. Galería de tarjetas */
.galeria {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.card {
  flex: 1 1 250px;
  /* Crece, se encoge y parte de 250px */
}

/* 5. Tags que se envuelven */
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
.tag {
  padding: 4px 12px;
  background: #f0f0f0;
  border-radius: 12px;
}

/* 6. Menú responsive sin media queries */
.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
  /* Los ítems se envuelven si no caben */
}

/* 7. Combinado con align-content */
.layout {
  display: flex;
  flex-wrap: wrap;
  align-content: center;
  gap: 16px;
  height: 400px;
}

/* 8. Grid de productos */
.productos {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}
.producto {
  flex: 1 1 200px;
  max-width: 300px;
}

/* 9. Wrap-reverse con column */
.column-reverse {
  display: flex;
  flex-direction: column;
  flex-wrap: wrap-reverse;
  height: 400px;
  /* Las columnas se invierten (primera a la derecha) */
}

/* 10. Shorthand de flex-flow */
.flow {
  display: flex;
  flex-flow: row wrap;
  /* flex-flow: flex-direction + flex-wrap */
}

⚠️ Errores comunes

  1. Confundir flex-wrap con flex-direction → direction es el eje; wrap es si los ítems se envuelven.
  1. Esperar que flex-wrap: wrap funcione sin display: flex → no tiene efecto.
  1. Olvidar que nowrap es el valor por defecto → los ítems se encogen en lugar de saltar de línea.
  1. Usar align-content sin flex-wrap: wrap → se ignora.
  1. Confundir wrap-reverse con row-reverse → wrap-reverse invierte las líneas; row-reverse invierte los ítems dentro de la línea.
  1. Esperar que los ítems mantengan su tamaño con nowrap → se encogen (flex-shrink) para caber.
  1. No usar gap → sin gap, los ítems envueltos quedan pegados. Añadir gap para espaciado.
  1. flex-wrap: wrap con height fija → las líneas pueden desbordarse si no caben.
  1. wrap-reverse con align-content → la alineación se invierte; verificar el resultado.
  1. Confundir flex-wrap con white-space → flex-wrap afecta a los ítems flex; white-space al texto.
  1. Usar flex-wrap en un ítem flex → solo aplica al contenedor.
  1. flex-wrap: wrap con ítems sin flex-basis → los ítems se encogen o crecen según flex; puede sorprender.

🧩 Relación con otros conceptos

  • display: flex → activa el contenedor flex.
  • flex-direction → define el eje principal.
  • flex-flow → shorthand de flex-direction + flex-wrap.
  • justify-content → alinea ítems en el eje principal (dentro de cada línea).
  • align-items → alinea ítems en el eje transversal (dentro de cada línea).
  • align-content → distribuye líneas (requiere flex-wrap: wrap).
  • flex → shorthand de flex-grow, flex-shrink, flex-basis.
  • flex-shrink → controla cómo se encogen los ítems con nowrap.
  • gap → espacio entre ítems y entre líneas.
  • Grid → grid-template-columns con auto-fit/minmax es una alternativa moderna.

🧠 Analogía

Imagina que los ítems flex son libros en un estante:

  • nowrap → intentas meter todos en una sola fila; si no caben, los aprietas (se encogen).
  • wrap → cuando ya no caben más en la fila, empiezas una nueva fila debajo.
  • wrap-reverse → como wrap, pero las filas se apilan de abajo a arriba (la primera fila queda abajo).

Es como organizar libros en una estantería: o los aprietas todos en un estante, o los repartes en varios estantes.

📝 Notas personales

  • nowrap es el valor por defecto → los ítems se encogen en lugar de saltar de línea.
  • wrap es esencial para galerías y grids → permite que los ítems se adapten al ancho disponible.
  • wrap activa align-content → sin wrap, align-content se ignora.
  • wrap-reverse → invierte las líneas, no los ítems. No confundir con row-reverse.
  • Combinar con gap → sin gap, los ítems envueltos quedan pegados.
  • Combinar con flex: 1 1 <base> → patrón clásico para grids responsive: los ítems crecen, se encogen y parten de un tamaño base.
  • flex-flow → shorthand útil: flex-flow: row wrap.
  • Alternativa moderna → display: grid con grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)) es más limpio para grids responsive.
  • nowrap con flex-shrink → controla cuánto se encogen los ítems; flex-shrink: 0 evita que se encojan.
  • En RTL, wrap-reverse se comporta según direction; verificar el resultado.
