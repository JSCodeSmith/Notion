align-self

📄 align-self

📝 Definición

align-self es una propiedad CSS que permite sobrescribir la alineación del eje transversal (align-items) para un ítem individual dentro de un contenedor flex o grid.

🧠 ¿Qué es?

Forma parte de las propiedades de alineación de flexbox y grid (junto con align-items, justify-self, justify-items, place-self).

A diferencia de align-items (que se aplica al contenedor y afecta a todos los ítems), align-self se aplica al ítem y solo afecta a ese elemento.

Es la contraparte individual de align-items, igual que justify-self lo es de justify-items en grid.

🎯 ¿Para qué sirve?

  • Destacar un ítem con una alineación distinta al resto.
  • Alinear un ítem al inicio, final o centro del eje transversal.
  • Hacer que un ítem no se estire cuando los demás sí lo hacen.
  • Alinear un ítem por su línea base de texto.
  • Construir layouts donde un elemento necesita un tratamiento especial.
  • Crear headers con un ítem alineado arriba y el resto centrados.

⚙️ ¿Cómo funciona?

El navegador alinea ese ítem concreto en el eje transversal según el valor, ignorando el align-items del contenedor.

Reglas clave:

  1. Sobrescribe align-items → solo para ese ítem.
  1. Aplica al ítem, no al contenedor → el contenedor debe ser flex o grid.
  1. auto es el valor por defecto → hereda el align-items del contenedor.
  1. Afecta al eje transversal → depende de flex-direction.
  1. Funciona en flex y grid → en grid, alinea el ítem dentro de su celda (eje block).
  1. No afecta a los demás ítems → cada ítem puede tener su propio align-self.
  1. stretch → el ítem se estira para llenar el contenedor (o su celda).
  1. No funciona en ítems que no son hijos directos → debe ser hijo directo del contenedor flex/grid.

📝 Sintaxis / Estructura

selector {
  align-self: valor;
}
ValorDescripción
autoPor defecto. Hereda el align-items del contenedor.
stretchEl ítem se estira para llenar el contenedor.
flex-startAlineado al inicio del eje transversal.
flex-endAlineado al final del eje transversal.
centerCentrado en el eje transversal.
baselineAlineado por la línea base del texto.
startLógico. Inicio según writing-mode.
endLógico. Final según writing-mode.
self-startAlineación basada en el propio ítem (inicio).
self-endAlineación basada en el propio ítem (final).

💡 Ejemplos

/* 1. Destacar un ítem centrado */
.container {
  display: flex;
  align-items: flex-start;
}
.item-especial {
  align-self: center;
  /* Este ítem se centra, los demás arriba */
}

/* 2. Ítem al final */
.container {
  display: flex;
  align-items: center;
}
.item-final {
  align-self: flex-end;
}

/* 3. Ítem que no se estira */
.container {
  display: flex;
  align-items: stretch; /* por defecto */
}
.item-no-estirado {
  align-self: flex-start;
  /* Este ítem no se estira; los demás sí */
}

/* 4. Ítem estirado (sobrescribe center) */
.container {
  display: flex;
  align-items: center;
}
.item-estirado {
  align-self: stretch;
}

/* 5. Header con logo arriba y nav centrado */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  height: 80px;
}
.logo {
  align-self: flex-start;
  /* El logo se alinea arriba */
}

/* 6. Grid con un ítem alineado arriba */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  align-items: center;
}
.grid-item-especial {
  align-self: start;
}

/* 7. Baseline para un ítem concreto */
.row {
  display: flex;
  align-items: center;
}
.texto-grande {
  align-self: baseline;
  font-size: 2rem;
}

/* 8. Formulario con botón al fondo */
.form-row {
  display: flex;
  align-items: flex-start;
  gap: 8px;
}
.form-row__submit {
  align-self: flex-end;
  /* El botón se alinea al fondo de la fila */
}

/* 9. Card con footer al fondo */
.card {
  display: flex;
  flex-direction: column;
  min-height: 200px;
}
.card__footer {
  margin-top: auto;
  /* Alternativa a align-self en column */
}

/* 10. Comportamiento con auto */
.container {
  display: flex;
  align-items: center;
}
.item-auto {
  align-self: auto;
  /* Hereda center del contenedor */
}

  align-self: flex-start;

  align-self: flex-start;
  /* El logo se alinea arriba, el nav centrado */

  align-items: flex-start;
  gap: 8px;

.form-row__submit {
  align-self: flex-end;
  /* Alineado al fondo de la fila */

Grid con un ítem alineado arriba

  display: grid;
  grid-template-columns: repeat(3, 1fr);
  align-items: center;
  gap: 16px;
  height: 300px;
}
.grid__item--top {
  align-self: start;
  /* Este ítem se alinea arriba */
}

Baseline para un ítem concreto

.row {
  display: flex;
  align-items: center;
  gap: 16px;
}
.precio {
  align-self: baseline;
  font-size: 2.5rem;
  font-weight: bold;
}
.periodo {
  align-self: baseline;
  font-size: 0.875rem;
}
/* Ambos alineados por su línea base */

Card con footer al fondo (column)

.card {
  display: flex;
  flex-direction: column;
  min-height: 300px;
  padding: 20px;
}
.card__body {
  flex: 1;
  /* Ocupa el espacio disponible */
}
.card__footer {
  margin-top: auto;
  /* Alternativa a align-self: flex-end en column */
}

⚠️ Errores comunes

  1. Confundir align-self con align-items → align-items es del contenedor (todos los ítems); align-self es del ítem (uno solo).
  1. Aplicar align-self al contenedor → no tiene efecto; debe aplicarse al ítem.
  1. Olvidar que auto hereda align-items → si no defines align-self, el ítem sigue el align-items del contenedor.
  1. Esperar que funcione sin display: flex o grid → el padre debe ser flex o grid.
  1. Confundir align-self con justify-self → align-self = eje transversal; justify-self = eje principal (solo grid).
  1. Aplicar align-self a un elemento que no es hijo directo → no tiene efecto; debe ser hijo directo del contenedor.
  1. align-self: stretch sin altura definida → el ítem se estira a la altura del contenedor; si el contenedor no tiene altura, no se nota.
  1. align-self: baseline con ítems sin texto → no tiene efecto; la línea base se calcula del texto.
  1. Confundir align-self con align-content → align-self = ítem; align-content = líneas (requiere flex-wrap).
  1. align-self en grid → alinea el ítem dentro de su celda (eje block), no en el contenedor completo.
  1. Usar align-self en un contenedor sin altura → el efecto puede no notarse; el contenedor necesita altura definida.
  1. Confundir align-self: flex-end con margin-top: auto → ambos alinean al final, pero margin-top: auto es más limpio en columnas.

🧩 Relación con otros conceptos

  • align-items → alineación de todos los ítems (contenedor).
  • align-self → alineación de un ítem (individual).
  • justify-content → alineación en el eje principal.
  • justify-self → alineación individual en el eje principal (solo grid).
  • place-self → shorthand de align-self + justify-self (solo grid).
  • align-content → distribución de líneas (requiere flex-wrap).
  • flex-direction → define el eje transversal.
  • margin: auto → alternativa para alinear un ítem al final.
  • display: flex → activa el contenedor flex.
  • display: grid → en grid, align-self alinea dentro de la celda.
  • writing-mode → afecta a start/end.

Diferencia entre align-items y align-self:

align-items: center (contenedor)

┌─────────────────────────────┐
│                             │
│ [1]  [2]  [3]  [4]          │  ← todos centrados
│                             │
└─────────────────────────────┘

align-self: flex-end (solo el 3)

┌─────────────────────────────┐
│                             │
│ [1]  [2]       [4]          │  ← 1, 2, 4 centrados
│            [3]              │  ← 3 al fondo
└─────────────────────────────┘

🧠 Analogía

Imagina que los ítems flex son alumnos en una fila. align-items es la instrucción general del profesor: "todos sentados en el centro". align-self es la excepción individual: "tú, Juan, siéntate al fondo". El resto sigue la instrucción general; solo Juan tiene su propia alineación.

Es como un uniforme escolar con una insignia especial para un alumno: todos siguen el uniforme, pero uno destaca con algo diferente.

📝 Notas personales

  • align-self sobrescribe align-items → solo para un ítem concreto.
  • auto es el valor por defecto → hereda el align-items del contenedor.
  • Se aplica al ítem, no al contenedor → debe ser hijo directo del flex/grid.
  • Eje transversal → depende de flex-direction. Con row, alinea verticalmente.
  • No confundir con justify-self → align-self = eje transversal; justify-self = eje principal (solo grid).
  • stretch → el ítem se estira a la altura del contenedor (o celda).
  • baseline → útil para alinear textos de distintos tamaños.
  • Alternativa en column → margin-top: auto en lugar de align-self: flex-end para footer al fondo.
  • En grid → align-self alinea el ítem dentro de su celda, no en el contenedor.
  • Valores lógicos → preferir start/end sobre flex-start/flex-end en proyectos multiidioma.
  • No funciona en ítems que no son hijos directos → el padre debe ser el contenedor flex/grid.
