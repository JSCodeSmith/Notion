flex-direction

📄 flex-direction

📝 Definición

flex-direction es una propiedad CSS que establece la dirección del eje principal de un contenedor flex, es decir, cómo se colocan sus ítems (en fila o en columna) y en qué orden.

🧠 ¿Qué es?

Forma parte de las propiedades de flexbox (junto con justify-content, align-items, flex-wrap, flex, gap, etc.).

Solo aplica a contenedores flex (display: flex o display: inline-flex).

Define el eje principal del contenedor:

  • Eje principal (main axis) → la dirección en la que se colocan los ítems (flex-direction).
  • Eje transversal (cross axis) → perpendicular al eje principal.

Todas las propiedades de alineación (justify-content, align-items, etc.) dependen de esta dirección.

🎯 ¿Para qué sirve?

  • Colocar ítems en fila (horizontal) o columna (vertical).
  • Invertir el orden visual de los ítems (sin cambiar el HTML).
  • Definir el eje principal para justify-content.
  • Construir layouts verticales con flexbox.
  • Crear menús de navegación horizontales o verticales.
  • Diseñar tarjetas con contenido apilado.
  • Adaptar layouts con media queries cambiando la dirección.

⚙️ ¿Cómo funciona?

El navegador coloca los ítems flex a lo largo del eje principal según el valor:

  1. row (por defecto) → los ítems se colocan horizontalmente, de izquierda a derecha (en LTR).
  1. row-reverse → horizontalmente, de derecha a izquierda (en LTR).
  1. column → verticalmente, de arriba a abajo.
  1. column-reverse → verticalmente, de abajo a arriba.

Reglas clave:

  • Afecta al eje principal → justify-content alinea a lo largo de este eje.
  • Afecta al eje transversal → align-items alinea perpendicularmente.
  • No cambia el orden del DOM → solo el orden visual. El orden de tabulación y accesibilidad se mantiene.
  • row-reverse y column-reverse → el orden visual se invierte, pero el DOM no.
  • Se puede cambiar con media queries → patrón común para responsive.
  • En RTL → row se interpreta de derecha a izquierda automáticamente.

📝 Sintaxis / Estructura

selector {
  display: flex;
  flex-direction: valor;
}

💡 Ejemplos

/* 1. Fila horizontal (por defecto) */
.row {
  display: flex;
  flex-direction: row;
}

/* 2. Fila invertida */
.row-reverse {
  display: flex;
  flex-direction: row-reverse;
}

/* 3. Columna vertical */
.column {
  display: flex;
  flex-direction: column;
}

/* 4. Columna invertida */
.column-reverse {
  display: flex;
  flex-direction: column-reverse;
}

/* 5. Menú horizontal */
.menu {
  display: flex;
  flex-direction: row;
  gap: 16px;
}

/* 6. Menú vertical */
.menu-vertical {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

/* 7. Tarjeta con contenido apilado */
.card {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

/* 8. Responsive: fila en desktop, columna en móvil */
.layout {
  display: flex;
  flex-direction: column;
  gap: 16px;
}
@media (min-width: 768px) {
  .layout {
    flex-direction: row;
  }
}

/* 9. Centrar contenido vertical y horizontal */
.centrar {
  display: flex;
  flex-direction: row;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* 10. Columna con scroll */
.scroll-column {
  display: flex;
  flex-direction: column;
  overflow-y: auto;
  max-height: 400px;
}

Eje principal vs eje transversal

/* row (por defecto) */
.row {
  display: flex;
  flex-direction: row;
  justify-content: space-between; /* eje principal: horizontal */
  align-items: center;            /* eje transversal: vertical */
}

/* column */
.column {
  display: flex;
  flex-direction: column;
  justify-content: space-between; /* eje principal: vertical */
  align-items: center;            /* eje transversal: horizontal */
}

Responsive: fila → columna

.layout {
  display: flex;
  flex-direction: column;
  gap: 16px;
}
@media (min-width: 768px) {
  .layout {
    flex-direction: row;
  }
}

Menú de navegación horizontal

.nav {
  display: flex;
  flex-direction: row;
  gap: 24px;
  align-items: center;
}

Tarjeta con contenido apilado

.card {
  display: flex;
  flex-direction: column;
  gap: 12px;
  padding: 20px;
  border: 1px solid #ddd;
  border-radius: 8px;
}
.card__title { font-size: 1.25rem; }
.card__body  { flex: 1; }
.card__footer { display: flex; gap: 8px; }

Fila invertida (sin cambiar el DOM)

/* HTML:
<div class="row-reverse">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>
*/

.row-reverse {
  display: flex;
  flex-direction: row-reverse;
  /* Visualmente: 3, 2, 1 */
  /* En el DOM: 1, 2, 3 */
  /* El orden de tabulación sigue siendo 1, 2, 3 */
}

Columna con footer al fondo

.page {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
.page__main {
  flex: 1;
  /* Ocupa el espacio disponible */
}
.page__footer {
  /* Se queda al fondo */
}

⚠️ Errores comunes

  1. Confundir flex-direction con justify-content → flex-direction define el eje; justify-content alinea a lo largo de ese eje.
  1. Esperar que row-reverse cambie el orden del DOM → solo cambia el orden visual. El orden de tabulación y accesibilidad se mantiene.
  1. Usar row-reverse para "invertir" el HTML → no es una solución semántica; si el orden importa, cambiar el HTML.
  1. Olvidar que justify-content cambia de eje → con column, justify-content alinea verticalmente.
  1. Usar flex-direction sin display: flex → no tiene efecto. El padre debe ser un contenedor flex.
  1. Confundir flex-direction con flex-wrap → direction es el eje; wrap es si los ítems se envuelven.
  1. row-reverse con order → puede ser confuso; el orden visual depende de ambos.
  1. No considerar RTL → en árabe/hebreo, row se interpreta de derecha a izquierda automáticamente; row-reverse invierte eso.
  1. Usar column-reverse para listas → el orden de tabulación sigue siendo el del DOM; puede ser confuso para usuarios de teclado.
  1. Cambiar flex-direction sin ajustar justify-content/align-items → las alineaciones se invierten y el layout se rompe.
  1. flex-direction: column con height: 100% → el contenedor necesita una altura definida para que los ítems se distribuyan.
  1. Confundir column con grid → column es unidireccional; grid es bidireccional.

🧩 Relación con otros conceptos

  • display: flex → activa el contenedor flex.
  • justify-content → alinea a lo largo del eje principal.
  • align-items → alinea a lo largo del eje transversal.
  • align-self → sobrescribe align-items en un ítem.
  • flex-wrap → si los ítems se envuelven en múltiples líneas.
  • flex → shorthand de flex-grow, flex-shrink, flex-basis.
  • gap → espacio entre ítems (funciona en flex y grid).
  • order → cambia el orden visual de los ítems.
  • writing-mode → afecta a cómo se interpretan row y column.
  • direction → afecta a row en RTL/LTR.
  • grid-auto-flow → equivalente en grid (dirección del flujo).
  • Media queries → cambiar dirección en responsive.

Eje principal vs transversal:

flex-direction: row (por defecto)

Eje principal (main axis) →
┌─────────────────────────────┐
│  [1]  [2]  [3]  [4]         │  ← justify-content
│                             │
└─────────────────────────────┘
  ↑ align-items (cross axis)

flex-direction: column

Eje transversal (cross axis) →
┌─────────────────────────────┐
│  [1]                        │
│  [2]                        │  ← justify-content
│  [3]                        │     (ahora vertical)
│  [4]                        │
└─────────────────────────────┘
  ↑ align-items (ahora horizontal)

🧠 Analogía

Imagina que un contenedor flex es una estantería. flex-direction decide cómo colocas los libros:

  • row → los libros de pie, uno al lado del otro, de izquierda a derecha.
  • row-reverse → los libros de pie, de derecha a izquierda.
  • column → los libros apilados uno encima de otro, de arriba a abajo.
  • column-reverse → los libros apilados de abajo a arriba.

Y las propiedades justify-content (a lo largo de la estantería) y align-items (perpendicular) dependen de cómo hayas colocado los libros.

📝 Notas personales

  • row es el valor por defecto → si no defines flex-direction, los ítems van en fila.
  • Define el eje principal → justify-content alinea a lo largo de este eje; align-items, perpendicular.
  • row-reverse y column-reverse → cambian el orden visual, no el del DOM. El orden de tabulación se mantiene.
  • No usar row-reverse para invertir el HTML → si el orden importa semánticamente, cambiar el HTML.
  • Responsive → cambiar flex-direction con media queries es el patrón más común para layouts adaptativos.
  • column + flex: 1 → patrón para footer al fondo (el main ocupa el espacio disponible).
  • En RTL, row se interpreta automáticamente de derecha a izquierda → no necesitas row-reverse.
  • Confundir con flex-wrap → direction es el eje; wrap es si los ítems se envuelven en varias líneas.
  • Para layouts bidimensionales → usar grid en lugar de flex
