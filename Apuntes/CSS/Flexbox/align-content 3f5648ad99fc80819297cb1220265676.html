align-content

📄 align-content

📝 Definición

align-content es una propiedad CSS que distribuye y alinea las líneas de un contenedor flex (o grid) a lo largo del eje transversal, controlando cómo se reparte el espacio libre entre líneas cuando hay múltiples filas o columnas.

🧠 ¿Qué es?

Forma parte de las propiedades de alineación de flexbox (junto con justify-content, align-items, align-self, place-content).

Es la menos comprendida de las propiedades de flexbox porque solo tiene efecto cuando hay más de una línea.

Actúa sobre el eje transversal, igual que align-items, pero con una diferencia clave:

  • align-items → alinea los ítems dentro de cada línea.
  • align-content → distribuye las líneas entre sí.

⚠️ Requiere flex-wrap: wrap o wrap-reverse → si todos los ítems caben en una sola línea, align-content no tiene efecto visible.

🎯 ¿Para qué sirve?

  • Distribuir múltiples líneas de ítems en un contenedor flex.
  • Controlar el espacio entre filas cuando hay flex-wrap.
  • Alinear líneas al inicio, final, centro o estiradas.
  • Construir grids con flexbox (aunque hoy se usa CSS Grid).
  • Repartir el espacio libre entre filas de tarjetas, tags, botones.
  • Crear layouts tipo mosaico con flex.

⚙️ ¿Cómo funciona?

El navegador distribuye las líneas del contenedor flex a lo largo del eje transversal según el valor:

  1. stretch (por defecto) → las líneas se estiran para llenar el contenedor.
  1. flex-start → líneas agrupadas al inicio del eje transversal.
  1. flex-end → líneas agrupadas al final.
  1. center → líneas centradas.
  1. space-between → primera línea al inicio, última al final, espacio entre ellas.
  1. space-around → cada línea con el mismo espacio alrededor; extremos con la mitad.
  1. space-evenly → espacio uniforme entre todas las líneas (incluidos los extremos).
  1. start, end → valores lógicos.
  1. baseline, first baseline, last baseline → alineación por línea base.

Reglas clave:

  • Solo aplica con flex-wrap: wrap o wrap-reverse → con nowrap, se ignora.
  • Solo aplica con múltiples líneas → con una sola línea, se ignora.
  • Depende de flex-direction → con row, distribuye filas; con column, columnas.
  • Afecta a las líneas, no a los ítems → para ítems, usar align-items.
  • En grid → distribuye las filas dentro del contenedor (eje block).
  • stretch es el valor por defecto → las líneas se estiran para ocupar todo el espacio.

📝 Sintaxis / Estructura

selector {
  display: flex;
  flex-wrap: wrap;
  align-content: valor;
}
ValorDescripción
stretchPor defecto. Las líneas se estiran para llenar el contenedor.
flex-startLíneas agrupadas al inicio del eje transversal.
flex-endLíneas agrupadas al final del eje transversal.
centerLíneas centradas en el eje transversal.
space-betweenPrimera línea al inicio, última al final, espacio entre ellas.
space-aroundEspacio uniforme alrededor de cada línea (extremos con la mitad).
space-evenlyEspacio uniforme entre todas las líneas (incluidos extremos).
startLógico. Inicio según writing-mode.
endLógico. Final según writing-mode.
baseline, first baseline, last baselineAlineación por línea base.

💡 Ejemplos

/* 1. Stretch (por defecto) */
.stretch {
  display: flex;
  flex-wrap: wrap;
  align-content: stretch;
  /* Las líneas se estiran para llenar el contenedor */
}

/* 2. Líneas al inicio */
.inicio {
  display: flex;
  flex-wrap: wrap;
  align-content: flex-start;
}

/* 3. Líneas al final */
.final {
  display: flex;
  flex-wrap: wrap;
  align-content: flex-end;
}

/* 4. Líneas centradas */
.centro {
  display: flex;
  flex-wrap: wrap;
  align-content: center;
}

/* 5. Espacio entre líneas */
.entre {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between;
}

/* 6. Espacio alrededor de cada línea */
.alrededor {
  display: flex;
  flex-wrap: wrap;
  align-content: space-around;
}

/* 7. Espacio uniforme entre líneas */
.uniforme {
  display: flex;
  flex-wrap: wrap;
  align-content: space-evenly;
}

/* 8. Combinado con align-items y justify-content */
.layout {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;   /* eje principal: horizontal */
  align-items: center;       /* ítems dentro de cada línea */
  align-content: center;     /* líneas en el eje transversal */
  gap: 16px;
  height: 100vh;
}

/* 9. Galería de tags */
.tags {
  display: flex;
  flex-wrap: wrap;
  align-content: flex-start;
  gap: 8px;
  max-height: 200px;
  overflow-y: auto;
}

/* 10. Grid de tarjetas con flex */
.cards {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between;
  gap: 16px;
}
.card {
  flex: 1 1 250px;
}

Centrar múltiples líneas

  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  align-content: center;

}

Diferencia con align-items

.container {
  display: flex;
  flex-wrap: wrap;
  align-items: center;    /* centra los ÍTEMS dentro de cada línea */
  align-content: center;  /* centra las LÍNEAS en el contenedor */
  height: 400px;
}

⚠️ Errores comunes

  1. Usar align-content sin flex-wrap: wrap → se ignora por completo. Error nº1.
  1. Usar align-content con una sola línea → no tiene efecto visible (no hay varias líneas que distribuir).
  1. Confundir align-content con align-items → align-content = líneas; align-items = ítems dentro de cada línea.
  1. Confundir align-content con justify-content → align-content = eje transversal; justify-content = eje principal.
  1. Esperar que funcione en un contenedor sin altura fija → si el contenedor no tiene altura definida (o flex: 1), no hay espacio libre que distribuir.
  1. Olvidar que stretch es el valor por defecto → las líneas se estiran para llenar el contenedor.
  1. Usar align-content en un ítem flex → solo aplica al contenedor.
  1. Confundir con place-content → place-content es shorthand de align-content + justify-content.
  1. align-content en grid → distribuye las filas dentro del contenedor (eje block); en flex, distribuye líneas.
  1. Esperar que cambie el tamaño de los ítems → solo distribuye las líneas; para tamaño, usar flex, height o gap.
  1. No usar gap → align-content distribuye líneas, pero gap controla el espacio entre ítems (y entre líneas).
  1. Usar align-content con flex-direction: column sin entender el eje → con column, distribuye columnas en el eje transversal (horizontal).

🧩 Relación con otros conceptos

  • display: flex → activa el contenedor flex.
  • flex-wrap → obligatorio para que align-content tenga efecto.
  • flex-direction → define el eje transversal sobre el que actúa.
  • justify-content → alinea en el eje principal.
  • align-items → alinea ítems dentro de cada línea (eje transversal).
  • align-self → sobrescribe align-items en un ítem individual.
  • place-content → shorthand de align-content + justify-content.
  • gap → espacio entre ítems y entre líneas.
  • Grid → align-content distribuye filas dentro del contenedor.
  • height → sin altura definida, align-content no tiene espacio que distribuir.
  • flex: 1 → hace que el contenedor ocupe el espacio disponible, útil con align-content.

Eje principal vs transversal (con flex-wrap):

🧠 Analogía

Imagina que tienes varias filas de estanterías en una pared (cada fila = una línea de ítems). align-content decide cómo distribuyes esas filas verticalmente en la pared:

  • flex-start → todas las filas arriba.
  • flex-end → todas las filas abajo.
  • center → todas las filas centradas.
  • space-between → primera fila arriba, última abajo, espacio entre ellas.
  • space-around → espacio uniforme alrededor de cada fila.
  • space-evenly → espacio igual entre todas las filas.
  • stretch → las filas se alargan para llenar la pared.

Y align-items sería cómo colocas los objetos dentro de cada fila (arriba, centro, abajo de la fila).

📝 Notas personales

  • Requiere flex-wrap: wrap → sin él, se ignora. Error nº1.
  • Requiere múltiples líneas → con una sola línea, no tiene efecto visible.
  • Distribuye LÍNEAS, no ítems → para ítems, usar align-items.
  • Actúa sobre el eje transversal → depende de flex-direction.
  • stretch es el valor por defecto → las líneas se estiran para llenar el contenedor.
  • Necesita altura fija → si el contenedor no tiene altura, no hay espacio que distribuir. Usar height, min-height o flex: 1.
  • Confundir con align-items → es el error más común. align-content = líneas; align-items = ítems.
  • Confundir con justify-content → align-content = eje transversal; justify-content = eje principal.
  • Hoy se usa menos → CSS Grid es mejor para layouts 2D con múltiples filas. Pero sigue siendo útil en flex con wrap.
  • place-content → shorthand útil: place-content: center = align-content: center; justify-content: center.
