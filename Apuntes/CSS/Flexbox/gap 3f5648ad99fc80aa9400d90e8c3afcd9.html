gap

📄 gap

📝 Definición

gap es una propiedad CSS que establece el espacio entre filas y columnas en contenedores flex, grid y multi-column.

Es un shorthand de row-gap (espacio entre filas) y column-gap (espacio entre columnas).

🧠 ¿Qué es?

Forma parte de las propiedades de layout moderno (junto con display: flex, display: grid, grid-template-columns, etc.).

Nació en CSS Grid (como grid-gap) y luego se extendió a flexbox y multi-column.

Reemplaza el uso de márgenes negativos, márgenes individuales o padding para separar ítems, ofreciendo una solución más limpia y mantenible.

🎯 ¿Para qué sirve?

  • Separar ítems en flexbox y grid sin usar márgenes.
  • Crear grids con espaciado uniforme.
  • Separar filas y columnas con distintos valores.
  • Simplificar layouts responsive.
  • Evitar el patrón de margin-right en todos los ítems menos el último.
  • Crear galerías, menús, dashboards y formularios con espaciado consistente.

⚙️ ¿Cómo funciona?

El navegador aplica el espacio indicado entre ítems adyacentes, pero no en los bordes del contenedor.

Reglas clave:

  1. Shorthand → gap: <row-gap> <column-gap>.
  1. Un valor → mismo espacio para filas y columnas.
  1. Dos valores → primero filas, segundo columnas.
  1. No aplica en los bordes → el espacio es solo entre ítems.
  1. No colapsa → a diferencia de margin, no se fusiona.
  1. Funciona en flex → desde 2020, soportado en navegadores modernos.
  1. Funciona en grid → propiedad nativa.
  1. Funciona en multi-column → con column-gap (o gap).
  1. Acepta cualquier unidad de longitud → px, em, rem, %, vw, etc.
  1. No acepta valores negativos → a diferencia de margin.

📝 Sintaxis / Estructura

/* Un valor: filas y columnas iguales */
gap: 16px;

/* Dos valores: filas | columnas */
gap: 16px 24px;

/* Propiedades individuales */
row-gap: 16px;
column-gap: 24px;

💡 Ejemplos

/* 1. Gap uniforme en flex */
.flex {
  display: flex;
  gap: 16px;
}

/* 2. Gap uniforme en grid */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* 3. Gap distinto para filas y columnas */
.grid-asimetrico {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px 16px;
  /* 24px entre filas, 16px entre columnas */
}

/* 4. Propiedades individuales */
.individual {
  display: grid;
  row-gap: 24px;
  column-gap: 16px;
}

/* 5. Menú horizontal con gap */
.menu {
  display: flex;
  gap: 24px;
  align-items: center;
}

/* 6. Galería de tarjetas */
.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

/* 7. Formulario con gap */
.form {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

/* 8. Dashboard con grid y gap */
.dashboard {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 24px;
}

/* 9. Multi-column con gap */
.texto-columnas {
  column-count: 3;
  column-gap: 32px;
}

/* 10. Flex wrap con gap */
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
.tag {
  padding: 4px 12px;
  background: #f0f0f0;
  border-radius: 12px;
}

Grid responsive con gap

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

}

Flex con gap (sin márgenes)

.nav {
  display: flex;
  gap: 24px;
  align-items: center;
}
/* Sin necesidad de margin-right en los ítems */

Formulario con gap

.form {
  display: flex;
  flex-direction: column;
  gap: 16px;
}
.form__group {
  display: flex;
  flex-direction: column;
  gap: 4px;
}

Comparativa: gap vs margin

/* ❌ Con margin: hay que gestionar el último ítem */
.nav-margin {
  display: flex;
}
.nav-margin > * {
  margin-right: 16px;
}
.nav-margin > *:last-child {
  margin-right: 0;
}

/* ✅ Con gap: limpio y sin excepciones */
.nav-gap {
  display: flex;
  gap: 16px;
}

Gap en flex-wrap

  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

Gap asimétrico en grid

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 32px 16px;
  /* 32px entre filas, 16px entre columnas */
}

⚠️ Errores comunes

  1. Esperar que gap añada espacio en los bordes → gap solo separa ítems entre sí, no añade espacio en los extremos del contenedor.
  1. Usar gap en un contenedor sin display: flex o grid → no tiene efecto.
  1. Confundir gap con margin → gap no colapsa y no genera espacio exterior.
  1. Intentar valores negativos → no permitidos.
  1. Confundir el orden de los dos valores → primero filas, luego columnas (gap: 24px 16px).
  1. Usar gap en navegadores muy antiguos → el soporte en flex es de 2020; en grid, algo anterior. Verificar Can I Use.
  1. Confundir gap con grid-gap → grid-gap es el nombre antiguo; hoy gap es el estándar.
  1. Esperar que gap funcione en multi-column igual que en flex/grid → en multi-column, gap es un alias de column-gap; row-gap no aplica.
  1. Usar gap y margin a la vez → el espacio se suma, no se reemplaza. Puede dar sorpresas.
  1. gap en grid con grid-template-areas → funciona igual; el gap separa las celdas.
  1. Confundir gap con padding → gap es espacio entre ítems; padding es espacio dentro del contenedor.
  1. gap con porcentajes → el porcentaje se calcula respecto al tamaño del contenedor; puede ser impredecible con flex-wrap.

🧩 Relación con otros conceptos

  • display: flex → activa el contenedor flex; gap funciona desde 2020.
  • display: grid → gap es nativo y muy usado.
  • row-gap → espacio entre filas (individual).
  • column-gap → espacio entre columnas (individual).
  • margin → alternativa antigua; colapsa y requiere gestionar el último ítem.
  • padding → espacio dentro del contenedor, no entre ítems.
  • flex-wrap → gap separa tanto horizontal como verticalmente con wrap.
  • grid-template-columns → combinado con gap para grids completos.
  • justify-content / align-content → distribuyen espacio libre; gap es espacio fijo.
  • Multi-column → column-gap funciona; row-gap no aplica.
  • place-content → shorthand de align-content + justify-content, no de gap.
  • grid-gap → nombre antiguo de gap en grid (obsoleto pero funciona).

🧠 Analogía

Imagina que los ítems son cuadros colgados en una pared. gap es la distancia entre los clavos donde los cuelgas: no añade espacio en los extremos de la pared, solo entre los cuadros. Es como si los cuadros tuvieran una separación fija entre ellos, sin importar cuántos haya.

margin, en cambio, sería como poner espacio alrededor de cada cuadro: también genera espacio en los extremos, y hay que eliminarlo manualmente del último.

📝 Notas personales

  • gap es la forma moderna de separar ítems → reemplaza margin en flex y grid.
  • No añade espacio en los bordes → solo entre ítems. Para padding exterior, usar padding en el contenedor.
  • Orden de valores: primero filas, luego columnas (gap: 24px 16px).
  • No colapsa → a diferencia de margin, no se fusiona.
  • No acepta negativos → solo valores ≥ 0.
  • Funciona en flex desde 2020 → soporte amplio hoy; verificar navegadores antiguos si es necesario.
  • row-gap y column-gap → usar individuales si necesitas distintos valores.
  • En multi-column → column-gap es lo que se usa; row-gap no aplica.
  • No confundir con justify-content/align-content → esos distribuyen espacio libre; gap es espacio fijo entre ítems.
  • Combinar gap con flex: 1 1 <base> → patrón clásico para grids responsive en flex.
  • Alternativa moderna en grid → grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; es el patrón más limpio para galerías responsive.
