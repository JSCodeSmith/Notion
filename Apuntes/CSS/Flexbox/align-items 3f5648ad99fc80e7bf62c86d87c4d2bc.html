align-items

📄 align-items

📝 Definición

align-items es una propiedad CSS que alinea los ítems de un contenedor flex (o grid) a lo largo del eje transversal, controlando cómo se distribuyen perpendicularmente al eje principal.

🧠 ¿Qué es?

Forma parte de las propiedades de alineación de flexbox (junto con justify-content, align-self, align-content, place-items).

Es una de las propiedades más usadas para centrar ítems verticalmente en flexbox.

Actúa sobre el eje transversal, que depende de flex-direction:

  • Con flex-direction: row → eje transversal vertical.
  • Con flex-direction: column → eje transversal horizontal.

⚠️ No confundir con justify-content → justify-content alinea en el eje principal; align-items, en el eje transversal.

🎯 ¿Para qué sirve?

  • Centrar ítems verticalmente en un contenedor row.
  • Centrar ítems horizontalmente en un contenedor column.
  • Estirar ítems para que ocupen toda la altura (o ancho) del contenedor.
  • Alinear ítems al inicio o al final del eje transversal.
  • Alinear ítems por su línea base de texto.
  • Construir headers, tarjetas, botones con iconos y layouts centrados.
  • Evitar tener que usar line-height o margin: auto para centrar verticalmente.

⚙️ ¿Cómo funciona?

El navegador alinea los ítems flex a lo largo del eje transversal según el valor:

  1. stretch (por defecto) → los ítems se estiran para llenar el contenedor en el eje transversal.
  1. flex-start → alineados al inicio del eje transversal.
  1. flex-end → alineados al final del eje transversal.
  1. center → centrados en el eje transversal.
  1. baseline → alineados por la línea base del texto.
  1. start, end → valores lógicos (respetan writing-mode).
  1. self-start, self-end → alineación basada en el propio ítem.

Reglas clave:

  • Solo aplica al contenedor flex/grid → no a los ítems individuales.
  • Afecta a todos los ítems → salvo que un ítem sobrescriba con align-self.
  • Depende de flex-direction → con row, alinea verticalmente; con column, horizontalmente.
  • stretch es el valor por defecto → por eso los ítems flex se estiran a la misma altura por defecto.
  • baseline → útil para alinear texto de distintos tamaños.
  • Funciona con grid → alinea los ítems dentro de sus celdas (eje block).

📝 Sintaxis / Estructura

selector {
  display: flex;
  align-items: valor;
}
ValorDescripción
stretchPor defecto. Los ítems se estiran para llenar el contenedor.
flex-startAlineados al inicio del eje transversal.
flex-endAlineados al final del eje transversal.
centerCentrados en el eje transversal.
baselineAlineados por la línea base del texto.
startLógico. Inicio según writing-mode.
endLógico. Final según writing-mode.
self-startAlineación basada en el propio ítem (inicio).
self-endAlineación basada en el propio ítem (final).

💡 Ejemplos

/* 1. Centrar verticalmente (row) */
.centrar {
  display: flex;
  align-items: center;
}

/* 2. Centrar horizontal y verticalmente */
.centrar-todo {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* 3. Ítems al inicio (arriba) */
.inicio {
  display: flex;
  align-items: flex-start;
}

/* 4. Ítems al final (abajo) */
.final {
  display: flex;
  align-items: flex-end;
}

/* 5. Stretch (por defecto) */
.stretch {
  display: flex;
  align-items: stretch;
  /* Los ítems se estiran a la misma altura */
}

/* 6. Baseline (texto alineado por la base) */
.baseline {
  display: flex;
  align-items: baseline;
  /* Útil cuando hay textos de distintos tamaños */
}

/* 7. Header con logo y nav centrados */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px;
}

/* 8. Botón con icono + texto */
.btn {
  display: inline-flex;
  align-items: center;
  gap: 8px;
  padding: 12px 20px;
}

/* 9. Card con contenido centrado */
.card {
  display: flex;
  flex-direction: column;
  align-items: center;
  text-align: center;
  padding: 24px;
}

/* 10. Columna con ítems al inicio */
.columna {
  display: flex;
  flex-direction: column;
  align-items: flex-start;
  gap: 8px;
}

Stretch (por defecto)

.row {
  display: flex;
  align-items: stretch;
  /* Los ítems se estiran a la altura del más alto */
}
.col {
  flex: 1;
  /* Todos los hijos tienen la misma altura */
}

Sobrescribir con align-self

.container {
  display: flex;
  align-items: center;
  /* Todos centrados */
}
.item-especial {
  align-self: flex-start;
  /* Este ítem se alinea arriba, ignorando align-items */
}

⚠️ Errores comunes

  1. Confundir align-items con justify-content → align-items = eje transversal; justify-content = eje principal. Error nº1.
  1. Esperar que funcione sin display: flex → no tiene efecto si el padre no es flex/grid.
  1. Olvidar que stretch es el valor por defecto → por eso los ítems se estiran a la misma altura.
  1. Usar align-items para alinear un solo ítem → usar align-self en el ítem concreto.
  1. Confundir align-items con align-content → align-items alinea ítems; align-content distribuye líneas (con flex-wrap).
  1. align-items: center con ítems sin altura → si el ítem no tiene altura, centrar no se nota. Usar stretch o definir altura.
  1. baseline con ítems sin texto → no tiene efecto; la línea base se calcula del texto.
  1. Olvidar el gap → align-items no controla el espacio entre ítems; usar gap.
  1. Esperar que align-items cambie el tamaño de los ítems → solo los alinea; para tamaño, usar flex o height.
  1. align-items en grid → en grid, alinea los ítems dentro de sus celdas (eje block). No es lo mismo que en flex.
  1. align-items: center y text-align: center → el primero alinea los ítems flex; el segundo, el texto.
  1. Usar align-items para centrar verticalmente un bloque sin flex → no funciona; usar flex, grid o position.

🧩 Relación con otros conceptos

  • display: flex → activa el contenedor flex.
  • flex-direction → define el eje transversal sobre el que actúa align-items.
  • justify-content → alinea en el eje principal.
  • align-self → sobrescribe align-items en un ítem individual.
  • align-content → distribuye líneas en el eje transversal (con flex-wrap).
  • place-items → shorthand de align-items + justify-items (grid).
  • place-content → shorthand de align-content + justify-content.
  • gap → espacio entre ítems (no confundir con alineación).
  • text-align → centra texto, no ítems flex.
  • margin: auto → alternativa para centrar un ítem individual.
  • Grid → align-items alinea los ítems dentro de sus celdas (eje block).

Eje principal vs transversal:

flex-direction: row

Eje principal →  justify-content actúa aquí
┌─────────────────────────────────────┐
│ [1]   [2]   [3]   [4]               │
│                                     │  ↑ align-items
└─────────────────────────────────────┘  actúa aquí

flex-direction: column

Eje transversal → align-items actúa aquí
┌─────────────────────────────────────┐
│ [1]                                 │
│ [2]  ← justify-content actúa aquí   │
│ [3]                                 │
│ [4]                                 │
└─────────────────────────────────────┘

🧠 Analogía

Imagina que los ítems flex son cuadros colgados en una pared:

  • flex-start → todos colgados arriba.
  • flex-end → todos colgados abajo.
  • center → todos colgados a media altura.
  • stretch → los cuadros se alargan para ocupar toda la pared.
  • baseline → todos alineados por la base del texto que contienen.

justify-content sería dónde los cuelgas a lo largo de la pared (izquierda, centro, derecha), y align-items sería a qué altura.

📝 Notas personales

  • stretch es el valor por defecto → por eso los ítems flex se estiran a la misma altura sin que lo pidas.
  • Actúa sobre el eje transversal → depende de flex-direction. Con row, alinea verticalmente; con column, horizontalmente.
  • No confundir con justify-content → align-items = eje transversal; justify-content = eje principal.
  • El patrón de centrado → display: flex; justify-content: center; align-items: center; centra todo.
  • align-self → para sobrescribir align-items en un ítem concreto.
  • baseline → útil para alinear textos de distintos tamaños (ej. precios, títulos).
  • stretch → se puede desactivar con align-items: flex-start si no quieres que los ítems se estiren.
  • No confundir con align-content → align-content distribuye líneas cuando hay flex-wrap.
  • Para centrar verticalmente sin flex → usar grid o position. align-items requiere un contenedor flex/grid.
  • Valores lógicos → preferir start/end sobre flex-start/flex-end en proyectos multiidioma.
