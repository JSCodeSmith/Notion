background-blend-mode

📄 background-blend-mode

📝 Definición

background-blend-mode es una propiedad CSS que define cómo se mezclan entre sí las capas de fondo de un elemento:

El color de fondo (background-color) y cada una de las imágenes (background-image), usando modos de fusión similares a los de programas de diseño como Photoshop.

🧠 ¿Qué es?

Forma parte de las propiedades de fondo y de fusión (junto con mix-blend-mode, isolation, filter).

Controla cómo se combinan las capas dentro del propio elemento, no con el fondo externo.

Es importante no confundirla con mix-blend-mode:

  • background-blend-mode → mezcla las capas de fondo del propio elemento entre sí.
  • mix-blend-mode → mezcla el elemento completo con lo que hay detrás de él (otros elementos, el fondo del padre, etc.).

🎯 ¿Para qué sirve?

  • Mezclar una imagen con un color (tintes, duotonos).
  • Combinar múltiples imágenes con efectos visuales.
  • Aplicar gradientes sobre fotos con fusión.
  • Crear efectos de superposición sin editar la imagen en un editor.
  • Añadir texturas que se fundan con el fondo.
  • Lograr efectos retro, duotono, sepia, multiply.

⚙️ ¿Cómo funciona?

El navegador toma las capas de fondo de abajo a arriba y las va mezclando según el modo indicado:

  1. La capa más baja es el background-color (o la última imagen).
  1. Cada capa superior se mezcla con el resultado de las capas inferiores.
  1. El modo de fusión se aplica entre cada capa y el "lienzo" acumulado.
  1. Si hay varias capas, se pueden especificar varios modos separados por comas.

Reglas clave:

  • Requiere al menos 2 capas → si solo hay background-color, no hay nada que mezclar.
  • Se aplica por capa → cada valor corresponde a la capa en la misma posición de background-image.
  • No afecta al contenido → solo al fondo, no al texto ni a los hijos.
  • El orden importa → la primera capa de background-image es la más cercana al usuario.
  • Compatible con background-color → el color es la capa base.
  • No funciona con background-clip: text de la misma forma → el fondo se recorta antes de mezclarse.

📝 Sintaxis / Estructura

selector {
  background-blend-mode: modo;
}

Múltiples capas

background-blend-mode: multiply, screen, overlay;
/* cada valor corresponde a la capa en la misma posición de background-image */

💡 Ejemplos

/* 1. Imagen + color con multiply (tinte oscuro) */
.tinte {
  background-image: url("foto.jpg");
  background-color: #3498db;
  background-blend-mode: multiply;
  /* La foto se tiñe de azul oscuro */
}

/* 2. Imagen + color con screen (tinte claro) */
.tinte-claro {
  background-image: url("foto.jpg");
  background-color: #f39c12;
  background-blend-mode: screen;
  /* La foto se tiñe de naranja claro */
}

/* 3. Duotono: imagen + gradiente */
.duotono {
  background-image:
    linear-gradient(135deg, #667eea, #764ba2),
    url("foto.jpg");
  background-blend-mode: multiply;
  /* El gradiente se multiplica con la foto → efecto duotono */
}

/* 4. Textura sobre color */
.textura {
  background-image: url("textura.png");
  background-color: #f5f5f5;
  background-blend-mode: multiply;
  /* La textura se funde con el color de fondo */
}

/* 5. Múltiples capas con distintos modos */
.multicapa {
  background-image:
    url("capa-1.png"),
    url("capa-2.png"),
    linear-gradient(135deg, #667eea, #764ba2);
  background-blend-mode: multiply, screen, normal;
  /* Cada capa se mezcla con las inferiores */
}

/* 6. Overlay para oscurecer sin gradiente */
.overlay-multiply {
  background-image: url("hero.jpg");
  background-color: rgba(0, 0, 0, 0.5);
  background-blend-mode: multiply;
  /* Oscurece la imagen para que el texto blanco destaque */
}

/* 7. Efecto sepia */
.sepia {
  background-image: url("foto.jpg");
  background-color: #d4a373;
  background-blend-mode: multiply;
  filter: sepia(0.5);
  /* Combinación de blend + filtro */
}

/* 8. Diferencia (efecto psicodélico) */
.difference {
  background-image: url("foto.jpg");
  background-color: #ff0080;
  background-blend-mode: difference;
}

/* 9. Soft-light para tintes suaves */
.suave {
  background-image: url("foto.jpg");
  background-color: #ff6b6b;
  background-blend-mode: soft-light;
  /* Tinte suave sin sobresaturar */
}

/* 10. Luminosity: color con la luz de la imagen */
.luminosity {
  background-image: url("foto.jpg");
  background-color: #2c3e50;
  background-blend-mode: luminosity;
  /* Toma la luminosidad de la imagen y el color de fondo */
}

Tinte de color sobre imagen (patrón muy común)

.hero {
  background-image: url("hero.jpg");
  background-color: #3498db;
  background-blend-mode: multiply;
  background-size: cover;
  background-position: center;
  /* La imagen se tiñe de azul */
}

Duotono con gradiente

.duotono {
  background-image:
    linear-gradient(135deg, #f39c12, #e74c3c),
    url("foto.jpg");
  background-blend-mode: multiply;
  background-size: cover;
  background-position: center;
  /* El gradiente se multiplica con la foto */
}

Textura sutil sobre color

.card {
  background-image: url("noise.png");
  background-color: #f8f9fa;
  background-blend-mode: multiply;
  /* Textura sutil sobre el color de fondo */
}

Overlay para texto legible

.hero {
  background-image: url("hero.jpg");
  background-color: rgba(0, 0, 0, 0.4);
  background-blend-mode: multiply;
  /* Oscurece la imagen para que el texto blanco destaque */
  color: white;
}

Múltiples capas con distintos modos

.multicapa {
  background-image:
    url("patron.png"),         /* capa superior */
    url("foto.jpg");           /* capa inferior */
  background-color: #3498db;
  background-blend-mode: screen, multiply;
  /* patron.png se mezcla con screen → resultado se mezcla con multiply */
}

⚠️ Errores comunes

  1. Confundir background-blend-mode con mix-blend-mode → el primero mezcla capas de fondo del propio elemento; el segundo mezcla el elemento con lo que hay detrás.
  1. Usarlo sin background-image → solo con background-color no hay nada que mezclar.
  1. Esperar que afecte al contenido → solo afecta al fondo, no al texto ni a los hijos.
  1. Olvidar el orden de las capas → la primera capa de background-image es la más cercana al usuario y se mezcla con las inferiores.
  1. Usar multiply con colores claros → el resultado también será claro; para oscurecer, usar colores oscuros.
  1. Usar screen con colores oscuros → el resultado será oscuro; para aclarar, usar colores claros.
  1. No considerar el rendimiento → los blend modes son costosos; usarlos con moderación en animaciones.
  1. Combinar con background-clip: text → el recorte se aplica antes de la mezcla; los resultados pueden ser inesperados.
  1. Esperar que funcione en todos los navegadores → el soporte es bueno hoy, pero conviene verificar en Can I Use.
  1. Usar difference o exclusion con texto encima → el resultado puede ser ilegible. Verificar contraste.
  1. No usar fallback → si el navegador no soporta el modo, se aplica normal (la capa superior tapa la inferior). Considerar un fallback con opacidad.
  1. Mezclar demasiadas capas → el resultado puede ser caótico. Limitar a 2-3 capas.

🧩 Relación con otros conceptos

  • background-image → define las capas a mezclar.
  • background-color → es la capa base de la mezcla.
  • mix-blend-mode → mezcla el elemento con lo que hay detrás.
  • isolation → aísla un contexto de fusión.
  • background-clip → recorta el fondo antes de la mezcla.
  • background-origin → define desde dónde se posiciona.
  • filter → efectos adicionales (sepia, blur, etc.).
  • opacity → alternativa más simple para transparencias.
  • background → shorthand que no incluye background-blend-mode.
  • Modos de fusión de Photoshop → misma lógica y nombres.
  • @supports → para detectar soporte y ofrecer fallback.

Diferencia entre background-blend-mode y mix-blend-mode:

background-blend-mode:
┌─────────────────────────┐
│  capa 1 (background)    │  ← se mezcla con
│  capa 2 (background)    │
│  color (background)     │
└─────────────────────────┘
  Todo dentro del elemento

mix-blend-mode:
┌─────────────────────────┐
│  Elemento               │  ← se mezcla con
│  ┌───────────────────┐  │
│  │  Fondo del padre  │  │
│  └───────────────────┘  │
└─────────────────────────┘
  El elemento con lo de detrás

🧠 Analogía

Imagina que tienes varias transparencias de colores apiladas sobre una mesa. background-blend-mode decide cómo se combinan esas transparencias entre sí: si las multiplicas (oscuridad), las aclaras (luz), las superpones (overlay), etc. El resultado es lo que ves a través del montón.

mix-blend-mode, en cambio, sería cómo se combina toda tu pila de transparencias con lo que hay debajo de la mesa (el fondo del padre, otros elementos…).

📝 Notas personales

  • Regla mental: background-blend-mode mezcla capas de fondo; mix-blend-mode mezcla el elemento con lo de detrás.
  • Requiere al menos 2 capas → background-color + background-image, o dos background-image.
  • multiply es el más usado → tinte oscuro sobre foto; ideal para overlays de texto.
  • screen aclara → útil para tintes claros y efectos luminosos.
  • Duotono → linear-gradient + url() con multiply es el patrón clásico.
  • Overlay para texto legible → background-color: rgba(0,0,0,0.4) + multiply en lugar de gradiente.
  • No afecta al contenido → solo al fondo, no al texto ni a los hijos.
  • Rendimiento → los blend modes son costosos; evitar animarlos.
  • Fallback → sin soporte, se aplica normal (la capa superior tapa la inferior). Usar @supports o valores alternativos.
  • Combinación con filter → multiply + sepia() o grayscale() permite efectos muy interesantes.
  • Modos de fusión → los nombres coinciden con Photoshop; si sabes usarlos allí, los entiendes aquí.
  • isolation: isolate → útil para aislar un contexto de fusión y evitar que se mezcle con elementos externos.
