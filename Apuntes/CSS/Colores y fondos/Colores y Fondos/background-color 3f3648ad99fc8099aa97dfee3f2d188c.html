background-color

📄 background-color

📝 Definición

background-color es una propiedad CSS que establece el color de fondo de un elemento.

Es el color que se pinta detrás del contenido, del padding y, por defecto, hasta el borde.

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-image, background-repeat, background-position, background-size, background-attachment, background-clip, background-origin).

Es la más básica y la que se aplica por defecto si usas el shorthand background.

A diferencia de border (que es visible por defecto cuando tiene estilo), background-color es transparente por defecto → no se ve hasta que le asignas un color.

🎯 ¿Para qué sirve?

  • Dar color de fondo a secciones, tarjetas, botones, badges.
  • Crear contraste entre bloques (hero, footer, sidebar).
  • Indicar estados (hover, focus, error, éxito, selección).
  • Alternar filas en tablas (filas cebreadas) combinado con :nth-child.
  • Crear efectos visuales con transparencia (rgba, hsla).
  • Sustituir imágenes de fondo con colores planos más ligeros.

⚙️ ¿Cómo funciona?

El navegador pinta el color de fondo detrás del contenido y el padding, y por defecto también detrás del borde (aunque el borde tenga su propio color).

El área de pintado se controla con:

  • background-clip → hasta dónde se extiende el fondo:
    • border-box (por defecto) → hasta el borde exterior.
    • padding-box → solo hasta el padding.
    • content-box → solo el contenido.
    • text → el fondo se recorta al texto (efecto de texto con gradiente).
  • background-origin → desde dónde empieza a posicionarse (útil con imágenes).

Conceptos clave:

  1. Transparente por defecto → si no se define, se ve el fondo del padre.
  1. Se pinta debajo del contenido → el texto/imagen van encima.
  1. Acepta transparencia → rgba(), hsla(), transparent, #RRGGBBAA.
  1. Acepta currentColor → hereda el color del texto.
  1. Acepta variables CSS → var(--color-primario).

📝 Sintaxis / Estructura

selector {
  background-color: valor;
}

Formatos de color comunes

background-color: #3498db;              /* Hex */
background-color: #3498db80;            /* Hex con alpha (50%) */
background-color: rgb(52, 152, 219);    /* RGB */
background-color: rgba(52, 152, 219, 0.5); /* RGB con alpha */
background-color: hsl(204, 70%, 53%);   /* HSL */
background-color: hsla(204, 70%, 53%, 0.5); /* HSL con alpha */
background-color: oklch(60% 0.15 240);  /* OKLCH (moderno) */
background-color: transparent;          /* Sin color */
background-color: currentColor;         /* Color del texto */

💡 Ejemplos

/* 1. Fondo de sección */
.hero {
  background-color: #f5f5f5;
}

/* 2. Botón primario */
.btn-primary {
  background-color: #3498db;
  color: white;
}

/* 3. Botón con hover */
.btn-primary:hover {
  background-color: #2980b9;
}

/* 4. Fila cebreada en tabla */
tr:nth-child(even) {
  background-color: #f9f9f9;
}

/* 5. Fondo con transparencia */
.overlay {
  background-color: rgba(0, 0, 0, 0.5);
}

/* 6. Badge con currentColor */
.badge {
  border: 1px solid currentColor;
  background-color: transparent;
}

/* 7. Variables CSS */
:root {
  --color-primario: #3498db;
}
.card {
  background-color: var(--color-primario);
}

/* 8. Fondo solo hasta el padding (no tapa el borde) */
.box {
  background-color: #eee;
  background-clip: padding-box;
  border: 5px solid #333;
}

/* 9. Texto con gradiente usando background-clip: text */
.gradient-text {
  background: linear-gradient(90deg, #f39c12, #e74c3c);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

Diferencia entre background y background-color

/* Solo color de fondo */
.elemento {
  background-color: #fff;
}

/* Shorthand: resetea TODAS las propiedades de fondo */
.elemento {
  background: #fff; /* equivale a background-color + resto a valores por defecto */
}

⚠️ Usar background borra background-image, background-position, etc.

Usar background-color para cambiar solo el color sin tocar el resto.

⚠️ Errores comunes

  1. Usar background en lugar de background-color → el shorthand resetea todas las propiedades de fondo (imagen, posición, repeat…). Si solo quieres cambiar el color, usar background-color.
  1. Olvidar box-sizing → no afecta al background-color (el fondo no ocupa espacio), pero sí a cómo se ve combinado con padding y border.
  1. Esperar que el fondo cubra el borde → por defecto background-clip: border-box sí lo cubre, pero si pones padding-box, el borde queda transparente por dentro.
  1. Contraste insuficiente → texto sobre fondo de color similar → problema de accesibilidad (WCAG exige ratio mínimo 4.5:1).
  1. Abusar de rgba sin necesidad → a veces un color sólido con currentColor o variable es más limpio.
  1. No considerar el modo oscuro → usar variables CSS o prefers-color-scheme para adaptar.
  1. Confundir con color → color es el color del texto; background-color es el color del fondo.
  1. Usar background-clip: text sin webkit- → algunos navegadores aún necesitan el prefijo para el efecto de texto con gradiente.

🧩 Relación con otros conceptos

  • color → color del texto.
  • background → shorthand que incluye background-color y más.
  • background-image → imagen que se pinta encima del color de fondo.
  • background-clip → hasta dónde se extiende el fondo.
  • background-origin → desde dónde se posiciona la imagen.
  • background-blend-mode → mezcla color e imagen.
  • box-shadow → sombra que puede imitar un fondo extendido.
  • opacity → afecta al fondo y al contenido.
  • rgba / hsla → color con transparencia sin afectar al contenido.
  • prefers-color-scheme → adaptar el fondo al modo claro/oscuro.

Modelo visual del fondo:

┌─────────────────────────┐
│        margin           │  ← sin fondo
│  ┌───────────────────┐  │
│  │      border       │  │  ← fondo cubre hasta aquí (border-box)
│  │  ┌─────────────┐  │  │
│  │  │  padding    │  │  │  ← fondo cubre hasta aquí (padding-box)

🧠 Analogía

Imagina que cada elemento es una habitación. El background-color es la pintura de las paredes: se aplica detrás de todo (muebles, cuadros), y puede llegar hasta el marco de la puerta (border-box) o solo hasta el rodapié (padding-box). Si no pintas, las paredes son transparentes y se ve la habitación de al lado (el padre).

📝 Notas personales

  • background-color ≠ background → el shorthand resetea todo. Usar background-color cuando solo quieras cambiar el color.
  • Transparente por defecto → si no ves fondo, es porque no lo has definido o el padre lo tapa.
  • background-clip: text es el truco para texto con gradiente → requiere webkit-background-clip: text y color: transparent.
  • Contraste → verificar siempre con herramientas (WebAIM, Stark) para cumplir WCAG AA.
  • Modo oscuro → usar variables CSS + @media (prefers-color-scheme: dark).
  • currentColor → muy útil para badges y botones outline: el fondo/texto se adapta al color.
  • background-blend-mode → permite mezclar color e imagen para efectos creativos.
  • oklch() → formato moderno con mejor percepción de luminosidad; ideal para paletas consistentes.
  • ::selection → se puede personalizar el fondo de la selección de texto.
  • En tablas cebreadas, combinar :nth-child(even) con background-color es el patrón clásico.
