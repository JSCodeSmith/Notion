background-clip

📄 background-clip

📝 Definición

background-clip es una propiedad CSS que establece hasta dónde se extiende (se pinta) el fondo de un elemento:

hasta el borde exterior (border-box), hasta el interior del borde (padding-box), hasta el contenido (content-box) o recortado a la forma del texto (text).

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-image, background-origin, background-size, background-position, etc.).

Controla el área de pintado del fondo, no su posición.

Es fácil de confundir con background-origin, pero son complementarias:

  • background-origin → desde dónde se calcula la posición del fondo.
  • background-clip → hasta dónde se pinta el fondo.

El valor más famoso es text, que permite crear texto con gradiente o imagen de fondo recortando el fondo a la forma de las letras.

🎯 ¿Para qué sirve?

  • Evitar que el fondo se pinte bajo un borde transparente o semitransparente.
  • Recortar el fondo al padding o al contenido.
  • Crear texto con gradiente (background-clip: text).
  • Controlar el área de pintado en múltiples capas de fondo.
  • Diseñar bordes con gradientes visibles (background-clip: padding-box).
  • Crear efectos de texto con imagen.

⚙️ ¿Cómo funciona?

El navegador pinta el fondo (color + imágenes) solo dentro del área indicada:

  1. border-box (por defecto) → el fondo se pinta hasta el borde exterior (incluye border + padding + content).
  1. padding-box → el fondo se pinta hasta el interior del borde (excluye el border).
  1. content-box → el fondo se pinta solo en el contenido (excluye padding y border).
  1. text → el fondo se recorta a la forma del texto (el texto actúa como máscara).

Reglas clave:

  • Afecta a background-color y background-image → ambos se recortan.
  • No afecta al border → el borde tiene su propio color (border-color).
  • No cambia la posición del fondo → eso es background-origin.
  • Con text → el color del texto debe ser transparent para que se vea el fondo.
  • Con text → se necesita el prefijo webkit- en Safari y algunos navegadores.
  • Múltiples capas → cada capa tiene su propio background-clip.

⚠️ Con border-box (por defecto), el fondo se pinta debajo del borde. Si el borde es transparente o semitransparente, el fondo se ve a través de él.

📝 Sintaxis / Estructura

selector {
  background-clip: valor;
}

Múltiples capas

background-clip: padding-box, content-box, text;
/* cada valor corresponde a la capa en la misma posición de background-image */

💡 Ejemplos

/* 1. Valor por defecto (border-box) */
.elemento {
  background-color: #f5f5f5;
  border: 10px solid transparent;
  /* El fondo se pinta bajo el borde → se ve a través del borde transparente */
}

/* 2. Fondo solo hasta el padding (no bajo el borde) */
.padding-box {
  background-color: #f5f5f5;
  background-clip: padding-box;
  border: 10px solid rgba(0,0,0,0.2);
  /* El fondo NO se pinta bajo el borde */
}

/* 3. Fondo solo en el contenido */
.content-box {
  background-color: #f5f5f5;
  background-clip: content-box;
  padding: 20px;
  border: 10px solid #333;
  /* El fondo solo cubre el contenido */
}

/* 4. Texto con gradiente (el más famoso) */
.gradient-text {
  background: linear-gradient(90deg, #f39c12, #e74c3c);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  /* El gradiente se ve solo a través del texto */
}

/* 5. Texto con imagen de fondo */
.texto-imagen {
  background-image: url("foto.jpg");
  background-size: cover;
  background-position: center;
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

/* 6. Borde con gradiente (técnica clásica) */
.borde-gradiente {
  background: linear-gradient(135deg, #667eea, #764ba2);
  border: 4px solid transparent;
  background-clip: padding-box;
  /* El gradiente se ve solo dentro del padding, dejando el borde "vacío" */
}

/* 7. Múltiples capas con distintos clips */
.layered {
  background-image:
    url("icon.png"),
    linear-gradient(135deg, #667eea, #764ba2);
  background-clip: content-box, border-box;
  padding: 20px;
  border: 10px solid transparent;
}

/* 8. Combinado con background-origin */
.combo {
  background-image: url("bg.jpg");
  background-origin: content-box;  /* posición desde el contenido */
  background-clip: padding-box;    /* se pinta hasta el padding */
  padding: 20px;
  border: 10px solid #333;
}

Texto con gradiente (patrón muy popular)

.gradient-text {
  background: linear-gradient(90deg, #f39c12, #e74c3c, #9b59b6);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  /* El texto se ve con el gradiente */
}

Borde con gradiente (técnica con background-clip)

/* El borde "vacío" deja ver el fondo del padre */
.borde-gradiente {
  background: linear-gradient(135deg, #667eea, #764ba2);
  border: 4px solid transparent;
  background-clip: padding-box;
  /* El gradiente se pinta solo dentro del padding */
  /* El border transparente deja ver el fondo del padre */
  /* Resultado: borde con gradiente alrededor */
}

Fondo que no se pinta bajo el borde

.card {
  background-color: #fff;
  background-clip: padding-box; /* el fondo no invade el borde */
  border: 8px solid rgba(0, 0, 0, 0.1);
  /* El borde se ve semitransparente sin fondo debajo */
}

Combinación con background-origin

/* Fondo posicionado desde el contenido, pintado hasta el padding */
.elemento {
  background-image: url("pattern.png");
  background-origin: content-box;
  background-clip: padding-box;
  padding: 20px;
  border: 10px solid #333;
}

⚠️ Errores comunes

  1. Confundir background-clip con background-origin → clip = hasta dónde se pinta; origin = desde dónde se posiciona. Error muy común.
  1. Olvidar color: transparent con background-clip: text → sin él, el texto se ve con su color y tapa el fondo.
  1. Olvidar webkit-background-clip: text → Safari y algunos navegadores basados en WebKit requieren el prefijo.
  1. Usar text en un elemento sin texto → no tiene efecto.
  1. Pensar que background-clip afecta al border → no, el borde tiene su propio color (border-color).
  1. Esperar que padding-box cambie el tamaño del fondo → no, solo cambia hasta dónde se pinta.
  1. Usar background shorthand sin especificar clip → se resetea a border-box.
  1. Múltiples capas mal ordenadas → cada valor corresponde a la capa en la misma posición de background-image.
  1. background-clip: text con texto muy pequeño → el gradiente puede no apreciarse; funciona mejor en títulos grandes.
  1. No considerar accesibilidad → el texto con gradiente debe tener contraste suficiente con el fondo del padre. Verificar con herramientas.
  1. Usar background-clip: text en body → puede afectar a todos los textos; aplicar solo a elementos específicos.
  1. Combinar text con background-color → solo funciona con background-image (gradientes o imágenes), no con colores planos.

🧩 Relación con otros conceptos

  • background-origin → desde dónde se posiciona el fondo (complementaria).
  • background-image → la imagen afectada.
  • background-color → también se recorta con background-clip.
  • background-position → dónde se coloca la imagen.
  • background-size → el porcentaje se calcula respecto al origen, no al clip.
  • border → no le afecta background-clip; tiene su propio color.
  • padding → separa el contenido del borde.
  • box-sizing → define cómo se calculan las cajas.
  • background → shorthand que incluye background-clip.
  • webkit-background-clip → prefijo necesario para text en Safari.
  • color: transparent → requisito para background-clip: text.
  • mix-blend-mode → alternativa para efectos de fusión.

background-clip: border-box  → fondo cubre todo (bajo el borde incluido)
background-clip: padding-box → fondo cubre hasta el interior del borde
background-clip: content-box → fondo cubre solo el contenido
background-clip: text        → fondo recortado a la forma del texto

🧠 Analogía

Imagina que la caja del elemento es un cuadro con marco y passe-partout:

  • border-box → pintas toda la superficie, incluido el marco.
  • padding-box → pintas solo dentro del marco, sin tocarlo.
  • content-box → pintas solo la zona de la foto, sin el passe-partout.
  • text → usas las letras como plantilla: solo se ve el fondo donde hay texto.

Y background-origin sería desde dónde empiezas a colocar la pintura; background-clip es hasta dónde la extiendes.

📝 Notas personales

  • Regla mental: clip = hasta dónde se pinta; origin = desde dónde se posiciona. No confundir.
  • text es el valor estrella → texto con gradiente o imagen. Requiere color: transparent + prefijo webkit-.
  • padding-box para bordes con gradiente → técnica clásica: background-clip: padding-box + border: 4px solid transparent.
  • Valor por defecto border-box → el fondo se pinta bajo el borde. Si el borde es transparente, se ve el fondo a través.
  • No afecta al border → el borde tiene su propio border-color.
  • Afecta a color e imagen → ambos se recortan con background-clip.
  • Múltiples capas → cada capa tiene su propio clip, separado por comas.
  • Accesibilidad → el texto con gradiente debe tener contraste suficiente. Verificar con WebAIM o Stark.
  • No usar background-clip: text en textos largos → funciona mejor en títulos grandes y llamativos.
  • Safari → recordar siempre webkit-background-clip: text además de la versión estándar.
  • Combinación útil: background-origin: content-box + background-clip: padding-box → el fondo se posiciona desde el contenido pero se pinta hasta el padding.
