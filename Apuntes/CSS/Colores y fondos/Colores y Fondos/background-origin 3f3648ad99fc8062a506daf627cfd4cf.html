background-origin

📄 background-origin

📝 Definición

background-origin es una propiedad CSS que establece desde dónde se posiciona una imagen de fondo (background-image): desde el borde exterior (border-box), desde el interior del borde (padding-box) o desde el contenido (content-box).

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-image, background-position, background-size, background-clip, etc.).

Controla el punto de referencia para calcular la posición del fondo.

Es fácil de confundir con background-clip, pero son complementarias:

  • background-origin → desde dónde se calcula la posición del fondo.
  • background-clip → hasta dónde se pinta el fondo.

Ambas pueden tener valores distintos, lo que permite efectos interesantes (por ejemplo, que el fondo empiece desde el borde pero se recorte al padding).

🎯 ¿Para qué sirve?

  • Alinear patrones con el contenido en lugar del borde.
  • Evitar que el fondo se dibuje bajo el borde en cajas con bordes gruesos.
  • Controlar la posición de gradientes respecto al padding o al contenido.
  • Crear efectos donde el fondo empieza desde una zona concreta.
  • Ajustar el posicionamiento de múltiples capas de fondo.

⚙️ ¿Cómo funciona?

El navegador calcula la posición de la imagen de fondo desde el área indicada por background-origin:

  1. padding-box (por defecto) → desde el interior del borde (incluye padding).
  1. border-box → desde el borde exterior (incluye border + padding).
  1. content-box → desde el contenido (excluye padding y border).

Reglas clave:

  • Afecta a background-position → el punto 0% 0% cambia según el origen.
  • Afecta a background-size → el porcentaje se calcula respecto al área del origen.
  • No afecta a background-clip → son independientes, pero se combinan.
  • Por defecto padding-box → la mayoría de las veces no se nota, porque los bordes suelen ser finos.
  • Solo aplica a background-image → no al color de fondo.
  • Múltiples capas → cada capa tiene su propio background-origin.

⚠️ Es especialmente visible cuando hay bordes gruesos o padding grande.

📝 Sintaxis / Estructura

selector {
  background-origin: valor;
}

Múltiples capas

background-origin: content-box, padding-box, border-box;
/* cada valor corresponde a la capa en la misma posición de background-image */

💡 Ejemplos

/* 1. Valor por defecto (padding-box) */
.elemento {
  background-image: url("pattern.png");
  background-origin: padding-box;
  /* La imagen empieza desde el interior del borde */
}

/* 2. Desde el borde exterior */
.border-origin {
  background-image: url("pattern.png");
  background-origin: border-box;
  /* La imagen empieza desde el borde exterior */
}

/* 3. Desde el contenido */
.content-origin {
  background-image: url("pattern.png");
  background-origin: content-box;
  /* La imagen empieza desde el contenido (excluye padding) */
}

/* 4. Combinado con background-clip */
.combinado {
  background-image: url("bg.jpg");
  background-origin: content-box;   /* posición desde el contenido */
  background-clip: padding-box;     /* se pinta hasta el padding */
  padding: 20px;
  border: 10px solid #333;
}

/* 5. Múltiples capas con distintos orígenes */
.layered {
  background-image:
    url("icon.png"),
    url("pattern.png");
  background-origin: content-box, border-box;
  background-repeat: no-repeat, repeat;
}

/* 6. Gradiente que empieza desde el contenido */
.gradient-content {
  background: linear-gradient(135deg, #667eea, #764ba2);
  background-origin: content-box;
  padding: 20px;
}

/* 7. Shorthand con background */
.card {
  background: url("bg.jpg") content-box / cover no-repeat;
  /* origin se puede especificar en el shorthand */
}

/* 8. Diferencia visible con border grueso */
.grueso {
  background-image: url("pattern.png");
  background-origin: padding-box; /* por defecto */
  border: 20px solid transparent;
  background-clip: padding-box;
  /* El fondo NO se extiende bajo el borde */
}

Diferencia visual entre valores

<div class="caja">Contenido</div>
.caja {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 10px solid #333;
  background-image: url("dot.png");
  background-size: 20px 20px;
  background-repeat: repeat;
}

/* padding-box (por defecto) */
.origen-padding {
  background-origin: padding-box;
  /* El patrón empieza desde el interior del borde (incluye padding) */
}

/* border-box */
.origen-border {
  background-origin: border-box;
  /* El patrón empieza desde el borde exterior */
}

/* content-box */
.origen-content {
  background-origin: content-box;
  /* El patrón empieza desde el contenido (excluye padding) */
}

Combinación con background-clip

/* El fondo se posiciona desde el contenido pero se pinta hasta el borde */
.combo-1 {
  background-image: url("bg.jpg");
  background-origin: content-box;
  background-clip: border-box;
}

/* El fondo se posiciona desde el borde pero se pinta solo en el padding */
.combo-2 {
  background-image: url("bg.jpg");
  background-origin: border-box;
  background-clip: padding-box;
}

/* El fondo se posiciona y se pinta solo en el contenido */
.combo-3 {
  background-image: url("bg.jpg");
  background-origin: content-box;
  background-clip: content-box;
}

Patrón alineado con el contenido

.codigo {
  background-image: linear-gradient(to bottom, #eee 1px, transparent 1px);
  background-size: 100% 24px; /* alineado con line-height */
  background-origin: content-box; /* desde el texto, no desde el padding */
  padding: 20px;
  line-height: 24px;
  font-family: monospace;
}

⚠️ Errores comunes

  1. Confundir background-origin con background-clip → origin = desde dónde se posiciona; clip = hasta dónde se pinta. Error muy común.
  1. Esperar que afecte al color de fondo → solo afecta a background-image. El color siempre cubre según background-clip.
  1. Usarlo sin bordes gruesos → con bordes finos apenas se nota la diferencia. Es más relevante con border grande o padding grande.
  1. Olvidar que el valor por defecto es padding-box → si no lo cambias, no verás diferencia.
  1. Confundir con background-position → origin define el punto de referencia; position define dónde se coloca dentro de ese origen.
  1. No considerar múltiples capas → cada capa tiene su propio origin, separado por comas.
  1. Usar background shorthand y perder el origin → el shorthand puede incluir origin, pero si no lo especificas, se resetea a padding-box.
  1. Pensar que afecta al tamaño de la caja → no, solo al posicionamiento del fondo.
  1. Usarlo con gradientes y esperar cambios grandes → los gradientes suelen cubrir toda la caja; el efecto es sutil.
  1. Confundir content-box con "solo el texto" → content-box es el área de contenido de la caja, no el texto en sí.

🧩 Relación con otros conceptos

  • background-clip → hasta dónde se pinta el fondo (complementaria).
  • background-position → dónde se coloca la imagen dentro del origen.
  • background-size → el porcentaje se calcula respecto al origen.
  • background-image → la imagen afectada.
  • background-color → no le afecta background-origin.
  • background → shorthand que incluye background-origin.
  • box-sizing → define cómo se calculan las cajas, pero no afecta a origin.
  • border / padding → cuanto más grandes, más visible es el efecto.
  • background-repeat → el patrón se genera desde el origen.

background-origin: content-box → posición calculada desde el contenido

🧠 Analogía

Imagina que la caja del elemento es un cuadro enmarcado:

  • border-box → empiezas a colocar el fondo desde el marco exterior.
  • padding-box → empiezas desde el borde interior del marco (por defecto).
  • content-box → empiezas desde la zona donde va la foto, sin contar el passe-partout.

background-position sería dónde colocas la imagen dentro de esa zona, y background-clip sería hasta dónde dejas que se pinte el fondo.

📝 Notas personales

  • Regla mental: origin = desde dónde se posiciona; clip = hasta dónde se pinta.
  • Valor por defecto padding-box → la mayoría de las veces no necesitas cambiarlo.
  • Solo afecta a background-image → no al color de fondo.
  • Más visible con bordes gruesos → con border: 20px solid se nota claramente.
  • Combinación útil: background-origin: content-box + background-clip: border-box → el fondo se posiciona desde el contenido pero se pinta hasta el borde.
  • Código con líneas guía → background-origin: content-box + background-size: 100% <line-height> alinea las líneas con el texto.
  • No confundir con background-position → origin es el sistema de coordenadas; position es el punto dentro de él.
  • Múltiples capas → cada capa tiene su propio origin, separado por comas.
  • En la práctica, se usa menos que background-clip o background-size; muchos desarrolladores ni lo tocan.
