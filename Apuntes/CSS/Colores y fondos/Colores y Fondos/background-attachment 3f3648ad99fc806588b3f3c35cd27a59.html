background-attachment

📄 background-attachment

📝 Definición

background-attachment es una propiedad CSS que determina si la imagen de fondo (background-image) se desplaza con el contenido, permanece fija respecto al viewport, o se desplaza con el propio elemento cuando este tiene scroll interno.

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-image, background-size, background-position, background-repeat, background-clip, etc.).

Controla el comportamiento de scroll del fondo.

Es la propiedad clave para crear efectos parallax (el fondo parece quedarse quieto mientras el contenido se desplaza), aunque hoy existen técnicas más modernas y con mejor rendimiento.

🎯 ¿Para qué sirve?

  • Crear efectos parallax sutiles.
  • Mantener un fondo fijo mientras el usuario hace scroll.
  • Controlar si el fondo se desplaza con el contenido del elemento o con la página.
  • Evitar que el fondo "salte" al hacer scroll.
  • Construir secciones con imagen de fondo estática.

⚙️ ¿Cómo funciona?

El navegador decide el punto de referencia del fondo:

  1. scroll (por defecto) → el fondo se desplaza con el contenido del elemento (y con la página si el elemento se mueve).
  1. fixed → el fondo permanece fijo respecto al viewport; el contenido se desplaza encima. Crea efecto parallax.
  1. local → el fondo se desplaza con el contenido del elemento, incluyendo su scroll interno. Se diferencia de scroll cuando el elemento tiene su propio scroll.

Reglas clave:

  • scroll vs local → solo se diferencian si el elemento tiene scroll interno (overflow: auto/scroll).
    • Con scroll, el fondo se queda fijo respecto a la caja del elemento.
    • Con local, el fondo se desplaza con el contenido del elemento.
  • fixed → el fondo se ancla al viewport, no al elemento. Si el elemento se mueve (por scroll de página), el fondo no.
  • fixed en móvil → muchos navegadores móviles lo ignoran o lo tratan como scroll por rendimiento.
  • Múltiples capas → cada capa puede tener su propio attachment, separado por comas.

📝 Sintaxis / Estructura

selector {
  background-attachment: valor;
}

Múltiples capas

background-attachment: fixed, scroll, local;
/* cada valor corresponde a la capa en la misma posición de background-image */

💡 Ejemplos

/* 1. Fondo normal (por defecto) */
.normal {
  background-image: url("bg.jpg");
  background-attachment: scroll;
}

/* 2. Fondo fijo (parallax) */
.parallax {
  background-image: url("bg.jpg");
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
}

/* 3. Fondo local (con scroll interno) */
.scrollable {
  height: 200px;
  overflow-y: auto;
  background-image: url("pattern.png");
  background-attachment: local;
  /* El fondo se desplaza con el contenido al hacer scroll interno */
}

/* 4. Combinado con shorthand */
.hero {
  background: url("hero.jpg") center / cover no-repeat fixed;
}

/* 5. Múltiples capas con distintos attachments */
.layered {
  background-image:
    url("icon.png"),
    url("pattern.png");
  background-attachment: scroll, fixed;
  background-repeat: no-repeat, repeat;
}

/* 6. Parallax moderno con ::before (mejor rendimiento) */
.parallax-moderno {
  position: relative;
  overflow: hidden;
}
.parallax-moderno::before {
  content: "";
  position: absolute;
  inset: 0;
  background-image: url("bg.jpg");
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  z-index: -1;
}

/* 7. Fondo fijo con overlay */
.hero-overlay {
  background:
    linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),
    url("hero.jpg") center / cover no-repeat fixed;
}

Diferencia entre scroll y local

<div class="scrollable">
  <p>Contenido largo...</p>
  <p>Contenido largo...</p>
  <p>Contenido largo...</p>
</div>
.scrollable {
  height: 200px;
  overflow-y: auto;
  background-image: url("pattern.png");
  background-size: 50px 50px;
}

/* Con scroll (por defecto): el fondo se queda fijo respecto a la caja */
.scroll {
  background-attachment: scroll;
  /* Al hacer scroll interno, el fondo NO se mueve */
}

/* Con local: el fondo se desplaza con el contenido */
.local {
  background-attachment: local;
  /* Al hacer scroll interno, el fondo SÍ se mueve */
}

Parallax clásico

.parallax {
  height: 500px;
  background-image: url("mountains.jpg");
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  /* Al hacer scroll por la página, el fondo parece quedarse quieto */
}

Parallax moderno (mejor rendimiento)

.parallax {
  position: relative;
  overflow: hidden;
  min-height: 500px;
}
.parallax::before {
  content: "";
  position: absolute;
  inset: 0;
  background-image: url("mountains.jpg");
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  z-index: -1;
  /* En móvil, usar transform para evitar problemas */
}
@media (hover: none) {
  .parallax::before {
    background-attachment: scroll;
    /* Fallback en móvil */
  }
}

⚠️ Errores comunes

  1. Usar background-attachment: fixed en móvil → muchos navegadores móviles lo ignoran o lo tratan como scroll por problemas de rendimiento. Probar siempre en móvil.
  1. Confundir scroll con local → solo se diferencian si el elemento tiene scroll interno. Sin scroll interno, son idénticos.
  1. Esperar que fixed funcione dentro de transform → un ancestro con transform, filter o will-change rompe background-attachment: fixed (crea un nuevo contexto de apilado).
  1. Usar fixed con background-size: cover → funciona, pero el fondo se calcula respecto al viewport, no al elemento, lo que puede dar sorpresas.
  1. Olvidar el fallback → en navegadores que no soportan fixed en móvil, el fondo se desplaza. Proporcionar alternativa.
  1. Problemas de rendimiento → background-attachment: fixed es costoso; el navegador repinta en cada scroll. Preferir position: fixed con ::before.
  1. Usar fixed en contenedores con overflow: hidden → puede no funcionar como se espera.
  1. Combinar con background shorthand mal → el orden importa; fixed puede ir en cualquier posición pero debe ser un valor válido.
  1. No considerar prefers-reduced-motion → el parallax puede causar mareo. Ofrecer alternativa.
  1. fixed con múltiples capas → cada capa tiene su propio attachment; no se puede simplificar a uno solo.

🧩 Relación con otros conceptos

  • background-image → define la imagen.
  • background-size → controla el tamaño; interactúa con fixed.
  • background-position → posición de la imagen; con fixed, es relativa al viewport.
  • background-repeat → repetición.
  • background → shorthand que incluye background-attachment.
  • position: fixed → alternativa moderna para parallax con ::before.
  • transform → rompe background-attachment: fixed en ancestros.
  • overflow → local solo se nota con scroll interno.
  • prefers-reduced-motion → considerar desactivar parallax.
  • will-change → puede romper fixed (crea contexto de apilado).

🧠 Analogía

Imagina que estás en un tren mirando por la ventana:

  • scroll → el paisaje se mueve contigo (como si el fondo estuviera pegado al tren).
  • fixed → el paisaje se queda quieto y tú te mueves (efecto parallax: el fondo no acompaña al movimiento).
  • local → el paisaje se mueve con el vagón cuando caminas dentro de él (scroll interno).

📝 Notas personales

  • scroll es el valor por defecto → en la mayoría de casos no necesitas cambiarlo.
  • fixed en móvil es problemático → muchos navegadores lo ignoran. Probar siempre y ofrecer fallback con position: fixed + ::before.
  • scroll vs local → solo se diferencian si el elemento tiene scroll interno (overflow: auto/scroll).
  • transform, filter, will-change → rompen background-attachment: fixed en ancestros. Cuidado con animaciones.
  • Parallax moderno → preferir position: fixed en un ::before en lugar de background-attachment: fixed por rendimiento y compatibilidad.
  • prefers-reduced-motion → ofrecer alternativa sin parallax para usuarios sensibles al movimiento.
  • Múltiples capas → cada capa tiene su propio attachment; no se simplifica.
  • Con background-size: cover y fixed → el fondo se calcula respecto al viewport, no al elemento. Esto puede dar resultados inesperados.
  • Optimización → fixed es costoso (repinta en cada scroll). Usar con moderación.
  • Alternativa moderna: background-attachment: scroll + position: sticky o transform: translateZ() para efectos similares con mejor rendimiento.
