background-position

📄 background-position

📝 Definición

background-position es una propiedad CSS que establece la posición inicial de una imagen de fondo (background-image) dentro de la caja de un elemento.

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-image, background-size, background-repeat, background-attachment, background-clip, etc.).

Controla dónde se coloca la imagen dentro del área de fondo.

Solo tiene efecto visible cuando la imagen no cubre toda la caja (por ejemplo, con background-repeat: no-repeat o cuando la imagen es más pequeña que el contenedor).

Si la imagen cubre todo (background-size: cover), la posición apenas se nota, salvo que se recorte.

🎯 ¿Para qué sirve?

  • Colocar una imagen en una esquina o zona concreta (logo arriba a la derecha).
  • Centrar una imagen de fondo.
  • Ajustar qué parte de la imagen se ve cuando se recorta con cover.
  • Alinear patrones repetidos (rayas abajo, iconos a la izquierda).
  • Crear sprites CSS (usar una imagen grande con varias posiciones).
  • Controlar múltiples capas de fondo con posiciones distintas.

⚙️ ¿Cómo funciona?

El navegador coloca la imagen según dos ejes: horizontal (x) y vertical (y).

Reglas clave:

  1. Dos valores → primero horizontal, segundo vertical.
  1. Un solo valor → el segundo se asume center.
  1. Palabras clave → left, center, right (horizontal); top, center, bottom (vertical).
  1. Longitudes → px, em, rem, %, etc.
  1. Porcentajes → alinean el punto correspondiente de la imagen con el punto correspondiente de la caja.
  1. Orden flexible → el navegador distingue palabras clave por eje.
  1. Múltiples capas → cada capa tiene su propia posición, separadas por comas.
  1. background-origin → define desde dónde se calcula la posición (padding-box por defecto).

El truco del porcentaje

background-position: X% Y%;

X% → alinea el X% del ancho de la IMAGEN con el X% del ancho de la CAJA.
Y% → alinea el Y% de la altura de la IMAGEN con el Y% de la altura de la CAJA.

Ejemplos:

  • 0% 0% → esquina superior izquierda.
  • 50% 50% → centro (imagen centrada).
  • 100% 100% → esquina inferior derecha.
  • 100% 0% → superior derecha.

📝 Sintaxis / Estructura

selector {
  background-position: valor;
}

Sintaxis con palabras clave (orden libre)

/* Equivalencias */
background-position: top left;       /* = left top */
background-position: bottom right;   /* = right bottom */
background-position: center;         /* = center center */
background-position: top;            /* = top center */
background-position: left;           /* = left center */

Sintaxis con 4 valores (offset)

/* palabra-clave + offset */
background-position: right 20px bottom 10px;
background-position: left 10px top 5px;
/* Separa la palabra clave del desplazamiento */

Múltiples capas

background-position: top right, center, bottom left;
/* cada valor corresponde a la capa en la misma posición de background-image */

💡 Ejemplos

/* 1. Imagen centrada */
.hero {
  background-image: url("hero.jpg");
  background-repeat: no-repeat;
  background-position: center;
}

/* 2. Imagen arriba a la derecha (logo decorativo) */
.card {
  background-image: url("icon.png");
  background-repeat: no-repeat;
  background-position: top right;
  padding-right: 60px;
}

/* 3. Patrón con posición específica */
.stripe {
  background-image: url("line.png");
  background-repeat: repeat-x;
  background-position: bottom; /* rayas abajo */
}

/* 4. Icono a la izquierda en un input */
.input {
  background-image: url("search.svg");
  background-repeat: no-repeat;
  background-position: 10px center;
  padding-left: 40px;
}

/* 5. Controlar el recorte de una imagen "cover" */
.portrait {
  background-image: url("persona.jpg");
  background-size: cover;
  background-position: top center; /* prioriza la cara (arriba) */
}

/* 6. Fondo con offset en px */
.box {
  background-image: url("pattern.png");
  background-position: 20px 40px;
}

/* 7. Porcentajes */
.percent {
  background-image: url("bg.jpg");
  background-position: 50% 20%;
}

/* 8. Palabra clave + offset (4 valores) */
.offset {
  background-image: url("icon.png");
  background-position: right 20px bottom 10px;
}

/* 9. Múltiples capas con posiciones distintas */
.layered {
  background-image:
    url("icon.png"),
    url("pattern.png");
  background-position: top right, center;
  background-repeat: no-repeat, repeat;
}

/* 10. Shorthand */
.card {
  background: #fff url("bg.jpg") center / cover no-repeat;
  /* position / size */
}

Sprites CSS (truco clásico)

.icon {
  width: 32px;
  height: 32px;
  background-image: url("sprite.png");
  background-repeat: no-repeat;
}
.icon-home {
  background-position: 0 0;
}
.icon-user {
  background-position: -32px 0;
}
.icon-settings {
  background-position: -64px 0;
}

Input con icono a la izquierda

.input-search {
  padding-left: 40px;
  background-image: url("search.svg");
  background-repeat: no-repeat;
  background-position: 12px center;
  background-size: 16px;
}

Controlar la parte visible de una imagen con cover

/* Imagen de persona: mostrar la cara (arriba) */
.avatar {
  background-image: url("persona.jpg");
  background-size: cover;
  background-position: top center;
}

/* Paisaje: mostrar el horizonte (centro-abajo) */
.landscape {
  background-image: url("paisaje.jpg");
  background-size: cover;
  background-position: center 70%;
}

Múltiples capas

.multi {
  background-image:
    url("icon.png"),         /* capa 1: arriba derecha */
    url("pattern.png");      /* capa 2: centro */
  background-position: top right, center;
  background-repeat: no-repeat, repeat;
}

⚠️ Errores comunes

  1. Confundir el orden → primero horizontal (x), luego vertical (y). center top = centrado horizontal, arriba.
  1. Creer que % es un desplazamiento → no lo es. Alinea el X% de la imagen con el X% de la caja.
  1. Olvidar background-repeat: no-repeat → la imagen se repite y la posición pierde sentido visual.
  1. Usar background-position sin background-image → no tiene efecto.
  1. Confundir con background-origin → position es dónde se coloca; origin es desde dónde se calcula.
  1. Usar background en lugar de background-position → el shorthand resetea todo.
  1. Mezclar palabras clave con longitudes mal → left 20px es válido, pero 20px left no. El orden importa en la sintaxis de 4 valores.
  1. No usar background-size → si la imagen es más grande que la caja, la posición puede no notarse.
  1. Usar sprites en 2025 → hoy es mejor SVG inline o mask-image. Los sprites siguen funcionando pero son menos flexibles.
  1. Múltiples capas mal ordenadas → cada valor corresponde a la capa en la misma posición de background-image.

🧩 Relación con otros conceptos

  • background-image → define la imagen a posicionar.
  • background-size → controla el tamaño; interactúa con position.
  • background-repeat → controla la repetición; si es no-repeat, la posición se nota más.
  • background-attachment → si se desplaza con el scroll.
  • background-origin → desde dónde se calcula la posición (padding-box por defecto).
  • background-clip → hasta dónde se pinta.
  • background → shorthand que incluye background-position.
  • object-position → equivalente para elementos reemplazados (<img>, <video>).
  • mask-position → equivalente para máscaras.
  • transform: translate() → alternativa para mover elementos, no fondos.

Sistema de coordenadas:

background-position: 0% 0%        50% 0%        100% 0%
                    ┌───────────┬───────────┬───────────┐
                    │ top left  │ top center│ top right │
                    ├───────────┼───────────┼───────────┤
          50% 50%   │ left      │  center   │ right     │
                    ├───────────┼───────────┼───────────┤
                    │ bottom    │ bottom    │ bottom    │
                    │ left      │ center    │ right     │
                    └───────────┴───────────┴───────────┘
                   100% 100% → esquina inferior derecha

🧠 Analogía

Imagina que la caja del elemento es una pared y la imagen de fondo es un cuadro. background-position decide dónde cuelgas el cuadro en la pared: puedes ponerlo en la esquina superior izquierda, centrado, o abajo a la derecha. Si el cuadro es más grande que la pared, la posición decide qué parte del cuadro se ve (por ejemplo, la cara de un retrato en lugar de los pies).

📝 Notas personales

  • Orden: primero horizontal (x), luego vertical (y). center top = centrado horizontal, arriba.
  • Un solo valor → el segundo se asume center. background-position: top = top center.
  • % no es desplazamiento → alinea el X% de la imagen con el X% de la caja. 50% 50% = centro.
  • background-position: 100% 100% → esquina inferior derecha (no "mover 100%").
  • Combinar con background-size: cover → muy útil para controlar qué parte de la imagen se ve (caras, horizontes).
  • Input con icono → background-position: 12px center + padding-left para que el texto no se solape.
  • Sprites CSS → técnica clásica para iconos; hoy preferir SVG inline o mask-image.
  • Múltiples capas → cada valor corresponde a la capa en la misma posición de background-image.
  • Sintaxis de 4 valores → right 20px bottom 10px permite palabra clave + offset.
  • object-position → el equivalente para <img>, <video>, etc.
