background-image

📄 background-image

📝 Definición

background-image es una propiedad CSS que establece una o varias imágenes de fondo para un elemento, ya sean archivos de imagen (url()) o gradientes generados por CSS (linear-gradient(), radial-gradient(), conic-gradient()).

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-color, background-position, background-size, background-repeat, etc.).

Es una de las propiedades más versátiles de CSS porque acepta no solo imágenes externas, sino también gradientes, que son imágenes generadas por el navegador sin necesidad de archivos.

Es la capa superior del fondo: se dibuja encima de background-color, pero debajo del contenido y del padding (aunque el fondo se extienda hasta el borde con background-clip: border-box).

🎯 ¿Para qué sirve?

  • Añadir imágenes decorativas a secciones, tarjetas, botones.
  • Crear gradientes de color sin usar imágenes.
  • Construir patrones repetidos con gradientes.
  • Aplicar múltiples capas de imagen/gradiente.
  • Crear overlays sobre imágenes (gradiente + foto).
  • Generar texturas y efectos visuales sin archivos externos.
  • Sustituir imágenes pesadas por gradientes ligeros.

⚙️ ¿Cómo funciona?

El navegador dibuja las capas de fondo de arriba a abajo (la primera es la más cercana al usuario). Reglas clave:

  1. Múltiples capas → separadas por comas; la primera se dibuja encima.
  1. background-color → siempre se dibuja debajo de todas las imágenes.
  1. Por defecto → la imagen se repite (repeat) y se posiciona en 0% 0% (arriba a la izquierda).
  1. background-size → controla el tamaño (auto por defecto = tamaño intrínseco).
  1. background-position → controla la posición.
  1. background-repeat → controla la repetición.
  1. background-clip → controla hasta dónde se pinta.
  1. Gradientes → son funciones que generan una imagen; se comportan como cualquier imagen.
  1. image-set() → permite imágenes responsive para fondos.
  1. url() con comillas → recomendado para rutas con espacios o caracteres especiales.

📝 Sintaxis / Estructura

selector {
  background-image: url("imagen.jpg");
  background-image: linear-gradient(135deg, #f39c12, #e74c3c);
  background-image: url("a.png"), url("b.png"), linear-gradient(...);
  background-image: none;
}

Funciones de gradiente

/* Lineal */
linear-gradient(dirección, color1, color2, ...)
linear-gradient(135deg, #f39c12, #e74c3c)
linear-gradient(to right, red, blue)
linear-gradient(90deg, red 0%, yellow 50%, blue 100%)

/* Radial */
radial-gradient(forma tamaño at posición, color1, color2, ...)
radial-gradient(circle, #fff, #000)
radial-gradient(ellipse at top left, red, blue)

/* Cónico */
conic-gradient(from ángulo at posición, color1, color2, ...)
conic-gradient(from 0deg, red, yellow, green, blue, red)

/* Repetidos */
repeating-linear-gradient(45deg, #eee 0 10px, #fff 10px 20px)
repeating-radial-gradient(circle, #eee 0 10px, #fff 10px 20px).

💡 Ejemplos

/* 1. Imagen simple */
.hero {
  background-image: url("hero.jpg");
}

/* 2. Imagen que cubre */
.hero {
  background-image: url("hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* 3. Gradiente lineal */
.gradient {
  background-image: linear-gradient(135deg, #667eea, #764ba2);
}

/* 4. Gradiente radial */
.radial {
  background-image: radial-gradient(circle at center, #fff, #000);
}

/* 5. Gradiente cónico (rueda de color) */
.conic {
  background-image: conic-gradient(from 0deg, red, yellow, lime, cyan, blue, magenta, red);
  border-radius: 50%;
}

/* 6. Múltiples capas: overlay + imagen */
.hero-overlay {
  background-image:
    linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),
    url("hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* 7. Patrón repetido con gradiente */
.stripes {
  background-image: repeating-linear-gradient(
    45deg,
    #eee 0 10px,
    #fff 10px 20px
  );
}

/* 8. Cuadrícula con gradientes */
.grid {
  background-image:
    linear-gradient(#ddd 1px, transparent 1px),
    linear-gradient(90deg, #ddd 1px, transparent 1px);
  background-size: 20px 20px;
}

/* 9. Texto con gradiente */
.gradient-text {
  background-image: linear-gradient(90deg, #f39c12, #e74c3c);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

/* 10. Imagen responsive con image-set() */
.responsive-bg {
  background-image: image-set(
    url("bg-1x.jpg") 1x,
    url("bg-2x.jpg") 2x,
    url("bg.avif") type("image/avif")
  );
}

/* 11. Múltiples capas con posiciones distintas */
.layered {
  background-image:
    url("icon.png"),
    linear-gradient(135deg, #667eea, #764ba2);
  background-position: top right, center;
  background-size: 50px, cover;
  background-repeat: no-repeat, no-repeat;
}

Overlay sobre imagen (patrón muy común)

.hero {
  background-image:
    linear-gradient(
      to bottom,
      rgba(0, 0, 0, 0.3),
      rgba(0, 0, 0, 0.7)
    ),
    url("hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

Patrón de cuadrícula (grid pattern)

.grid-bg {
  background-image:
    linear-gradient(to right, #e0e0e0 1px, transparent 1px),
    linear-gradient(to bottom, #e0e0e0 1px, transparent 1px);
  background-size: 20px 20px;
}

Gradiente de texto (efecto popular)

.gradient-text {
  background-image: linear-gradient(90deg, #f39c12, #e74c3c, #9b59b6);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  /* El texto se ve con el gradiente */
}

Múltiples capas con shorthand

.multi {
  background:
    url("capa-superior.png") center / 50px no-repeat,
    url("capa-media.png") top right / 100px no-repeat,
    linear-gradient(135deg, #667eea, #764ba2);
}

⚠️ Errores comunes

  1. Olvidar background-size: cover → la imagen se muestra a su tamaño original y se repite.
  1. Olvidar background-repeat: no-repeat → la imagen se repite como patrón no deseado.
  1. Usar background en lugar de background-image → el shorthand resetea todas las propiedades de fondo (color, size, position…).
  1. No definir un background-color de fallback → si la imagen no carga, el elemento queda transparente.
  1. Imágenes muy pesadas → afectan al rendimiento. Optimizar con WebP/AVIF y usar image-set().
  1. Confundir background-image con background → background-image solo define la imagen; el resto de propiedades se mantienen.
  1. Olvidar webkit-background-clip: text → Safari requiere el prefijo para el gradiente en texto.
  1. Múltiples capas mal ordenadas → el primer valor se dibuja encima. Si quieres la imagen arriba y el gradiente debajo, la imagen va primero.
  1. url() sin comillas con espacios → puede fallar. Usar url("mi imagen.jpg").
  1. Gradientes sin dirección → linear-gradient(red, blue) funciona (por defecto to bottom), pero es mejor ser explícito.
  1. No usar background-attachment para parallax → sin él, la imagen se desplaza con el contenido.
  1. Usar background-image en body sin height → el fondo cubre solo el área de contenido. Usar min-height: 100vh.

🧩 Relación con otros conceptos

  • background-color → se dibuja debajo de background-image.
  • background → shorthand que incluye background-image.
  • background-size → controla el tamaño (cover, contain).
  • background-position → posición de la imagen.
  • background-repeat → repetición.
  • background-attachment → scroll, fixed, local.
  • background-clip → hasta dónde se pinta (text para gradiente en texto).
  • background-origin → desde dónde se posiciona.
  • background-blend-mode → mezcla capas.
  • border-radius → el fondo se recorta con las esquinas.
  • image-set() → imágenes responsive.
  • prefers-color-scheme → adaptar gradientes a modo oscuro.
  • filter: blur() → desenfocar el fondo con ::before.

🧠 Analogía

Imagina que cada elemento es una vitrina de cristal con varias capas de decoración. background-image es lo que colocas dentro: puedes poner un póster (imagen url()), una pintura degradada (gradiente), o varias capas superpuestas (una foto con un filtro oscuro encima). El color de fondo (background-color) es la pared del fondo, siempre detrás de todo. Y las capas se apilan como transparencias: la primera que pones es la que se ve encima.

📝 Notas personales

  • background-image solo define la imagen → el resto de propiedades (size, position, repeat) se mantienen. A diferencia del shorthand background, que resetea todo.
  • Siempre definir un background-color de fallback → por si la imagen no carga.
  • Múltiples capas → separadas por comas; la primera se dibuja encima.
  • Overlay clásico → linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)), url(...) es el patrón para oscurecer una imagen de fondo.
  • Gradiente en texto → background-clip: text + color: transparent + prefijo webkit-.
  • image-set() → imágenes responsive sin media queries.
  • Optimización → usar WebP/AVIF, comprimir imágenes, y preferir gradientes a imágenes cuando sea posible.
  • Patrones con gradientes → repeating-linear-gradient y repeating-radial-gradient permiten crear texturas sin archivos.
  • Data URIs → url("data:image/svg+xml,...") permite incrustar SVG pequeños directamente en CSS.
  • conic-gradient → ideal para gráficos circulares, ruedas de color y efectos modernos.
  • prefers-color-scheme → adaptar gradientes e imágenes a modo oscuro.
  • Cuidado con background-attachment: fixed → problemas en móvil; considerar alternativas con position: fixed y ::before.
