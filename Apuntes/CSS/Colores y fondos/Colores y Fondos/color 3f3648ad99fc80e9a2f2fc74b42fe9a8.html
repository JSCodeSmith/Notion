color

📄 color

📝 Definición

color es una propiedad CSS heredable que establece el color del texto (y de la decoración de texto como subrayados) de un elemento.

No afecta al fondo ni a los bordes, salvo que estos usen currentColor.

🧠 ¿Qué es?

Forma parte de las propiedades de texto y es una de las más básicas de CSS.

Es heredable: si la defines en un padre, los hijos la heredan automáticamente, salvo que la sobrescriban.

Es la base del sistema currentColor: cualquier propiedad que acepte currentColor (border, background, outline, box-shadow, fill, stroke en SVG…) usará el valor de color de ese elemento.

🎯 ¿Para qué sirve?

  • Definir el color del texto en toda la interfaz.
  • Establecer jerarquía visual (títulos, cuerpo, enlaces, errores).
  • Indicar estados (error rojo, éxito verde, aviso amarillo).
  • Alimentar currentColor para bordes, iconos SVG y sombras.
  • Adaptar la interfaz al modo oscuro con variables.
  • Cumplir contraste accesible (WCAG) sobre el fondo.

⚙️ ¿Cómo funciona?

El navegador pinta el texto del elemento con el color especificado.

Reglas clave:

  1. Heredable → los hijos heredan color si no lo sobrescriben.
  1. Valor inicial → depende del user-agent (normalmente negro, canvastext en navegadores modernos).
  1. Afecta al texto y decoraciones → subrayado, tachado, text-decoration-color por defecto.
  1. Afecta a currentColor → cualquier propiedad con currentColor usa este valor.
  1. No afecta al fondo ni al borde → a menos que uses currentColor explícitamente.
  1. Afecta a caret-color y accent-color en algunos casos (por herencia).

📝 Sintaxis / Estructura

selector {
  color: valor;
}

Formatos de color comunes

color: #333;                       /* Hex */
color: #333c;                      /* Hex con alpha */
color: rgb(51, 51, 51);            /* RGB */
color: rgba(51, 51, 51, 0.8);      /* RGB con alpha */
color: hsl(0, 0%, 20%);            /* HSL */
color: hsla(0, 0%, 20%, 0.8);      /* HSL con alpha */
color: oklch(30% 0 0);             /* OKLCH (moderno) */
color: currentColor;               /* Se refiere a sí mismo */
color: transparent;                /* Invisible */

💡 Ejemplos

/* 1. Color base del body */
body {
  color: #333;
  background-color: #fff;
}

/* 2. Jerarquía de títulos */
h1 { color: #111; }
h2 { color: #222; }
p  { color: #555; }

/* 3. Enlaces */
a {
  color: #3498db;
}
a:hover {
  color: #2980b9;
}

/* 4. Estados de formulario */
.error { color: crimson; }
.success { color: seagreen; }
.warning { color: darkorange; }

/* 5. currentColor en bordes e iconos */
.btn-outline {
  color: #3498db;
  border: 2px solid currentColor;
  background: transparent;
}

/* 6. Icono SVG que hereda color */
.icon {
  fill: currentColor;
}

/* 7. Modo oscuro con variables */
:root {
  --texto: #111;
}
@media (prefers-color-scheme: dark) {
  :root {
    --texto: #eee;
  }
}
body {
  color: var(--texto);
}

/* 8. Texto con gradiente (truco) */
.gradient-text {
  background: linear-gradient(90deg, #f39c12, #e74c3c);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

⚠️ Errores comunes

  1. Confundir color con background-color → color es el texto; background-color es el fondo. Error clásico de principiante.
  1. Texto invisible por color: transparent → útil solo en trucos (gradiente en texto). Asegurar que el texto sigue siendo legible para lectores de pantalla.
  1. Contraste insuficiente → texto gris claro sobre blanco. WCAG AA exige ratio mínimo 4.5:1 para texto normal y 3:1 para texto grande.
  1. No considerar :visited → los enlaces visitados tienen color propio del navegador que puede sobrescribir tu color. Estilizar :visited explícitamente.
  1. Olvidar la herencia → definir color en body y no en cada elemento es más limpio; sobrescribir solo donde haga falta.
  1. Usar color para iconos SVG → en SVG, usar fill: currentColor o stroke: currentColor; color solo no basta para colorear el trazo.
  1. No adaptar a modo oscuro → textos oscuros sobre fondos oscuros. Usar variables + prefers-color-scheme.
  1. Confundir con caret-color → el cursor de texto se controla con caret-color, no con color (aunque se hereda en algunos casos).
  1. Olvidar el contraste en hover → el color de hover puede reducir el contraste y violar WCAG.

🧩 Relación con otros conceptos

  • background-color → color de fondo (no confundir).
  • currentColor → palabra clave que toma el valor de color.
  • caret-color → color del cursor de texto.
  • text-decoration-color → color del subrayado/tachado.
  • fill / stroke → en SVG, aceptan currentColor.
  • accent-color → color de controles nativos (checkboxes, radios).
  • ::selection → color del texto seleccionado.
  • ::placeholder → color del placeholder.
  • prefers-color-scheme → adaptar al modo claro/oscuro.
  • WCAG → define ratios de contraste mínimos.
  • Herencia → color es heredable; background-color no.

Herencia visual:

body { color: #333 }
  └── section (hereda #333)
        └── h1 { color: #111 } (sobrescribe)
        └── p (hereda #333)
              └── a { color: #3498db } (sobrescribe)

🧠 Analogía

Imagina que cada elemento es un lápiz. El color es el color de la mina con la que escribe. Los hijos heredan el lápiz del padre si no tienen el suyo propio. currentColor sería como decir "usa la misma mina para dibujar el marco de este cuadro" → todo queda coherente con el color del texto.

📝 Notas personales

  • Regla mental: color = texto; background-color = fondo. Nunca confundir.
  • Herencia → definir color en body y sobrescribir solo donde haga falta.
  • currentColor es una navaja suiza → úsalo para bordes, iconos SVG, sombras y todo lo que deba ir a juego con el texto.
  • Contraste → verificar siempre con WebAIM, Stark o DevTools. WCAG AA: 4.5:1 texto normal, 3:1 texto grande.
  • Modo oscuro → variables CSS + prefers-color-scheme es el patrón moderno.
  • :visited tiene restricciones de privacidad → solo permite cambiar color, background-color, border-color, outline-color y column-rule-color.
  • color: transparent → útil para gradiente en texto, pero ojo con lectores de pantalla (el texto sigue ahí, solo invisible).
  • SVG → fill y stroke con currentColor es el patrón para iconos que heredan color.
  • oklch() → formato moderno con mejor percepción de luminosidad; ideal para paletas consistentes en claro/oscuro.
  • ::selection → personalizar el color del texto seleccionado mejora la coherencia visual.
