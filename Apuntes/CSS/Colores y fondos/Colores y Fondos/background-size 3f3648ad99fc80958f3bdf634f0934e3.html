background-size

📄 background-size

📝 Definición

background-size es una propiedad CSS que establece el tamaño de las imágenes de fondo (background-image) dentro de la caja de un elemento.

🧠 ¿Qué es?

Forma parte de las propiedades de fondo (junto con background-image, background-position, background-repeat, background-attachment, background-clip, etc.).

Controla cuánto ocupa la imagen de fondo, independientemente de su tamaño intrínseco.

Es una de las propiedades más importantes para fondos responsive: permite que una imagen se adapte al contenedor sin deformarse ni repetirse.

🎯 ¿Para qué sirve?

  • Hacer que una imagen de fondo cubra toda la caja (cover).
  • Mostrar la imagen entera sin recortarla (contain).
  • Ajustar una imagen a un tamaño exacto (100% auto, 200px 100px).
  • Crear patrones con tamaño controlado.
  • Hacer responsive una imagen de fondo sin media queries.
  • Controlar el tamaño de múltiples capas de fondo.

⚙️ ¿Cómo funciona?

El navegador escala la imagen según el valor y el tamaño de la caja del elemento.

Reglas clave:

  1. Un valor → se aplica al ancho; la altura se calcula automáticamente para mantener la proporción (auto).
  1. Dos valores → ancho y alto explícitos.
  1. cover → la imagen cubre toda la caja, recortando lo que sobra. Mantiene proporción.
  1. contain → la imagen cabe entera dentro de la caja, dejando espacio vacío. Mantiene proporción.
  1. auto → usa el tamaño intrínseco de la imagen.
  1. % → porcentaje del tamaño de la caja.
  1. Interactúa con background-repeat → si la imagen es más pequeña que la caja, se repite (salvo no-repeat).
  1. Interactúa con background-position → la posición decide qué parte de la imagen se ve cuando cover recorta.
  1. Múltiples capas → cada valor corresponde a la capa en la misma posición de background-image.
  1. background-origin → define desde dónde se calcula el tamaño.

📝 Sintaxis / Estructura

selector {
  background-size: valor;
}

Sintaxis de uno o dos valores

/* Un valor: ancho (alto = auto) */
background-size: 200px;      /* ancho 200px, alto proporcional */
background-size: 50%;        /* 50% del ancho, alto proporcional */
background-size: cover;      /* palabra clave */

/* Dos valores: ancho | alto */
background-size: 200px 100px;
background-size: 100% auto;
background-size: auto 100%;
background-size: 50% 50%;

Múltiples capas

background-size: cover, 50px 50px, auto;
/* cada valor corresponde a la capa en la misma posición de background-image */

💡 Ejemplos

/* 1. Imagen que cubre toda la caja (hero) */
.hero {
  background-image: url("hero.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* 2. Imagen entera sin recortar (logo) */
.logo {
  background-image: url("logo.png");
  background-size: contain;
  background-position: center;
  background-repeat: no-repeat;
}

/* 3. Ancho completo, alto automático */
.banner {
  background-image: url("banner.jpg");
  background-size: 100% auto;
  background-repeat: no-repeat;
}

/* 4. Tamaño fijo */
.icon {
  background-image: url("icon.png");
  background-size: 32px 32px;
  background-repeat: no-repeat;
}

/* 5. Patrón con tamaño controlado */
.pattern {
  background-image: url("dot.png");
  background-size: 20px 20px;
  background-repeat: repeat;
}

/* 6. Fondo responsive con porcentaje */
.fluid {
  background-image: url("bg.jpg");
  background-size: 100% 100%; /* ⚠️ puede deformar */
}

/* 7. Imagen responsive manteniendo proporción */
.responsive {
  background-image: url("bg.jpg");
  background-size: 100% auto;
  background-repeat: no-repeat;
  background-position: top center;
}

/* 8. Múltiples capas con distintos tamaños */
.layered {
  background-image:
    url("icon.png"),
    url("pattern.png");
  background-size: 32px 32px, 20px 20px;
  background-repeat: no-repeat, repeat;
}

/* 9. Shorthand (position / size) */
.card {
  background: #fff url("bg.jpg") center / cover no-repeat;
}

/* 10. Fondo con degradado (los gradientes ignoran background-size) */
.gradient {
  background: linear-gradient(135deg, #667eea, #764ba2);
  /* background-size no aplica a gradientes */
}

Diferencia entre cover y contain

/* cover: llena toda la caja, recorta lo que sobra */
.cover {
  background-image: url("foto.jpg");
  background-size: cover;
  /* ✅ Llena todo, ⚠️ puede recortar partes de la imagen */
}

/* contain: muestra la imagen entera, deja espacio */
.contain {
  background-image: url("logo.png");
  background-size: contain;
  /* ✅ Muestra todo, ⚠️ puede dejar espacio vacío */
}

Controlar qué parte se ve con cover

/* Imagen de persona: mostrar la cara (arriba) */
.portrait {
  background-image: url("persona.jpg");
  background-size: cover;
  background-position: top center;
}

/* Paisaje: mostrar el horizonte (centro-abajo) */
.landscape {
  background-image: url("paisaje.jpg");
  background-size: cover;
  background-position: center 70%;
}

Fondo responsive con porcentaje

/* ✅ Mantiene proporción */
.responsive {
  background-image: url("bg.jpg");
  background-size: 100% auto;
  background-repeat: no-repeat;
}

/* ⚠️ Puede deformar si la proporción no coincide */
.deformed {
  background-image: url("bg.jpg");
  background-size: 100% 100%;
}

⚠️ Errores comunes

  1. Usar 100% 100% sin pensar → deforma la imagen si la proporción no coincide con la caja.
  1. Olvidar background-repeat: no-repeat → con contain, la imagen se repite si no cubre toda la caja.
  1. Confundir cover con contain → cover llena (recorta); contain cabe entero (deja aire).
  1. No combinar cover con background-position → por defecto recorta desde el centro; a veces la parte importante está arriba o abajo.
  1. Usar background-size sin background-image → no tiene efecto.
  1. Confundir background-size con width/height → background-size no cambia el tamaño de la caja, solo de la imagen de fondo.
  1. Usar background en lugar de background-size → el shorthand resetea todo.
  1. Aplicar background-size a gradientes → los gradientes se generan al tamaño de la caja; background-size no los afecta (salvo con repeating-*).
  1. Olvidar el orden en múltiples capas → cada valor corresponde a la capa en la misma posición de background-image.
  1. Usar cover con imágenes muy grandes → pueden afectar al rendimiento. Optimizar con WebP/AVIF.
  1. No usar image-set() → para imágenes responsive, image-set() es más eficiente que background-size.
  1. Confundir background-size: cover con object-fit: cover → el primero es para fondos; el segundo para <img>, <video>, etc.

🧩 Relación con otros conceptos

  • background-image → define la imagen a escalar.
  • background-position → decide qué parte se ve con cover.
  • background-repeat → controla la repetición si la imagen no cubre.
  • background-attachment → si se desplaza con el scroll.
  • background-origin → desde dónde se calcula el tamaño.
  • background-clip → hasta dónde se pinta.
  • background → shorthand que incluye background-size (con position / size).
  • object-fit → equivalente para <img>, <video>, etc.
  • image-set() → imágenes responsive para fondos.
  • aspect-ratio → ayuda a mantener proporciones en la caja.

Interacción size + repeat + position:

background-size: cover          → repeat no se nota (cubre todo)
background-size: contain        → repeat se nota si no cubre todo
background-size: 50% 50%        → repeat forma patrón 2x2
background-size: 200px 200px    → repeat forma patrón de 200px
background-repeat: no-repeat    → solo una copia, position decide dónde

🧠 Analogía

Imagina que la caja del elemento es una pared y la imagen de fondo es un póster. background-size decide cómo de grande es el póster:

  • auto → tamaño original del póster.
  • cover → agrandas el póster hasta que cubra toda la pared (recortas lo que sobra).
  • contain → encoges el póster hasta que quepa entero (deja pared vacía alrededor).
  • 100% 100% → estiras el póster para llenar la pared → se deforma si no coincide la proporción.
  • 200px 100px → póster de tamaño exacto.

Y background-position decide dónde lo cuelgas (centro, esquina, etc.).

📝 Notas personales

  • cover es el más usado → llena la caja sin deformar, recortando lo que sobra.
  • contain para logos e iconos → muestra la imagen entera sin recortar.
  • 100% 100% deforma → evitar salvo que la proporción coincida.
  • 100% auto → mantiene proporción, ancho completo, alto automático.
  • Siempre combinar cover con background-position → para elegir qué parte se ve (caras, horizontes).
  • Añadir no-repeat → casi siempre quieres una sola copia.
  • Múltiples capas → cada valor corresponde a la capa en la misma posición de background-image.
  • background-size no afecta a gradientes → los gradientes se generan al tamaño de la caja.
  • image-set() → mejor opción para imágenes responsive que background-size + media queries.
  • Optimización → usar WebP/AVIF, comprimir imágenes, y considerar SVG para patrones e iconos.
  • object-fit → el equivalente para <img> y <video>, no confundir.
