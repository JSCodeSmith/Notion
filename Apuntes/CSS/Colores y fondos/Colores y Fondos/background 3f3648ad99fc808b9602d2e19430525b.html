background

📄 background

📝 Definición

background es una propiedad abreviada (shorthand) de CSS que agrupa todas las propiedades de fondo de un elemento en una sola declaración: color, imagen, posición, tamaño, repetición, origen, recorte, adhesión y modo de fusión.

🧠 ¿Qué es?

Forma parte de las propiedades de fondo y es el shorthand de:

  • background-color
  • background-image
  • background-position
  • background-size
  • background-repeat
  • background-origin
  • background-clip
  • background-attachment
  • background-blend-mode

⚠️ Importante: al usar background, todas las propiedades no especificadas se resetean a sus valores por defecto.

Esto es la causa nº1 de bugs al cambiar solo un aspecto del fondo.

🎯 ¿Para qué sirve?

  • Definir fondos complejos en una sola línea.
  • Combinar color + imagen + gradiente.
  • Crear patrones repetidos.
  • Aplicar múltiples fondos en capas.
  • Establecer fondos fijos (parallax) o que se desplazan con el scroll.
  • Recortar fondos a texto o padding.

⚙️ ¿Cómo funciona?

El navegador aplica las capas de fondo de arriba a abajo (la primera es la más cercana al usuario). Reglas clave:

  1. Shorthand resetea todo → si solo pones background: red, borras cualquier imagen previa.
  1. Múltiples fondos → separados por comas, el primero se dibuja encima.
  1. Orden flexible → el navegador distingue color, image, position/size, etc.
  1. position y size juntos → se escriben position / size (ej. center / cover).
  1. background-clip: text → recorta el fondo al texto (efecto gradiente en texto).
  1. background-attachment: fixed → efecto parallax (cuidado en móvil).
  1. El color siempre va al final → si se especifica, es la última capa.

📝 Sintaxis / Estructura

selector {
  background: [color] [image] [position] / [size] [repeat] [attachment] [origin] [clip] [blend-mode];
}

Parámetros / Valores comunes

background-image

background-image: url("imagen.jpg");
background-image: linear-gradient(135deg, #f39c12, #e74c3c);
background-image: radial-gradient(circle, #fff, #000);
background-image: repeating-linear-gradient(45deg, #eee 0 10px, #fff 10px 20px);
background-image: none;

background-position

background-position: center;
background-position: top right;
background-position: 50% 20%;
background-position: 20px 40px;

background-size

background-size: cover;      /* cubre todo, recorta */
background-size: contain;    /* cabe entero, deja aire */
background-size: 100% auto;
background-size: 200px 100px;

background-repeat

background-repeat: repeat;
background-repeat: no-repeat;
background-repeat: repeat-x;
background-repeat: repeat-y;
background-repeat: space;    /* distribuye sin recortar */
background-repeat: round;    /* escala para encajar */

background-attachment

background-attachment: scroll;  /* por defecto */
background-attachment: fixed;   /* fijo al viewport (parallax) */
background-attachment: local;   /* scroll con el contenido */

background-clip

background-clip: border-box;   /* por defecto */
background-clip: padding-box;
background-clip: content-box;
background-clip: text;         /* recorta al texto */

💡 Ejemplos

/* 1. Color simple (¡resetea todo!) */
.elemento {
  background: #f5f5f5;
}

/* 2. Imagen que cubre */
.hero {
  background: url("hero.jpg") center / cover no-repeat;
}

/* 3. Gradiente lineal */
.gradient {
  background: linear-gradient(135deg, #667eea, #764ba2);
}

/* 4. Gradiente radial */
.radial {
  background: radial-gradient(circle at center, #fff, #000);
}

/* 5. Múltiples fondos en capas */
.layered {
  background:
    url("overlay.png") center / cover no-repeat,
    linear-gradient(135deg, #f39c12, #e74c3c);
}

/* 6. Patrón repetido */
.pattern {
  background:
    repeating-linear-gradient(
      45deg,
      #eee 0 10px,
      #fff 10px 20px
    );
}

/* 7. Texto con gradiente */
.gradient-text {
  background: linear-gradient(90deg, #f39c12, #e74c3c);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

/* 8. Fondo fijo (parallax) */
.parallax {
  background: url("bg.jpg") center / cover no-repeat fixed;
}

/* 9. Color + imagen */
.card {
  background: #fff url("pattern.png") top right / 100px no-repeat;
}

/* 10. Variables CSS para fondos */
:root {
  --bg-primary: linear-gradient(135deg, #667eea, #764ba2);
}
.hero {
  background: var(--bg-primary);
}

Diferencia crítica: background vs background-color

/* ❌ Peligroso: resetea la imagen */
.elemento {
  background: #fff;
  /* Si tenía una imagen, se pierde */
}

/* ✅ Seguro: solo cambia el color */
.elemento {
  background-color: #fff;
  /* La imagen previa se mantiene */
}

Orden de las capas

.layered {
  background:
    url("capa-superior.png") center / cover no-repeat,  /* ← arriba */
    url("capa-media.png") center / cover no-repeat,
    linear-gradient(#000, #333);                        /* ← abajo */
}

background-clip: text para gradiente en texto

.gradient-text {
  background: linear-gradient(90deg, #f39c12, #e74c3c);
  -webkit-background-clip: text;  /* Safari */
  background-clip: text;
  color: transparent;             /* el texto se vuelve transparente */
  /* El fondo se ve solo a través del texto */
}

⚠️ Errores comunes

  1. Usar background en lugar de background-color → el shorthand resetea todas las propiedades de fondo. Si solo quieres cambiar el color, usar background-color.
  1. No definir background-size después de position → la sintaxis es position / size, con barra. center cover es inválido; center / cover es correcto.
  1. Olvidar no-repeat → por defecto la imagen se repite y puede verse como patrón no deseado.
  1. Usar background-attachment: fixed en móvil → algunos navegadores móviles lo ignoran o causan problemas de rendimiento.
  1. Confundir background-clip con background-origin → clip = hasta dónde se pinta; origin = desde dónde se posiciona.
  1. No usar webkit-background-clip: text → Safari aún requiere el prefijo.
  1. Olvidar el color de fallback → si la imagen no carga, el elemento queda transparente. Definir un background-color de respaldo.
  1. Imágenes muy pesadas → afectan al rendimiento. Optimizar con WebP/AVIF y usar image-set().
  1. Múltiples fondos mal ordenados → el primero se dibuja encima; el último, debajo. Invertir el orden es un error frecuente.
  1. background en body sin height → el fondo cubre solo el área de contenido, no toda la pantalla. Usar min-height: 100vh.

🧩 Relación con otros conceptos

  • background-color → solo el color (no resetea nada).
  • background-image → imagen o gradiente.
  • background-size → cover / contain.
  • background-position → posición de la imagen.
  • background-clip → hasta dónde se pinta el fondo.
  • background-origin → desde dónde se posiciona.
  • background-blend-mode → mezcla capas.
  • border-radius → el fondo se recorta con las esquinas.
  • box-shadow → sombra de la caja, no del fondo.
  • filter: blur() → desenfoca el fondo (con ::before para no afectar al contenido).
  • image-set() → imágenes responsive para fondos.
  • prefers-color-scheme → adaptar fondos a modo oscuro.

🧠 Analogía

Imagina que cada elemento es una vitrina de cristal. El background es todo lo que colocas dentro: el color de la pared (background-color), un póster (background-image), cómo lo colocas (position), de qué tamaño (size), si se repite (repeat), etc. Si usas el shorthand, es como vaciar la vitrina y volver a decorarla desde cero. Si solo usas background-color, cambias solo el color de la pared sin tocar el póster.

📝 Notas personales

  • Regla de oro: si solo quieres cambiar el color, usar background-color; si quieres definir todo el fondo, usar background.
  • El shorthand resetea → causa nº1 de bugs de fondo. Tenerlo siempre presente.
  • Sintaxis position / size → center / cover es el patrón más usado.
  • Múltiples capas → separadas por comas, la primera se dibuja encima.
  • background-clip: text → gradiente en texto; requiere webkit-background-clip en Safari.
  • background-attachment: fixed → cuidado en móvil; algunos navegadores lo ignoran.
  • Fallback de color → siempre definir un background-color de respaldo por si la imagen falla.
  • Optimización → usar WebP/AVIF, image-set(), y evitar imágenes muy pesadas en fondos.
  • background-size: cover vs contain → cover llena (recorta), contain muestra todo (deja aire).
  • Variables CSS → definir gradientes de marca como variables para consistencia.
  • prefers-color-scheme → adaptar fondos a modo oscuro (gradientes y colores).
