border-style

📄 border-style

📝 Definición

border-style es una propiedad CSS que establece el estilo de la línea del borde de un elemento: sólido, discontinuo, punteado, doble, etc.

Es la propiedad que hace visible el borde; sin ella, border-width y border-color no tienen efecto.

🧠 ¿Qué es?

Forma parte de las propiedades de borde (junto con border-width, border-color y el shorthand border).

Define cómo se dibuja la línea del borde.

Es la propiedad más importante de las tres: si border-style es none (valor por defecto), el borde no se renderiza, sin importar el grosor o el color que hayas definido.

🎯 ¿Para qué sirve?

  • Hacer visible el borde de un elemento.
  • Diferenciar visualmente componentes (sólido en tarjetas, discontinuo en zonas editables).
  • Indicar estados (punteado en focus, sólido en error).
  • Crear separadores con distintos estilos.
  • Diseñar efectos 3D (groove, ridge, inset, outset).
  • Construir triángulos y formas con el truco del border.

⚙️ ¿Cómo funciona?

El navegador dibuja el borde en el grosor indicado por border-width y con el color de border-color, usando el patrón del border-style.

Reglas clave:

  1. Sin border-style, no hay borde visible → aunque definas border-width: 10px; border-color: red, si border-style: none (por defecto), no se ve nada.
  1. Acepta 1 a 4 valores → igual que margin/padding.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el borde suma al width/height. Con border-box, se incluye.
  1. Propiedades individuales → border-top-style, border-right-style, etc.
  1. Propiedades lógicas → border-inline-style, border-block-style para i18n.
  1. Estilos 3D dependen del border-color → groove, ridge, inset, outset generan sombras automáticas basadas en el color.
  1. hidden vs none → ambos ocultan el borde, pero hidden gana en conflictos de tablas con border-collapse: collapse.

📝 Sintaxis / Estructura

/* Un valor: todos los lados */
border-style: solid;

/* Dos valores: vertical | horizontal */
border-style: solid dashed;

/* Tres valores: top | horizontal | bottom */
border-style: solid dashed dotted;

/* Cuatro valores: top | right | bottom | left (horario) */
border-style: solid dashed dotted double;

Propiedades individuales

border-top-style: solid;
border-right-style: dashed;
border-bottom-style: dotted;
border-left-style: double;

Propiedades lógicas (modernas)

border-block-style: solid dashed;   /* top | bottom */
border-inline-style: dotted double; /* left | right */
border-block-start-style: solid;
border-inline-end-style: dashed;

💡 Ejemplos

/* 1. Borde sólido (el más común) */
.card {
  border-style: solid;
  border-width: 1px;
  border-color: #ddd;
}

/* 2. Borde discontinuo */
.dashed {
  border-style: dashed;
  border-width: 2px;
  border-color: #999;
}

/* 3. Borde punteado (focus o zona editable) */
.dotted {
  border-style: dotted;
  border-width: 2px;
  border-color: #3498db;
}

/* 4. Borde doble (requiere ≥3px para verse) */
.double {
  border-style: double;
  border-width: 4px;
  border-color: #333;
}

/* 5. Borde 3D */
.tridimensional {
  border-style: groove;
  border-width: 6px;
  border-color: #ccc;
}

/* 6. Estilos distintos por lado */
.mixto {
  border-style: solid dashed dotted double;
  border-width: 2px;
  border-color: #333;
  /* top: solid | right: dashed | bottom: dotted | left: double */
}

/* 7. Solo borde abajo (divisor) */
h2 {
  border-bottom-style: solid;
  border-bottom-width: 2px;
  border-bottom-color: #333;
  padding-bottom: 8px;
}

/* 8. Shorthand completo */
.btn {
  border: 2px solid #3498db;
}

/* 9. Quitar borde */
.sin-borde {
  border-style: none;
  /* Aunque haya border-width y border-color, no se ve */
}

/* 10. Propiedades lógicas */
.logico {
  border-inline-style: solid; /* left y right */
  border-block-style: dashed; /* top y bottom */
  border-width: 2px;
  border-color: #333;
}

Los 4 estilos básicos comparados

.solid  { border: 3px solid #333; }   /* ───── */
.dashed { border: 3px dashed #333; }  /* ─ ─ ─ */
.dotted { border: 3px dotted #333; }  /* ····· */
.double { border: 4px double #333; }  /* ═════ */

Los 4 estilos 3D comparados

.groove { border: 6px groove #ccc; } /* hundido */
.ridge  { border: 6px ridge #ccc; }  /* saliente */
.inset  { border: 6px inset #ccc; }  /* interior */
.outset { border: 6px outset #ccc; } /* exterior */

Triángulo con border-style

.triangulo {
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 0 20px 30px 20px;
  border-color: transparent transparent #333 transparent;
  /* Triángulo apuntando hacia arriba */
}

Separador con border-bottom-style

hr {
  border: none;
  border-bottom-style: solid;
  border-bottom-width: 1px;
  border-bottom-color: #eee;
  margin: 24px 0;
}

Input con borde punteado en focus

input {
  border: 1px solid #ccc;
}
input:focus {
  border-style: dashed;
  border-color: #3498db;
  outline: none;
  /* Cambia a punteado al enfocar */
}

⚠️ Errores comunes

  1. Olvidar border-style → border-width: 2px; border-color: red no muestra nada sin border-style. Error nº1 de principiante.
  1. Usar border: 1px #333 → inválido; falta el estilo. El shorthand requiere los tres valores (o al menos el estilo).
  1. double con menos de 3px → no se ve el efecto doble; se renderiza como sólido o no se ve. Usar ≥3px.
  1. Confundir none con hidden → ambos ocultan, pero hidden gana en conflictos de tablas.
  1. No usar box-sizing: border-box → el borde suma al tamaño total.
  1. Asumir que los estilos 3D se ven igual en todos los navegadores → varían ligeramente; no son fiables para diseños precisos.
  1. Animar border-style → no es animable; el cambio es instantáneo. Para transiciones, usar box-shadow o outline.
  1. border-style: dashed en textos largos → los guiones pueden no alinearse con el contenido.
  1. Usar border-style para simular outline de focus → funciona, pero outline es más accesible y no rompe layout.
  1. Estilos distintos por lado sin coherencia → solid dashed dotted double puede verse caótico. Usar con intención.
  1. Olvidar el orden → top right bottom left (horario). Fácil de equivocar.
  1. border-style en tablas con border-collapse: collapse → los bordes se fusionan; el resultado puede sorprender.

🧩 Relación con otros conceptos

  • border-width → grosor del borde (no se ve sin border-style).
  • border-color → color del borde.
  • border → shorthand que incluye border-style.
  • box-sizing → border-box incluye el borde en el tamaño.
  • outline-style → equivalente para el outline.
  • border-radius → el borde sigue la curva.
  • box-shadow → alternativa para bordes sin afectar layout.
  • border-collapse → en tablas, controla la fusión de bordes.
  • border-image → usa imágenes como borde.
  • Propiedades lógicas → border-inline-style, border-block-style.
  • background-clip → hasta dónde se pinta el fondo respecto al borde.

🧠 Analogía

Imagina que cada elemento es un cuadro enmarcado. border-style es el tipo de moldura que eliges:

  • solid → moldura lisa y continua.
  • dashed → moldura a rayas.
  • dotted → moldura de puntos.
  • double → moldura doble.
  • groove / ridge → moldura con relieve 3D.

Si no eliges ninguna (none), el cuadro no tiene marco, aunque hayas definido su grosor y color.

📝 Notas personales

  • border-style es obligatorio → sin él, border-width y border-color no se ven. Error nº1 de principiante.
  • border: 1px solid → el shorthand más usado; recordar el solid.
  • solid es el 95% de los casos → los demás estilos son para casos específicos.
  • double requiere ≥3px → con menos, no se aprecia el efecto.
  • Estilos 3D (groove, ridge, inset, outset) → poco fiables para diseños precisos; varían entre navegadores.
  • none vs hidden → ambos ocultan, pero hidden gana en conflictos de tablas.
  • border-style no es animable → si necesitas transición, usar box-shadow o outline.
  • Para focus accesible → preferir outline sobre cambiar border-style (no rompe layout).
  • Siempre box-sizing: border-box → si no, el borde agranda el elemento.
  • Triángulos con border-style: solid + border-color: transparent → truco clásico; hoy clip-path es más flexible.
  • Propiedades lógicas → preferir border-inline-style y border-block-style en proyectos multiidioma.
