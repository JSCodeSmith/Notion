border-bottom

📄 border-bottom

📝 Definición

border-bottom es una propiedad abreviada (shorthand) de CSS que establece en una sola declaración el borde inferior de un elemento: grosor (border-bottom-width), estilo (border-bottom-style) y color (border-bottom-color).

🧠 ¿Qué es?

Forma parte de las propiedades de borde (junto con border-top, border-right, border-left y el shorthand general border).

Es un atajo para definir los tres aspectos del borde solo en el lado inferior.

Es la propiedad más usada para separadores horizontales debajo de títulos, secciones, filas de tabla, ítems de lista y enlaces.

🎯 ¿Para qué sirve?

  • Crear separadores inferiores (debajo de títulos, secciones, filas).
  • Definir el borde inferior de tarjetas, modales, alertas.
  • Indicar estados con un borde inferior de color (error, éxito, tab activo).
  • Construir triángulos y flechas con el truco del border.
  • Crear subrayados personalizados en enlaces (más control que text-decoration).
  • Añadir decoración sin afectar a los otros lados.

⚙️ ¿Cómo funciona?

El navegador dibuja el borde inferior con los valores indicados.

Reglas clave:

  1. Requiere border-bottom-style → sin estilo, no se ve nada (aunque definas grosor y color).
  1. Afecta solo al lado inferior → los otros lados no se tocan.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el borde suma a la altura. Con border-box, se incluye.
  1. Orden flexible en el shorthand → puedes escribir 1px solid red o solid 1px red; el navegador reconoce cada valor.
  1. Valores por defecto → si omites alguno, se usan los iniciales: medium none currentColor.
  1. No afecta a border-top, border-right, border-left → cada lado es independiente.
  1. Se combina con border-radius → el borde sigue la curva en las esquinas inferiores.

📝 Sintaxis / Estructura

selector {
  border-bottom: width style color;
}

Propiedades que agrupa

PropiedadDescripciónValor por defecto
border-bottom-widthGrosor del borde inferiormedium
border-bottom-styleEstilo del borde inferiornone
border-bottom-colorColor del borde inferiorcurrentColor
/* Orden flexible */
border-bottom: 2px solid #333;
border-bottom: solid 2px #333;
border-bottom: #333 solid 2px;

/* Solo algunos valores */
border-bottom: 2px solid;         /* color por defecto (currentColor) */
border-bottom: solid;             /* grosor y color por defecto */
border-bottom: 2px;               /* ⚠️ no se ve sin estilo */

Propiedades individuales

border-bottom-width: 2px;
border-bottom-style: solid;
border-bottom-color: #333;

Propiedades lógicas equivalentes

/* En writing-mode horizontal LTR, equivale a border-bottom */
border-block-end: 2px solid #333;
border-block-end-width: 2px;
border-block-end-style: solid;
border-block-end-color: #333;

💡 Ejemplos

/* 1. Separador inferior en un título */
h2 {
  border-bottom: 2px solid #333;
  padding-bottom: 8px;
}

/* 2. Enlace con subrayado personalizado */
a {
  text-decoration: none;
  border-bottom: 1px solid currentColor;
}

/* 3. Ítem de lista con separador */
li {
  border-bottom: 1px solid #eee;
  padding: 12px 0;
}
li:last-child {
  border-bottom: none;
}

/* 4. Tab activo con borde inferior */
.tab {
  border-bottom: 3px solid transparent;
  padding: 12px 20px;
}
.tab.active {
  border-bottom-color: #3498db;
}

/* 5. Fila de tabla con separador */
tr {
  border-bottom: 1px solid #ddd;
}

/* 6. Input con borde solo inferior (estilo minimalista) */
.input-minimal {
  border: none;
  border-bottom: 2px solid #ccc;
  background: transparent;
}
.input-minimal:focus {
  border-bottom-color: #3498db;
  outline: none;
}

/* 7. Triángulo apuntando hacia arriba (usa border-bottom) */
.triangulo-arriba {
  width: 0;
  height: 0;
  border-left: 20px solid transparent;
  border-right: 20px solid transparent;
  border-bottom: 30px solid #333;
  /* El border-bottom es el visible */
}

/* 8. Shorthand general vs border-bottom */
.btn {
  border: 1px solid #ccc;           /* los 4 lados */
  border-bottom: 3px solid #3498db; /* sobrescribe solo el inferior */
}

/* 9. Propiedades lógicas */
.logico {
  border-block-end: 2px solid #333;
  /* Equivale a border-bottom en LTR horizontal */
}

/* 10. Cita con barra inferior */
blockquote {
  border-bottom: 4px solid #3498db;
  padding-bottom: 16px;
  font-style: italic;
}

Separador inferior en títulos

h2 {
  border-bottom: 2px solid #333;
  padding-bottom: 8px;
  margin-bottom: 16px;
}

Enlace con subrayado personalizado

a {
  color: #3498db;
  text-decoration: none;
  border-bottom: 1px solid currentColor;
  transition: border-bottom-color 0.2s;
}
a:hover {
  border-bottom-color: #2980b9;
}

Tabs con borde inferior activo (patrón clásico)

.tabs {
  display: flex;
  gap: 4px;
  border-bottom: 1px solid #eee;
}
.tab {
  padding: 12px 20px;
  border-bottom: 3px solid transparent;
  margin-bottom: -1px; /* alinea con el borde del contenedor */
  cursor: pointer;
}
.tab.active {
  border-bottom-color: #3498db;
  color: #3498db;
}

Input minimalista con borde inferior

.input-minimal {
  border: none;
  border-bottom: 2px solid #ccc;
  border-radius: 0;
  background: transparent;
  padding: 8px 0;
  transition: border-bottom-color 0.2s;
}
.input-minimal:focus {
  border-bottom-color: #3498db;
  outline: none;
}

Lista con separadores (sin el último)

ul {
  list-style: none;
  padding: 0;
}
li {
  padding: 12px 0;
  border-bottom: 1px solid #eee;
}
li:last-child {
  border-bottom: none;
}

Triángulo apuntando hacia arriba

.tooltip::before {
  content: "";
  position: absolute;
  bottom: 100%;
  left: 50%;
  transform: translateX(-50%);
  width: 0;
  height: 0;
  border-left: 8px solid transparent;
  border-right: 8px solid transparent;
  border-bottom: 8px solid #333;
  /* El border-bottom forma el triángulo hacia arriba */
}

Sobrescribir solo el borde inferior

.btn {
  border: 1px solid #ccc;
  /* Los 4 lados con el mismo estilo */
}
.btn-destacado {
  border-bottom: 3px solid #3498db;
  /* Solo el inferior cambia; los demás siguen igual */
}

⚠️ Errores comunes

  1. Olvidar border-bottom-style → border-bottom: 2px #333 no se ve sin estilo. Error clásico.
  1. Confundir border-bottom con border → border afecta a los 4 lados; border-bottom solo al inferior.
  1. No usar box-sizing: border-box → el borde inferior suma a la altura total.
  1. Esperar que border-bottom herede el estilo de border → no; son independientes. Si defines border: 1px solid y luego border-bottom: 3px, el inferior se sobrescribe pero los demás mantienen border.
  1. Animar border-bottom sin transición → el cambio es brusco. Añadir transition: border-bottom-color 0.2s.
  1. Usar border-bottom para separadores verticales → es horizontal, no vertical. Usar border-left o border-right.
  1. Bordes inferiores en display: inline → se dibujan pero no empujan líneas. Usar inline-block.
  1. Triángulos con border-bottom en 2025 → truco clásico; hoy clip-path o SVG son más flexibles.
  1. No considerar border-radius → si hay esquinas redondeadas, el borde inferior se curva en los extremos.
  1. border-bottom con border-collapse: collapse en tablas → los bordes se fusionan; el resultado puede sorprender.
  1. No usar :last-child → olvidar quitar el separador del último ítem es un error estético muy común.
  1. Usar border-bottom para subrayar texto → funciona, pero text-decoration es más semántico. Combinar ambos con text-decoration-color y text-underline-offset si es necesario.

🧩 Relación con otros conceptos

  • border → shorthand de los 4 lados.
  • border-top → borde superior.
  • border-right → borde derecho.
  • border-left → borde izquierdo.
  • border-bottom-width → grosor del borde inferior.
  • border-bottom-style → estilo del borde inferior.
  • border-bottom-color → color del borde inferior.
  • border-block-end → equivalente lógico (i18n).
  • border-radius → el borde inferior se curva en las esquinas.
  • box-sizing → border-box incluye el borde en el tamaño.
  • padding-bottom → espacio interior sobre el borde inferior.
  • margin-bottom → espacio exterior bajo el borde inferior.
  • text-decoration → subrayado semántico de texto.
  • :last-child → patrón para quitar el separador del último ítem.
  • box-shadow → alternativa para bordes sin afectar layout.

🧠 Analogía

Imagina que cada elemento es un cuadro enmarcado. border-bottom es la moldura solo del lado inferior: puedes ponerle un grosor, un estilo y un color distintos a los otros tres lados. Es como decir "solo quiero decorar la base del cuadro" sin tocar los laterales ni la parte superior. Es la propiedad perfecta para separar visualmente un elemento del que viene debajo.

📝 Notas personales

  • border-bottom-style es obligatorio → sin él, no se ve. Error nº1.
  • Solo afecta al lado inferior → los otros lados no se tocan. Útil para sobrescribir un lado concreto.
  • Siempre box-sizing: border-box → si no, el borde inferior agranda el elemento.
  • El separador más usado → border-bottom: 1px solid #eee es el patrón más común para separar ítems de lista y secciones.
  • :last-child { border-bottom: none } → recordar quitar el separador del último ítem.
  • Tabs activos → border-bottom: 3px solid transparent + :hover/:focus { border-bottom-color: ... } + margin-bottom: -1px para alinear con el borde del contenedor.
  • Input minimalista → border: none; border-bottom: 2px solid es un patrón muy usado en diseño moderno.
  • Triángulos → border-bottom con laterales transparentes crea triángulos hacia arriba.
  • Añadir transición → transition: border-bottom-color 0.2s para cambios suaves.
  • Propiedades lógicas → border-block-end es el equivalente i18n; preferirlo en proyectos multiidioma.
  • Subrayado de enlaces → border-bottom: 1px solid currentColor es más controlable que text-decoration, pero text-decoration con text-underline-offset y text-decoration-thickness es hoy la opción más moderna y semántica.
