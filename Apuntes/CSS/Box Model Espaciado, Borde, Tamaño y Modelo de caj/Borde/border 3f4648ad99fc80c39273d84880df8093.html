border

📄 border

📝 Definición

border es una propiedad abreviada (shorthand) de CSS que define el borde de un elemento, es decir, la línea que rodea el padding y el contenido, separándolos del margen exterior.

🧠 ¿Qué es?

Forma parte del modelo de caja (box model) junto con margin, padding y content.

Es la única parte del box model que es visible por defecto si se le asigna un estilo; el resto es espacio.

border es un shorthand que agrupa tres propiedades:

  • border-width → grosor
  • border-style → estilo (obligatorio para que se vea)
  • border-color → color

🎯 ¿Para qué sirve?

  • Delimitar visualmente elementos (tarjetas, inputs, botones, tablas).
  • Crear separadores y divisores.
  • Indicar estados (focus, error, éxito).
  • Construir formas geométricas (triángulos, flechas) con el truco del border.
  • Añadir decoración sin afectar al contenido.

⚙️ ¿Cómo funciona?

El borde se dibuja entre el padding y el margin.

Por defecto su border-style es none, por lo que no se ve aunque definas width y color.

Es imprescindible definir un border-style distinto de none.

Conceptos clave:

  1. border-style es obligatorio → sin él, el borde no se renderiza.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el borde suma al width/height. Con border-box, se incluye.
  1. Cuatro lados independientes → border-top, border-right, border-bottom, border-left.
  1. Puede tener esquinas redondeadas → con border-radius.
  1. Puede usar imágenes → con border-image.
  1. border-collapse → en tablas, controla si los bordes de celdas se fusionan.
  1. outline ≠ border → el outline no ocupa espacio y no sigue el border-radius (hasta hace poco).

📝 Sintaxis / Estructura

/* Shorthand completo */
border: 1px solid #333;

/* Shorthand por lado */
border-top: 2px dashed red;
border-right: 1px dotted blue;
border-bottom: 3px double green;
border-left: none;

/* Propiedades individuales */
border-width: 1px;
border-style: solid;
border-color: #333;

Propiedades relacionadas

border-width: 1px 2px 3px 4px;   /* top right bottom left */
border-style: solid dashed dotted double;
border-color: red green blue black;

border-radius: 8px;              /* esquinas redondeadas */
border-image: url(...) 30 round; /* borde con imagen */

💡 Ejemplos

/* 1. Borde básico */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
}

/* 2. Borde solo abajo (divisor) */
h2 {
  border-bottom: 2px solid #333;
  padding-bottom: 8px;
}

/* 3. Input con borde de focus */
input {
  border: 1px solid #ccc;
}
input:focus {
  border-color: #3498db;
  outline: none;
}

/* 4. Borde de error */
.error {
  border: 2px solid crimson;
}

/* 5. Triángulo con border (truco clásico) */
.arrow-down {
  width: 0;
  height: 0;
  border-left: 8px solid transparent;
  border-right: 8px solid transparent;
  border-top: 8px solid #333;
}

/* 6. Borde con estilo dashed */
.dashed {
  border: 2px dashed #999;
}

/* 7. Borde con imagen */
.decorative {
  border: 20px solid transparent;
  border-image: url(border.png) 30 round;
}

/* 8. Tabla con bordes fusionados */
table {
  border-collapse: collapse;
}
td {
  border: 1px solid #ccc;
}

Triángulo con border (explicación visual)

.triangle {
  width: 0;
  height: 0;
  border-top: 50px solid red;
  border-right: 50px solid transparent;
  border-bottom: 50px solid transparent;
  border-left: 50px solid transparent;
}

Cada lado del border se dibuja como un trapecio que, con width: 0, se convierte en triángulo. Los lados transparentes "esconden" las partes no deseadas.

⚠️ Errores comunes

  1. Olvidar border-style → border: 1px #333 no muestra nada porque el estilo por defecto es none. Siempre incluir solid, dashed, etc.
  1. No usar box-sizing: border-box → el borde suma al tamaño total y rompe layouts.
  1. Confundir border con outline → outline no ocupa espacio y no empuja elementos.
  1. Intentar animar border-width → funciona pero es costoso (provoca reflow). Mejor animar outline o box-shadow.
  1. Bordes en inline → se dibujan pero el vertical no empuja líneas. Usar inline-block.
  1. border-collapse olvidado en tablas → los bordes se duplican entre celdas.
  1. Usar bordes para separar en flex/grid → mejor gap o background con líneas.
  1. Bordes individuales inconsistentes → si defines border-left después de border, puedes sobrescribir sin querer. Orden importante.
  1. border-radius con overflow: hidden → a veces el contenido se sale; añadir overflow: hidden en el padre.

🧩 Relación con otros conceptos

  • margin → espacio exterior (fuera del border).
  • padding → espacio interior (dentro del border).
  • box-sizing → border-box incluye el borde en el width.
  • outline → alternativa al border que no ocupa espacio (ideal para focus).
  • box-shadow → puede simular un borde sin afectar al layout.
  • border-radius → redondea las esquinas del borde (y del fondo).
  • border-image → usa imágenes como borde.
  • background-clip → controla si el fondo llega hasta el border.
  • border-collapse → en tablas, fusiona bordes adyacentes.
  • currentColor → el borde hereda el color del texto.

🧠 Analogía

Imagina que cada elemento es un cuadro enmarcado colgado en una pared. El padding es el passe-partout (cartón que rodea la foto dentro del marco), el border es el marco en sí (la línea visible), y el margin es la distancia entre el marco y otros cuadros. Si el marco no tiene estilo (border-style: none), simplemente no hay marco, aunque hayas definido su grosor y color.

📝 Notas personales

  • border-style es obligatorio → sin él, el borde no se ve. Error clásico de principiante.
  • Siempre box-sizing: border-box → si no, el borde agranda el elemento y rompe layouts.
  • El truco del triángulo con border sigue siendo útil, aunque hoy hay mejores alternativas (clip-path).
  • Para focus accesible, preferir outline sobre border → el outline no rompe el layout.
  • border-radius con overflow: hidden → a veces necesario para que los hijos no se salgan de las esquinas redondeadas.
  • currentColor es muy útil: border: 2px solid currentColor hereda el color del texto automáticamente.
  • En tablas, siempre usar border-collapse: collapse para evitar bordes dobles.
  • Para animaciones, evitar animar border-width; mejor usar box-shadow o outline.
  • Los bordes en elementos inline se dibujan pero el vertical no empuja líneas → usar inline-block si necesitas que afecte al flujo.
  • Preferir propiedades lógicas (border-inline, border-block) para soportar RTL/LTR.
