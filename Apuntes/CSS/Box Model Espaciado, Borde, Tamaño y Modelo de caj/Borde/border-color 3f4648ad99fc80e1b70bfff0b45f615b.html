border-color

📄 border-color

📝 Definición

border-color es una propiedad CSS que establece el color del borde de un elemento.

Acepta de uno a cuatro valores para definir el color de cada lado (top, right, bottom, left).

🧠 ¿Qué es?

Forma parte de las propiedades de borde (junto con border-width, border-style y el shorthand border).

Define el color de la línea del borde, pero solo se ve si border-style es distinto de none.

Si no se especifica, el valor por defecto es currentColor, es decir, hereda el color del texto del propio elemento.

Esto es muy útil para crear componentes coherentes.

🎯 ¿Para qué sirve?

  • Definir el color de bordes en botones, inputs, tarjetas, tablas.
  • Indicar estados (borde rojo en error, verde en éxito, azul en focus).
  • Crear separadores con colores sutiles o marcados.
  • Aprovechar currentColor para que el borde siga el color del texto.
  • Construir triángulos y formas con el truco del border.
  • Diseñar bordes con gradiente combinado con background-clip.

⚙️ ¿Cómo funciona?

El navegador dibuja el borde con el color indicado, siempre que border-style no sea none ni hidden.

Reglas clave:

  1. Sin border-style, no se ve → border-color: red sin estilo no renderiza nada.
  1. Valor por defecto: currentColor → el borde hereda el color del texto si no se especifica.
  1. Acepta 1 a 4 valores → igual que margin/padding.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el borde suma al width/height. Con border-box, se incluye.
  1. Acepta todos los formatos de color → hex, rgb, hsl, oklch, nombres, transparent, currentColor.
  1. Propiedades individuales → border-top-color, border-right-color, etc.
  1. Propiedades lógicas → border-inline-color, border-block-color para i18n.
  1. Los estilos 3D (groove, ridge, inset, outset) generan sombras basadas en el color.

📝 Sintaxis / Estructura

/* Un valor: todos los lados */
border-color: #333;

/* Dos valores: vertical | horizontal */
border-color: #333 #999;

/* Tres valores: top | horizontal | bottom */
border-color: #333 #999 #666;

/* Cuatro valores: top | right | bottom | left (horario) */
border-color: #333 #999 #666 #ccc;

Propiedades individuales

border-top-color: #333;
border-right-color: #999;
border-bottom-color: #666;
border-left-color: #ccc;

Propiedades lógicas (modernas)

border-block-color: #333 #666;   /* top | bottom */
border-inline-color: #999 #ccc;  /* left | right */
border-block-start-color: #333;
border-inline-end-color: #999;

Formatos de color comunes

border-color: #333;                        /* Hex */
border-color: #333c;                       /* Hex con alpha */
border-color: rgb(51, 51, 51);             /* RGB */
border-color: rgba(51, 51, 51, 0.8);       /* RGB con alpha */
border-color: hsl(0, 0%, 20%);             /* HSL */
border-color: oklch(30% 0 0);              /* OKLCH (moderno) */
border-color: transparent;                 /* Transparente */
border-color: currentColor;                /* Color del texto */

💡 Ejemplos

/* 1. Borde gris sutil */
.card {
  border: 1px solid #ddd;
}

/* 2. Borde de input */
input {
  border: 1px solid #ccc;
  border-color: #ccc;
}

/* 3. Borde de focus */
input:focus {
  border-color: #3498db;
  outline: none;
}

/* 4. Borde de error */
.input-error {
  border: 2px solid crimson;
}

/* 5. Borde con currentColor (hereda el color del texto) */
.btn-outline {
  color: #3498db;
  border: 2px solid currentColor;
  /* El borde es azul porque el texto es azul */
}

/* 6. Colores distintos por lado */
.arcoiris {
  border-style: solid;
  border-width: 4px;
  border-color: red green blue yellow;
  /* top: red | right: green | bottom: blue | left: yellow */
}

/* 7. Borde transparente (útil para reservar espacio) */
.btn {
  border: 2px solid transparent;
  /* Reserva el espacio del borde sin que se vea */
}
.btn:hover {
  border-color: #3498db;
  /* Solo cambia el color al hacer hover */
}

/* 8. Borde semitransparente */
.sutil {
  border: 4px solid rgba(0, 0, 0, 0.1);
}

/* 9. Shorthand */
.btn {
  border: 2px solid #3498db;
}

/* 10. Propiedades lógicas */
.logico {
  border-style: solid;
  border-width: 2px;
  border-inline-color: #3498db; /* left y right */
  border-block-color: #e74c3c;  /* top y bottom */
}

currentColor: el patrón más elegante

/* El borde y el texto comparten color automáticamente */
.btn-outline {
  color: #3498db;
  border: 2px solid currentColor;
  background: transparent;
}

/* Cambiar el color del texto cambia el borde */
.btn-outline:hover {
  color: #2980b9;
  /* El borde se actualiza solo */
}

Triángulo con border-color: transparent

.triangulo {
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 0 20px 30px 20px;
  border-color: transparent transparent #333 transparent;
  /* Solo el borde inferior es visible → triángulo hacia arriba */
}

Borde de error/success con variables

:root {
  --color-error: crimson;
  --color-success: seagreen;
  --color-border: #ddd;
}

.input {
  border: 1px solid var(--color-border);
}
.input.error {
  border-color: var(--color-error);
}
.input.success {
  border-color: var(--color-success);
}

Borde transparente para evitar layout shift

/* ✅ Reserva el espacio del borde desde el principio */
.btn {
  border: 2px solid transparent;
  transition: border-color 0.2s ease;
}
.btn:hover {
  border-color: #3498db;
  /* Solo cambia el color, no el tamaño */
}

/* ❌ Evita esto: el borde aparece y desplaza el layout */
.btn-malo {
  border: none;
}
.btn-malo:hover {
  border: 2px solid #3498db; /* ⚠️ rompe el layout */
}

Borde con gradiente (técnica con background-clip)

/* El border-color no puede ser un gradiente directamente */
/* Se simula con background + background-clip */
.borde-gradiente {
  border: 4px solid transparent;
  background:
    linear-gradient(white, white) padding-box,
    linear-gradient(135deg, #667eea, #764ba2) border-box;
  /* Dos capas: una blanca en padding-box, otra gradiente en border-box */
}

⚠️ Errores comunes

  1. Olvidar border-style → border-color: red sin border-style: solid no se ve. Error clásico.
  1. No usar box-sizing: border-box → el borde suma al tamaño total y rompe layouts.
  1. Confundir border-color con background-color → uno es el borde, otro el fondo.
  1. Asumir que el color por defecto es negro → el valor por defecto es currentColor, que hereda del color del texto.
  1. Intentar poner un gradiente → border-color no acepta gradientes. Usar background-clip o border-image.
  1. Cambiar border-color sin transición → el cambio es brusco. Añadir transition: border-color 0.2s.
  1. Usar border-color para simular outline de focus → funciona, pero outline es más accesible y no rompe layout.
  1. Olvidar el orden → top right bottom left (horario). Fácil de equivocar.
  1. No usar currentColor → repetir el color del texto y del borde por separado es menos mantenible.
  1. Bordes transparentes en el shorthand → border: 2px solid transparent es válido, pero verificar que el fondo no se vea a través.
  1. border-color en tablas con border-collapse: collapse → los bordes se fusionan; el resultado puede sorprender.
  1. No verificar contraste → un borde de bajo contraste puede ser invisible para usuarios con baja visión.

🧩 Relación con otros conceptos

  • border-style → obligatorio para que el borde se vea.
  • border-width → grosor del borde.
  • border → shorthand que incluye border-color.
  • box-sizing → border-box incluye el borde en el tamaño.
  • color → el borde hereda el color del texto con currentColor.
  • background-color → color del fondo, no del borde.
  • outline-color → equivalente para el outline.
  • border-radius → el borde sigue la curva.
  • box-shadow → alternativa para bordes sin afectar layout.
  • border-image → usa imágenes o gradientes como borde.
  • background-clip → técnica para simular bordes con gradiente.
  • Propiedades lógicas → border-inline-color, border-block-color.

🧠 Analogía

Imagina que cada elemento es un cuadro enmarcado. border-color es el color de la madera del marco: puede ser negro, dorado, blanco, o incluso invisible (transparente). Si no eliges ningún estilo de marco (border-style: none), no importa de qué color sea la madera: no hay marco. Y si usas currentColor, el marco se pinta automáticamente del mismo color que el texto de dentro.

📝 Notas personales

  • border-style es obligatorio → sin él, border-color no se ve. Error nº1 de principiante.
  • Valor por defecto: currentColor → el borde hereda el color del texto. Muy útil para componentes coherentes.
  • currentColor es oro puro → border: 2px solid currentColor + cambiar color en hover = borde y texto coherentes sin repetir.
  • transparent para reservar espacio → border: 2px solid transparent + :hover { border-color: ... } evita layout shift.
  • No acepta gradientes → para bordes con gradiente, usar background-clip o border-image.
  • Siempre box-sizing: border-box → si no, el borde agranda el elemento.
  • Añadir transición → transition: border-color 0.2s ease para cambios suaves.
  • Contraste accesible → los bordes de focus deben tener contraste suficiente (WCAG 2.4.11 en WCAG 2.2).
  • Variables CSS → definir colores de borde como variables (-color-border) para consistencia.
  • Propiedades lógicas → preferir border-inline-color y border-block-color en proyectos multiidioma.
  • border-color: transparent en triángulos → truco clásico; recordar que los 3 lados no visibles deben ser transparentes.
