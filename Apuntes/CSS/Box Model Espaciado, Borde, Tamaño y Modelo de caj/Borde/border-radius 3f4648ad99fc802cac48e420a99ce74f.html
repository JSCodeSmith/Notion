border-radius

📄 border-radius

📝 Definición

border-radius es una propiedad CSS que redondea las esquinas de la caja de un elemento, curvando el borde (y el fondo, y el recorte del contenido si se combina con overflow).

🧠 ¿Qué es?

Forma parte de las propiedades de fondo y borde (junto con border, background, box-shadow).

Acepta uno o más valores para definir el radio horizontal y vertical de cada esquina, permitiendo desde esquinas sutilmente redondeadas hasta formas elípticas o círculos perfectos.

Aunque su nombre dice "border", en realidad afecta al borde, al fondo y al área de recorte del elemento.

Es una de las propiedades más usadas para suavizar interfaces y crear formas.

🎯 ¿Para qué sirve?

  • Suavizar esquinas de botones, tarjetas, inputs, modales.
  • Crear avatares circulares o con forma de "squircle".
  • Construir píldoras (botones redondeados por completo).
  • Diseñar formas decorativas (blobs, círculos, elipses).
  • Redondear imágenes sin recortarlas manualmente.
  • Aplicar recortes combinado con overflow: hidden.

⚙️ ¿Cómo funciona?

border-radius define el radio de curvatura de cada esquina.

Reglas clave:

  1. Afecta a borde, fondo y recorte → el contenido también se recorta si hay overflow: hidden.
  1. Acepta 1 a 4 valores → igual que margin/padding.
  1. Acepta 2 valores por esquina → radio horizontal y vertical (elipse).
  1. Se puede expresar en % → porcentaje del ancho (horizontal) y alto (vertical).
  1. 50% → convierte un cuadrado en círculo; un rectángulo en elipse.
  1. Los bordes siguen la curva → el border se dibuja siguiendo el radio.
  1. Se puede animar/transicionar → efectos suaves.
  1. No afecta al layout → no cambia el tamaño de la caja, solo la forma visual.

📝 Sintaxis / Estructura

/* Un valor: todas las esquinas */
border-radius: 8px;

/* Dos valores: diagonal (top-left/bottom-right) | (top-right/bottom-left) */
border-radius: 8px 16px;

/* Tres valores: top-left | top-right/bottom-left | bottom-right */
border-radius: 8px 16px 24px;

/* Cuatro valores: top-left | top-right | bottom-right | bottom-left (horario) */
border-radius: 8px 16px 24px 32px;

Sintaxis con barra / (elipses)

/* radio horizontal / radio vertical */
border-radius: 50% / 30%;

/* por esquina: horizontal 1 2 3 4 / vertical 1 2 3 4 */
border-radius: 10px 20px 30px 40px / 5px 10px 15px 20px;

Propiedades individuales

border-top-left-radius: 8px;
border-top-right-radius: 8px;
border-bottom-right-radius: 8px;
border-bottom-left-radius: 8px;

/* Con dos valores (horizontal / vertical) */
border-top-left-radius: 20px 10px;

Propiedades lógicas (modernas)

border-start-start-radius: 8px; /* top-left en LTR */
border-start-end-radius: 8px;   /* top-right en LTR */
border-end-start-radius: 8px;   /* bottom-left en LTR */
border-end-end-radius: 8px;     /* bottom-right en LTR */

Parámetros / Valores

ValorDescripción
lengthpx, em, rem, etc.
%Porcentaje del ancho (horizontal) y alto (vertical) de la caja.
0Sin redondeo (por defecto).
inherit, initial, unset, revertValores globales.

💡 Ejemplos

/* 1. Esquinas sutilmente redondeadas */
.card {
  border-radius: 8px;
}

/* 2. Botón tipo píldora */
.btn-pill {
  border-radius: 9999px; /* valor grande = píldora */
}

/* 3. Avatar circular */
.avatar {
  width: 64px;
  height: 64px;
  border-radius: 50%;
  object-fit: cover;
}

/* 4. Esquinas asimétricas */
.card-destacada {
  border-radius: 24px 8px 24px 8px;
}

/* 5. Forma de elipse */
.eliptico {
  width: 200px;
  height: 100px;
  border-radius: 50%;
}

/* 6. Elipse con radios distintos */
.blob {
  width: 200px;
  height: 100px;
  border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%;
}

/* 7. Solo una esquina redondeada */
.solo-una {
  border-radius: 0 16px 0 0;
}

/* 8. Input redondeado */
input {
  border-radius: 6px;
  border: 1px solid #ccc;
}

/* 9. Recortar imagen con forma */
.imagen-redondeada {
  border-radius: 16px;
  overflow: hidden;
}

/* 10. Animar el radio */
.morph {
  border-radius: 8px;
  transition: border-radius 0.3s ease;
}
.morph:hover {
  border-radius: 50%;
}

Crear un círculo perfecto

.circulo {
  width: 100px;
  height: 100px;
  border-radius: 50%;
  /* Requiere width === height */
}

Crear una píldora

.pildora {
  padding: 12px 24px;
  border-radius: 9999px;
  /* Valor grande asegura extremos semicirculares */
}

Formas orgánicas con radios asimétricos

.blob {
  width: 300px;
  height: 300px;
  background: linear-gradient(135deg, #f39c12, #e74c3c);
  border-radius: 62% 38% 46% 54% / 60% 43% 57% 40%;
  /* Mezcla radios horizontal/vertical para formas únicas */
}

Redondear solo una esquina

.card-destacada {
  border-top-left-radius: 24px;
  /* Solo esa esquina se redondea */
}

⚠️ Errores comunes

  1. Confundir border-radius: 50% con un círculo → en un rectángulo genera una elipse, no un círculo. Para un círculo, width === height.
  1. Esperar que recorte contenido → por defecto el contenido no se recorta. Añadir overflow: hidden si es necesario.
  1. Usar border-radius en img sin object-fit → la imagen se deforma para llenar la caja antes de redondear.
  1. Olvidar el orden de los valores → el orden es horario empezando por top-left: top-left top-right bottom-right bottom-left.
  1. Confundir la barra / con la coma → la barra separa radios horizontales de verticales; la coma separa esquinas.
  1. Usar border-radius para centrar verticalmente → no sirve para eso. Usar flex/grid.
  1. No considerar el overflow con hijos → un hijo con fondo o borde puede "salirse" de las esquinas redondeadas. Añadir overflow: hidden o clip.
  1. Usarlo en tablas con border-collapse: collapse → el redondeo puede no verse porque los bordes colapsan. Usar border-collapse: separate o contenedor.
  1. Olvidar el fallback en SVG → SVG usa rx/ry en <rect>, no border-radius.
  1. Abusar de border-radius: 50% en fotos → recorta información útil (caras cortadas). Verificar el object-position.

🧩 Relación con otros conceptos

  • border → el borde sigue la curva del radio.
  • background → el fondo también se recorta con el radio.
  • overflow → hidden o clip recorta los hijos a la forma redondeada.
  • box-shadow → la sombra respeta la forma redondeada.
  • object-fit → combinar con border-radius: 50% para avatares sin deformar.
  • clip-path → alternativa más potente para formas complejas.
  • outline → por defecto no sigue el radio; outline-offset ayuda.
  • mask → alternativa avanzada para recortes con imágenes.
  • Propiedades lógicas → border-start-start-radius, etc., para i18n.

🧠 Analogía

Imagina que cada elemento es una tarjeta de cartón con esquinas rectas. border-radius es la tijera que recorta las esquinas: puedes redondearlas todas por igual, solo una, o crear curvas asimétricas (elipses). Si además pegas la tarjeta a una foto (overflow: hidden), la foto también se recortará con esas esquinas.

📝 Notas personales

  • 50% en cuadrado = círculo; en rectángulo = elipse → recordarlo siempre.
  • Píldora → border-radius: 9999px es el truco más simple y robusto.
  • Recortar contenido → border-radius no recorta por sí solo; añadir overflow: hidden.
  • Con img → combinar con object-fit: cover para evitar deformación.
  • Radios asimétricos → border-radius: 60% 40% 30% 70% / 60% 30% 70% 40% para formas orgánicas.
  • Tablas → usar border-collapse: separate si quieres ver el redondeo.
  • Outline → no sigue el radio por defecto; considerar box-shadow como alternativa accesible.
  • clip-path → cuando necesites formas más complejas (polígonos, caminos SVG).
  • Propiedades lógicas → preferir border-start-start-radius, etc., en proyectos multiidioma.
  • Generadores → 9elements tiene un generador visual de "fancy border-radius" muy útil.
