border-image

📄 border-image

📝 Definición

border-image es una propiedad abreviada (shorthand) de CSS que permite usar una imagen (o un gradiente) como borde de un elemento, en lugar de un color o estilo sólido.

La imagen se divide en 9 regiones (4 esquinas, 4 lados y el centro) que se estiran, repiten o escalan para formar el borde.

🧠 ¿Qué es?

Forma parte de las propiedades de borde (junto con border, border-radius, border-color, etc.).

Es una técnica avanzada que permite bordes decorativos con texturas, patrones, gradientes o ilustraciones, sin necesidad de usar múltiples elementos o imágenes de fondo.

Reemplaza visualmente al borde normal: cuando border-image está activo, el border-color se ignora en las zonas donde se aplica la imagen.

Pero border-width y border-style siguen siendo necesarios para reservar el espacio del borde.

🎯 ¿Para qué sirve?

  • Crear bordes decorativos con texturas, patrones o ilustraciones.
  • Aplicar bordes con gradiente (algo que border-color no permite).
  • Diseñar marcos ornamentados (estilo retro, vintage, art deco).
  • Construir bordes escalables que se adaptan al tamaño del elemento.
  • Añadir detalles visuales sin imágenes de fondo ni elementos extra.
  • Simular bordes dibujados a mano o irregulares.

⚙️ ¿Cómo funciona?

La imagen de borde se corta en 9 regiones usando las líneas de corte (border-image-slice).

Luego cada región se aplica a una parte del borde:

┌─────┬─────────────┬─────┐
│  1  │      2      │  3  │  ← esquinas (1, 3, 7, 9)
├─────┼─────────────┼─────┤     lados (2, 4, 6, 8)
│  4  │      5      │  6  │     centro (5)
├─────┼─────────────┼─────┤
│  7  │      8      │  9  │
└─────┴─────────────┴─────┘
  • Esquinas (1, 3, 7, 9) → se colocan tal cual, sin escalar.
  • Lados (2, 4, 6, 8) → se estiran, repiten o escalan según border-image-repeat.
  • Centro (5) → se descarta por defecto (o se usa con fill).

Reglas clave:

  1. Requiere border-width → sin grosor de borde, border-image no tiene espacio para dibujarse.
  1. Requiere border-style → al menos solid, para que el borde exista (aunque el estilo visual lo ponga la imagen).
  1. border-image-slice es clave → define las líneas de corte de la imagen.
  1. border-image-repeat → controla cómo se rellenan los lados (stretch, repeat, round, space).
  1. border-image-source → la imagen o gradiente.
  1. border-image-width → grosor del borde (por defecto = border-width).
  1. border-image-outset → cuánto sobresale el borde hacia fuera.
  1. fill → incluye la región central de la imagen como fondo.
  1. border-radius se ignora → cuando border-image está activo, el radio no se aplica.

📝 Sintaxis / Estructura

selector {
  border-image: source slice / width / outset repeat;
}

border-image-source

border-image-source: url("border.png");
border-image-source: linear-gradient(135deg, #667eea, #764ba2);
border-image-source: none;

border-image-slice

border-image-slice: 30;                /* píxeles desde cada borde */
border-image-slice: 30%;               /* porcentaje */
border-image-slice: 30 40;             /* vertical | horizontal */
border-image-slice: 30 40 50 60;       /* top | right | bottom | left */
border-image-slice: 30 fill;           /* incluye el centro */

border-image-width

border-image-width: 10px;              /* longitud */
border-image-width: 1;                 /* múltiplo de border-width */
border-image-width: 30%;               /* porcentaje del área */
border-image-width: auto;              /* = border-image-slice */

border-image-outset

border-image-outset: 10px;             /* hacia fuera */
border-image-outset: 1;                /* múltiplo de border-width */

border-image-repeat

border-image-repeat: stretch;          /* estira (por defecto) */
border-image-repeat: repeat;           /* repite */
border-image-repeat: round;            /* repite escalando */
border-image-repeat: space;            /* repite con espacio */
border-image-repeat: stretch round;    /* horizontal | vertical */

💡 Ejemplos

/* 1. Borde con gradiente (el uso más común) */
.borde-gradiente {
  border: 10px solid;
  border-image: linear-gradient(135deg, #667eea, #764ba2) 1;
}

/* 2. Borde con gradiente y slice */
.borde-gradiente-2 {
  border: 8px solid;
  border-image: linear-gradient(90deg, #f39c12, #e74c3c) 1;
}

/* 3. Borde con imagen (marco decorativo) */
.marco {
  border: 30px solid transparent;
  border-image: url("marco.png") 30 round;
}

/* 4. Borde con slice en píxeles */
.borde-slice {
  border: 20px solid transparent;
  border-image: url("border.png") 30 / 20px / 0 repeat;
}

/* 5. Borde que sobresale (outset) */
.borde-outset {
  border: 10px solid transparent;
  border-image: url("border.png") 20 / 10px / 5px stretch;
}

/* 6. Borde con gradiente cónico */
.borde-conic {
  border: 8px solid;
  border-image: conic-gradient(red, yellow, lime, cyan, blue, magenta, red) 1;
}

/* 7. Borde con gradiente radial */
.borde-radial {
  border: 10px solid;
  border-image: radial-gradient(circle, #f39c12, #e74c3c) 1;
}

/* 8. Borde con repetición */
.borde-repeat {
  border: 20px solid transparent;
  border-image: url("pattern.png") 30 round;
}

/* 9. Borde con fill (incluye el centro) */
.borde-fill {
  border: 15px solid transparent;
  border-image: url("border.png") 30 fill;
}

/* 10. Shorthand completo */
.borde-completo {
  border: 20px solid transparent;
  border-image: url("border.png") 30 / 20px / 0 round;
}

Borde con gradiente (patrón más común)

.gradient-border {
  border: 8px solid;
  border-image: linear-gradient(135deg, #667eea, #764ba2) 1;
  /* El "1" es el slice: toda la imagen se usa como borde */
}

Borde arcoíris con gradiente cónico

.rainbow-border {
  border: 8px solid;
  border-image: conic-gradient(
    from 0deg,
    red, orange, yellow, green, cyan, blue, magenta, red
  ) 1;
}

Marco decorativo con imagen

.marco-decorativo {
  border: 30px solid transparent;
  border-image: url("marco.png") 30 round;
  /* El "30" es el slice: corta 30px desde cada borde */
  /* "round" repite la imagen escalándola */
}

Borde que sobresale del elemento

.borde-outset {
  border: 10px solid transparent;
  border-image: url("border.png") 20 / 10px / 5px stretch;
  /* outset: 5px → el borde sobresale 5px hacia fuera */
}

Borde con gradiente en botón

.btn-gradiente {
  border: 4px solid;
  border-image: linear-gradient(90deg, #f39c12, #e74c3c) 1;
  background: white;
  padding: 12px 24px;
  color: #333;
}

Borde con patrón repetido

.borde-patron {
  border: 20px solid transparent;
  border-image: url("pattern.png") 30 round;
  /* La imagen se corta a 30px y los lados se repiten escalando */
}

Borde con fill (imagen cubre el centro)

.borde-fill {
  border: 15px solid transparent;
  border-image: url("texture.png") 30 fill;
  /* fill: la región central también se usa como fondo */
}

⚠️ Errores comunes

  1. Olvidar border-width → sin grosor de borde, border-image no tiene espacio para dibujarse.
  1. Olvidar border-style → al menos solid es necesario; sin estilo, no hay borde que pintar.
  1. Confundir border-image-slice con border-image-width → slice corta la imagen; width define el grosor del borde en el elemento.
  1. Esperar que border-radius funcione → con border-image activo, border-radius se ignora.
  1. Usar border-color junto con border-image → el color se ignora en las zonas donde se aplica la imagen.
  1. No usar transparent en border → si el borde tiene color sólido, puede verse detrás de la imagen. Usar border: Xpx solid transparent.
  1. Slice mal calculado → si el slice es mayor que la imagen, el resultado es impredecible. Verificar dimensiones.
  1. Olvidar border-image-repeat → por defecto stretch, que puede deformar la imagen. Usar round o repeat según el caso.
  1. No considerar el rendimiento → las imágenes de borde pueden ser pesadas; optimizar.
  1. Esperar compatibilidad total → border-image tiene buen soporte, pero algunos valores (space, round) pueden variar.
  1. Usar border-image con border-collapse: collapse en tablas → el resultado es impredecible.
  1. No usar webkit- en navegadores antiguos → hoy ya no es necesario, pero verificar según el público objetivo.

🧩 Relación con otros conceptos

  • border → reserva el espacio del borde (width + style).
  • border-width → grosor del borde; border-image-width puede sobrescribirlo.
  • border-style → necesario para que el borde exista.
  • border-color → ignorado cuando border-image está activo.
  • border-radius → ignorado cuando border-image está activo.
  • background-image → alternativa para fondos, no bordes.
  • background-clip → técnica alternativa para bordes con gradiente.
  • box-shadow → alternativa para bordes sin afectar layout.
  • outline → no acepta imágenes; border-image es más potente.
  • mask-image → alternativa moderna para formas complejas.
  • clip-path → recorta el elemento a una forma; no es un borde.

🧠 Analogía

Imagina que tienes una imagen de un marco ornamentado y quieres usarla como borde de una caja de cualquier tamaño. border-image corta esa imagen en 9 trozos (4 esquinas, 4 lados, 1 centro) y los coloca alrededor de la caja: las esquinas se quedan tal cual, los lados se estiran o repiten para cubrir el largo, y el centro se descarta (o se usa con fill). Es como usar una plantilla de marcos escalable.

📝 Notas personales

  • Requiere border-width y border-style → sin ellos, no hay espacio para la imagen.
  • border-color se ignora → usar border: Xpx solid transparent para reservar el espacio sin color.
  • border-radius se ignora → si necesitas esquinas redondeadas con gradiente, usar background-clip.
  • El patrón más usado → border: 8px solid; border-image: linear-gradient(...) 1; para bordes con gradiente.
  • slice: 1 → usa toda la imagen como borde (ideal para gradientes).
  • slice: 30 → corta 30px desde cada borde (ideal para marcos decorativos).
  • repeat: round → repite la imagen escalándola para encajar sin cortes.
  • repeat: stretch (por defecto) → estira la imagen; puede deformarla.
  • fill → incluye la región central como fondo.
  • Alternativa moderna → para bordes con gradiente, background-clip: padding-box + background: linear-gradient(...) es más simple y compatible.
  • Rendimiento → las imágenes de borde pueden ser pesadas; preferir gradientes cuando sea posible.
  • Cuándo usarlo → solo cuando border-color y border-style no bastan (gradientes, texturas, marcos decorativos).
