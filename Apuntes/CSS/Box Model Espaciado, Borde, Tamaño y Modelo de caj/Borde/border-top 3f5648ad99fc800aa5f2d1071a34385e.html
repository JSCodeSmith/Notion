border-top

📄 border-top

📝 Definición

border-top es una propiedad abreviada (shorthand) de CSS que establece en una sola declaración el borde superior de un elemento: grosor (border-top-width), estilo (border-top-style) y color (border-top-color).

🧠 ¿Qué es?

Forma parte de las propiedades de borde (junto con border-right, border-bottom, border-left y el shorthand general border).

Es un atajo para definir los tres aspectos del borde solo en el lado superior.

Es la propiedad más usada para crear separadores horizontales encima de secciones, títulos o filas de tabla.

🎯 ¿Para qué sirve?

  • Crear separadores superiores (encima de títulos, secciones, filas).
  • Definir el borde superior de tarjetas, modales, alertas.
  • Indicar estados con un borde superior de color (error, éxito).
  • Construir triángulos y flechas con el truco del border.
  • Crear efectos de "tab" activo" (borde superior de color).
  • Añadir decoración sin afectar a los otros lados.

⚙️ ¿Cómo funciona?

El navegador dibuja el borde superior con los valores indicados.

Reglas clave:

  1. Requiere border-top-style → sin estilo, no se ve nada (aunque definas grosor y color).
  1. Afecta solo al lado superior → los otros lados no se tocan.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el borde suma al height. Con border-box, se incluye.
  1. Orden flexible en el shorthand → puedes escribir 1px solid red o solid 1px red; el navegador reconoce cada valor.
  1. Valores por defecto → si omites alguno, se usan los iniciales: medium none currentColor.
  1. No afecta a border-right, border-bottom, border-left → cada lado es independiente.
  1. Se combina con border-radius → el borde sigue la curva en las esquinas superiores.

📝 Sintaxis / Estructura

selector {
  border-top: width style color;
}

Propiedades que agrupa

PropiedadDescripciónValor por defecto
border-top-widthGrosor del borde superiormedium
border-top-styleEstilo del borde superiornone
border-top-colorColor del borde superiorcurrentColor
/* Orden flexible */
border-top: 2px solid #333;
border-top: solid 2px #333;
border-top: #333 solid 2px;

/* Solo algunos valores */
border-top: 2px solid;         /* color por defecto (currentColor) */
border-top: solid;             /* grosor y color por defecto */
border-top: 2px;               /* ⚠️ no se ve sin estilo */

Propiedades individuales

border-top-width: 2px;
border-top-style: solid;
border-top-color: #333;

Propiedades lógicas equivalentes

/* En writing-mode horizontal LTR, equivalen a border-top */
border-block-start: 2px solid #333;
border-block-start-width: 2px;
border-block-start-style: solid;
border-block-start-color: #333;

💡 Ejemplos

/* 1. Separador superior en un título */
h2 {
  border-top: 2px solid #333;
  padding-top: 12px;
}

/* 2. Borde superior en tarjeta */
.card {
  border-top: 3px solid #3498db;
}

/* 3. Alertas con borde superior de color */
.alert-error {
  border-top: 4px solid crimson;
  background: #fdf2f2;
}
.alert-success {
  border-top: 4px solid seagreen;
  background: #f0fdf4;
}

/* 4. Tab activo con borde superior */
.tab {
  border-top: 3px solid transparent;
  padding: 12px 20px;
}
.tab.active {
  border-top-color: #3498db;
}

/* 5. Solo borde superior (sin los demás lados) */
.solo-arriba {
  border-top: 1px solid #eee;
  border-right: none;
  border-bottom: none;
  border-left: none;
}

/* 6. Triángulo apuntando hacia arriba */
.triangulo-arriba {
  width: 0;
  height: 0;
  border-left: 20px solid transparent;
  border-right: 20px solid transparent;
  border-bottom: 30px solid #333;
  /* El border-bottom es el visible */
}

/* 7. Triángulo apuntando hacia abajo (usa border-top) */
.triangulo-abajo {
  width: 0;
  height: 0;
  border-left: 20px solid transparent;
  border-right: 20px solid transparent;
  border-top: 30px solid #333;
  /* El border-top es el visible */
}

/* 8. Shorthand general vs border-top */
.btn {
  border: 1px solid #ccc;       /* los 4 lados */
  border-top: 3px solid #3498db; /* sobrescribe solo el superior */
}

/* 9. Propiedades lógicas */
.logico {
  border-block-start: 2px solid #333;
  /* Equivale a border-top en LTR horizontal */
}

/* 10. Borde superior con gradiente (técnica) */
.borde-gradiente-arriba {
  border-top: 4px solid transparent;
  background:
    linear-gradient(white, white) padding-box,
    linear-gradient(90deg, #667eea, #764ba2) border-box;
}

Separador superior en títulos

h2 {
  border-top: 2px solid #333;
  padding-top: 12px;
  margin-top: 32px;
}

Alertas con borde superior de color

.alert {
  padding: 16px;
  background: #f9f9f9;
  border-top: 4px solid;
}
.alert-error   { border-top-color: crimson; }
.alert-warning { border-top-color: darkorange; }
.alert-success { border-top-color: seagreen; }
.alert-info    { border-top-color: #3498db; }

Tabs con borde superior activo

.tabs {
  display: flex;
  gap: 4px;
}
.tab {
  padding: 12px 20px;
  border-top: 3px solid transparent;
  background: #f5f5f5;
  cursor: pointer;
}
.tab.active {
  border-top-color: #3498db;
  background: #fff;
}

Triángulo apuntando hacia abajo

.tooltip::after {
  content: "";
  position: absolute;
  top: 100%;
  left: 50%;
  transform: translateX(-50%);
  width: 0;
  height: 0;
  border-left: 8px solid transparent;
  border-right: 8px solid transparent;
  border-top: 8px solid #333;
  /* El border-top forma el triángulo hacia abajo */
}

Sobrescribir solo el borde superior

.btn {
  border: 1px solid #ccc;
  /* Los 4 lados con el mismo estilo */
}
.btn-destacado {
  border-top: 3px solid #3498db;
  /* Solo el superior cambia; los demás siguen igual */
}

⚠️ Errores comunes

  1. Olvidar border-top-style → border-top: 2px #333 no se ve sin estilo. Error clásico.
  1. Confundir border-top con border → border afecta a los 4 lados; border-top solo al superior.
  1. No usar box-sizing: border-box → el borde superior suma a la altura total.
  1. Esperar que border-top herede el estilo de border → no; son independientes. Si defines border: 1px solid y luego border-top: 3px, el superior se sobrescribe pero los demás mantienen border.
  1. Animar border-top sin transición → el cambio es brusco. Añadir transition: border-top-color 0.2s.
  1. Usar border-top para separadores verticales → es horizontal, no vertical. Usar border-left o border-right.
  1. Bordes superiores en display: inline → se dibujan pero no empujan líneas. Usar inline-block.
  1. Triángulos con border-top en 2025 → truco clásico; hoy clip-path o SVG son más flexibles.
  1. No considerar border-radius → si hay esquinas redondeadas, el borde superior se curva en los extremos.
  1. border-top con border-collapse: collapse en tablas → los bordes se fusionan; el resultado puede sorprender.

🧩 Relación con otros conceptos

  • border → shorthand de los 4 lados.
  • border-right → borde derecho.
  • border-bottom → borde inferior.
  • border-left → borde izquierdo.
  • border-top-width → grosor del borde superior.
  • border-top-style → estilo del borde superior.
  • border-top-color → color del borde superior.
  • border-block-start → equivalente lógico (i18n).
  • border-radius → el borde superior se curva en las esquinas.
  • box-sizing → border-box incluye el borde en el tamaño.
  • padding-top → espacio interior bajo el borde superior.
  • margin-top → espacio exterior sobre el borde superior.
  • box-shadow → alternativa para bordes sin afectar layout.
  • background-clip → técnica para bordes con gradiente.

🧠 Analogía

Imagina que cada elemento es un cuadro enmarcado. border-top es la moldura solo del lado superior: puedes ponerle un grosor, un estilo y un color distintos a los otros tres lados. Es como decir "solo quiero decorar la parte de arriba del cuadro" sin tocar los laterales ni la base.

📝 Notas personales

  • border-top-style es obligatorio → sin él, no se ve. Error nº1.
  • Solo afecta al lado superior → los otros lados no se tocan. Útil para sobrescribir un lado concreto.
  • Siempre box-sizing: border-box → si no, el borde superior agranda el elemento.
  • Para separadores de título → border-top: 2px solid #333 + padding-top es el patrón clásico.
  • Tabs activos → border-top: 3px solid transparent + :hover/:focus { border-top-color: ... } evita layout shift.
  • Triángulos → border-top con laterales transparentes crea triángulos hacia abajo.
  • Añadir transición → transition: border-top-color 0.2s para cambios suaves.
  • Propiedades lógicas → border-block-start es el equivalente i18n; preferirlo en proyectos multiidioma.
  • No confundir con border → border afecta a los 4 lados; border-top solo al superior.
  • Para bordes con gradiente → usar background-clip o border-image, no border-top-color (no acepta gradientes).
