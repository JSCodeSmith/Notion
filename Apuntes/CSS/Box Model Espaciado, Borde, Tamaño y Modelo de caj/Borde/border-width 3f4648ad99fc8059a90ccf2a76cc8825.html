border-width

📄 border-width

📝 Definición

border-width es una propiedad CSS que establece el grosor del borde de un elemento.

Acepta de uno a cuatro valores para definir el grosor de cada lado (top, right, bottom, left).

🧠 ¿Qué es?

Forma parte de las propiedades de borde (junto con border-style, border-color, y el shorthand border).

Define el grosor de la línea del borde, pero solo se ve si border-style es distinto de none.

Es la primera capa visible del box model: se dibuja entre el padding (interior) y el margin (exterior).

🎯 ¿Para qué sirve?

  • Definir el grosor de bordes en botones, inputs, tarjetas, tablas.
  • Crear separadores con distintos grosores.
  • Indicar estados (borde grueso en focus o error).
  • Ajustar el tamaño visual del borde sin cambiar el border-style.
  • Controlar el grosor por lado (solo abajo, solo izquierda, etc.).
  • Construir triángulos y flechas con el truco del border.

⚙️ ¿Cómo funciona?

El navegador dibuja el borde con el grosor indicado, siempre que border-style no sea none ni hidden.

Reglas clave:

  1. Sin border-style, no se ve → border-width: 5px sin estilo no renderiza nada.
  1. Acepta 1 a 4 valores → igual que margin/padding.
  1. No acepta valores negativos → a diferencia de margin, no se permiten negativos.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el borde suma al width/height. Con border-box, se incluye.
  1. Palabras clave → thin, medium, thick (dependen del navegador, ~1px, ~3px, ~5px).
  1. Propiedades individuales → border-top-width, border-right-width, etc.
  1. Propiedades lógicas → border-inline-width, border-block-width para i18n.
  1. El grosor puede variar por lado → útil para efectos asimétricos.

📝 Sintaxis / Estructura

/* Un valor: todos los lados */
border-width: 2px;

/* Dos valores: vertical | horizontal */
border-width: 1px 2px;

/* Tres valores: top | horizontal | bottom */
border-width: 1px 2px 3px;

/* Cuatro valores: top | right | bottom | left (horario) */
border-width: 1px 2px 3px 4px;

Propiedades individuales

border-top-width: 2px;
border-right-width: 1px;
border-bottom-width: 4px;
border-left-width: 1px;

Propiedades lógicas (modernas)

border-block-width: 2px 4px;   /* top | bottom */
border-inline-width: 1px 3px;  /* left | right */
border-block-start-width: 2px;
border-inline-end-width: 3px;

💡 Ejemplos

/* 1. Borde uniforme */
.card {
  border-style: solid;
  border-width: 1px;
}

/* 2. Borde grueso (focus accesible) */
input:focus {
  border-style: solid;
  border-width: 3px;
  border-color: #3498db;
}

/* 3. Borde solo abajo (divisor) */
h2 {
  border-bottom-style: solid;
  border-bottom-width: 2px;
  border-bottom-color: #333;
}

/* 4. Grosor distinto por lado */
.asimetrico {
  border-style: solid;
  border-width: 4px 2px 8px 1px;
  /* top: 4px | right: 2px | bottom: 8px | left: 1px */
}

/* 5. Palabras clave */
.keyword {
  border-style: solid;
  border-width: thick; /* ~5px */
}

/* 6. Shorthand completo */
.btn {
  border: 2px solid #3498db;
}

/* 7. Borde con box-sizing: border-box */
.btn-borde-box {
  box-sizing: border-box;
  width: 200px;
  border: 10px solid #333;
  /* Ancho total = 200px (borde incluido) */
}

/* 8. Borde sin box-sizing (content-box) */
.btn-content-box {
  box-sizing: content-box;
  width: 200px;
  border: 10px solid #333;
  /* Ancho total = 220px (200 + 10 + 10) */
}

/* 9. Triángulo con border-width */
.triangulo {
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 0 20px 30px 20px;
  border-color: transparent transparent #333 transparent;
  /* Triángulo apuntando hacia arriba */
}

/* 10. Propiedades lógicas */
.logico {
  border-style: solid;
  border-inline-width: 2px; /* left y right */
  border-block-width: 4px;  /* top y bottom */
}

Triángulo con border-width (truco clásico)

/* Triángulo apuntando hacia arriba */
.triangulo-arriba {
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 0 20px 30px 20px; /* top | right | bottom | left */
  border-color: transparent transparent #333 transparent;
  /* El lado inferior es visible, los demás transparentes */
}

/* Triángulo apuntando hacia abajo */
.triangulo-abajo {
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 30px 20px 0 20px;
  border-color: #333 transparent transparent transparent;
}

/* Triángulo apuntando a la derecha */
.triangulo-derecha {
  width: 0;
  height: 0;
  border-style: solid;
  border-width: 20px 0 20px 30px;
  border-color: transparent transparent transparent #333;
}

Diferencia con y sin box-sizing: border-box

/* content-box (por defecto) */
.caja-a {
  box-sizing: content-box;
  width: 200px;
  border-width: 10px;
  border-style: solid;
  /* ancho total = 200 + 10 + 10 = 220px ⚠️ */
}

/* border-box (recomendado) */
.caja-b {
  box-sizing: border-box;
  width: 200px;
  border-width: 10px;
  border-style: solid;
  /* ancho total = 200px ✅ */
}

Borde de error con grosor variable

.input-error {
  border-style: solid;
  border-width: 2px;
  border-color: crimson;
}

.input-error:focus {
  border-width: 3px;
  /* Aumenta el grosor al enfocar */
}

⚠️ Errores comunes

  1. Olvidar border-style → border-width: 5px sin border-style: solid no se ve. Error clásico.
  1. No usar box-sizing: border-box → el borde suma al tamaño total y rompe layouts.
  1. Usar valores negativos → no están permitidos. Solo positivos o 0.
  1. Confundir border-width con outline-width → el outline no ocupa espacio ni afecta al layout.
  1. Asumir que thin/medium/thick son exactos → varían según el navegador. Usar longitudes para precisión.
  1. Cambiar border-width en hover sin transición → el cambio es brusco y puede desplazar el layout. Considerar box-shadow o outline.
  1. Animar border-width → es costoso (provoca reflow). Preferir box-shadow o outline.
  1. Bordes en display: inline → se dibujan pero el vertical no empuja líneas. Usar inline-block.
  1. Olvidar el orden → top right bottom left (horario). Fácil de equivocar.
  1. Triángulos con border-width en 2025 → hoy es mejor usar clip-path o SVG. El truco sigue funcionando pero es menos flexible.
  1. border-width en tablas con border-collapse: collapse → los bordes pueden fusionarse y el grosor resultante puede sorprender.
  1. Usar border-width para separar elementos → usar margin o gap en su lugar.

🧩 Relación con otros conceptos

  • border-style → obligatorio para que el borde se vea.
  • border-color → color del borde.
  • border → shorthand que incluye border-width.
  • box-sizing → border-box incluye el borde en el tamaño.
  • outline-width → grosor del outline (no ocupa espacio).
  • padding → espacio interior, separado del borde.
  • margin → espacio exterior, separado del borde.
  • border-radius → el borde sigue la curva.
  • box-shadow → alternativa para bordes sin afectar layout.
  • Propiedades lógicas → border-inline-width, border-block-width.
  • border-image → usa imágenes como borde.
  • border-collapse → en tablas, controla la fusión de bordes.

🧠 Analogía

Imagina que cada elemento es un cuadro enmarcado. El border-width es el grosor del marco: puede ser fino (1px), medio (3px) o grueso (10px). Si el marco no tiene estilo (border-style: none), no existe, aunque hayas definido su grosor. Y si no usas box-sizing: border-box, el marco agranda el cuadro total, como si el marco se añadiera por fuera del tamaño que pediste.

📝 Notas personales

  • border-style es obligatorio → sin él, border-width no se ve. Error nº1 de principiante.
  • Siempre box-sizing: border-box → si no, el borde agranda el elemento y rompe layouts.
  • No acepta negativos → a diferencia de margin, solo valores ≥ 0.
  • thin/medium/thick → dependen del navegador. Para precisión, usar px.
  • Animar border-width es costoso → provoca reflow. Preferir box-shadow o outline.
  • Para focus accesible → outline es mejor que cambiar border-width (no rompe layout).
  • Triángulos con border-width → truco clásico; hoy clip-path o SVG son más flexibles.
  • Grosor por lado → útil para separadores (border-bottom-width) y efectos asimétricos.
  • En tablas → con border-collapse: collapse, los bordes se fusionan y el grosor puede sorprender.
  • Propiedades lógicas → preferir border-inline-width y border-block-width en proyectos multiidioma.
  • border-width: 0 → útil para quitar el borde en un estado (hover, focus) sin cambiar el layout.
