padding

📄 padding

📝 Definición

padding es una propiedad CSS de la caja (box model) que define el espacio interior de un elemento, es decir, la distancia entre el contenido y su borde.

🧠 ¿Qué es?

Forma parte del modelo de caja (box model) junto con margin, border y content.

Es el espacio dentro del borde, que separa el contenido (texto, imágenes, hijos) del borde del elemento.

A diferencia de margin, padding sí tiene fondo y color: si aplicas background-color, el fondo cubre también el padding.

Y no colapsa como los márgenes.

🎯 ¿Para qué sirve?

  • Dar aire interior a botones, tarjetas, inputs y contenedores.
  • Aumentar el área clicable de un elemento sin usar width extra.
  • Crear separación entre el borde y el contenido.
  • Controlar el tamaño visual de elementos con fondo o borde.
  • Estilizar celdas de tabla, badges, chips, tooltips, etc.

⚙️ ¿Cómo funciona?

Cada elemento de bloque tiene 4 paddings: top, right, bottom, left.

Se aplican dentro del borde y forman parte del área de fondo del elemento.

Conceptos clave:

  1. No colapsa → a diferencia de margin, el padding nunca se fusiona con el de otros elementos.
  1. Sí acepta % → y, curiosamente, el porcentaje se calcula respecto al ancho del contenedor, incluso en padding-top/padding-bottom.
  1. No acepta negativos → valores negativos son inválidos.
  1. Afecta al tamaño total → con box-sizing: content-box (por defecto), el padding se suma al width/height. Con border-box, se incluye dentro.
  1. En display: inline → el padding vertical no afecta al flujo de línea (no empuja líneas), pero sí se dibuja. El horizontal sí afecta.
  1. En flex/grid → funciona igual, sin colapso.

📝 Sintaxis / Estructura

/* Un valor: todos los lados */
padding: 10px;

/* Dos valores: vertical | horizontal */
padding: 10px 20px;

/* Tres valores: top | horizontal | bottom */
padding: 10px 20px 30px;

/* Cuatro valores: top | right | bottom | left (sentido horario) */
padding: 10px 20px 30px 40px;

Propiedades individuales

padding-top: 10px;
padding-right: 20px;
padding-bottom: 30px;
padding-left: 40px;

Propiedades lógicas (modernas)

padding-block: 10px 20px;   /* top | bottom */
padding-inline: 20px 30px;  /* left | right */
padding-block-start: 10px;
padding-inline-end: 20px;

💡 Ejemplos

/* 1. Botón con aire interior */
.btn {
  padding: 12px 24px;
}

/* 2. Tarjeta */
.card {
  padding: 16px 20px;
}

/* 3. Input cómodo */
input {
  padding: 10px 14px;
}

/* 4. Celda de tabla */
td {
  padding: 8px 12px;
}

/* 5. Contenedor con padding uniforme */
.section {
  padding: 4rem 2rem;
}

/* 6. Aspect ratio con padding % */
.video-wrapper {
  position: relative;
  padding-top: 56.25%; /* 16:9 */
  height: 0;
}
.video-wrapper iframe {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
}

/* 7. Propiedades lógicas */
.box {
  padding-block: 1rem;
  padding-inline: 2rem;
}

/* 8. box-sizing recomendado */
*, *::before, *::after {
  box-sizing: border-box;
}

Diferencia con y sin border-box

.a {
  width: 200px;
  padding: 20px;
  /* box-sizing: content-box (por defecto) → ancho total = 240px */
}
.b {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  /* ancho total = 200px (padding incluido) */
}

⚠️ Errores comunes

  1. Olvidar box-sizing: border-box → el padding suma al width/height y rompe layouts. Resetear siempre.
  1. Esperar que el padding acepte negativos → no se puede. Usar margin negativo si es necesario.
  1. Confundir % en padding-top/bottom → el porcentaje se calcula sobre el ancho, no la altura → base del truco de aspect ratio.
  1. Aplicar padding vertical a display: inline → se dibuja pero no empuja líneas, produciendo solapamientos visuales. Usar inline-block o block.
  1. Usar padding para separar elementos → para eso es margin o gap. El padding separa contenido del borde, no elementos entre sí.
  1. Padding en tablas sin control → border-collapse: collapse cambia cómo se comporta el padding de las celdas.
  1. Padding excesivo en móvil → reduce el espacio útil. Usar unidades relativas (rem, %) o media queries.
  1. Confundir padding con gap → en flex/grid, gap es lo correcto para separar ítems, no padding.

🧩 Relación con otros conceptos

  • margin → espacio exterior (fuera del borde).
  • border → línea entre padding y margin.
  • box-sizing → border-box incluye padding y border en el width.
  • gap → alternativa moderna para separar ítems en flex/grid.
  • background-clip → controla si el fondo cubre el padding (padding-box) o el border (border-box).
  • inline-block → hace que el padding vertical sí empuje líneas.
  • aspect-ratio → alternativa moderna al truco de padding-top para ratios.
  • Propiedades lógicas → padding-inline, padding-block para i18n.

🧠 Analogía

Imagina que cada elemento es una caja de cartón con un objeto dentro. El padding es el relleno de espuma que pones entre el objeto y las paredes de la caja: separa el contenido del borde. Si pintas la caja de color, el relleno también se pinta. Y si compras la caja de un tamaño fijo (border-box), el relleno va dentro de ese tamaño; si no (content-box), el relleno agranda la caja.

📝 Notas personales

  • Regla mental: padding = espacio dentro; margin = espacio fuera.
  • Siempre usar box-sizing: border-box → evita cálculos mentales y layouts rotos.
  • El padding no colapsa ni acepta negativos → es "seguro" comparado con margin.
  • El truco de padding-top: 56.25% para aspect ratio 16:9 sigue siendo útil, aunque aspect-ratio es la alternativa moderna.
  • En display: inline, el padding vertical se dibuja pero no empuja → usar inline-block si necesitas que afecte al flujo.
  • Para separar elementos entre sí, usar margin o gap, no padding.
  • El padding aumenta el área clicable de botones y enlaces → mejora la accesibilidad táctil (mínimo 44x44px recomendado por WCAG).
  • Preferir propiedades lógicas (padding-inline, padding-block) para soportar RTL/LTR sin cambios.
  • En tablas con border-collapse: collapse, el padding de las celdas se respeta pero el borde se fusiona.
