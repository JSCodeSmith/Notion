object-fit

📄 object-fit

📝 Definición

object-fit es una propiedad CSS que define cómo se ajusta el contenido de un elemento reemplazado (como <img>, <video>, <canvas>, <picture>) dentro de su caja, cuando el tamaño de la caja y el del contenido no coinciden.

🧠 ¿Qué es?

Forma parte de las propiedades de medios reemplazados (junto con object-position).

Solo aplica a elementos reemplazados: imágenes, videos, iframes, canvas, etc.

No funciona en <div> ni en elementos normales.

Para ellos se usa background-size si el contenido es una imagen de fondo.

El valor por defecto es fill, que deforma el contenido para ocupar toda la caja → por eso muchas imágenes se ven "aplastadas" cuando solo se define width y height sin object-fit.

🎯 ¿Para qué sirve?

  • Evitar que las imágenes se deformen al fijar width y height.
  • Recortar imágenes para llenar una caja (tipo "cover" de fondo).
  • Ajustar videos a un contenedor sin deformarlos.
  • Crear avatares cuadrados a partir de fotos rectangulares.
  • Construir galerías con miniaturas uniformes.
  • Controlar cómo se ve una imagen dentro de una tarjeta de tamaño fijo.

⚙️ ¿Cómo funciona?

El navegador dibuja el contenido del elemento dentro de su caja siguiendo el valor de object-fit:

  1. Se calcula la caja del elemento (width × height).
  1. Se calcula el tamaño intrínseco del contenido (imagen/video).
  1. Según object-fit, el contenido se escala, recorta o ajusta dentro de la caja.
  1. object-position controla la posición del contenido dentro de la caja (por defecto 50% 50% = centro).

⚠️ object-fit no cambia el tamaño de la caja, solo cómo se pinta el contenido dentro de ella.

📝 Sintaxis / Estructura

selector {
  object-fit: valor;
  object-position: valor; /* opcional, controla la posición */
}
object-position: center;         /* por defecto */
object-position: top;            /* arriba centrado */
object-position: bottom right;   /* abajo a la derecha */
object-position: 50% 20%;        /* 50% horizontal, 20% vertical */
object-position: 20px 40px;      /* desplazamiento en px */

💡 Ejemplos

/* 1. Imagen que cubre su caja sin deformarse */
.card img {
  width: 100%;
  height: 200px;
  object-fit: cover;
}

/* 2. Avatar cuadrado desde foto rectangular */
.avatar {
  width: 64px;
  height: 64px;
  border-radius: 50%;
  object-fit: cover;
}

/* 3. Imagen que cabe entera (con posible espacio) */
.logo {
  width: 200px;
  height: 100px;
  object-fit: contain;
}

/* 4. Video que llena su contenedor */
video {
  width: 100%;
  height: 400px;
  object-fit: cover;
}

/* 5. Control de posición del recorte */
.hero-img {
  width: 100%;
  height: 300px;
  object-fit: cover;
  object-position: top; /* prioriza la parte superior */
}

/* 6. Miniatura de galería */
.thumb {
  width: 150px;
  height: 150px;
  object-fit: cover;
  object-position: center;
}

/* 7. Imagen sin escalar */
.icon {
  width: 100px;
  height: 100px;
  object-fit: none;
}

/* 8. Imagen que se reduce solo si es necesario */
.responsive-img {
  width: 300px;
  height: 200px;
  object-fit: scale-down;
}

Comparativa visual de valores

/* Imagen original: 800×600 (ratio 4:3) */
/* Caja destino: 200×200 (ratio 1:1) */

.fill       { object-fit: fill; }       /* ⚠️ deformada */
.contain    { object-fit: contain; }    /* ✅ entera, con espacio arriba/abajo */
.cover      { object-fit: cover; }      /* ✅ llena, recorta lados */
.none       { object-fit: none; }       /* ⚠️ recortada, tamaño original */
.scale-down { object-fit: scale-down; } /* como contain, pero solo si es más pequeña */

Combinación con object-position

/* Foto de persona: queremos que se vea la cara (arriba) */
.portrait {
  width: 100%;
  height: 300px;
  object-fit: cover;
  object-position: top center;
}

/* Paisaje: queremos ver el horizonte (centro-abajo) */
.landscape {
  width: 100%;
  height: 300px;
  object-fit: cover;
  object-position: center 70%;
}

⚠️ Errores comunes

  1. Confundir object-fit con background-size → object-fit es para elementos reemplazados (img, video); background-size para imágenes de fondo.
  1. Usarlo en elementos no reemplazados → no funciona en <div>, <p>, etc. Para esos, usar background-size.
  1. Olvidar object-position → por defecto recorta desde el centro; a veces la parte importante de la imagen está arriba o abajo.
  1. No definir width y height → sin ambos, object-fit no tiene efecto (la caja se ajusta al contenido).
  1. Usar fill sin saberlo → es el valor por defecto y deforma las imágenes. Muchos bugs visuales vienen de aquí.
  1. Confundir cover con contain → cover llena la caja (recorta); contain muestra todo (deja espacio).
  1. Aplicar object-fit a <iframe> → funciona en teoría, pero pocos navegadores lo soportan correctamente.
  1. Olvidar el aspect-ratio → a veces es mejor usar aspect-ratio + object-fit: cover que fijar height.
  1. No considerar CLS → reservar el espacio con width/height o aspect-ratio evita saltos de layout.
  1. Usarlo en SVG → los SVG tienen su propio sistema de viewBox; object-fit funciona de forma limitada.

🧩 Relación con otros conceptos

  • object-position → controla la posición del contenido dentro de la caja.
  • background-size → equivalente para imágenes de fondo.
  • background-position → equivalente para fondos.
  • aspect-ratio → define la proporción de la caja; combinado con object-fit: cover es muy potente.
  • width / height → deben estar definidos para que object-fit tenga efecto.
  • overflow → object-fit no genera scroll; el contenido se recorta o escala.
  • Elementos reemplazados → img, video, canvas, iframe, embed, object.
  • <picture> y srcset → combinar con object-fit para imágenes responsive.
  • CLS → reservar espacio con aspect-ratio evita saltos de layout.

🧠 Analogía

Imagina que tienes una foto impresa y un marco de distinta proporción. object-fit decide cómo colocarla:

  • fill → estiras la foto para que llene el marco (se deforma).
  • contain → la encoges hasta que quepa entera (deja aire alrededor).
  • cover → la agrandas hasta cubrir todo el marco y recortas lo que sobra.
  • none → la dejas a su tamaño original, aunque no quepa.
  • scale-down → como contain, pero solo si hay que encogerla.

Y object-position decide dónde la colocas dentro del marco (centro, arriba, abajo…).

📝 Notas personales

  • Solo funciona en elementos reemplazados → <img>, <video>, <canvas>, <iframe>. No en <div>.
  • cover es el más usado → llena la caja sin deformar, recortando lo que sobra.
  • contain para logos e iconos → no queremos recortar, queremos ver todo.
  • fill (por defecto) deforma → por eso muchas imágenes se ven aplastadas si solo definimos width y height.
  • Combinar con object-position → esencial para elegir qué parte de la imagen se ve (caras, horizontes, etc.).
  • Con aspect-ratio → aspect-ratio: 16/9; object-fit: cover es el patrón moderno para imágenes responsive.
  • Accesibilidad → no usar object-fit: cover para ocultar información relevante de la imagen (texto, datos).
  • CLS → reservar el espacio con aspect-ratio o width/height explícitos evita saltos de layout.
  • SVG: object-fit funciona pero con matices; a veces es mejor usar preserveAspectRatio dentro del SVG.
  • <picture> + srcset → combinar con object-fit para imágenes responsive que se adaptan al contenedor.
