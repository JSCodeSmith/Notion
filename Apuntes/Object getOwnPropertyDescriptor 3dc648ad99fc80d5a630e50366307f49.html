Object.getOwnPropertyDescriptor

Object.getOwnPropertyDescriptor()

📄 Título

Object.getOwnPropertyDescriptor()

📝 Definición

Object.getOwnPropertyDescriptor()

Es un método estático de Object que obtiene el descriptor de una propiedad propia de un objeto.

🧠 ¿Qué es?

Es una herramienta que permite inspeccionar cómo está configurada una propiedad.

Por ejemplo:

const usuario= {
    nombre:"Josué"
};
const descriptor=Object.getOwnPropertyDescriptor(usuario,"nombre");
console.log(descriptor);

Devuelve un objeto similar a:

{
	value:"Josué",
	writable:true,
	enumerable:true,
	configurable:true
}

Es decir, permite descubrir las "reglas internas" de una propiedad.

🎯 ¿Para qué sirve?

Sirve para:

  • 🔍 Inspeccionar propiedades de un objeto.
  • ⚙️ Conocer si una propiedad es modificable.
  • 👀 Saber si una propiedad es enumerable.
  • 🗑️ Saber si puede configurarse o eliminarse.
  • 🧮 Inspeccionar getters y setters.
  • 🧩 Trabajar con Property Descriptors.
  • 🛠️ Crear herramientas, librerías y sistemas de metaprogramación.

⚙️ ¿Cómo funciona?

Recibe un objeto y el nombre de una propiedad:

Object.getOwnPropertyDescriptor(obj,prop)

El proceso es:

Objeto
  │
  └── propiedad
        ↓
Object.getOwnPropertyDescriptor()
        ↓
Property Descriptor
        │
        ├── value
        ├── writable
        ├── enumerable
        └── configurable

Por ejemplo:

const producto= {
    precio:100
};
const descriptor=Object.getOwnPropertyDescriptor(producto,"precio");
console.log(descriptor.value);// 100
console.log(descriptor.writable);// true

📝 Sintaxis / Estructura

Object.getOwnPropertyDescriptor(obj,prop)

Parámetros

obj

El objeto donde se buscará la propiedad.

prop

El nombre de la propiedad cuyo descriptor quieres obtener.

Puede ser una cadena o un Symbol.

Object.getOwnPropertyDescriptor(obj,"nombre");

Retorno

Devuelve un objeto descriptor si la propiedad existe directamente en el objeto.

{
	value: ...,
	writable: ...,
	enumerable: ...,
	configurable: ...
}

Si la propiedad no existe como propiedad propia, devuelve:

undefined

💡 Ejemplos

1. Inspeccionar una propiedad

const persona= {
    nombre:"Josué"
};
const descriptor=Object.getOwnPropertyDescriptor(persona,"nombre");
console.log(descriptor);

Resultado:

{
		value:"Josué",
		writable:true,
		enumerable:true,
		configurable:true
}

2. Comprobar writable

const persona= {
    nombre:"Josué"
};
const descriptor=Object.getOwnPropertyDescriptor(persona,"nombre");
console.log(descriptor.writable);// true

Significa que la propiedad puede modificarse.

3. Inspeccionar una propiedad creada con defineProperty()

const usuario= {};
Object.defineProperty(usuario,"id", {
    value:100,
    writable:false,
    enumerable:false,
    configurable:false
});
const descriptor=Object.getOwnPropertyDescriptor(usuario,"id");
console.log(descriptor);

Resultado:

{
	value:100,
	writable:false,
	enumerable:false,
	configurable:false
}

Aquí se ve claramente la relación:

Object.defineProperty()
        ↓
    CONFIGURA
        ↓
Property Descriptor
        ↑
    INSPECCIONA
        ↑
Object.getOwnPropertyDescriptor()

4. Inspeccionar un getter

const persona= {
    nombre:"Josué"
};
Object.defineProperty(persona,"nombreCompleto", {
    get() {
		    return persona.nombre;
    }
});
const descriptor=Object.getOwnPropertyDescriptor(persona,"nombreCompleto");
console.log(descriptor);

El descriptor será de tipo accessor descriptor:

{
	get: [Function:get],
	set:undefined,
	enumerable:false,
	configurable:false
}

En este caso no encontrarás value ni writable.

⚠️ Errores comunes

1. Confundirlo con Object.getOwnPropertyDescriptors()

Object.getOwnPropertyDescriptor(obj,"nombre");

→ obtiene el descriptor de una propiedad.

Object.getOwnPropertyDescriptors(obj);

→ obtiene los descriptores de todas las propiedades propias.

2. Confundir propiedad propia con propiedad heredada

const padre= {
    nombre:"Josué"
};
const hijo=Object.create(padre);
console.log(Object.getOwnPropertyDescriptor(hijo,"nombre"));

Resultado:

undefined

¿Por qué?

Porque nombre pertenece a padre, no directamente a hijo.

hijo
 │
 └── [[Prototype]]
       ↓
     padre
       └── nombre

getOwnPropertyDescriptor() solamente inspecciona propiedades propias.

3. Pensar que modifica la propiedad

Este método:

Object.getOwnPropertyDescriptor(obj,"nombre");

no modifica la propiedad.

Solo la inspecciona.

Para modificar/configurar propiedades se utilizan métodos como:

Object.defineProperty();
Object.defineProperties();

🧩 Relación con otros conceptos

Este método forma parte del grupo de herramientas de Property Descriptors:

Property Descriptors
        │
        ├── Object.defineProperty()
        │       └── define/modifica 1 propiedad
        │
        ├── Object.defineProperties()
        │       └── define/modifica varias
        │
        ├── Object.getOwnPropertyDescriptor()
        │       └── obtiene 1 descriptor
        │
        └── Object.getOwnPropertyDescriptors()
                └── obtiene todos los descriptores

Y los descriptores pueden contener:

Data Descriptor
├── value
└── writable

Common
├── enumerable
└── configurable

Accessor Descriptor
├── get
└── set

🧠 Analogía

Imagina que una propiedad es una puerta 🚪.

Object.defineProperty() sería quien instala la puerta y decide sus reglas:

"Esta puerta puede abrirse, puede verse y no puede eliminarse."

Object.getOwnPropertyDescriptor() sería el inspector 🔎 que llega después y pregunta:

"¿Cómo está configurada esta puerta?"

Y devuelve:

¿Puede modificarse?     → writable
¿Puede verse/listarse?  → enumerable
¿Puede reconfigurarse?  → configurable
¿Qué valor tiene?       → value
¿Tiene getter/setter?   → get / set
