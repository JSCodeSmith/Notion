<header>

📄 <header>

📝 Definición

<header> es un elemento semántico de HTML5 que representa un grupo de contenido introductorio o de navegación al inicio de una página o sección.

Suele contener el título, logotipo, menú de navegación, buscador u otra información introductoria.

🧠 ¿Qué es?

Es un elemento de bloque y semántico.

No confundir con <head> (metadatos del documento). 

<header> es visible y se usa dentro del <body>, mientras que <head> es invisible y va antes del <body>.

🎯 ¿Para qué sirve?

  • Encabezado de página: título, logo, navegación principal.
  • Encabezado de artículo: título, autor, fecha.
  • Encabezado de sección: título y descripción de una sección.
  • Aportar semántica: indica al navegador y a lectores de pantalla que es contenido introductorio.
  • Mejorar SEO: agrupa el <h1> y la navegación principal.
  • Facilitar el diseño con CSS (grid, flexbox).

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como bloque (sin estilos visuales por defecto).
  1. Puede contener: <h1>–<h6>, <p>, <nav>, <img>, <form>, <a>, etc.
  1. Puede haber varios <header> en una página: uno por página y uno por <article> o <section>.
  1. No puede anidarse dentro de otro <header> ni dentro de <footer> o <address>.
  1. Los lectores de pantalla lo anuncian como "banner" si es el header principal.

📝 Sintaxis / Estructura

<header>
  <h1>Mi sitio</h1>
  <nav>...</nav>
</header>

💡 Ejemplos

Header de página:

<header>
  <h1>Mi Blog</h1>
  <nav>
    <ul>
      <li><a href="/">Inicio</a></li>
      <li><a href="/blog">Blog</a></li>
      <li><a href="/contacto">Contacto</a></li>
    </ul>
  </nav>
</header>

Header con logo y buscador:

<header>
  <img src="logo.svg" alt="Mi sitio">
  <h1>Mi Tienda</h1>
  <form role="search">
    <input type="search" placeholder="Buscar productos...">
    <button type="submit">Buscar</button>
  </form>
</header>

Header de artículo:

<article>
  <header>
    <h2>Cómo aprender HTML en 30 días</h2>
    <p>Por <strong>Ana Pérez</strong> · <time datetime="2026-10-02">2 de octubre de 2026</time></p>
  </header>
  <p>Contenido del artículo...</p>
</article>

Header de sección:

<section>
  <header>
    <h2>Productos destacados</h2>
    <p>Los más vendidos de la semana.</p>
  </header>
  <ul>...</ul>
</section>

Con estilos CSS:

<header class="principal">
  <h1>Mi sitio</h1>
  <nav>...</nav>
</header>
header.principal {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
  background: #222;
  color: #fff;
}

⚠️ Errores comunes

  • ❌ Confundir <header> (visible) con <head> (metadatos).
  • ❌ Anidar <header> dentro de otro <header>.
  • ❌ Anidar <header> dentro de <footer> o <address>.
  • ❌ Usarlo como contenedor genérico (para eso <div>).
  • ❌ Poner más de un <header> como encabezado principal de página (solo uno debe ser "banner").
  • ❌ Usarlo dentro de <main> como único encabezado de página.
  • ❌ Olvidar la jerarquía de encabezados (<h1>, <h2>) dentro.
  • ❌ Usar <header> sin ningún encabezado (<h1>–<h6>) ni contenido introductorio.

💼 Casos de uso

  • Encabezado principal de una página web.
  • Encabezado de artículo de blog (título, autor, fecha).
  • Encabezado de sección con título y descripción.
  • Barra de navegación principal.
  • Cabecera de tarjetas de producto.
  • Encabezado de comentarios (autor, fecha).
  • Encabezado de páginas de documentación.
  • Landing pages: hero con título y CTA.

🧩 Relación con otros conceptos

  • <head>: metadatos del documento (no confundir).
  • <nav>: navegación (suele ir dentro del <header>).
  • <h1>–<h6>: encabezados (suelen ir dentro del <header>).
  • <footer>: pie de página o sección (opuesto al <header>).
  • <article> / <section>: pueden tener su propio <header>.
  • <main>: no debe ir dentro del <header>.
  • role="banner": rol ARIA implícito del header principal.
  • CSS: display: flex, grid, position: sticky.
  • Accesibilidad: los lectores de pantalla lo anuncian como "banner".

🧠 Analogía

Un <header> es como la portada o cabecera de un libro: el título, el autor, el índice. Aparece al inicio y da contexto a todo lo que sigue. Y así como un libro puede tener portadas por capítulo, una página puede tener varios <header> (uno por sección o artículo).

📝 Notas personales

  • No confundir con <head>: <header> es visible; <head> es metadatos.
  • Puede haber varios <header> en una página (uno por <article> o <section>).
  • Solo uno debe ser el header principal de la página (rol banner).
  • No puede anidarse dentro de otro <header>, <footer> o <address>.
  • Los lectores de pantalla lo anuncian como "banner" si es el principal.
  • Suele contener <h1>, <nav>, logo, buscador.
  • Para header sticky, usa CSS: position: sticky; top: 0;.
  • En CSS, <header> no tiene estilos por defecto (solo display: block).
  • En frameworks (React, Vue), <header> es un componente más.
  • Buena práctica: si el contenido es introductorio o de navegación, usa <header>; si es solo un contenedor, usa <div>.
