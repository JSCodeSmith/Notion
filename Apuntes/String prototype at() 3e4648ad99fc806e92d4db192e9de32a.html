String.prototype.at()

String.prototype.at()

📄 Título

String.prototype.at()

📝 Definición

Método de String que devuelve el carácter ubicado en un índice determinado de una cadena.

Permite utilizar índices negativos para acceder a caracteres empezando desde el final.

🧠 ¿Qué es?

at() sirve para acceder directamente a un carácter de un String mediante su posición.

const texto="JavaScript";
texto.at(0);// "J"

La característica más importante es que acepta índices negativos:

const texto="JavaScript";
texto.at(-1);// "t"

Es decir:

at(0)   → primer carácter
at(1)   → segundo carácter
at(-1)  → último carácter
at(-2)  → penúltimo carácter

🎯 ¿Para qué sirve?

Sirve para:

  • Obtener un carácter específico de una cadena.
  • Acceder fácilmente al último carácter.
  • Utilizar índices negativos.
  • Evitar cálculos manuales como string[string.length - 1].
  • Acceder a elementos de un String de forma similar a Array.prototype.at().

⚙️ ¿Cómo funciona?

Recibe un índice y devuelve el carácter correspondiente.

const texto="Hola";
console.log(texto.at(0));// "H"
console.log(texto.at(3));// "a"

Con índices negativos:

console.log(texto.at(-1));// "a"
console.log(texto.at(-2));// "l"

Visualmente:

 H   o   l   a
 0   1   2   3
-4  -3  -2  -1

Por eso:

"Hola".at(-1);// "a"

📝 Sintaxis / Estructura

cadena.at(indice)

Parámetros

indice

Es el índice del carácter que quieres obtener.

Puede ser:

  • Positivo → desde el inicio.
  • Negativo → desde el final.
"JavaScript".at(0);// "J"
"JavaScript".at(-1);// "t"

Retorno

Devuelve:

string

con el carácter encontrado.

Si el índice está fuera de los límites:

"Hola".at(10);// undefined

💡 Ejemplos

1. Obtener el primer carácter

"JavaScript".at(0);// "J"

2. Obtener un carácter específico

"JavaScript".at(4);// "S"

3. Obtener el último carácter

"JavaScript".at(-1);// "t"

4. Obtener el penúltimo

"JavaScript".at(-2);// "p"

5. Índice fuera de rango

"Hola".at(10);// undefined

🔥 at() vs charAt()

Ambos pueden obtener caracteres:

"Hola".at(1);// "o"
"Hola".charAt(1);// "o"

Pero at() tiene una ventaja importante:

"Hola".at(-1);// "a"

Mientras que:

"Hola".charAt(-1);// ""

Por eso:

at()
→ acepta índices negativos

charAt()
→ no acepta índices negativos

🔥 at() vs acceso mediante []

También puedes hacer:

"Hola"[1];// "o"

Y:

"Hola"[-1];// undefined

En cambio:

"Hola".at(-1);// "a"

Así que at() resulta especialmente cómodo para acceder desde el final.

⚠️ Errores comunes

1. Pensar que at() devuelve el código Unicode

No.

"A".at(0);// "A"

Si quieres el code point:

"A".codePointAt(0);// 65

2. Confundir índice negativo con posición inexistente

"Hola".at(-1);// "a"
  • -1 significa último carácter, no un índice inválido.

3. Confundirlo con charAt()

"Hola".at(-1);// "a"
"Hola".charAt(-1);// ""

La diferencia de los índices negativos es una de las razones principales para utilizar at().

4. Pensar que modifica el String

const texto="Hola";
texto.at(0);
console.log(texto);// "Hola"

at() solamente consulta la cadena.

💼 Casos de uso

  • Obtener el primer o último carácter.
  • Validar la primera letra de una palabra.
  • Comprobar extensiones de archivos.
  • Analizar cadenas.
  • Recorrer Strings mediante índices.
  • Obtener caracteres desde el final de forma sencilla.

Ejemplo:

const archivo="foto.jpg";
console.log(archivo.at(-1));// "g"
console.log(archivo.at(-2));// "p"

Y at() comparte el concepto de índices negativos con:

Array.prototype.at()

Por ejemplo:

"Hola".at(-1);// "a"

["H","o","l","a"].at(-1);// "a"

🧠 Analogía

Imagina que una palabra es una fila de casilleros:

 H   o   l   a
 0   1   2   3

at(2) pregunta:

"Dame lo que hay en el casillero 2."
"Hola".at(2);// "l"

Y at(-1) dice:

"Dame el último casillero."
"Hola".at(-1);// "a"
