<source>

📄 <source>

📝 Definición

<source> es el elemento que especifica recursos multimedia alternativos para <picture>, <audio> y <video>.

Permite ofrecer múltiples formatos, tamaños o tipos de un mismo recurso para que el navegador elija el más adecuado.

🧠 ¿Qué es?

Es un elemento vacío (no tiene etiqueta de cierre).

Se usa como hijo de <picture>, <audio> o <video>.

El navegador evalúa los <source> en orden y usa el primero compatible (o el que cumpla las condiciones de media/type).

🎯 ¿Para qué sirve?

  • Ofrecer múltiples formatos de audio/video (MP4, WebM, OGG).
  • Servir imágenes responsive con <picture> (distintos tamaños/formatos).
  • Cargar recursos según condiciones (media, type).
  • Mejorar compatibilidad entre navegadores.
  • Optimizar rendimiento sirviendo el formato más eficiente.
  • Adaptar contenido a resoluciones o art directions.

⚙️ ¿Cómo funciona?

  1. El navegador recorre los <source> en orden.
  1. Para cada uno, evalúa:
    • type: ¿soporta el formato?
    • media: ¿cumple la consulta de medios?
    • srcset / sizes (en <picture>): elige la mejor imagen.
  1. Usa el primer <source> válido y detiene la evaluación.
  1. Si ninguno es válido, usa el fallback (<img> en <picture>, texto en <audio>/<video>).
  1. El <source> no se renderiza: solo aporta información.

📝 Sintaxis / Estructura

<source src="recurso.mp4" type="video/mp4">

💡 Ejemplos

Múltiples formatos de video:

<video controls width="640" height="360">
  <source src="video.webm" type="video/webm">
  <source src="video.mp4" type="video/mp4">
  <source src="video.ogv" type="video/ogg">
  Tu navegador no soporta video HTML5.
</video>

Múltiples formatos de audio:

<audio controls>
  <source src="audio.ogg" type="audio/ogg">
  <source src="audio.mp3" type="audio/mpeg">
  Tu navegador no soporta audio HTML5.
</audio>

Imágenes responsive con <picture> (art direction):

<picture>
  <source media="(min-width: 800px)" srcset="grande.jpg">
  <source media="(min-width: 400px)" srcset="mediana.jpg">
  <img src="pequena.jpg" alt="Paisaje montañoso">
</picture>

Formatos modernos con fallback:

<picture>
  <source srcset="imagen.avif" type="image/avif">
  <source srcset="imagen.webp" type="image/webp">
  <img src="imagen.jpg" alt="Descripción de la imagen">
</picture>

Con srcset y sizes (resolución):

<picture>
  <source
    srcset="foto-400.jpg 400w, foto-800.jpg 800w, foto-1600.jpg 1600w"
    sizes="(max-width: 600px) 400px, 800px"
    type="image/jpeg">
  <img src="foto-800.jpg" alt="Playa al atardecer">
</picture>

Con media para responsive:

<picture>
  <source media="(orientation: landscape)" srcset="horizontal.jpg">
  <source media="(orientation: portrait)" srcset="vertical.jpg">
  <img src="default.jpg" alt="Imagen adaptable">
</picture>

⚠️ Errores comunes

  • ❌ Usarlo fuera de <picture>, <audio> o <video> (inválido).
  • ❌ Ponerlo después del fallback (el <img> en <picture> debe ir al final).
  • ❌ Olvidar el type → el navegador descarga el archivo para comprobar.
  • ❌ Poner type incorrecto → el navegador puede saltarse un formato válido.
  • ❌ Usar src y srcset a la vez en <picture> (son contextos distintos).
  • ❌ Olvidar el fallback (<img> en <picture>, texto en audio/video).
  • ❌ No ordenar los formatos de más moderno a menos (AVIF → WebP → JPG).
  • ❌ Usar <source> como elemento independiente.
  • ❌ Anidar <source> dentro de otro <source>.

💼 Casos de uso

  • Video/audio multiplataforma (WebM + MP4 + OGG).
  • Imágenes en formatos modernos (AVIF, WebP) con fallback JPG/PNG.
  • Art direction: distintas imágenes según orientación o tamaño.
  • Imágenes responsive con srcset y sizes.
  • Optimización de ancho de banda: servir la imagen adecuada.
  • Contenido adaptado a condiciones de red o resolución.
  • Compatibilidad con navegadores antiguos.

🧩 Relación con otros conceptos

  • <picture>: contenedor de <source> para imágenes.
  • <audio>: contenedor de <source> para audio.
  • <video>: contenedor de <source> para video.
  • <img>: fallback obligatorio en <picture>.
  • <track>: subtítulos para <audio> y <video>.
  • srcset / sizes: imágenes responsive.
  • type: tipo MIME (ayuda al navegador a decidir).
  • media: consulta de medios (solo en <picture>).
  • Formatos de imagen: AVIF, WebP, JPEG, PNG.
  • Formatos de video: MP4 (H.264), WebM (VP9/AV1), OGG (Theora).
  • Formatos de audio: MP3, OGG, WAV, AAC, FLAC, Opus.
  • Accesibilidad: alt en el <img> de fallback.

🧠 Analogía

Un <source> es como un menú de opciones en un restaurante: el cliente (navegador) elige la primera opción que puede consumir (compatible). Si no hay ninguna, pide el plato del día (fallback). Tú ofreces varias opciones para que todos puedan comer.

📝 Notas personales

  • Solo válido dentro de <picture>, <audio> o <video>.
  • El navegador evalúa en orden y usa el primero válido.
  • Siempre incluye type para que el navegador no descargue archivos innecesarios.
  • Ordena los formatos de más moderno a menos (AVIF → WebP → JPG).
  • En <picture>, el <img> es obligatorio como fallback y va al final.
  • El atributo media solo funciona en <source> dentro de <picture>.
  • No puede usarse como elemento independiente.
  • En XHTML, se cierra como <source ... />; en HTML5 no necesita cierre.
  • Buena práctica: ofrece varios formatos para maximizar compatibilidad y rendimiento.
  • Para imágenes simples, considera <img srcset> directamente en lugar de <picture> + <source>.
