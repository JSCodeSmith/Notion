<u>

📄 <u>

📝 Definición

<u> (del inglés underline, "subrayado") es el elemento que aplica subrayado al texto en HTML.

A diferencia de versiones anteriores, en HTML5 no implica un enlace ni énfasis: se usa para marcar texto que requiere una anotación no textual (como errores ortográficos, nombres propios en chino, etc.).

🧠 ¿Qué es?

Es un elemento inline (en línea) de estilo visual.

En HTML5 se redefine para representar texto que debe distinguirse visualmente por razones específicas, sin connotación semántica de importancia.

🎯 ¿Para qué sirve?

  • Marcar errores ortográficos (como en procesadores de texto).
  • Anotar nombres propios en textos chinos o japoneses.
  • Indicar texto insertado en contextos donde no aplica <ins>.
  • Destacar visualmente sin implicar énfasis ni importancia.
  • Representar etiquetas de interfaz o valores introducidos por el usuario (aunque <output> es más apropiado).

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza con subrayado por defecto (text-decoration: underline).
  1. No cambia la entonación en lectores de pantalla (a diferencia de <em> o <strong>).
  1. No aporta peso semántico para SEO.
  1. Es un elemento inline: no genera saltos de línea.
  1. Cuidado: el subrayado se confunde fácilmente con enlaces.

📝 Sintaxis / Estructura

<u>Texto subrayado</u>

💡 Ejemplos

Error ortográfico (como en un editor):

<p>El <u>pero</u> ladra muy fuerte.</p>

Nombre propio en texto chino (ejemplo conceptual):

<p>Su nombre es <u>王小明</u>.</p>

Texto insertado en un contexto informal:

<p>El precio es <u>19,99 €</u>.</p>

Con estilos CSS personalizados:

<p>Texto <u class="error">incorrecto</u>.</p>
u.error {
  text-decoration: underline wavy red;
  text-decoration-skip-ink: none;
}

Anotación con subrayado ondulado (emulando corrector):

u.spellcheck {
  text-decoration: underline wavy #e53935;
  text-decoration-thickness: 1px;
}

⚠️ Errores comunes

  • ❌ Usarlo como enlace falso: <u>Ir a inicio</u> (los usuarios esperan un <a>).
  • ❌ Usarlo solo para subrayar cuando CSS es suficiente.
  • ❌ Usarlo para énfasis (ahí van <em> o <strong>).
  • ❌ Anidar <u> dentro de otro <u> (redundante).
  • ❌ Usarlo en párrafos completos: es ilegible.
  • ❌ Confundir <u> con <ins> (que sí implica texto insertado).
  • ❌ Usarlo en títulos (<h1>–<h6>): ya son importantes.
  • ❌ Olvidar que el subrayado se confunde con enlaces (accesibilidad).
  • ❌ No considerar el color de contraste en el subrayado.

💼 Casos de uso

  • Marcar errores ortográficos (editores, correctores).
  • Nombres propios en textos chinos o japoneses.
  • Anotaciones específicas en documentación técnica.
  • Emular correctores ortográficos con CSS (wavy underline).
  • Representar texto insertado cuando <ins> no aplica.
  • Etiquetas de interfaz (aunque <label> es mejor).
  • Valores introducidos por el usuario (aunque <output> es mejor).
  • Marcas tipográficas específicas en ciertos idiomas.

🧩 Relación con otros conceptos

  • <a>: subrayado con semántica de enlace (el subrayado es un indicador visual).
  • <ins>: texto insertado en una edición (fecha, contexto).
  • <em> / <strong>: énfasis e importancia.
  • <s> / <del>: texto tachado (obsoleto o eliminado).
  • <mark>: texto resaltado con fondo amarillo.
  • CSS: text-decoration: underline es la alternativa sin etiqueta.
  • text-decoration-style: solid, double, dotted, dashed, wavy.
  • text-decoration-color: color del subrayado.
  • Accesibilidad: el subrayado se confunde con enlaces → úsalo con criterio.
  • SEO: sin impacto.

🧠 Analogía

<u> es como subrayar con lápiz un texto en un libro: se ve distinto, pero no comunica ni énfasis ni importancia, y en la web puede confundirse con un enlace. Como si subrayaras algo y el lector pensara "¿esto es clickeable?".

📝 Notas personales

  • En HTML5, <u> no implica enlace ni énfasis: es solo una anotación no textual.
  • Cuidado: el subrayado se confunde con enlaces → problema de accesibilidad.
  • Si quieres subrayar solo por estilo, usa CSS: text-decoration: underline.
  • Para errores ortográficos, combina <u> con text-decoration: underline wavy red.
  • Para texto insertado con contexto, usa <ins>.
  • Para texto eliminado, usa <del> o <s>.
  • No lo uses en párrafos completos: es ilegible.
  • En frameworks (React, Vue), <u> es un componente más.
  • Buena práctica: en HTML moderno, <u> se usa poco; la mayoría de las veces CSS es suficiente.
  • Si lo usas, asegúrate de que no se confunda con un enlace.
