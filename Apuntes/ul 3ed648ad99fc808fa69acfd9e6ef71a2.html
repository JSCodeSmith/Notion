<ul>

📄 <ul>

📝 Definición

<ul> (del inglés unordered list, "lista desordenada") es el elemento que crea una lista sin orden jerárquico en HTML.

Sus ítems se muestran con viñetas (bullets) por defecto, y el orden de los elementos no es relevante.

🧠 ¿Qué es?

Es un elemento de bloque que contiene ítems de lista (<li>) como hijos directos.

Se usa cuando el orden de los elementos no importa: ingredientes, características, opciones, enlaces de navegación, etc.

🎯 ¿Para qué sirve?

  • Agrupar elementos sin orden específico.
  • Mostrar características de un producto.
  • Listar ingredientes, materiales, requisitos.
  • Crear menús de navegación (muy común con CSS).
  • Aportar semántica: indica que es una lista, no solo texto con viñetas.
  • Facilitar accesibilidad: los lectores de pantalla anuncian "lista de N elementos".

⚙️ ¿Cómo funciona?

  1. El navegador lo renderiza como bloque con padding-left y viñetas.
  1. Cada <li> dentro se muestra como ítem con  (disco) por defecto.
  1. Los lectores de pantalla anuncian "lista" y el número de ítems.
  1. Solo admite <li> como hijos directos en HTML válido (aunque también <script> y <template>).
  1. Los estilos de viñeta se controlan con CSS (list-style-type).

📝 Sintaxis / Estructura

<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
  <li>Elemento 3</li>
</ul>

💡 Ejemplos

Lista simple:

<ul>
  <li>Manzana</li>
  <li>Plátano</li>
  <li>Naranja</li>
</ul>

Lista anidada:

<ul>
  <li>Frutas
    <ul>
      <li>Manzana</li>
      <li>Plátano</li>
    </ul>
  </li>
  <li>Verduras
    <ul>
      <li>Zanahoria</li>
      <li>Brócoli</li>
    </ul>
  </li>
</ul>

Menú de navegación:

<nav>
  <ul class="menu">
    <li><a href="/">Inicio</a></li>
    <li><a href="/blog">Blog</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>
.menu {
  list-style: none;
  display: flex;
  gap: 1rem;
  padding: 0;
}

Con estilos personalizados:

ul.lista-check {
  list-style: none;
  padding-left: 0;
}
ul.lista-check li::before {
  content: "✓ ";
  color: green;
}

⚠️ Errores comunes

  • ❌ Poner contenido que no sea <li> directamente dentro (texto suelto, <div>).
  • ❌ Usar <ul> para texto que no es una lista (solo por las viñetas).
  • ❌ Usar type="disc" (obsoleto, usar CSS list-style-type).
  • ❌ Anidar <ul> fuera de un <li> (debe ir dentro).
  • ❌ Usar <ul> para listas numeradas (ahí va <ol>).
  • ❌ Omitir <li> y separar ítems con <br>.
  • ❌ Usar list-style: none sin considerar accesibilidad (los lectores de pantalla en Safari eliminan la semántica de lista).
  • ❌ Poner un <ul> vacío.
  • ❌ Usar <ul> para formularios o layouts completos.

💼 Casos de uso

  • Menús de navegación (con CSS para quitar viñetas).
  • Listas de características de productos.
  • Ingredientes de recetas.
  • Requisitos de instalación.
  • Redes sociales o enlaces en footer.
  • Breadcrumbs (migas de pan).
  • Pasos cuando el orden no importa.
  • Etiquetas / tags.
  • Listas de archivos o recursos.

🧩 Relación con otros conceptos

  • <ol>: lista ordenada (numerada).
  • <li>: ítem de lista (hijo obligatorio).
  • <dl> / <dt> / <dd>: lista de definiciones.
  • <nav>: contenedor típico de menús con <ul>.
  • CSS: list-style-type, list-style-image, list-style-position.
  • Accesibilidad: role="list" cuando se quita el estilo en Safari.
  • display: flex / grid: muy usado en menús con <ul>.
  • ::marker: pseudoelemento para estilizar viñetas.

🧠 Analogía

Un <ul> es como una lista de compras en un papel: los ítems están uno debajo de otro con un punto al lado, y el orden no importa. Si el orden importara (como una receta), usarías <ol>.

📝 Notas personales

  • Solo <li> como hijo directo (en HTML válido).
  • Para listas numeradas, usa <ol>; para definiciones, <dl>.
  • Para menús, quita las viñetas con list-style: none y usa flex/grid.
  • En Safari, list-style: none elimina la semántica de lista; añade role="list" para restaurarla.
  • Las listas anidadas van dentro de un <li>, no directamente dentro del <ul>.
  • type está obsoleto en HTML5: usa CSS list-style-type.
  • El padding por defecto es padding-inline-start: 40px (aprox.).
  • Puedes personalizar viñetas con ::marker o ::before.
  • No abuses: no conviertas todo en <ul> solo por las viñetas.
  • Para navegación accesible, envuelve el <ul> en <nav> con aria-label.
